JavaScript: Percorrendo Objetos (for … in, Object.entries)

Com um array, percorrer é fácil: o for … of entrega um item por volta. Mas e com um objeto? Às vezes você não sabe de antemão quais propriedades ele tem: o carrinho pode ter 2 ou 20 produtos, o placar pode ter qualquer comida votada. Para "ler a ficha linha por linha", o JavaScript oferece o laço for … in e três funções que transformam o objeto em array: Object.keys (as chaves), Object.values (os valores) e Object.entries (os pares).

Você vai aprender
  • O laço for … in, que passa por cada chave do objeto.
  • Object.keys, Object.values e Object.entries: o objeto virando array.
  • O jeito moderno: for (const [chave, valor] of Object.entries(obj)).
  • Como usar os métodos de array (reduce, filter, map) num objeto, e voltar para objeto com Object.fromEntries.
  • Em que ordem as chaves aparecem, e por que as que parecem números vêm primeiro.
  • Como agrupar uma lista num objeto com Object.groupBy ES2024.
  • Os erros reais: for … of direto no objeto, for … in num array, Object.keys de undefined.

Todos os programas desta aula rodaram no Node.js 24 da máquina da Ana (usuária ana, computador notebook), salvos na pasta pessoal dela e executados com node arquivo.js. Você pode rodar cada um no editor do guia.

A ideia: ler a ficha de cima a baixo

A Ana recebeu a ficha de um produto e quer copiar tudo para o caderno. Ela não precisa saber quais campos a ficha tem: passa o dedo de linha em linha e, em cada uma, lê o nome do campo e o valor. Percorrer um objeto é isso: uma volta por propriedade, com a chave em mãos para ler o valor.

1. O laço for … in

const produto = { nome: "caderno", preco: 18, estoque: 40 };
for (const chave in produto) {
  console.log(`${chave}: ${produto[chave]}`);
}

$ node forin.js
nome: caderno
preco: 18
estoque: 40
for (const chave in produto)
"Para cada chave em produto" (in = "em"). O corpo roda uma vez por propriedade, e a cada volta chave vale o nome de uma delas, como texto: "nome", depois "preco", depois "estoque".
const chave
Uma variável nova a cada volta; pode ser const, como no for … of. O nome é você quem escolhe (campo, chave, item).
produto[chave]
O valor da propriedade. Tem de ser com colchetes, porque o nome da chave está numa variável (aula Propriedades).

Missão: o programa mostra só o nome do produto. Troque o console.log por um for … in que mostre todas as propriedades, uma por linha, no formato preco: 18. Depois, acrescente cor: "azul" ao objeto e rode de novo: o laço pega a nova propriedade sem você mudar nada nele.

const produto = { nome: "caderno", preco: 18, estoque: 40 };
console.log(`nome: ${produto.nome}`);

const produto = { nome: "caderno", preco: 18, estoque: 40 };
for (const chave in produto) {
  console.log(`${chave}: ${produto[chave]}`);
}

2. O objeto virando array: keys, values, entries

const produto = { nome: "caderno", preco: 18, estoque: 40 };
console.log(Object.keys(produto));
console.log(Object.values(produto));
console.log(Object.entries(produto));
console.log("Propriedades:", Object.keys(produto).length);

$ node keys.js
[ 'nome', 'preco', 'estoque' ]
[ 'caderno', 18, 40 ]
[ [ 'nome', 'caderno' ], [ 'preco', 18 ], [ 'estoque', 40 ] ]
Propriedades: 3
Object.keys(produto)
Um array com as chaves (keys = "chaves"), como textos.
Object.values(produto)
Um array com os valores (values), na mesma ordem.
Object.entries(produto)
Um array de pares (entries = "entradas"): cada item é um pequeno array [chave, valor]. É uma matriz de duas colunas.
Object.keys(produto).length
Quantas propriedades o objeto tem. Objetos não têm .length; o jeito é contar as chaves.

Essas três são funções do Object (com O maiúsculo): você passa o objeto entre parênteses, e não escreve produto.keys(). Como o resultado é um array, todos os métodos de array passam a valer.

3. O jeito moderno: for … of com Object.entries

const produto = { nome: "caderno", preco: 18, estoque: 40 };
for (const [chave, valor] of Object.entries(produto)) {
  console.log(`${chave} → ${valor}`);
}
for (const par of Object.entries(produto)) {
  console.log(par[0], "=", par[1]);
}

$ node entries.js
nome → caderno
preco → 18
estoque → 40
nome = caderno
preco = 18
estoque = 40
Object.entries(produto)
O array de pares [ [ 'nome', 'caderno' ], … ].
for (const … of …)
O for … of de sempre: uma volta por item do array, ou seja, um par por volta.
const [chave, valor]
Em vez de um nome só para o par, dois nomes entre colchetes: o JavaScript põe o item 0 do par em chave e o item 1 em valor. Isso se chama desestruturação (aula Desestruturação). O segundo laço faz o mesmo "à mão", com par[0] e par[1].

Com esse laço você recebe a chave e o valor prontos, sem produto[chave]. É o jeito mais usado hoje.

4. Métodos de array num objeto

O carrinho da Ana é um objeto "produto → preço". Para somar, basta pegar os valores e usar o reduce; para escolher, as chaves e o filter:

const carrinho = { pao: 8, leite: 6, cafe: 15, queijo: 22 };
const total = Object.values(carrinho).reduce((soma, preco) => soma + preco, 0);
console.log(`Total: R$ ${total}`);
const caros = Object.keys(carrinho).filter((item) => carrinho[item] > 10);
console.log("Mais de R$ 10:", caros);

$ node values.js
Total: R$ 51
Mais de R$ 10: [ 'cafe', 'queijo' ]

E de volta para objeto: Object.fromEntries

A padaria deu 10% de desconto em tudo. A Ana quer um objeto novo com os preços com desconto. O caminho: objeto → pares (entries) → muda cada par (map) → objeto de novo (fromEntries, "a partir das entradas"):

const precos = { pao: 8, leite: 6, cafe: 15 };
const comDesconto = Object.fromEntries(
  Object.entries(precos).map(([item, preco]) => [item, preco * 0.9]),
);
console.log(comDesconto);
console.log(precos);

$ node fromentries.js
{ pao: 7.2, leite: 5.4, cafe: 13.5 }
{ pao: 8, leite: 6, cafe: 15 }
Object.entries(precos)
[ [ 'pao', 8 ], [ 'leite', 6 ], [ 'cafe', 15 ] ].
.map(([item, preco]) => [item, preco * 0.9])
Para cada par, devolve um par novo: a mesma chave, o preço vezes 0,9. A desestruturação também funciona nos parâmetros da função.
Object.fromEntries(…)
O contrário do entries: transforma o array de pares num objeto.

O objeto precos original continuou intacto: o resultado é um objeto novo.

5. Em que ordem as chaves aparecem?

A agenda da Ana mistura horários (números) e períodos (textos):

const agenda = {
  manha: "padaria",
  15: "dentista",
  tarde: "mercado",
  9: "academia",
  "10": "reunião",
};
console.log(Object.keys(agenda));
for (const chave in agenda) {
  console.log(chave, typeof chave);
}

$ node ordem.js
[ '9', '10', '15', 'manha', 'tarde' ]
9 string
10 string
15 string
manha string
tarde string

Duas regras do JavaScript aparecem aqui:

  • Toda chave é texto. O 15 e o 9 foram escritos como números, mas viraram '15' e '9': o typeof diz string para todas.
  • A ordem: primeiro as chaves que parecem números inteiros ('9', '10', '15'), em ordem crescente; depois as outras, na ordem em que foram criadas (manha antes de tarde). A mesma ordem vale para for … in, keys, values e entries.

Na prática: não dependa da ordem das chaves de um objeto. Se a ordem importa, use um array (e ordene) ou um Map, que guarda tudo na ordem em que entrou.

6. O contrário: agrupar uma lista num objeto ES2024

Às vezes você tem uma lista e quer um objeto: os alunos separados por situação. O Object.groupBy ("agrupar por") recebe a lista e uma função que diz o grupo de cada item:

const turma = [
  { nome: "Ana", nota: 7 },
  { nome: "Bia", nota: 4 },
  { nome: "Caio", nota: 9 },
  { nome: "Davi", nota: 5 },
];
const grupos = Object.groupBy(turma, (aluno) => (aluno.nota >= 7 ? "aprovados" : "recuperacao"));
console.log(grupos);
for (const [situacao, alunos] of Object.entries(grupos)) {
  console.log(`${situacao}: ${alunos.map((a) => a.nome).join(", ")}`);
}

$ node groupby.js
[Object: null prototype] {
  aprovados: [ { nome: 'Ana', nota: 7 }, { nome: 'Caio', nota: 9 } ],
  recuperacao: [ { nome: 'Bia', nota: 4 }, { nome: 'Davi', nota: 5 } ]
}
aprovados: Ana, Caio
recuperacao: Bia, Davi
  • O resultado é um objeto com uma chave por grupo; o valor de cada chave é um array com os itens daquele grupo.
  • O [Object: null prototype] é só o Node avisando que este objeto foi criado "limpo", sem as propriedades herdadas que os objetos comuns têm (aula Protótipos). Para percorrer e ler, ele funciona como qualquer objeto.
  • O Object.groupBy entrou no JavaScript em 2024 (ECMAScript 2024). Antes dele, o mesmo se fazia com um reduce montando um placar (aula reduce).

for … in ou Object.keys?

Para os objetos que você cria com { }, dão o mesmo resultado. A diferença: o for … in também passa por propriedades herdadas (aula Protótipos), e o Object.keys/entries só pelas próprias. Por isso muitos guias de estilo preferem Object.entries com for … of.

Como consertar: percorra um dos arrays do objeto: for (const valor of Object.values(produto)), ou use for … in para as chaves.

for … in num array 
const notas = [7, 8, 9];
for (const i in notas) {
  console.log(i, typeof i, i + 1);
}

$ node forin-array.js

Funciona… mais ou menos. Num array, o for … in entrega os índices, e não os itens, e os índices vêm como texto: i + 1 deu "01", "11", "21" em vez de 1, 2, 3 (aula Conversão Automática). Como consertar: para arrays, use for … of (os itens) ou o for com contador (os índices como número). Regra: in para objetos, of para arrays.

As chaves aparecem, os valores não. produto.chave procura uma propriedade chamada chave, literalmente. Como consertar: produto[chave].

Missão final: o que está em falta?

Missão: o estoque da papelaria é um objeto "produto → quantidade". Monte o array emFalta com os nomes dos produtos de quantidade 0, para aparecer Em falta: caneta, borracha. Use Object.entries (ou Object.keys), com filter e map ou com um laço.

const estoque = { caderno: 40, caneta: 0, mochila: 5, borracha: 0 };
const emFalta = [];
console.log(`Em falta: ${emFalta.join(", ")}`);

const estoque = { caderno: 40, caneta: 0, mochila: 5, borracha: 0 };
const emFalta = Object.entries(estoque)
  .filter(([produto, quantidade]) => quantidade === 0)
  .map(([produto]) => produto);
console.log(`Em falta: ${emFalta.join(", ")}`);

No lab, a solução mostrou Em falta: caneta, borracha. Outro jeito: Object.keys(estoque).filter((p) => estoque[p] === 0).

Resumo

  • for (const chave in obj) dá uma volta por chave; leia o valor com obj[chave].
  • Object.keys, Object.values e Object.entries transformam o objeto num array de chaves, de valores ou de pares, e liberam os métodos de array.
  • O jeito moderno: for (const [chave, valor] of Object.entries(obj)).
  • Object.fromEntries volta de pares para objeto: entries → map → fromEntries transforma um objeto inteiro.
  • As chaves são sempre textos; as que parecem números inteiros vêm primeiro, em ordem crescente. Não dependa da ordem das chaves.
  • Object.groupBy ES2024 agrupa uma lista num objeto de arrays.
  • in para objetos, of para arrays. for … of direto num objeto dá is not iterable.
