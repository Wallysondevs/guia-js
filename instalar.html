JavaScript Instalar o Node.js

Para rodar programas JavaScript no terminal, com node arquivo.js, você precisa do Node.js instalado. O navegador já vem com JavaScript, mas o Node.js não vem com o computador: é um programa que se instala, como qualquer outro. Esta aula mostra como conferir se você já tem, qual versão escolher e como instalar no Linux, no Windows e no macOS. Se ainda não quiser instalar nada, tudo bem: as caixas "Experimente" do guia funcionam sem instalação (aula O Editor do Guia).

Você vai aprender
  • A conferir se o Node.js já está instalado, com node -v.
  • A diferença entre as versões LTS e Current, e por que este guia usa o Node.js 24 LTS.
  • A instalar no Linux com o nvm, o jeito que o site oficial recomenda, e por que o apt install nodejs do Ubuntu entrega uma versão mais velha.
  • A instalar no Windows (instalador ou winget) e no macOS (instalador, nvm ou Homebrew).
  • A conferir o node, o npm e o npx, e a rodar o teste final.
  • Os erros reais: comando não encontrado, nvm não encontrado logo depois de instalar, opção errada.

As transcrições de Linux desta aula são reais: foram feitas na máquina fictícia da Ana, um Ubuntu 26.04 (usuária ana, computador notebook), primeiro sem Node.js e depois instalando de verdade. As partes de Windows e macOS não puderam ser rodadas aqui: estão marcadas como ilustrativas e seguem as instruções oficiais de nodejs.org.

A ideia: a receita e a cozinha

O arquivo .js é uma receita. Sozinha, uma receita não faz bolo nenhum: alguém precisa de uma cozinha para seguir os passos. O Node.js é essa cozinha: o programa que lê a sua receita em JavaScript e a executa no computador.

Na cozinhaNo computador
A receitaO seu arquivo receita.js
A cozinha que segue a receitaO Node.js (o comando node)
A despensa de ingredientes prontosO npm, que vem junto, e busca bibliotecas prontas (aula npm)

1. O Node.js já está instalado?

Abra o terminal (no Ubuntu, Ctrl+Alt+T) e pergunte a versão do Node.js com node -v (o -v é de version, "versão"). Num computador que ainda não tem o Node.js, a resposta do Ubuntu é esta:

$ node -v
Comando 'node' não encontrado, mas poder ser instalado com:
sudo apt install nodejs
Comando 'node' não encontrado
O terminal procurou um programa chamado node e não achou: o Node.js não está instalado (ou está num lugar que o terminal não conhece).
mas poder ser instalado com:
O Ubuntu tenta ajudar e sugere um pacote. (O "poder" no lugar de "pode" é um errinho da tradução do próprio Ubuntu; saiu assim mesmo.)
sudo apt install nodejs
O comando que ele sugere. Cuidado: esse pacote existe, mas traz uma versão mais velha que a do guia. Veja a seção 4 antes de usar.

Se, em vez disso, aparecer um número como v24.22.0, o Node.js já está instalado. Se o número começar com v24 (ou maior), você pode pular para a seção 7. Se começar com v18, v20 ou v22, ele funciona, mas algumas aulas usam recursos novos que só existem no 24: vale atualizar.

No Windows e no macOS a ideia é a mesma: abra o Terminal (ou o PowerShell) e digite node -v. Sem Node.js, aparece uma mensagem dizendo que node não é reconhecido como comando.

2. Qual versão: LTS ou Current

O Node.js lança uma versão "grande" nova a cada seis meses. As de número par (20, 22, 24, 26…) viram LTS e recebem correções por anos. (Isso muda depois do 26: a partir do 27, sai uma versão grande por ano, e todas viram LTS.) O site oficial sempre oferece duas:

TipoO que éPara quem
LTS (Long Term Support, "suporte de longo prazo")A versão estável, com correções garantidas por bastante tempoPara você. É a recomendada para o dia a dia e para aprender
Current ("atual")A mais nova, com as novidades primeiro; muda maisPara quem quer testar o que vem por aí

Este guia usa o Node.js 24 LTS (cada LTS ganha também um apelido; o do 24 é Krypton, que você vai ver no nvm logo abaixo). Na máquina da Ana, a versão é a v24.22.0, a mais nova do 24 em outubro de 2026. Os números depois do 24 (.22.0) mudam a cada atualização; o que importa é o 24.

E o Node.js 26?

O Node.js 26 está previsto para virar LTS em 28 de outubro de 2026 (e o 24 entra em "manutenção" em 20 de outubro: continua recebendo correções importantes, mas sem novidades). Se você instalar "a LTS" depois disso, pode receber o 26. A linguagem que o guia ensina é a mesma; as diferenças entre versões ficam em Versões do Node.js. Para ter exatamente o 24, use os comandos com o número (nvm install 24, brew install node@24), mostrados abaixo.

3. Linux: o jeito recomendado, com o nvm

O nvm (Node Version Manager, "gerenciador de versões do Node") é um pequeno programa que instala o Node.js dentro da sua pasta pessoal, sem pedir senha de administrador, e deixa você ter várias versões e trocar entre elas. É o primeiro jeito que a página de download do nodejs.org mostra para Linux e macOS. São três comandos, que você pode copiar de lá. Na máquina da Ana, ainda sem Node.js, foi assim:

sudo apt install nodejs

Vamos por partes:

curl -o- https://…/install.sh | bash
O curl baixa da internet o instalador do nvm (o -o- manda o que baixou para a tela, em vez de salvar num arquivo) e a barra | (o "cano") entrega esse texto ao bash, que o executa. O v0.40.8 no endereço é a versão do nvm; copie o comando do nodejs.org ou do site do nvm para ter a mais nova.
Downloading nvm as script to '/home/ana/.nvm'
O nvm foi baixado para a pasta escondida .nvm dentro da pasta da Ana. Nada foi instalado fora dela; por isso não precisou de sudo nem de senha.
Appending … to /home/ana/.bashrc
O instalador acrescentou três linhas no fim do .bashrc, o arquivo que o terminal lê toda vez que abre. Assim, os próximos terminais já conhecem o comando nvm.
Close and reopen your terminal…
"Feche e abra o terminal para começar a usar o nvm, ou rode o seguinte para usar agora". O terminal que já estava aberto ainda não leu o .bashrc novo.
\. "$HOME/.nvm/nvm.sh"
É o "rode agora" do aviso: carrega o nvm neste terminal mesmo, sem precisar fechar. O . (ponto) lê um arquivo de comandos dentro do terminal atual; a \ na frente só garante que é o ponto "de verdade" do bash.
nvm install 24
Baixa e instala a versão mais nova do Node.js 24 (aqui, a v24.22.0), direto do nodejs.org.
Checksums matched!
"As somas de verificação bateram": o nvm conferiu que o arquivo baixado chegou inteiro e sem alterações.
Now using node v24.22.0 (npm v11.19.1)
"Agora usando o node v24.22.0". O npm, a "despensa" de bibliotecas, veio junto, na versão 11.19.1.
Creating default alias: default -> 24
Como é a primeira versão instalada, ela vira a padrão: todo terminal novo já abre usando o Node.js 24.

4. A armadilha do apt install nodejs

O próprio Ubuntu sugeriu sudo apt install nodejs, e esse comando funciona: instala o Node.js que vem nos pacotes do Ubuntu. O problema é a versão. As distribuições Linux congelam as versões dos programas quando lançam, e o Node.js anda rápido. Segundo o site oficial de pacotes do Ubuntu (packages.ubuntu.com):

UbuntuVersão do pacote nodejsServe para o guia?
26.04 LTS22.22.1Quase tudo, mas não o que é novo do 24
24.04 LTS18.19.1Não: velho demais para várias aulas

Além disso, no Ubuntu o npm é um pacote separado (sudo apt install npm), também numa versão mais velha (9.2.0 no 26.04). Por isso, para este guia, prefira o nvm (seção 3). Se você já instalou pelo apt, não tem problema: o nvm instala o 24 na sua pasta e passa na frente do Node.js do sistema.

Outros caminhos no Linux

A página de download do nodejs.org também mostra outros gerenciadores (como o fnm) e o Node.js em Docker, e o site oficial oferece o arquivo pronto (node-v24.22.0-linux-x64.tar.xz) para quem quer descompactar à mão. Há ainda repositórios de terceiros com versões novas para o apt. Todos funcionam; o nvm é o mais simples de desfazer e de atualizar.

5. Windows (ilustrativo)

No Windows há dois caminhos simples. Esta seção segue o nodejs.org e não foi rodada na máquina da Ana (que é Linux).

Com o instalador (o mais fácil)

  1. Abra https://nodejs.org e clique no botão de download da versão LTS. Para um computador comum (64 bits, processador Intel ou AMD), o arquivo é algo como node-v24.22.0-x64.msi.
  2. Abra o arquivo baixado. Clique em Next ("Próximo"), aceite a licença e deixe as opções como estão: elas já colocam o node e o npm no PATH (a lista de lugares onde o Windows procura comandos).
  3. Na tela Tools for Native Modules ("ferramentas para módulos nativos"), pode deixar a caixa desmarcada: este guia não precisa delas.
  4. Clique em Install e, no fim, em Finish.
  5. Abra um terminal novo (o Terminal do Windows ou o PowerShell) e digite node -v. Deve aparecer v24. seguido de mais números.

Com o winget, pelo terminal

O winget é o instalador de programas por linha de comando que vem no Windows 10 e 11. No Terminal ou no PowerShell:

winget install OpenJS.NodeJS.LTS

O OpenJS.NodeJS.LTS é o nome do pacote do Node.js LTS no catálogo do winget. Depois, feche o terminal, abra outro e confira com node -v. Como esse pacote acompanha "a LTS do momento", ele pode instalar o 26 a partir do fim de outubro de 2026 (veja o aviso da seção 2).

Abra um terminal novo depois de instalar

Um terminal que já estava aberto antes da instalação não fica sabendo do node novo. É a causa número um do "instalei e não funciona" no Windows.

6. macOS (ilustrativo)

Também segue o nodejs.org; não foi rodado na máquina da Ana. Três caminhos:

  • O instalador: no nodejs.org, baixe o arquivo .pkg da LTS (algo como node-v24.22.0.pkg), abra e siga os passos. Ele instala o node e o npm.
  • O nvm: os mesmos três comandos da seção 3, no aplicativo Terminal. No macOS o terminal padrão é o zsh, e o instalador do nvm escreve no arquivo de configuração dele.
  • O Homebrew, para quem já usa o brew: brew install node@24. O Homebrew pode avisar, no fim, que é preciso acrescentar uma pasta ao PATH; siga o aviso que ele mostrar.

Em qualquer caso, termine abrindo um Terminal novo e digitando node -v.

7. Conferindo a instalação

Junto com o Node.js vêm três comandos. Na máquina da Ana, com o Node.js oficial (instalado em /usr/local, a pasta dos programas instalados "à mão"):

$ node -v
v24.22.0
$ npm -v
11.19.1
$ npx -v
11.19.1
$ which node
/usr/local/bin/node
ComandoO que é
nodeO Node.js: roda os seus arquivos .js (aula Rodando um Programa) e abre o modo interativo (aula O Modo Interativo)
npmO gerenciador de pacotes: instala bibliotecas prontas (aula npm)
npxRoda uma ferramenta de um pacote sem instalar de vez; vem junto com o npm, por isso a mesma versão

O node --version, por extenso, faz o mesmo que node -v. O lugar que o which node mostra muda conforme o jeito de instalar: /usr/local/bin/node (arquivo oficial), /usr/bin/node (apt), uma pasta dentro de ~/.nvm (nvm).

8. O teste final

Agora o teste de verdade: um programa. Crie um arquivo teste.js (a aula Rodando um Programa mostra como criar e salvar, passo a passo) com estas duas linhas:

console.log("O Node.js está funcionando!");
console.log("Versão:", process.version);

$ node teste.js
O Node.js está funcionando!
Versão: v24.22.0

Se apareceram as duas linhas, está tudo pronto. O process.version é a versão do Node.js que rodou o arquivo (é só do Node: veja Onde o JavaScript Roda).

Missão: sem instalar nada, faça o teste aqui: troque os ??? para que a primeira linha mostre O Node.js está funcionando! e clique em Rodar. A segunda linha mostra a versão que o editor do guia imita.

9. Um editor para escrever os programas

Um programa JavaScript é um arquivo de texto puro. Para escrevê-lo, use um editor de código, nunca um editor de documentos como o Word ou o LibreOffice Writer (eles gravam formatação escondida e trocam as aspas " por aspas "curvas", que o JavaScript não entende).

nodejs em vez de node 
$ nodejs -v
Comando 'nodejs' não encontrado, mas poder ser instalado com:
sudo apt install nodejs
$ node -v
v24.22.0

O pacote do Ubuntu se chama nodejs, mas o comando se chama node. Na máquina da Ana, que tem o Node.js oficial, o comando nodejs não existe. Como consertar: digite sempre node.

Opção com a letra errada 
$ node -V
node: bad option: -V
$ echo $?
9

"Opção ruim: -V". Para o Node.js, o -V maiúsculo não existe: a versão é com -v minúsculo (ou --version). O terminal diferencia maiúsculas de minúsculas, igual ao JavaScript. O echo $? mostra o código de saída: 9, que o Node.js usa para "opção inválida" (diferente do 0 de quando dá certo).

Instalei no Windows e o terminal não acha o node (ilustrativo)

Quase sempre o terminal já estava aberto antes da instalação. Como consertar: feche todas as janelas do terminal (ou do VS Code) e abra de novo. Se ainda assim não funcionar, reinicie o computador; se continuar, rode o instalador outra vez e confira se a opção de pôr o Node.js no PATH ficou marcada.

O node -v mostra uma versão velha

Se aparece v18… ou v22… e você queria o 24, provavelmente há um Node.js antigo do sistema (do apt) sendo achado primeiro. Use which node para ver qual está sendo usado. Com o nvm, rode nvm install 24 e abra um terminal novo; o do nvm passa na frente.

Resumo

  • O Node.js é o programa que roda os seus arquivos .js no computador. Confira se ele existe com node -v.
  • Use a versão LTS; este guia usa o Node.js 24 LTS (v24.22.0 na máquina da Ana).
  • Linux e macOS: o nvm instala o Node.js na sua pasta, sem senha: instale o nvm com o comando do nodejs.org, abra um terminal novo (ou carregue o nvm.sh) e rode nvm install 24.
  • O apt install nodejs do Ubuntu funciona, mas entrega uma versão mais velha (22 no 26.04, 18 no 24.04).
  • Windows: o instalador .msi do nodejs.org ou winget install OpenJS.NodeJS.LTS. macOS: o .pkg, o nvm ou brew install node@24. Depois, sempre um terminal novo.
  • Junto vêm o npm e o npx. O teste final é rodar um console.log com node teste.js.
