Como ler as tabelas

{ ...obj } faz uma cópia rasa: se uma propriedade guarda outro objeto ou array, a cópia e o original continuam apontando para o mesmo. Para copiar tudo, use structuredClone.

JSON

O JSON (JavaScript Object Notation, "notação de objetos do JavaScript") é um texto que se parece com um objeto, mas com regras mais rígidas: chaves sempre entre aspas duplas, textos só com aspas duplas, sem vírgula sobrando no fim e sem funções nem undefined. A aula completa é JSON (stringify e parse).

Missão: os dados da Ana chegaram como texto JSON, e por isso pessoa.cidade deu undefined (um texto não tem a propriedade cidade). Use JSON.parse para transformar o texto em objeto, e o programa vai mostrar Cidade: Recife.

const texto = '{"nome":"Ana","cidade":"Recife"}';

const pessoa = texto;
console.log(`Cidade: ${pessoa.cidade}`);

const texto = '{"nome":"Ana","cidade":"Recife"}';

const pessoa = JSON.parse(texto);
console.log(`Cidade: ${pessoa.cidade}`);

$ node cidade.js
Cidade: undefined
$ node cidade2.js
Cidade: Recife

Livre: percorra o objeto com Object.entries, transforme em JSON e volte. Acrescente propriedades ao produto e rode de novo.

const produto = { nome: "Caderno", preco: 12.5, estoque: 30 };

for (const [chave, valor] of Object.entries(produto)) {
  console.log(`${chave}: ${valor}`);
}

const json = JSON.stringify(produto, null, 2);
console.log(json);

const deVolta = JSON.parse(json);
console.log(deVolta.preco * 2);

Resumo

  • Ler: obj.chave ou obj["chave"]; o que não existe dá undefined. Perguntar: "chave" in obj ou Object.hasOwn.
  • Listar: Object.keys, Object.values, Object.entries (pares, ótimo no for … of); Object.fromEntries faz o caminho de volta.
  • Copiar: { ...obj, chave: novo } (rasa) ou structuredClone (profunda). Tirar para variáveis: const { a, ...resto } = obj.
  • Object.freeze congela; Object.groupBy agrupa uma lista.
  • JSON.stringify: objeto → texto (null, 2 para ficar bonito). JSON.parse: texto → objeto. JSON exige aspas duplas e não aceita vírgula sobrando.
