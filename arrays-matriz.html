JavaScript: Arrays de Arrays (Matrizes)

Um array guarda uma lista. Mas muita informação do dia a dia tem a forma de uma tabela, com linhas e colunas: as notas de cada aluno em cada prova, as poltronas de um cinema, o tabuleiro do jogo da velha, uma planilha. No JavaScript, uma tabela é um array de arrays: um array em que cada item é outro array (uma linha). Os matemáticos chamam isso de matriz.

Você vai aprender
  • Como montar uma tabela como array de arrays, e como vê-la com console.table.
  • Como ler e mudar um valor com dois índices: notas[linha][coluna].
  • Como saber quantas linhas e quantas colunas a tabela tem.
  • Como percorrer a tabela inteira com dois laços, um dentro do outro.
  • Como calcular a média de cada linha e de cada coluna, e achar o maior valor da tabela.
  • Como criar uma tabela vazia do jeito certo (o jogo da velha), e linhas de tamanhos diferentes.
  • Os erros reais: a linha que não existe, a vírgula no lugar dos colchetes, a mesma linha repetida.

Todos os programas desta aula rodaram no Node.js 24 da máquina da Ana (usuária ana, computador notebook), salvos na pasta pessoal dela e executados com node arquivo.js. Você pode rodar cada um no editor do guia.

A ideia: o diário de classe

A professora da Ana tem um caderno com as notas da turma. Cada linha é um aluno; cada coluna é uma prova:

Prova 1Prova 2Prova 3
Ana786
Bia957
Caio6810

Para achar uma nota, você faz duas perguntas: "qual aluno?" (a linha) e "qual prova?" (a coluna). A nota da Bia na prova 3 é 7. No JavaScript, cada linha vira um array ([9, 5, 7] é a linha da Bia), e a tabela vira um array com essas linhas dentro.

1. Criando a tabela

const notas = [
  [7, 8, 6],
  [9, 5, 7],
  [6, 8, 10],
];
console.log(notas);
console.table(notas);

O array de fora: a tabela. Ele tem 3 itens, e cada item é uma linha.
[7, 8, 6]
A primeira linha (a Ana): um array comum, com as três notas. As linhas são separadas por vírgula, como quaisquer itens.
uma linha por linha do código
Escrever cada linha da tabela numa linha do código não é obrigatório, mas deixa a "forma" da tabela visível. A vírgula depois da última linha é permitida e facilita acrescentar outra.
console.log(notas)
O Node mostra os arrays de dentro de colchetes nos de fora.
console.table(notas)
Desenha a tabela com bordas (aula console.error, warn e table). A coluna (index) mostra o índice de cada linha; o cabeçalho, o índice de cada coluna. É o melhor jeito de "ver" uma matriz.

Repare que, no JavaScript, a contagem começa do zero: a Ana é a linha 0, a Bia a linha 1, o Caio a linha 2; a "prova 1" é a coluna 0.

2. Lendo um valor: [linha][coluna]

const notas = [
  [7, 8, 6],
  [9, 5, 7],
  [6, 8, 10],
];
console.log(notas[1]);
console.log(notas[1][2]);
const linhaDaBia = notas[1];
console.log(linhaDaBia[2]);
console.log(notas.at(-1).at(-1));

$ node acessar.js
[ 9, 5, 7 ]
7
7
10
notas[1]
Com um índice, você pega uma linha inteira: o array da Bia, [ 9, 5, 7 ].
notas[1][2]
Com dois índices, um valor só. O JavaScript lê da esquerda para a direita: primeiro notas[1] (a linha da Bia), depois o item [2] dessa linha (a 3ª prova). Resultado: 7.
linhaDaBia[2]
O mesmo, em dois passos, com uma variável no meio. Se o [1][2] parecer confuso, pense assim.
notas.at(-1).at(-1)
O at com -1 pega o último item (aula Acessando e Alterando Itens): a última nota da última linha, o 10 do Caio.
Para não confundir

A ordem é sempre primeiro a linha, depois a coluna: notas[aluno][prova]. Dê nomes que lembrem isso aos índices (linha e coluna, ou i e j, nessa ordem).

3. Mudando valores e contando linhas e colunas

A Bia pediu revisão da prova 2 e a nota subiu para 6,5. O Caio fez uma prova extra:

const notas = [
  [7, 8, 6],
  [9, 5, 7],
  [6, 8, 10],
];
notas[1][1] = 6.5;
notas[2].push(9);
console.log(notas);
console.log("Linhas:", notas.length);
console.log("Colunas da linha 0:", notas[0].length);
console.log("Colunas da linha 2:", notas[2].length);

$ node alterar.js
[ [ 7, 8, 6 ], [ 9, 6.5, 7 ], [ 6, 8, 10, 9 ] ]
Linhas: 3
Colunas da linha 0: 3
Colunas da linha 2: 4
  • notas[1][1] = 6.5: os mesmos dois índices, agora do lado esquerdo do =, trocam o valor.
  • notas[2].push(9): notas[2] é um array comum, então tem todos os métodos de array. O push acrescentou uma nota só na linha do Caio.
  • notas.length é o número de linhas (3). notas[0].length é o número de colunas de uma linha. Depois do push, a linha do Caio ficou com 4: no JavaScript, as linhas não precisam ter o mesmo tamanho (seção 7).

4. Percorrendo a tabela inteira

Para passar por todas as notas, você precisa de dois laços, um dentro do outro (aula Laços Aninhados): o de fora anda pelas linhas; o de dentro, pelas colunas da linha atual.

const alunos = ["Ana", "Bia", "Caio"];
const notas = [
  [7, 8, 6],
  [9, 5, 7],
  [6, 8, 10],
];
for (let i = 0; i < notas.length; i++) {
  for (let j = 0; j < notas[i].length; j++) {
    console.log(`${alunos[i]}, prova ${j + 1}: ${notas[i][j]}`);
  }
}

$ node percorrer.js
Ana, prova 1: 7
Ana, prova 2: 8
Ana, prova 3: 6
Bia, prova 1: 9
Bia, prova 2: 5
Bia, prova 3: 7
Caio, prova 1: 6
Caio, prova 2: 8
Caio, prova 3: 10
for (let i = 0; i < notas.length; i++)
O laço de fora: i é a linha (0, 1, 2). O notas.length é o número de linhas.
for (let j = 0; j < notas[i].length; j++)
O laço de dentro: j é a coluna. O limite é o tamanho da linha atual, notas[i].length. Assim funciona mesmo se as linhas tiverem tamanhos diferentes.
notas[i][j]
A nota da linha i, coluna j.
alunos[i] e j + 1
O nome vem de outro array, na mesma posição da linha. O j + 1 mostra "prova 1" em vez de "prova 0", para gente.

A ordem da saída mostra como os laços trabalham: o de dentro dá a volta completa (as três provas) antes de o de fora passar para o próximo aluno.

Com for … of, quando você não precisa dos índices

const notas = [
  [7, 8, 6],
  [9, 5, 7],
  [6, 8, 10],
];
for (const linha of notas) {
  let texto = "";
  for (const nota of linha) {
    texto += nota + " ";
  }
  console.log(texto);
}
for (const linha of notas) {
  console.log(linha.join(" | "));
}

$ node forof.js
7 8 6
9 5 7
6 8 10
7 | 8 | 6
9 | 5 | 7
6 | 8 | 10

O for … of de fora entrega cada linha (um array); o de dentro, cada nota dessa linha. O segundo bloco faz o mesmo desenho com um laço só, usando o join (aula some, every, join…) em cada linha.

5. Contas com linhas e colunas

const alunos = ["Ana", "Bia", "Caio"];
const notas = [
  [7, 8, 6],
  [9, 5, 7],
  [6, 8, 10],
];
const medias = notas.map((linha) => linha.reduce((soma, n) => soma + n, 0) / linha.length);
console.log(medias);
const mediaProva1 = notas.reduce((soma, linha) => soma + linha[0], 0) / notas.length;
console.log("Média da prova 1:", mediaProva1.toFixed(2));
const todas = notas.flat();
console.log("Maior nota:", Math.max(...todas));

$ node medias.js
[ 7, 7, 8 ]
Média da prova 1: 7.33
Maior nota: 10
Média de cada linha (aluno)
O map passa por cada linha; para cada uma, o reduce soma as notas e a divisão pelo linha.length dá a média. O resultado é um array com uma média por aluno.
Média de uma coluna (prova)
Para a prova 1, some o item [0] de cada linha: soma + linha[0]. Divida pelo número de linhas. O toFixed(2) mostra com 2 casas (aula Formatando Números).
notas.flat()
"Achata" a tabela numa lista só com as 9 notas (aula some, every, join, flat…). Com ela, o Math.max acha a maior nota da tabela inteira.

6. Criando uma tabela vazia: o jogo da velha

A Ana quer um tabuleiro 3 × 3 começando com espaços em branco. O jeito seguro é o Array.from com uma função, que cria uma linha nova para cada posição:

const tabuleiro = Array.from({ length: 3 }, () => Array(3).fill(" "));
tabuleiro[0][0] = "X";
tabuleiro[1][1] = "O";
tabuleiro[2][2] = "X";
console.log(tabuleiro.map((linha) => linha.join(" | ")).join("\n---------\n"));

$ node velha.js
X |   |
---------
  | O |
---------
  |   | X
Array.from({ length: 3 }, () => …)
Cria 3 linhas. A função roda 3 vezes, e cada vez devolve um array novo.
Array(3).fill(" ")
Cada linha: 3 casas com um espaço.
tabuleiro[1][1] = "O"
A jogada: linha 1, coluna 1, o centro.
map(… join(" | ")).join("\n---------\n")
Para desenhar: cada linha vira um texto com " | " entre as casas, e as linhas são juntadas com uma linha de tracinhos no meio.

Por que não Array(3).fill(Array(3).fill(" ")), que parece mais curto? A seção Quando dá errado mostra.

7. Linhas de tamanhos diferentes

Nada obriga as linhas a terem o mesmo tamanho. A escola tem três turmas com quantidades diferentes de alunos:

const turmas = [
  ["Ana", "Bia", "Caio"],
  ["Davi"],
  ["Edu", "Fabi"],
];
for (let i = 0; i < turmas.length; i++) {
  console.log(`Turma ${i + 1}: ${turmas[i].length} aluno(s) - ${turmas[i].join(", ")}`);
}

$ node irregular.js
Turma 1: 3 aluno(s) - Ana, Bia, Caio
Turma 2: 1 aluno(s) - Davi
Turma 3: 2 aluno(s) - Edu, Fabi

Por isso, ao percorrer, use sempre turmas[i].length (o tamanho da linha atual) no laço de dentro, e nunca um número fixo.

Vírgula no lugar dos colchetes

Quem vem de outras linguagens escreve notas[1, 2]:

const notas = [
  [7, 8, 6],
  [9, 5, 7],
  [6, 8, 10],
];
console.log(notas[1, 2]);
console.log(notas[1][2]);

$ node virgula.js
[ 6, 8, 10 ]
7

Não deu erro, mas veio a linha 2 inteira, e não a nota da Bia. Dentro dos colchetes, 1, 2 é uma expressão que vale o último valor, o 2; então notas[1, 2] é o mesmo que notas[2]. Como consertar: um par de colchetes para cada índice: notas[1][2].

A mesma linha repetida: fill com um array 
const tabuleiro = Array(3).fill(Array(3).fill(" "));
tabuleiro[0][0] = "X";
console.log(tabuleiro.map((linha) => linha.join(" | ")).join("\n---------\n"));

$ node velha-errado.js
X |   |
---------
X |   |
---------
X |   |

Uma jogada só, e apareceram três X! O Array(3).fill(" ") de dentro roda uma vez e cria uma linha; o fill de fora põe essa mesma linha nos três lugares. Mudar a "linha 0" é mudar as três, porque são uma só (o mesmo problema da aula Copiando Arrays). Como consertar: Array.from({ length: 3 }, () => Array(3).fill(" ")), como na seção 6.

Trocou a ordem dos índices

Sem erro: você queria "Bia, prova 3" e escreveu notas[2][1] (que é "Caio, prova 2"). Numa tabela quadrada, os dois existem, e o número errado passa despercebido. Como consertar: lembre-se: linha primeiro. Nomes como notas[aluno][prova] ajudam.

Missão final: o boletim da turma

Missão: o laço já passa por cada aluno, mas só mostra o nome. Complete-o para calcular a média das notas da linha i e mostrar Ana: 7, Bia: 7 e Caio: 8. Dica: some notas[i] com um reduce (ou com um laço de dentro) e divida por notas[i].length.

const alunos = ["Ana", "Bia", "Caio"];
const notas = [
  [7, 8, 6],
  [9, 5, 7],
  [6, 8, 10],
];
for (let i = 0; i < notas.length; i++) {
  console.log(`${alunos[i]}: ?`);
}

const alunos = ["Ana", "Bia", "Caio"];
const notas = [
  [7, 8, 6],
  [9, 5, 7],
  [6, 8, 10],
];
for (let i = 0; i < notas.length; i++) {
  const soma = notas[i].reduce((total, n) => total + n, 0);
  console.log(`${alunos[i]}: ${soma / notas[i].length}`);
}

No lab, a solução mostrou Ana: 7, Bia: 7 e Caio: 8.

Resumo

  • Uma matriz é um array de arrays: cada item do array de fora é uma linha.
  • m[i] é a linha i; m[i][j] é o valor da linha i, coluna j. Linha primeiro, e tudo começa do zero.
  • m.length conta as linhas; m[i].length, as colunas daquela linha. As linhas podem ter tamanhos diferentes.
  • Para percorrer tudo: dois laços aninhados, com j < m[i].length no de dentro. console.table ajuda a ver.
  • Para criar uma matriz vazia, Array.from({ length: L }, () => Array(C).fill(v)). Com fill de um array, todas as linhas são a mesma.
  • Ler uma linha que não existe e depois um item dela dá TypeError: Cannot read properties of undefined.
