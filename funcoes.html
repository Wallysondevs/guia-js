JavaScript Funções

Uma função (em inglês, function) é um pedaço de código com um nome. Você escreve as instruções uma vez, dá um nome a elas e, depois, sempre que precisar, só chama pelo nome. Você já usa funções desde o primeiro programa: o console.log é uma função que alguém escreveu para você. Nesta aula, você vai criar as suas.

Você vai aprender
  • Para que serve uma função: não repetir código e dar nome às tarefas.
  • Como criar (declarar) uma função com function e como chamar com ().
  • O caminho que o programa faz quando chama uma função: entra, roda, volta.
  • Uma função chamando outra, e uma função chamada dentro de um laço.
  • As outras formas de escrever uma função (const … = function e a arrow =>).
  • Os erros reais mais comuns: nome errado, chamar o que não é função, a chave que faltou.

Todos os programas desta aula rodaram no Node.js 24 (v24.22.0) da máquina da Ana, com node arquivo.js. Você pode rodar cada um no editor do guia.

A ideia: a receita com nome

Num caderno de receitas, a Ana escreveu uma vez, com todos os passos, a receita de "massa básica". Nas outras receitas (pizza, esfiha, pão de alho), ela não copia tudo de novo: escreve só "faça a massa básica". Isso tem duas vantagens:

  • Menos repetição: os passos ficam num lugar só.
  • Mudar fica fácil: se ela descobrir que a massa fica melhor com mais sal, corrige num lugar só, e todas as receitas que usam a massa ficam certas.

Uma função é a "massa básica" do programa: escrever os passos e dar um nome é declarar a função; dizer "faça a massa básica" é chamar a função.

1. O problema: código repetido

O recibo da padaria tem uma linha tracejada em três lugares:

console.log("------------------------------");
console.log("Padaria do Bairro");
console.log("------------------------------");
console.log("Pão francês ........ R$ 0,80");
console.log("Café ............... R$ 4,50");
console.log("------------------------------");

$ node repetido.js
------------------------------
Padaria do Bairro
------------------------------
Pão francês ........ R$ 0,80
Café ............... R$ 4,50
------------------------------

Funciona. Mas se o dono da padaria pedir uma linha de = em vez de -, a Ana tem de mudar três linhas (e, num programa grande, seriam trinta, e ela esqueceria alguma).

2. Criando e chamando a primeira função

function mostrarLinha() {
  console.log("------------------------------");
}

mostrarLinha();
console.log("Padaria do Bairro");
mostrarLinha();
console.log("Pão francês ........ R$ 0,80");
console.log("Café ............... R$ 4,50");
mostrarLinha();

$ node recibo.js
------------------------------
Padaria do Bairro
------------------------------
Pão francês ........ R$ 0,80
Café ............... R$ 4,50
------------------------------

A mesma saída. As três primeiras linhas do arquivo declaram a função; cada mostrarLinha(); a chama.

function
A palavra-chave que avisa: "vou criar uma função".
mostrarLinha
O nome da função. Segue as regras dos nomes de variáveis (veja Nomes de Variáveis): camelCase, sem espaço, sem acento. Como uma função faz algo, o costume é começar com um verbo: mostrarLinha, calcularTotal, abrirLoja.
()
Os parênteses, aqui vazios. É neles que a função recebe informações de fora, os parâmetros: o assunto da próxima aula, Parâmetros e Argumentos.
{ … }
O corpo da função: as instruções que rodam a cada chamada, com 2 espaços de recuo.
mostrarLinha();
A chamada: o nome, os parênteses (obrigatórios, mesmo vazios) e o ponto e vírgula. É só aqui que o corpo roda.

==============================

Declarar não é rodar

Um arquivo só com a declaração não mostra nada. A Ana salvou só isto em sochama.js: function saudar() { console.log("Olá!"); }, e rodou:

3. O caminho do programa: entra, roda, volta

O JavaScript lê o programa de cima para baixo. Quando encontra uma chamada, ele pula para dentro da função, roda o corpo inteiro e volta para a linha seguinte à chamada:

function saudar() {
  console.log("  (dentro da função) Olá!");
  console.log("  (dentro da função) Bem-vinda à padaria!");
}

console.log("1. Antes de chamar");
saudar();
console.log("2. Entre as chamadas");
saudar();
console.log("3. Depois de chamar");

$ node ordem.js
1. Antes de chamar
  (dentro da função) Olá!
  (dentro da função) Bem-vinda à padaria!
2. Entre as chamadas
  (dentro da função) Olá!
  (dentro da função) Bem-vinda à padaria!
3. Depois de chamar
  1. As linhas 1 a 4 só registram a função saudar; nada aparece.
  2. A linha 6 mostra 1. Antes de chamar.
  3. A linha 7 chama saudar(): o programa entra na função, mostra as duas linhas dela e volta.
  4. A linha 8 mostra 2. Entre as chamadas; a linha 9 chama de novo (entra, roda, volta).
  5. A linha 10 mostra 3. Depois de chamar, e o programa acaba.

4. Uma função chamando outra

O corpo de uma função pode ter qualquer instrução, inclusive a chamada de outra função:

function mostrarLinha() {
  console.log("------------------------------");
}

function abrirLoja() {
  mostrarLinha();
  console.log("A padaria está aberta!");
  mostrarLinha();
}

abrirLoja();

$ node outra.js
------------------------------
A padaria está aberta!
------------------------------

A única chamada "de fora" é abrirLoja(). Lá dentro, ela chama mostrarLinha() duas vezes. É assim que programas grandes se organizam: tarefas grandes chamam tarefas menores, cada uma com um nome que explica o que faz.

Função dentro de um laço

Uma chamada dentro de um for roda a função a cada volta:

function mostrarEstrelas() {
  console.log("* * * * *");
}

for (let i = 1; i <= 3; i++) {
  mostrarEstrelas();
}

$ node laco.js
* * * * *
* * * * *
* * * * *

No modo interativo

No > do Node (veja O Modo Interativo), depois da linha com {, o prompt vira | até você fechar a chave:

$ node

Type ".help" for more information.
> function saudar() {
|   console.log("Olá, Ana!");
| }
undefined
> saudar()
Olá, Ana!
undefined
> saudar
[Function: saudar]
> typeof saudar
'function'
> .exit

Repare em três coisas: declarar a função responde undefined (não é erro: declarar não produz valor); saudar(), com parênteses, roda a função; e saudar, sem parênteses, não roda nada: o Node só mostra que ali existe uma função chamada saudar ([Function: saudar]). O typeof confirma: uma função é um valor do tipo 'function'. (O undefined depois de Olá, Ana! é o resultado da chamada; ele vai fazer sentido na aula return.)

5. Chamar antes de declarar

Uma função criada com function pode ser chamada antes da linha em que foi declarada:

saudar();

function saudar() {
  console.log("Olá!");
}

$ node antes.js
Olá!

Antes de rodar a primeira linha, o JavaScript passa pelo arquivo e registra todas as declarações function. Esse comportamento se chama hoisting ("içamento", como quem iça uma bandeira para o alto) e tem aula própria: Hoisting. Muita gente aproveita isso para deixar o "programa principal" no alto do arquivo e as funções embaixo; outros preferem declarar tudo antes de usar. Os dois jeitos funcionam com function.

Formas diferentes de fazer a mesma coisa

Existem três jeitos comuns de criar uma função. Os três programas abaixo mostram Olá!.

1. Declaração (o que você viu até aqui):

function saudar() {
  console.log("Olá!");
}

2. Expressão de função: uma função sem nome guardada numa constante. Repare no ; depois da }: é o fim da instrução const.

const saudar = function () {
  console.log("Olá!");
};

saudar();

$ node expressao.js
Olá!

3. Arrow function (função "flecha", por causa do =>): a forma curta, muito usada no JavaScript moderno. Tem aula própria: Arrow Functions.

const saudar = () => {
  console.log("Olá!");
};

saudar();

$ node seta.js
Olá!

A chamada é igual nos três: saudar(). A diferença que aparece logo é a do hoisting: as formas 2 e 3 são constantes, e uma constante não pode ser usada antes da linha que a cria (veja em Quando dá errado).

FormaQuando usar
function nome() { … }As funções principais do programa; o jeito mais claro para quem está começando, e o desta parte do guia

const nome = function () { … };Aparece bastante em código mais antigo; hoje, quase sempre se usa a arrow no lugar

"Erro de tipo: preco não é uma função". Agora o nome existe, mas guarda um número, e um número não pode ser chamado com (). Isso acontece quando uma variável e uma função têm o mesmo nome, ou quando se põe () onde não devia. Resumo

  • Uma função é um pedaço de código com nome: escrito uma vez, usado quantas vezes quiser. Mudou? Muda num lugar só.
  • function nome() { … } declara; nome(); chama. Sem a chamada, o corpo nunca roda.
  • Na chamada, o programa entra na função, roda o corpo inteiro e volta para a instrução seguinte.
  • Funções podem chamar outras funções e ser chamadas dentro de laços.
  • Nomes de função: verbo + camelCase, e maiúsculas fazem diferença.
  • Variáveis criadas dentro da função só existem lá dentro. Para mandar informação para dentro, use parâmetros; para trazer de volta, return.
