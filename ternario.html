JavaScript O Operador Ternário (? :)

Muitas vezes o if … else só serve para escolher entre dois valores: "aprovada" ou "reprovada", "item" ou "itens", R$ 15 de frete ou zero. Para esses casos existe uma forma curta, que cabe numa linha: o operador ternário, escrito com ? e :. Ele se chama assim porque é o único operador do JavaScript com três partes ("ternário" quer dizer "de três").

Você vai aprender
  • Como se escreve condição ? valorSeSim : valorSeNão, e como ler em voz alta.
  • Por que o ternário produz um valor, e o if não.
  • Onde ele brilha: numa const, dentro de um template string, no singular/plural.
  • Ternários em cadeia, e quando é melhor voltar ao if.
  • A diferença entre o ternário, o || e o ??.
  • Os erros reais: os dois-pontos esquecidos, const dentro do ternário e a armadilha da precedência com +.

Todos os programas desta aula rodaram no Node.js 24 da máquina da Ana (usuária ana, computador notebook), salvos na pasta pessoal dela e executados com node arquivo.js (veja Rodando um Programa). Você pode rodar cada um no editor do guia.

A ideia: "com açúcar ou sem?"

Na padaria, o atendente pergunta: "Café com açúcar?". Dependendo da resposta, ele te entrega uma de duas xícaras: a adoçada ou a amarga. Ele não faz um discurso; ele só escolhe qual xícara entregar.

O ternário é isso: uma pergunta e duas respostas prontas. Ele te entrega uma delas, e você faz o que quiser com ela: guarda numa variável, mostra na tela, junta num texto.

1. A forma do ternário

const nota = 8;
const situacao = nota >= 7 ? "Aprovada" : "Reprovada";
console.log(situacao);
nota >= 7
A condição, a pergunta. Os parênteses são opcionais aqui (no if eles são obrigatórios).
?
Separa a pergunta das respostas. Leia como "se sim, então…".
"Aprovada"
O valor entregue quando a condição é verdadeira (ou truthy; veja Truthy e Falsy).
:
Leia como "senão…".
"Reprovada"
O valor entregue quando a condição é falsa.
const situacao = …
O valor escolhido vai direto para a constante.
$ node situacao.js
Aprovada

Em voz alta: "a situação é: a nota é maior ou igual a 7? Se sim, Aprovada; senão, Reprovada".

O mesmo com if … else

Compare com a versão da aula else e else if:

const nota = 8;
let situacao;
if (nota >= 7) {
  situacao = "Aprovada";
} else {
  situacao = "Reprovada";
}
console.log(situacao);

$ node situacao-if.js
Aprovada

Mesma saída, mas repare: com o if, a variável tem de ser let (criada vazia e preenchida depois) e o nome situacao aparece três vezes. Com o ternário, é uma linha, e dá para usar const.

Missão: complete o ternário para a constante tipo valer "Maior de idade" se a idade for 18 ou mais, e "Menor de idade" senão. Teste também com uma idade menor.

const idade = 20;
const tipo = "";
console.log(tipo);

const idade = 20;
const tipo = idade >= 18 ? "Maior de idade" : "Menor de idade";
console.log(tipo);

2. O ternário produz um valor; o if, não

Esta é a diferença mais importante. O ternário é uma expressão: como 2 + 3, ele vale alguma coisa. O if é uma instrução: ele manda o programa fazer coisas, mas não vale nada. Por isso o ternário pode ir em qualquer lugar onde caberia um valor:

const quantidade = 3;
const vip = false;

console.log(quantidade > 0 ? "Em estoque" : "Esgotado");
console.log(`Frete: R$ ${vip ? 0 : 15}`);
console.log("Total: R$ " + (100 + (vip ? 0 : 15)));

$ node valor.js
Em estoque
Frete: R$ 15
Total: R$ 115
console.log(… ? … : …)
O valor escolhido vai direto para o console.log.
${vip ? 0 : 15}
Dentro do ${ } de um template string (veja Template Strings) cabe qualquer expressão, inclusive um ternário.
100 + (vip ? 0 : 15)
Numa conta. Os parênteses em volta do ternário são importantes aqui: veja Quando dá errado.

Já um if dentro do ${ } o Node recusa, porque o if não tem valor para pôr no texto:

const vip = true;
console.log(`Frete: ${if (vip) { 0 }}`);

"if inesperado": dentro do ${ }, o Node esperava um valor e encontrou uma instrução.

3. O uso clássico: singular e plural

A lista de compras da Ana mostra quantos itens faltam comprar. Com 1, é "item"; com outro número, "itens":

const faltam = 1;
console.log(`Falta ${faltam} ${faltam === 1 ? "item" : "itens"} na lista.`);

const faltam2 = 4;
console.log(`Faltam ${faltam2} ${faltam2 === 1 ? "item" : "itens"} na lista.`);

$ node plural.js
Falta 1 item na lista.
Faltam 4 itens na lista.

Sem o ternário, a Ana teria de escrever "1 itens" ou um if … else com duas frases inteiras quase iguais.

Missão: o programa mostra Você tem 1 mensagens novas.. Use um ternário dentro do template para escrever mensagem nova quando for 1, e mensagens novas nos outros casos. Depois teste com 5.

const novas = 1;
console.log(`Você tem ${novas} mensagens novas.`);

const novas = 1;
console.log(`Você tem ${novas} ${novas === 1 ? "mensagem nova" : "mensagens novas"}.`);

4. Ternários em cadeia

A parte do "senão" pode ser outro ternário. É o equivalente ao else if. Os conceitos da escola da Ana:

const nota = 6;
const conceito =
  nota >= 9 ? "A" :
  nota >= 7 ? "B" :
  nota >= 5 ? "C" :
  "D";
console.log(`Conceito ${conceito}`);

$ node cadeia.js
Conceito C

Escrito assim, uma pergunta por linha, ainda dá para ler: "nota maior ou igual a 9? A. Senão, maior ou igual a 7? B…". Funciona exatamente como a cadeia de else if: a primeira condição verdadeira ganha. Mas, se você escrever tudo numa linha só, vira isto:

const nota = 6;
const conceito = nota >= 9 ? "A" : nota >= 7 ? "B" : nota >= 5 ? "C" : "D";
console.log(conceito);

$ node cadeia-linha.js
C

Funciona igual, mas é difícil de ler. Muitas equipes têm a regra: ternário em cadeia, só um por linha, ou nem isso. Com três caminhos ou mais, o if … else if costuma ser mais claro.

5. Ternário é para escolher valores, não para fazer coisas

Tecnicamente, dá para pôr ações nos dois lados:

const logado = true;
logado ? console.log("Bem-vinda de volta!") : console.log("Faça o login.");

$ node acao.js
Bem-vinda de volta!

Funciona, mas é um uso torto: o ternário existe para entregar um valor, e aqui o valor é jogado fora. Quando cada caminho faz algo (mostrar, mudar uma variável, salvar), use if … else. Ou, se as duas ações são iguais e só muda o texto, mova o ternário para dentro: console.log(logado ? "Bem-vinda de volta!" : "Faça o login.");.

Formas diferentes de fazer a mesma coisa

Mostrar o apelido, ou o nome quando não há apelido, tem três formas curtas:

const nome = "Beatriz";
const apelido = "";

console.log(apelido ? apelido : nome);
console.log(apelido || nome);
console.log(apelido ?? nome);

$ node formas.js
Beatriz
Beatriz
apelido ? apelido : nome
O ternário com truthy: o texto vazio é falsy, então vai o nome.
apelido || nome
O "ou" faz exatamente o mesmo, mais curto: dá o primeiro se ele for truthy, senão o segundo (veja Operadores Lógicos).
apelido ?? nome
O ?? só troca null e undefined. O "" não é nenhum dos dois, então ele ficou com o texto vazio: a terceira linha da saída está em branco. Aqui o ?? não era o que a Ana queria (veja ?. e ??).

Quando dá errado

Esqueceu os dois-pontos 
const nota = 8;
const situacao = nota >= 7 ? "Aprovada";
console.log(situacao);

$ node semdoispontos.js
/home/ana/semdoispontos.js:2
const situacao = nota >= 7 ? "Aprovada";
                                       ^

SyntaxError: Unexpected token ';'
    at wrapSafe (node:internal/modules/cjs/loader:1861:18)   « e mais 7 linhas at node:internal/…, cortadas aqui

Node.js v24.22.0

Linha por linha:

/home/ana/semdoispontos.js:2
O problema está na linha 2.
const situacao = nota >= 7 ? "Aprovada";
A linha 2, com a setinha embaixo do ;.
SyntaxError: Unexpected token ';'
"Ponto e vírgula inesperado". Depois do "Aprovada", o Node esperava o : com a segunda resposta, e encontrou o fim da instrução. O ternário sempre tem as duas respostas: não existe "ternário sem senão".

Como consertar: escreva o "senão": nota >= 7 ? "Aprovada" : "Reprovada". Se você realmente só quer fazer algo quando a condição é verdadeira, e nada senão, isso é um if sem else (aula if).

Instrução dentro do ternário 
const nota = 8;
nota >= 7 ? const situacao = "Aprovada" : const situacao = "Reprovada";

$ node constdentro.js
/home/ana/constdentro.js:2
nota >= 7 ? const situacao = "Aprovada" : const situacao = "Reprovada";
            ^^^^^

SyntaxError: Unexpected token 'const'
    at wrapSafe (node:internal/modules/cjs/loader:1861:18)   « e mais 7 linhas at node:internal/…, cortadas aqui

Node.js v24.22.0

"const inesperado". Os lados do ternário só aceitam expressões (coisas que têm valor); const, let, if e os laços são instruções e não cabem ali. Como consertar: o const vai do lado de fora, recebendo o valor do ternário: const situacao = nota >= 7 ? "Aprovada" : "Reprovada";.

A armadilha da precedência

Este não dá erro. A Ana quer mostrar se o pedido está pago:

const pago = false;
console.log("Pagamento: " + pago ? "confirmado" : "pendente");

$ node precedencia.js
confirmado

Saiu "confirmado" com pago igual a false, e sem o "Pagamento:" na frente! O + tem prioridade maior que o ? (veja Precedência dos Operadores). Então o Node primeiro juntou "Pagamento: " + pago, que deu o texto "Pagamento: false", e só depois perguntou: esse texto é truthy? É (texto não vazio), então entregou "confirmado". Como consertar: parênteses em volta do ternário: "Pagamento: " + (pago ? "confirmado" : "pendente"). Ou use um template string: `Pagamento: ${pago ? "confirmado" : "pendente"}`.

Missão: conserte a precedência para o programa mostrar Pagamento: pendente.

const pago = false;
console.log("Pagamento: " + pago ? "confirmado" : "pendente");

const pago = false;
console.log("Pagamento: " + (pago ? "confirmado" : "pendente"));

Missão final: o selo do produto

Missão: a vitrine da lojinha mostra um selo em cada produto: esgotado se o estoque for 0, últimas unidades se for menor que 5, e disponível nos outros casos. Troque o "?" por um ternário em cadeia, uma pergunta por linha. Com o estoque 3, deve aparecer Arroz: últimas unidades; depois teste com 0 e com 20.

const estoque = 3;
const selo = "?";
console.log(`Arroz: ${selo}`);

const estoque = 3;
const selo =
  estoque === 0 ? "esgotado" :
  estoque < 5 ? "últimas unidades" :

Resumo

  • condição ? valorSeSim : valorSeNão escolhe um entre dois valores. Leia: "condição? Se sim, isto; senão, aquilo".
  • O ternário é uma expressão (tem valor): cabe numa const, num console.log, dentro do ${ }. O if é uma instrução e não cabe nesses lugares.
  • Uso clássico: singular e plural, `${n === 1 ? "item" : "itens"}`.
  • Em cadeia, funciona como o else if; escreva uma pergunta por linha, ou volte ao if.
  • Para fazer ações, use if … else; o ternário é para valores.
  • Os dois lados são obrigatórios; instruções não cabem dentro; e com +, ponha parênteses em volta do ternário.
