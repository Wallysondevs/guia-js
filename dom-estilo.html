JavaScript Mudando o Estilo

Trocar o texto já faz muita coisa, mas a página também conversa pela aparência: o item esgotado fica cinza e riscado, o aviso importante fica em destaque, o menu aparece e some. Quem cuida da aparência é o CSS, e o JavaScript pode mexer nele de dois jeitos: mudando o estilo de um elemento direto (style) ou trocando as classes dele (classList). O segundo jeito é o que os profissionais usam quase sempre, e esta aula explica por quê.

Você vai aprender
  • Mudar a cor, o fundo e o tamanho com elemento.style, e os nomes das propriedades em camelCase.
  • Por que style.color pode vir vazio, e como ler o estilo de verdade com getComputedStyle.
  • As classes: classList.add, remove, toggle, contains e replace, e o antigo className.
  • Três jeitos de esconder e mostrar um elemento.
  • Quando usar style e quando usar classes.
  • Os erros reais: style.background-color, o número sem px, a classe com ponto e a classe com espaço.

As respostas do Console desta aula foram colhidas no Chromium da máquina da Ana, com a vitrine abaixo aberta. Se você ainda não conhece CSS, tudo bem: os poucos trechos de CSS da aula são explicados no caminho.

A ideia: pintar a parede ou trocar a etiqueta

Na vitrine da padaria, a Ana quer mostrar que a esfiha acabou. Ela tem dois jeitos:

  1. Pintar na hora: pega a etiqueta da esfiha e pinta de cinza, risca com caneta, diminui a letra. Funciona, mas se amanhã quiser outro jeito de mostrar "esgotado", terá de repintar cada etiqueta.
  2. Trocar a etiqueta: a padaria tem um modelo pronto de etiqueta "ESGOTADO" (cinza e riscada). Ela só pendura esse modelo. Para mudar o visual de todos os esgotados, basta mudar o modelo.

Pintar na hora é o style. O modelo pronto é uma classe do CSS, e pendurá-la é o classList.add.

Esta é a vitrine, com um arquivo de estilo, o estilo.css, que define os modelos (as classes):

<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="utf-8">
  <title>Vitrine da Padaria</title>
  <link rel="stylesheet" href="estilo.css">
</head>
<body>
  <h1 id="titulo">Vitrine da Padaria</h1>
  <p id="aviso" class="aviso">Fornada nova às 16h!</p>
  <ul>
    <li class="item">Coxinha</li>
    <li class="item esgotado">Esfiha</li>
    <li class="item">Pão de queijo</li>
  </ul>
</body>
</html>

.aviso {
  color: green;
}
.destaque {
  background-color: gold;
  font-weight: bold;
}
.esgotado {
  color: gray;
  text-decoration: line-through;
}
.escondido {
  display: none;
}

No CSS, .esgotado { … } quer dizer "todo elemento com a classe esgotado fica assim": cor cinza (color: gray) e riscado (text-decoration: line-through). O display: none da classe escondido faz o elemento sumir.

1. style: pintando na hora

Todo elemento tem a propriedade style, um objeto com uma propriedade para cada característica do CSS. A Ana digitou no Console:

> const titulo = document.querySelector("#titulo")
undefined
> titulo.style.color = "darkred"
'darkred'
> titulo.style.backgroundColor = "#fff3c4"
'#fff3c4'
> titulo.style.fontSize = "40px"
'40px'

O título ficou vermelho-escuro, com fundo amarelo-claro e letras maiores. No DOM, essas mudanças viraram o atributo style do elemento:

<h1 id="titulo" style="color: darkred; background-color: rgb(255, 243, 196); font-size: 40px;">Vitrine da Padaria</h1>
titulo.style.color = "darkred"
A cor do texto. O valor é um texto, igual ao que se escreveria no CSS: um nome de cor ("darkred"), um código ("#fff3c4") ou "rgb(…)".
style.backgroundColor
A cor de fundo. No CSS ela se chama background-color, com hífen; no JavaScript, o hífen some e a letra seguinte vira maiúscula: backgroundColor. É o camelCase, o mesmo jeito dos nomes de variáveis. (O navegador guardou o #fff3c4 como rgb(255, 243, 196): é a mesma cor escrita de outro jeito.)
style.fontSize = "40px"
O tamanho da letra (font-size). Medidas precisam da unidade junto, dentro do texto: "40px" (pixels), "2em", "150%".
No CSSNo JavaScript
colorstyle.color
background-colorstyle.backgroundColor
font-sizestyle.fontSize
font-weightstyle.fontWeight
text-decorationstyle.textDecoration
border-radiusstyle.borderRadius
displaystyle.display

Voltar ao normal

Para desfazer uma mudança do style, dê a ela um texto vazio:

> titulo.style.color = ""
''

A cor saiu do atributo (style="background-color: rgb(255, 243, 196); font-size: 40px;"), e o título voltou à cor que o CSS da página dá a ele.

Missão: com style, deixe o título com a cor darkred e o tamanho da letra em 40px.

2. Lendo o estilo de verdade: getComputedStyle

Uma pegadinha: o style só conhece o que está no atributo style do elemento. O aviso é verde, mas por causa da classe do arquivo estilo.css:

> const aviso = document.querySelector("#aviso")
undefined
> aviso.style.color
''
> getComputedStyle(aviso).color
'rgb(0, 128, 0)'
> getComputedStyle(aviso).fontSize
'16px'
aviso.style.color → ''
Vazio: ninguém pôs color no atributo style do aviso.
getComputedStyle(aviso)
"Pegar o estilo calculado": o resultado final, depois de juntar o CSS da página, as classes, o style e o padrão do navegador. É o que a tela mostra.
'rgb(0, 128, 0)'
O verde (green), escrito como o navegador guarda as cores: quanto de vermelho, verde e azul, de 0 a 255.
'16px'
O tamanho de letra padrão do navegador, que ninguém mudou.

Resumo: para mudar, use style (ou classes); para ler como está na tela, use getComputedStyle (que só lê: não dá para mudar por ele).

3. classList: trocando a etiqueta

Todo elemento tem a lista das suas classes, o classList, com métodos para mexer nela:

> aviso.classList.add("destaque")
undefined
> aviso.classList.contains("destaque")
true
> aviso.classList.remove("destaque")
undefined
> aviso.classList.contains("destaque")
false
classList.add("destaque")
"Adicionar": pendura a classe. O aviso ficou <p id="aviso" class="aviso destaque">: manteve a classe aviso e ganhou a destaque, com o fundo dourado e o negrito que o CSS define. Se a classe já estiver lá, nada acontece (não repete).
classList.contains("destaque")
"Contém?": true ou false.
classList.remove("destaque")
"Remover": tira só essa classe; as outras ficam.

O nome da classe vai sem o ponto: o ponto é do seletor (querySelector(".destaque")), não do nome.

toggle: liga e desliga

toggle ("alternar") põe a classe se ela não estiver lá, e tira se estiver. E devolve true se a classe ficou, false se saiu:

> aviso.classList.toggle("escondido")
true
> getComputedStyle(aviso).display
'none'
> aviso.classList.toggle("escondido")
false
> getComputedStyle(aviso).display
'block'

Na primeira vez, a classe escondido entrou e o aviso sumiu da tela (display: none); na segunda, saiu e ele voltou (block é o normal de um parágrafo). É o jeito clássico de um botão "mostrar/esconder" ou de um modo escuro: um toggle a cada clique.

replace e className

> const esfiha = document.querySelector(".esgotado")
undefined
> esfiha.classList.replace("esgotado", "destaque")
true
> esfiha.className
'item destaque'
> esfiha.className = "novo"
'novo'
classList.replace("esgotado", "destaque")
"Substituir": troca uma classe por outra (a esfiha voltou ao estoque e virou destaque). Devolve true se a primeira existia.
className
O jeito antigo: o atributo class inteiro, como um texto só, com as classes separadas por espaço.
className = "novo"
Substitui todas as classes: a esfiha ficou <li class="novo"> e perdeu a item. Por isso, para mexer numa classe só, prefira o classList.

Em vários elementos de uma vez

Junte com o querySelectorAll da aula Selecionando Elementos:

> document.querySelectorAll(".item").forEach((li) => li.classList.add("destaque"))
undefined

Os itens que ainda tinham a classe item (a coxinha e o pão de queijo) ganharam a classe destaque: <li class="item destaque">Coxinha</li>.

4. Esconder e mostrar

Esconder um elemento é tão comum que existem três jeitos:

JeitoEsconderMostrar
Classe do CSS (recomendado)el.classList.add("escondido")el.classList.remove("escondido") (ou um toggle para os dois)
style.displayel.style.display = "none"el.style.display = ""
Atributo hiddenel.hidden = trueel.hidden = false

O hidden ("escondido") é um atributo do próprio HTML: no lab, aviso.hidden = true pôs hidden="" na tag, e getComputedStyle(aviso).display deu 'none'. Cuidado com um detalhe: se o CSS da página der um display ao elemento (por exemplo, display: flex), o hidden perde a disputa e o elemento não some. A classe não tem esse problema se o seu CSS for escrito para ela.

Qual usar: style ou classes?

SituaçãoUsePor quê
Mudar a aparência para um estado (esgotado, selecionado, erro, escondido, modo escuro)classListO visual fica no CSS, num lugar só; o JavaScript só diz "está esgotado"

Quando dá errado

Escreveu o nome do CSS com hífen 
> titulo.style.background-color = "gold"
Uncaught SyntaxError: Invalid left-hand side in assignment

"Erro de sintaxe: lado esquerdo inválido na atribuição." Para o JavaScript, titulo.style.background - color é uma conta de menos entre titulo.style.background e uma variável color, e não dá para guardar um valor numa conta. Como consertar: use o nome em camelCase, style.backgroundColor, ou o nome do CSS entre colchetes e aspas: style["background-color"].

Esqueceu a unidade 
> titulo.style.fontSize = 20
20
> titulo.style.fontSize
'40px'

Nenhum erro, e nada mudou: o tamanho continuou 40px. O número 20 sozinho não é um valor válido para o CSS (20 o quê?), e o navegador simplesmente ignora valores inválidos. O mesmo acontece com um nome de cor errado. Como consertar: titulo.style.fontSize = "20px" (ou, com uma variável, `${tamanho}px`).

Pôs o ponto no nome da classe 
> aviso.classList.add(".destaque")
undefined

Nenhum erro, e nenhum destaque: o aviso ganhou uma classe chamada, literalmente, .destaque (com o ponto): <p id="aviso" class="aviso .destaque">. O CSS procura a classe destaque, sem ponto, e não acha. Como consertar: classList.add("destaque").

Duas classes num texto só 
> aviso.classList.add("destaque grande")
Uncaught InvalidCharacterError: Failed to execute 'add' on 'DOMTokenList': The token provided ('destaque grande') contains HTML space characters, which are not valid in tokens.
    at <anonymous>:1:17

"Falha ao executar o add na DOMTokenList (o tipo do classList): o nome 'destaque grande' contém espaços, que não valem em nomes." Um nome de classe não pode ter espaço. Como consertar: para pôr duas classes, passe dois valores separados: classList.add("destaque", "grande").

Mudou o CSS, mas o style "não vê"

aviso.style.color deu '', mas o aviso está verde na tela. Não é erro: a cor vem da classe, e o style só vê o atributo style (seção 2). Como consertar: leia com getComputedStyle(aviso).color, ou pergunte pela classe com classList.contains.

O className apagou as outras classes

Depois de esfiha.className = "novo", a esfiha perdeu a classe item (seção 3), e o visual que dependia dela sumiu. Como consertar: use classList.add("novo"), que mantém as outras.

Resumo

  • el.style.propriedade = "valor" muda a aparência direto no elemento. Os nomes do CSS com hífen viram camelCase (backgroundColor), e medidas levam a unidade ("40px"). Um texto vazio desfaz.
  • O style só enxerga o atributo style; para ler o estilo que aparece na tela, use getComputedStyle(el).
  • classList mexe nas classes: add, remove, toggle, contains, replace. O nome vai sem ponto e sem espaço.
  • Prefira classes: o visual fica no CSS, e o JavaScript só liga e desliga estados. Use style para valores calculados.
  • Esconder: classList.add("escondido"), style.display = "none" ou hidden = true.
  • Valores inválidos no style (número sem unidade, cor com nome errado) são ignorados sem aviso.
