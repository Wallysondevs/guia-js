JavaScript Classes

Na aula Objetos, cada produto da padaria era escrito à mão: { nome: "sonho", preco: 3.5 }. Para três produtos, tudo bem. Para trezentos, com os mesmos campos e as mesmas funções em todos, escrever um por um é pedir para errar. A classe é um molde: você descreve uma vez como é um produto e o que ele sabe fazer, e depois cria quantos quiser com new. Classes existem no JavaScript desde 2015 (ES6) e funcionam igual no Node e no navegador.

Você vai aprender
  • A ideia de molde (a classe) e de objetos feitos com ele (as instâncias).
  • Como escrever uma classe: class, constructor, this e os métodos.
  • Como criar objetos com new e por que cada um tem os seus próprios dados.
  • Os campos de classe (estoque = 0;) e os métodos que mudam o objeto.
  • Como conferir de que classe é um objeto com instanceof.
  • Os outros jeitos de fazer o mesmo (a função fábrica e a função construtora antiga) e quando usar cada um.
  • Os erros reais: esquecer o new, usar a classe antes de criá-la, esquecer o this, a vírgula entre métodos, o this perdido.

Todos os programas rodaram no Node.js v24.22.0 da máquina da Ana (usuária ana, computador notebook), na pasta /home/ana/classes.

A ideia: a forma de bolo

A padaria tem uma forma de bolo. A forma não é um bolo: ninguém come a forma. Ela é o molde que diz o formato. Com ela, a Ana faz um bolo de chocolate, um de fubá, um de cenoura: todos com o mesmo formato, cada um com o seu sabor. Comer o de fubá não mexe no de chocolate.

1. A primeira classe

class Produto {
  constructor(nome, preco) {
    this.nome = nome;
    this.preco = preco;
  }

  descricao() {
    return `${this.nome}: R$ ${this.preco.toFixed(2)}`;
  }
}

const sonho = new Produto("sonho", 3.5);
const broa = new Produto("broa", 2);

console.log(sonho);
console.log(broa.nome);
console.log(sonho.descricao());
console.log(broa.descricao());
class Produto { … }
Cria a classe (o molde) chamada Produto. Por tradição, nomes de classe começam com letra maiúscula (Produto, ContaBancaria), para não confundir com variáveis comuns (produto).
constructor(nome, preco) { … }
O construtor: uma função especial que roda uma vez, sozinha, cada vez que alguém faz new Produto(…). Os parâmetros recebem o que foi passado entre parênteses. É ali que o objeto novo ganha os seus dados.
this.nome = nome;
this ("este") é o objeto que está sendo criado. A linha quer dizer: "este produto novo ganha a propriedade nome, com o valor do parâmetro nome". Os dois nomes iguais são só costume: o da esquerda é a propriedade do objeto; o da direita, o parâmetro.
descricao() { … }
Um método: uma função que mora dentro da classe. Escreve-se sem a palavra function e sem vírgula entre um método e outro. Dentro dele, this é o objeto que chamou o método (sonho.descricao() → this é o sonho).
new Produto("sonho", 3.5)
new ("novo") cria um objeto vazio, roda o constructor com ele como this e devolve o objeto pronto. É a "forma indo ao forno".
sonho.descricao()
Chama o método no objeto sonho, com ponto e parênteses, como os métodos que você já conhece (texto.toUpperCase()).
$ node produto.js
Produto { nome: 'sonho', preco: 3.5 }
broa
sonho: R$ 3.50
broa: R$ 2.00

Repare na primeira linha: o Node mostra o nome da classe antes das chaves, Produto { … }. É assim que você sabe que o objeto foi feito por um molde, e qual. O método descricao não aparece ali: ele fica guardado na classe, não em cada objeto (você vai ver onde em Protótipos).

Por dentro, uma classe é um tipo especial de função (a que monta objetos). O console.log mostra [class Produto] para deixar claro que é uma classe.

3. Métodos que mudam o objeto, e campos de classe

Um produto da padaria tem estoque, que começa em zero, sobe quando chega mercadoria e desce quando se vende. Os métodos podem mudar as propriedades do próprio objeto pelo this:

class Produto {
  estoque = 0;

  constructor(nome, preco) {
    this.nome = nome;
    this.preco = preco;
  }

  repor(quantidade) {
    this.estoque += quantidade;
    console.log(`Chegaram ${quantidade} ${this.nome}(s). Estoque: ${this.estoque}`);
  }

  vender(quantidade) {
    if (quantidade > this.estoque) {
      console.log(`Não dá: só há ${this.estoque} ${this.nome}(s).`);
      return 0;
    }
    this.estoque -= quantidade;
    const total = quantidade * this.preco;
    console.log(`Vendi ${quantidade} ${this.nome}(s) por R$ ${total.toFixed(2)}. Estoque: ${this.estoque}`);
    return total;
  }
}

const sonho = new Produto("sonho", 3.5);
console.log(sonho);
sonho.repor(10);
sonho.vender(4);
sonho.vender(8);
console.log(sonho);
estoque = 0;
Um campo de classe ES2022: toda instância nasce com estoque valendo 0, sem precisar passar nada no new. Fica fora do constructor, sem this e sem let/const. Use para valores iniciais que são iguais para todos.
repor(quantidade)
Soma ao this.estoque deste produto.
vender(quantidade)
Confere se há o bastante, desconta e devolve (return) o valor da venda. Um método pode mudar o objeto e também devolver um valor.
$ node estoque.js
Produto { estoque: 0, nome: 'sonho', preco: 3.5 }
Chegaram 10 sonho(s). Estoque: 10
Vendi 4 sonho(s) por R$ 14.00. Estoque: 6
Não dá: só há 6 sonho(s).
Produto { estoque: 6, nome: 'sonho', preco: 3.5 }

O estoque aparece antes do nome: os campos de classe são criados antes de o constructor rodar. O objeto guardou o estado entre uma chamada e outra: 10, depois 6, e a venda de 8 foi recusada.

Dados e comportamento juntos

É essa a vantagem de uma classe: o estoque e as regras para mexer nele (repor, vender) moram juntos. Quem usa o produto chama sonho.vender(4) e não precisa lembrar de conferir o estoque antes. Nas próximas aulas você vai proteger ainda mais esses dados com get e set e campos privados (#).

Formas diferentes de fazer

Classes não são o único jeito de fabricar objetos parecidos. Você vai encontrar mais dois em código por aí.

A função fábrica

Uma função comum que devolve um objeto (veja Métodos e this):

function criarProduto(nome, preco) {
  return {
    nome,
    preco,
    descricao() {
      return `${this.nome}: R$ ${this.preco.toFixed(2)}`;
    },
  };
}

const sonho = criarProduto("sonho", 3.5);
console.log(sonho);
console.log(sonho.descricao());

$ node fabrica.js
{ nome: 'sonho', preco: 3.5, descricao: [Function: descricao] }
sonho: R$ 3.50

Funciona, sem new. Mas repare: o objeto não tem nome de classe, cada um carrega a sua própria cópia do método descricao (ela aparece dentro das chaves), e instanceof não serve para nada aqui.

A função construtora (o jeito antigo)

Antes de 2015 não existia class. O mesmo molde se escrevia com uma function e o prototype:

function Produto(nome, preco) {
  this.nome = nome;
  this.preco = preco;
}
Produto.prototype.descricao = function () {
  return `${this.nome}: R$ ${this.preco.toFixed(2)}`;
};

const sonho = new Produto("sonho", 3.5);
console.log(sonho);
console.log(sonho.descricao());

$ node antigo.js
Produto { nome: 'sonho', preco: 3.5 }
sonho: R$ 3.50

O resultado é o mesmo da classe: a class é, por baixo, um jeito mais claro de escrever isto (os detalhes estão em Protótipos). Reconheça em código antigo, mas escreva com class.

JeitoQuando usar
Objeto literal { … }Um objeto só, ou dados simples (vindos de um JSON, por exemplo)
Função fábricaObjetos simples, sem precisar de instanceof nem de herança
classMuitos objetos com os mesmos dados e comportamentos; quando haverá herança (extends), campos privados, static. O jeito moderno.
Função construtora + prototypeSó para ler código antigo

O this de um método é "quem está antes do ponto" na hora da chamada. Em funcao() não há ponto nem objeto, e dentro de uma classe o this fica undefined. class Comanda {
  constructor(cliente) {
    this.cliente = cliente;
    this.itens = [];
  }

  adicionar(nome, preco) {
    this.itens.push({ nome, preco });
  }

    let soma = 0;
    for (const item of this.itens) {
      soma += item.preco;
    }
    return soma;
  }
}

comanda.adicionar("café", 6);
console.log(`Comanda da ${comanda.cliente}: R$ ${comanda.total().toFixed(2)}`);

No lab, a solução mostrou Comanda da Bia: R$ 9.50. Rodando o código inicial, sem os métodos, o erro é TypeError: comanda.adicionar is not a function: o objeto não tem esse método.

Resumo

  • Uma classe é um molde; new Classe(…) cria uma instância (um objeto feito com ele). Nome de classe começa com maiúscula.
  • O constructor roda em cada new e guarda os dados no objeto com this.propriedade = valor. Campos de classe (estoque = 0;) dão valores iniciais.
  • Métodos são funções da classe, escritas sem function e sem vírgula entre elas. Dentro deles, this é o objeto que chamou.
  • Cada instância tem os seus próprios dados; os métodos são um só, compartilhados. instanceof diz de que classe é um objeto.
  • Erros comuns: sem new (cannot be invoked without 'new'), classe usada antes de criada (before initialization), sem this (is not defined), vírgula entre métodos, método separado do objeto (this undefined).
  • Próximos passos: get e set, herança, static e campos privados.
