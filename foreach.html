JavaScript forEach

Na aula for … of, você percorreu um array com um laço. Os arrays também têm um método que faz isso por você: o forEach (em inglês, "para cada"). Em vez de escrever o laço, você entrega ao array uma função dizendo o que fazer com um item, e ele mesmo chama essa função para cada um dos seus itens. É o primeiro de uma família de métodos que trabalham assim (map, filter, reduce), e entender o forEach é o caminho para entender todos.

Você vai aprender
  • Como se escreve um forEach com uma arrow function, e o que é cada parte.
  • Os três valores que a função recebe: o item, a posição e o array.
  • A passar uma função que já tem nome, em vez de escrever uma ali.
  • A somar e contar com forEach.
  • Por que o forEach devolve undefined, não para com break, e o que o return faz dentro dele.
  • A pegadinha do forEach(console.log).
  • Quando usar forEach e quando usar for … of.
  • Os erros reais mais comuns: Illegal break statement, undefined is not a function, forEach is not a function.

Todos os programas desta aula rodaram no Node.js 24 da máquina da Ana (usuária ana, computador notebook), com node arquivo.js. Você pode rodar cada um no editor do guia.

A ideia: o bilhete de instruções

A Ana vai viajar e deixa as plantas aos cuidados da vizinha. Ela poderia escrever: "regue a samambaia; depois regue a violeta; depois regue a orquídea…". Em vez disso, entrega a lista das plantas e um bilhete só: "Para cada planta da lista: regue com um copo d'água". A vizinha pega o bilhete e repete as instruções para cada planta, uma de cada vez.

No forEach, a lista é o array, e o bilhete é uma função. O array "lê" o bilhete uma vez para cada item, entregando o item da vez. Uma função entregue a outra para ser chamada depois se chama callback (em inglês, "chamar de volta"); você já usou uma no find, e o assunto tem aula própria: Funções como Valores.

1. O primeiro forEach

const plantas = ["samambaia", "violeta", "orquídea"];

plantas.forEach((planta) => {
  console.log(`Regando a ${planta}...`);
});
console.log("Todas regadas!");
plantas.forEach( … )
"Para cada item de plantas…". O forEach é um método do array, como o push; entre os parênteses vai a função.
(planta) => { … }
Uma arrow function: o "bilhete". O planta é o parâmetro (veja Parâmetros): a cada chamada, o forEach põe nele o item da vez. Como no for … of, o costume é usar o singular do nome do array.
console.log(`Regando a ${planta}...`);
O corpo da função: o que fazer com cada item.
});
Atenção à ordem dos fechamentos: } fecha a função, ) fecha os parênteses do forEach, e ; encerra a instrução. Esquecer um deles é o erro de digitação mais comum com forEach.
$ node plantas.js
Regando a samambaia...
Regando a violeta...
Regando a orquídea...
Todas regadas!

A função rodou 3 vezes, uma por planta, na ordem do array. Só depois que o forEach terminou de passar por todas é que o Todas regadas! apareceu.

A forma curta

Quando o corpo tem uma linha só, dá para tirar as chaves (e, com um parâmetro só, até os parênteses dele), como você viu em Arrow Functions:

const plantas = ["samambaia", "violeta", "orquídea"];
plantas.forEach((planta) => console.log(`Regando a ${planta}...`));
plantas.forEach(planta => console.log(planta.toUpperCase()));

$ node curta.js

Regando a violeta...
Regando a orquídea...

VIOLETA
ORQUÍDEA

Neste guia, os parênteses em volta do parâmetro ficam sempre: (planta) =>. É o que os formatadores de código mais usados fazem, e fica mais fácil de acrescentar um segundo parâmetro depois, como na próxima seção.

2. O item, a posição e o array

O forEach entrega três valores a cada chamada, nesta ordem: o item, a posição dele e o próprio array. Você recebe só os que quiser, escrevendo mais parâmetros:

const alunos = ["Ana", "Bia", "Caio"];

alunos.forEach((aluno, i) => {
  console.log(`${i + 1}. ${aluno}`);
});

alunos.forEach((aluno, i, lista) => {
  console.log(`${aluno} é ${i + 1}º de ${lista.length}`);
});
(aluno, i)
O primeiro parâmetro recebe o item; o segundo, a posição (começando do 0). Os nomes são escolha sua; i (de "índice") é o tradicional. O que manda é a ordem: o primeiro é sempre o item, o segundo sempre a posição.
(aluno, i, lista)
O terceiro recebe o array inteiro. É raro precisar dele, já que o array está ali mesmo na variável alunos.
$ node tres.js
1. Ana
2. Bia
3. Caio
Ana é 1º de 3
Bia é 2º de 3
Caio é 3º de 3

Essa é uma vantagem do forEach sobre o for … of: a posição vem de graça, sem o entries().

3. Uma função que já tem nome

O bilhete não precisa ser escrito ali na hora. Se você já tem uma função pronta (veja Funções), entregue o nome dela, sem parênteses:

function regar(planta) {
  console.log(`Regando a ${planta} com um copo d'água.`);
}

const plantas = ["samambaia", "violeta", "orquídea"];
plantas.forEach(regar);

$ node nomeada.js
Regando a samambaia com um copo d'água.
Regando a violeta com um copo d'água.
Regando a orquídea com um copo d'água.

Repare: forEach(regar), e não forEach(regar()). Sem os parênteses, você entrega a função para o forEach chamar depois. Com os parênteses, você mesmo a chamaria na hora (uma vez só, sem planta nenhuma) e entregaria o resultado dela ao forEach, o que dá erro (veja Quando dá errado).

4. Somar e contar com forEach

Como no for … of, uma variável criada antes pode ir acumulando. A função de dentro enxerga as variáveis de fora:

const vendas = [120, 98, 143, 110, 87];
let total = 0;
let diasBons = 0;

vendas.forEach((venda) => {
  total += venda;
  if (venda >= 110) {
    diasBons++;
  }
});

console.log(`Total da semana: ${total} pães`);
console.log(`Dias com 110 ou mais: ${diasBons}`);

$ node soma.js
Total da semana: 558 pães
Dias com 110 ou mais: 3

Funciona, mas para somar existe um método feito sob medida, o reduce, e para contar os que obedecem a uma regra, o filter com length. O forEach é o mais genérico: ele só "faz alguma coisa" com cada item.

Missão: some os preços dos pães com forEach.

const precos = [2.5, 8, 4, 13];
let total = 0;
// some com forEach aqui

console.log(`Total: R$ ${total}`);

const precos = [2.5, 8, 4, 13];
let total = 0;
// some com forEach aqui
precos.forEach((preco) => {
  total += preco;
});
console.log(`Total: R$ ${total}`);

5. O que o forEach não faz

Ele devolve undefined

O forEach só "faz": ele não monta nenhum resultado. O que ele devolve é sempre undefined, mesmo que a função de dentro tenha return:

const notas = [7, 8, 6];
const resultado = notas.forEach((nota) => nota + 1);
console.log(resultado);
console.log(notas);

$ node devolve.js
undefined
[ 7, 8, 6 ]

Se você quer um array novo com os resultados (cada nota mais 1), o método certo é o map, da próxima aula.

Ele não para no meio

O forEach sempre passa por todos os itens. Não existe break para ele (o Node recusa o programa, como você vai ver em Quando dá errado). E um return dentro da função só termina aquela chamada: o forEach segue com o próximo item, como um continue:

const pedidos = ["pão", "", "café", "FIM", "bolo"];

pedidos.forEach((pedido) => {
  if (pedido === "" || pedido === "FIM") {
    return;
  }
  console.log(`Separando: ${pedido}`);
});

$ node return.js
Separando: pão
Separando: café
Separando: bolo

O return no "FIM" não parou nada: o bolo foi separado do mesmo jeito. Se você precisa parar no meio, use o for … of com break, ou um método que para sozinho quando acha o que procura (find, some).

6. A pegadinha do forEach(console.log)

Já que dá para passar uma função pelo nome, que tal passar o próprio console.log? Parece uma ótima ideia:

const frutas = ["maçã", "uva"];
frutas.forEach(console.log);

$ node pegadinha.js
maçã 0 [ 'maçã', 'uva' ]
uva 1 [ 'maçã', 'uva' ]

Lembra dos três valores da seção 2? O forEach chamou console.log(item, posição, array), e o console.log mostra tudo o que recebe. Para mostrar só o item, escreva a função: frutas.forEach((fruta) => console.log(fruta));.

Formas diferentes: forEach ou for … of?

Os dois percorrem o array inteiro, na ordem. O resultado é o mesmo:

const alunos = ["Ana", "Bia", "Caio"];

alunos.forEach((aluno, i) => {
  console.log(`${i}: ${aluno}`);
});

for (const [i, aluno] of alunos.entries()) {
  console.log(`${i}: ${aluno}`);
}

$ node formas.js
0: Ana
1: Bia
2: Caio
0: Ana
1: Bia
2: Caio
SituaçãoQual usar
Fazer algo com cada item, já tendo uma função prontalista.forEach(funcao)
Precisar da posição sem complicarforEach((item, i) => …)
Parar no meio (break)for … of (o forEach não para)
Percorrer uma string ou outro iterável que não é arrayfor … of (strings não têm forEach)
Usar await dentro do laço (aula async e await)for … of
Montar um array novo transformadomap (não forEach + push)
Montar um array com só alguns itensfilter
Somar tudo num valor sóreduce (ou um for … of com acumulador)

Na dúvida entre os dois, muitas equipes preferem o for … of pelo break e pelo await. O forEach brilha quando a função já existe e tem um bom nome: pedidos.forEach(imprimirEtiqueta) se lê quase como português.

Missão: a função imprimirEtiqueta já está pronta, mas ainda falta o número. (1) Faça a função receber também a posição (segundo parâmetro) e mostrar #1 Pão francês ... R$ 0.9 (a posição + 1). (2) Entregue a função ao forEach pelo nome. (3) Mostre quantas etiquetas foram impressas usando o length.

const produtos = ["Pão francês", "Pão de queijo", "Sonho", "Bolo de fubá"];
const precos = [0.9, 4, 6.5, 12];

function imprimirEtiqueta(produto) {
  console.log(`${produto}`);
}

// (2) e (3) aqui

const produtos = ["Pão francês", "Pão de queijo", "Sonho", "Bolo de fubá"];
const precos = [0.9, 4, 6.5, 12];

function imprimirEtiqueta(produto, i) {
  console.log(`#${i + 1} ${produto} ... R$ ${precos[i]}`);
}

// (2) e (3) aqui
produtos.forEach(imprimirEtiqueta);
console.log(`Etiquetas impressas: ${produtos.length}`);

No lab, a solução mostrou as quatro etiquetas, de #1 Pão francês ... R$ 0.9 até #4 Bolo de fubá ... R$ 12, e Etiquetas impressas: 4. Repare no truque: a posição i serve para pegar, no outro array, o preço do mesmo produto.

Resumo

  • lista.forEach(funcao) chama a função uma vez para cada item, na ordem. A função entregue é um callback.
  • A função recebe (item, posição, array); use só os que precisar, na ordem.
  • Dá para escrever uma arrow function ali ou entregar uma função pelo nome, sem parênteses.
  • O forEach devolve sempre undefined. Para um array novo, use map; para filtrar, filter.
  • Ele não para: break dá erro de sintaxe e return só pula o item. Para parar no meio, use for … of.
  • Strings não têm forEach; forEach(console.log) mostra item, posição e array.
