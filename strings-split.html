JavaScript Dividindo e Juntando (split e join)

A Ana anotou a lista de compras num texto só: "pão, leite, café, manteiga". Para contar os itens, mostrar um por linha ou riscar o que já comprou, ela precisa separar esse texto em pedaços. E, no caminho de volta, juntar pedaços num texto só. O split ("dividir") quebra um texto num array (uma lista) de pedaços, e o join ("juntar") faz o contrário.

Você vai aprender
  • texto.split(separador): quebrar um texto onde aparece o separador, e o array que ele devolve.
  • Receitas: contar palavras, separar uma linha de planilha (CSV), pegar as letras uma a uma.
  • lista.join(separador): juntar os pedaços com vírgula, traço, quebra de linha ou nada.
  • Os dois juntos: inverter uma palavra e trocar a data de 19/10/2026 para 2026-10-19.
  • Os erros reais: join num texto, split numa lista, os espaços que sobram e os pedaços vazios.

Todos os programas desta aula rodaram no Node.js 24 da máquina da Ana (usuária ana, computador notebook), com node arquivo.js. Você pode rodar cada um no editor do guia.

A ideia: picotar a tira de papel

A lista de compras está escrita numa tira de papel comprida: pão, leite, café, manteiga. A Ana pega a tesoura e corta em cada vírgula. Sobram quatro papeizinhos, cada um com um item, e as vírgulas vão para o lixo. Isso é o split(",").

Depois, ela pode colar os papeizinhos de volta numa tira só, pondo entre eles o que quiser: um traço, uma barra, nada. Isso é o join.

Os papeizinhos soltos, em ordem, formam um array: uma lista de valores numa variável só. Os arrays têm um grupo inteiro de aulas, a partir de Arrays; aqui você só precisa de três coisas: o Node mostra um array entre colchetes ([ 'pão', 'leite' ]), cada item tem uma posição começando do 0 (lista[0]), e lista.length diz quantos itens há.

O separador é o texto exato

Quando a lista vem escrita "como gente escreve", com espaço depois da vírgula, o separador tem de incluir o espaço:

const lista = "pão, leite, café";

console.log(lista.split(","));
console.log(lista.split(", "));
console.log(lista.split(";"));

$ node separador.js
[ 'pão', ' leite', ' café' ]
[ 'pão', 'leite', 'café' ]
[ 'pão, leite, café' ]
  • Com split(","), o espaço depois de cada vírgula ficou grudado no item seguinte: ' leite'.
  • Com split(", ") (vírgula e espaço), os itens saem limpos.
  • Com um separador que não aparece no texto (";"), não há onde cortar: sai um array com um item, o texto inteiro.

Uma linha de planilha (CSV)

Planilhas salvas como texto (o formato CSV) guardam cada linha com os campos separados por vírgula ou ponto e vírgula. O split separa os campos:

const linha = "Ana Souza;30;Recife;ana@email.com";
const campos = linha.split(";");

console.log("Nome:", campos[0]);
console.log("Idade:", Number(campos[1]));
console.log("Cidade:", campos[2]);

$ node csv.js
Nome: Ana Souza
Idade: 30
Cidade: Recife

Tudo o que o split devolve é texto, inclusive o "30". Para fazer conta com a idade, converta com Number() (veja Conversão). Em Desestruturação você vai ver um jeito de pôr cada campo direto numa variável com nome: const [nome, idade, cidade] = linha.split(";");.

3. join: de uma lista para um texto

O join é um método das listas (arrays), não dos textos. Ele cola os itens numa string só, pondo o separador entre eles:

const itens = ["pão", "leite", "café"];

console.log(itens.join(", "));
console.log(itens.join(" - "));
console.log(itens.join(""));
console.log(itens.join());
console.log(itens.join("\n"));

$ node juntar.js

["pão", "leite", "café"]
Um array escrito direto no código: itens entre colchetes, separados por vírgula.
join(", ")
Cola com vírgula e espaço: o jeito de escrever uma lista para gente ler.
join("")
Cola sem nada entre os itens.
join()
Sem separador, o join usa a vírgula sem espaço. É o mesmo que você viu ao pôr um array num template string (aula Template Strings).
join("\n")
Com a quebra de linha (veja Caracteres Especiais), um item por linha.

O separador vai só entre os itens: não aparece antes do primeiro nem depois do último. Se você quer um tracinho na frente de cada item, ponha-o também no começo: "- " + itens.join("\n- ").

4. Os dois juntos

O poder de verdade aparece quando você divide, mexe na lista e junta de novo. Dois exemplos clássicos:

const palavra = "padaria";
const invertida = palavra.split("").reverse().join("");
console.log(invertida);

const data = "19/10/2026";
const partes = data.split("/");
console.log(partes);
console.log(partes.reverse().join("-"));

const telefone = "81 99999 0000";
console.log(telefone.split(" ").join(""));

$ node juntos.js
airadap

2026-10-19

split("").reverse().join("")
Quebra em letras, inverte a ordem da lista (o reverse, "inverter", é um método de array) e cola sem nada entre elas. Tudo encadeado, como em Métodos de String.
data.split("/") … reverse().join("-")
Dia, mês e ano viram uma lista; invertida, fica ano, mês, dia; colada com hífen, é o formato 2026-10-19, usado por bancos de dados e planilhas.
split(" ").join("")
Tirar todos os espaços: corta em cada espaço e cola sem nada. Funciona, mas a aula Substituindo mostra o jeito direto: replaceAll(" ", "").

Formas diferentes de fazer a mesma coisa

Para transformar um texto numa lista de caracteres há dois jeitos, e eles não são iguais quando o texto tem emoji:

const texto = "bolo🎂";

console.log(texto.split(""));
console.log([...texto]);
console.log(texto.length, [...texto].length);

$ node formas.js
[ 'b', 'o', 'l', 'o', '\ud83c', '\udf82' ]
[ 'b', 'o', 'l', 'o', '🎂' ]
6 5

O bolo de aniversário virou dois pedaços estranhos no split(""): '\ud83c' e '\udf82'. Por dentro, o JavaScript guarda os textos em unidades de 16 bits, e um emoji ocupa duas delas. O split("") e o .length contam essas unidades (por isso "bolo🎂".length é 6); o [...texto] (o "espalhar", aula Spread e Rest) separa por caractere de verdade e conta 5. Para textos só com letras, acentos e números, os dois dão o mesmo resultado.

Lista de caracteres (sem emojis)texto.split("")
Lista de caracteres (com emojis)[...texto]
Juntar uma lista num textolista.join(separador)

Espaços duplos e pedaços vazios 
console.log("o  pão".split(" "));
console.log("pão,leite,".split(","));
console.log("".split(","));
console.log("".split(",").length);

$ node vazios.js
[ 'o', '', 'pão' ]
[ 'pão', 'leite', '' ]
[ '' ]
1

Nenhum erro, mas pedaços vazios ('') apareceram na lista:

  • Entre dois espaços seguidos não há nada, e esse "nada" vira um item: "o pão" parece ter 3 palavras.
  • Uma vírgula no fim do texto cria um último item vazio.
  • Um texto vazio vira uma lista com um item vazio, e o .length dá 1, não 0.

Como consertar: arrume o texto antes (trim() tira os espaços das pontas), e, para jogar fora os itens vazios, use o filter (aula filter): texto.split(",").filter((item) => item !== "").

Resumo

  • texto.split(separador) corta o texto em cada separador e devolve um array de pedaços (textos); o separador some. O original não muda.
  • O separador é o texto exato: split(", ") para "vírgula e espaço". Se ele não aparece, sai um array com o texto inteiro.
  • split("") dá as letras; split(sep, n) só os n primeiros pedaços.
  • lista.join(separador) cola os itens num texto, com o separador só entre eles (sem argumento, vírgula).
  • Juntos: split("").reverse().join("") inverte; split("/").reverse().join("-") troca o formato da data.
  • Erros comuns: join num texto ou split numa lista (is not a function), espaços que sobram, itens vazios com separadores seguidos ou no fim.
