JavaScript Precedência dos Operadores

Quanto é 2 + 3 * 4? Se você fizer da esquerda para a direita, dá 20. O JavaScript responde 14, porque faz a multiplicação primeiro, como você aprendeu na escola. Essa regra de "quem vem primeiro" se chama precedência (do latim, "ir na frente"). Nesta aula você vê a ordem completa que o JavaScript segue numa expressão com vários operadores: contas, comparações e os operadores lógicos das aulas anteriores.

Você vai aprender
  • O que é precedência e por que 2 + 3 * 4 dá 14.
  • A tabela de prioridades: parênteses, !, **, * / %, + -, comparações, &&, || e, por último, o =.
  • O que acontece quando dois operadores têm a mesma prioridade (da esquerda para a direita, com duas exceções: ** e =).
  • Como usar parênteses para mandar na ordem, e quando eles são obrigatórios.
  • As pegadinhas reais: a média calculada errado, o "Total: " + 2 + 3, o !idade >= 18, o -2 ** 2 e o ?? misturado com ||.

A ideia: a fila do caixa preferencial

Na padaria do bairro, todo mundo entra na fila na ordem em que chegou, mas idosos e gestantes têm preferência: são atendidos antes, mesmo tendo chegado depois. Entre duas pessoas do mesmo grupo, vale a ordem de chegada.

Uma expressão como 2 + 3 * 4 é uma fila de operadores, e o JavaScript é o caixa:

  1. Ele olha a fila inteira e atende primeiro quem tem mais prioridade: o * vem antes do +. Então 3 * 4 vira 12.
  2. Sobra 2 + 12, que vira 14.
  3. Entre dois operadores com a mesma prioridade (como + e -), vale a ordem de chegada: da esquerda para a direita.
  4. Os parênteses são o "fura-fila" oficial: o que está dentro deles é sempre feito antes.

2. A tabela completa (a que importa)

As contas são só uma parte. Numa expressão como preco * 2 > 50 && temCupom há contas, comparação e lógica juntas. A tabela mostra a ordem, de cima (feito primeiro) para baixo (feito por último):

Você não precisa decorar a tabela. Repare só na lógica dela, que é a ordem natural de uma pergunta:

  1. Calcula os valores (contas);
  2. compara os resultados (>, ===), o que dá true/false;
  3. junta as respostas (&& antes do ||);
  4. e só no fim guarda o resultado na variável (=).

É por isso que nota >= 0 && nota <= 10, da aula Operadores Lógicos, funciona sem parênteses: as comparações são feitas antes do &&. Veja uma expressão grande sendo resolvida:

const preco = 30;
const temCupom = true;
const ganhaBrinde = preco * 2 > 50 && temCupom;
console.log("Ganha brinde?", ganhaBrinde);
console.log(1 + 2 === 3);

3. && antes de ||

Este é o ponto da tabela que mais confunde. O && tem prioridade maior que o ||, do mesmo jeito que o * tem prioridade maior que o +. No parque, a montanha-russa aceita quem tem 12 anos ou mais ou quem está com um adulto, e em qualquer caso exige 1,40 m:

const idade = 15;
const comAdulto = false;
const altura = 1.2;

const errado = idade >= 12 || comAdulto && altura >= 1.4;
const certo = (idade >= 12 || comAdulto) && altura >= 1.4;
console.log("Sem parênteses:", errado);
console.log("Com parênteses:", certo);

$ node parque.js
Sem parênteses: true
Com parênteses: false

O menino tem 15 anos mas só 1,20 m: não pode entrar. Sem parênteses, o JavaScript leu idade >= 12 || (comAdulto && altura >= 1.4), isto é, "tem 12 anos, ou então está com adulto e tem altura". Como ele tem 15 anos, entrou, sem ninguém medir a altura. Com os parênteses, a exigência de altura vale para todo mundo.

A regra prática

Misturou && com || na mesma expressão? Ponha parênteses, mesmo quando a ordem natural já é a que você quer. Quem ler o código depois (inclusive você) não vai precisar lembrar da tabela.

4. Mesma prioridade: esquerda ou direita?

Quase todos os operadores de mesma prioridade são feitos da esquerda para a direita, como você viu em 10 - 4 - 3. Duas exceções importantes vão da direita para a esquerda:

console.log(2 ** 3 ** 2);
console.log((2 ** 3) ** 2);

let a;
let b;
a = b = 5;
console.log(a, b);

A potência começa pela direita: primeiro 3 ** 2 = 9, depois 2 ** 9 = 512. É a mesma convenção da matemática para "torre de expoentes". Se quiser o outro jeito, parênteses: (2 ** 3) ** 2 = 8² = 64.
a = b = 5
A atribuição também começa pela direita: primeiro b = 5, e o resultado disso (o próprio 5) vai para a. Funciona, mas encadear atribuições deixa o código difícil de ler; prefira uma linha para cada variável.

Formas diferentes de fazer a mesma coisa

Quando uma expressão fica comprida, há três jeitos de escrevê-la. Os três dão o mesmo resultado; mudam na facilidade de ler.

const preco = 12;
const quantidade = 3;
const frete = 10;

// 1. Confiando na tabela de prioridades
const total1 = preco * quantidade + frete;

// 2. Com parênteses "de enfeite", que deixam a ordem visível
const total2 = (preco * quantidade) + frete;

// 3. Em partes, com nomes
const subtotal = preco * quantidade;
const total3 = subtotal + frete;

console.log(total1, total2, total3);

Quando dá errado

O ! pegou só a variável: !idade >= 18 
const idade = 20;
console.log(!idade >= 18);
console.log(!(idade >= 18));

$ node nao.js
false
false

A Ana queria perguntar "a idade não é 18 ou mais?". As duas linhas deram false, mas por motivos diferentes, e a primeira está errada por acaso. O ! tem prioridade alta (2ª da tabela), então a primeira linha fez !idade primeiro: !20 é false. Depois comparou false >= 18; o false vira 0, e 0 >= 18 é false. Com idade = 10, a primeira linha continuaria dando false (e a certa, true): a primeira linha dá false para qualquer idade diferente de zero. Como consertar: !(idade >= 18), ou, mais simples, idade < 18.

"Erro de sintaxe: símbolo inesperado ||", com as setinhas embaixo dele. O ?? (o "use isto se o outro faltar", da aula ?. e ??) e o || são parecidos demais, e os criadores da linguagem acharam melhor proibir misturá-los sem parênteses do que deixar cada um adivinhar a ordem. O mesmo vale para ?? com &&. Como consertar: diga o que vai junto: (apelido ?? nome) || "visitante", que aqui mostra visitante (o apelido falta, o nome está vazio, então vale o padrão).

O typeof também é da 2ª prioridade: na primeira linha ele pegou só o 1 (typeof 1 é o texto "number"), e depois o + 2 grudou o 2 no texto. Como consertar: parênteses em volta da expressão inteira: typeof (1 + 2).

Resumo

  • Precedência é a ordem em que o JavaScript resolve os operadores de uma expressão. Ela segue a matemática: parênteses, potência, * / %, + -.
  • Depois das contas vêm as comparações (< >, depois === !==), depois o &&, depois o ||/?? e, por último, o =: calcula, compara, junta, guarda.
  • Mesma prioridade: da esquerda para a direita (10 - 4 - 3 = 3), exceto ** e =, que começam pela direita.
  • O ! e o typeof pegam só o valor logo depois deles: !(idade >= 18), typeof (1 + 2).
  • Com textos, "Total: " + 2 + 3 dá "Total: 23"; use (2 + 3) ou um template string.
  • Na dúvida, parênteses. Misturar ?? com || ou && (e pôr um - antes de um **) exige parênteses: sem eles, é SyntaxError.
