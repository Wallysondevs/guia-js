JavaScript for … of

Você já sabe guardar uma lista num array e pegar um item pela posição. Mas quase sempre o programa precisa fazer alguma coisa com todos os itens: mostrar cada aluno da chamada, somar todas as notas, conferir cada produto do estoque. Escrever alunos[0], alunos[1], alunos[2]… não funciona (e se a turma tiver 40 alunos? e se amanhã chegar mais um?). O laço for … of (em inglês, "para cada … de") resolve isso: ele passa por cada item do array, do primeiro ao último, sem você precisar contar nada.

Você vai aprender
  • Como se escreve um for … of e o que é cada parte.
  • A somar, contar e achar o maior valor de um array com um laço.
  • A percorrer as letras de uma string.
  • A saber a posição de cada item com entries().
  • A parar antes do fim com break e pular um item com continue.
  • Por que mudar a variável do laço não muda o array.
  • A diferença entre for … of, o for clássico e o for … in (que engana).
  • Os erros reais mais comuns: is not iterable, Assignment to constant variable e o in no lugar do of.

Todos os programas desta aula rodaram no Node.js 24 da máquina da Ana (usuária ana, computador notebook), com node arquivo.js. Você pode rodar cada um no editor do guia.

A ideia: a professora fazendo a chamada

A professora da Ana pega a lista da turma e lê um nome de cada vez, de cima para baixo: "Ana?" "Presente!" "Bia?" "Presente!"… Ela não precisa saber quantos alunos são, nem numerar ninguém: só vai lendo o próximo nome até a lista acabar. Para cada nome, faz a mesma coisa (chamar e esperar a resposta).

O for … of é exatamente isso: "para cada aluno da lista, faça tal coisa". A cada volta do laço, uma variável recebe o próximo item; quando os itens acabam, o laço termina sozinho.

1. O primeiro for … of

const alunos = ["Ana", "Bia", "Caio", "Duda"];

for (const aluno of alunos) {
  console.log(`${aluno}? Presente!`);
}
console.log("Chamada encerrada.");
for
A palavra-chave dos laços "para" (a mesma do for clássico).
( … )
Os parênteses com a "receita" do laço.
const aluno
A variável que, a cada volta, recebe um item. Na 1ª volta vale "Ana", na 2ª "Bia", e assim por diante. O costume é usar o singular do nome do array: alunos → aluno, notas → nota. Pode ser const, porque a cada volta é uma variável nova (você não muda o valor dela dentro da volta).
of
"De". Separa a variável do array: "cada aluno de alunos".
alunos
O array que será percorrido.
{ … }
O corpo do laço: o que fazer com cada item. Roda uma vez por item, 4 vezes aqui.
console.log("Chamada encerrada.")
Depois da }, fora do laço: roda uma vez, quando os itens acabam.
$ node chamada.js
Ana? Presente!
Bia? Presente!
Caio? Presente!
Duda? Presente!
Chamada encerrada.

Repare que não há contador, nem length, nem [i]. O laço sabe sozinho onde começar e onde parar. Se você acrescentar um quinto aluno no array, ele aparece na chamada sem mudar mais nada.

2. Somar, contar, achar o maior

O laço fica poderoso quando você junta a ele uma variável que vai guardando alguma coisa de volta em volta. É a mesma ideia do acumulador do while.

Somar: a média da turma

const notas = [7.5, 8, 6.5, 9, 10];
let soma = 0;

for (const nota of notas) {
  soma += nota;
}

const media = soma / notas.length;
console.log(`Soma: ${soma}`);
console.log(`Média: ${media}`);
let soma = 0;
O acumulador, criado antes do laço, com let (porque ele muda). Começa em 0: antes de somar qualquer nota, a soma é zero.
soma += nota;
A cada volta, junta a nota da vez na soma (veja Atribuição).
soma / notas.length
Depois do laço, a soma está completa; dividida pela quantidade de notas, dá a média.
$ node media.js
Soma: 41
Média: 8.2

Contar: quantos passaram

const notas = [7.5, 5, 6.5, 9, 4, 10];
let aprovados = 0;

for (const nota of notas) {
  if (nota >= 6) {
    aprovados++;
  }
}
console.log(`${aprovados} de ${notas.length} alunos passaram.`);

$ node aprovados.js
4 de 6 alunos passaram.

Um if dentro do laço decide, item por item, se aquele conta. O aprovados++ soma 1 (veja Incremento).

Achar o maior: a melhor venda

const vendas = [120, 98, 143, 110, 87, 156, 132];
let maior = vendas[0];

for (const venda of vendas) {
  if (venda > maior) {
    maior = venda;
  }
}
console.log(`A melhor venda da semana foi ${maior} pães.`);

$ node maior.js
A melhor venda da semana foi 156 pães.

O maior começa com o primeiro item ("até agora, o maior que eu vi é este") e, a cada volta, se aparece alguém maior, ele é trocado. No fim, sobra o maior de todos. (Para números, também existe o atalho Math.max(...vendas); veja Math.)

3. Percorrendo as letras de uma string

O for … of não é só para arrays. Ele funciona com tudo o que o JavaScript chama de iterável (que pode ser percorrido item a item): arrays, strings, e outros que você vai conhecer depois (Set, Map). Numa string, cada volta recebe uma letra:

const palavra = "pão";
for (const letra of palavra) {
  console.log(letra);
}

let vogais = 0;
for (const letra of "abacaxi") {
  if ("aeiou".includes(letra)) {
    vogais++;
  }
}
console.log(`abacaxi tem ${vogais} vogais.`);

$ node letras.js
p
ã
o
abacaxi tem 4 vogais.

O segundo laço usa o includes das strings (veja Procurando em Strings) para perguntar "esta letra é uma vogal?".

4. E a posição? entries()

O for … of entrega o item, mas não a posição. Quando você precisa dos dois (para numerar a lista, por exemplo), use o método entries() (em inglês, "entradas"), que entrega pares [posição, item]:

const alunos = ["Ana", "Bia", "Caio", "Duda"];

for (const [i, aluno] of alunos.entries()) {
  console.log(`${i + 1}. ${aluno}`);
}
alunos.entries()
Entrega, um de cada vez, os pares [0, "Ana"], [1, "Bia"], [2, "Caio"], [3, "Duda"].
const [i, aluno]
Os colchetes do lado esquerdo "desmontam" o par em duas variáveis: a posição vai para i, o item para aluno. Isso se chama desestruturação e tem aula própria (Desestruturação); aqui basta copiar a forma.
${i + 1}
A posição começa em 0; para numerar para pessoas, some 1.
$ node entries.js
1. Ana
2. Bia
3. Caio
4. Duda

Outra saída é usar o for clássico, com contador (veja Formas diferentes). E na próxima aula, o forEach entrega o item e a posição sem precisar do entries().

5. Parar antes e pular: break e continue

As duas palavras que você conheceu em break e continue funcionam igualzinho no for … of:

const pedidos = ["pão", "leite", "", "café", "FIM", "bolo"];

for (const pedido of pedidos) {
  if (pedido === "") {
    continue;
  }
  if (pedido === "FIM") {
    break;
  }
  console.log(`Separando: ${pedido}`);
}
console.log("Pedidos separados.");

$ node break_continue.js
Separando: pão
Separando: leite
Separando: café
Pedidos separados.
continue
"Continue com o próximo": pula o resto desta volta. O pedido vazio ("") não foi separado, e o laço seguiu com o café.
break
"Quebre": sai do laço na hora. Ao chegar no "FIM", o laço parou, e o bolo nem foi olhado.

6. A variável do laço é uma cópia do item

Uma surpresa comum: a Ana quer dar 1 ponto a mais em cada nota e tenta mudar a variável do laço (com let, para poder mudar):

const notas = [7, 8, 6];

for (let nota of notas) {
  nota = nota + 1;
  console.log(`Dentro do laço: ${nota}`);
}
console.log(notas);

$ node copia.js
Dentro do laço: 8
Dentro do laço: 9
Dentro do laço: 7
[ 7, 8, 6 ]

Dentro do laço, a nota mudou; mas o array notas continua igual. A variável nota recebe uma cópia do valor do item, como um bilhete com o número anotado: rabiscar o bilhete não muda o boletim. Para mudar o array, você precisa escrever na posição (notas[i] = …, com o entries() ou o for clássico) ou, melhor ainda, criar um array novo com o map, que é exatamente para isso.

const notas = [7, 8, 6];
for (const [i, nota] of notas.entries()) {
  notas[i] = nota + 1;
}
console.log(notas);

$ node mudar.js
[ 8, 9, 7 ]

Formas diferentes de percorrer um array

A mesma chamada pode ser escrita de quatro jeitos. Todos mostram os mesmos nomes:

const alunos = ["Ana", "Bia", "Caio"];

// 1. for … of
for (const aluno of alunos) {
  console.log(aluno);
}

// 2. for clássico, com contador
for (let i = 0; i < alunos.length; i++) {
  console.log(alunos[i]);
}

// 3. forEach (próxima aula)
alunos.forEach((aluno) => console.log(aluno));

// 4. while
let j = 0;
while (j < alunos.length) {
  console.log(alunos[j]);
  j++;
}

Missão final: o estoque da lojinha

Missão: o array tem a quantidade de cada produto da lojinha. Com um for … of, calcule as três coisas de uma vez: o total de itens (soma), quantos produtos estão zerados (quantidade igual a 0) e o maior estoque.

const estoque = [12, 0, 5, 15, 0, 3, 2];
let total = 0;
let zerados = 0;
let maior = estoque[0];

// o for … of aqui

console.log(`Itens em estoque: ${total}`);
console.log(`Produtos zerados: ${zerados}`);
console.log(`Maior estoque: ${maior}`);

const estoque = [12, 0, 5, 15, 0, 3, 2];
let total = 0;
let zerados = 0;
let maior = estoque[0];

// o for … of aqui
for (const quantidade of estoque) {
  total += quantidade;
  if (quantidade === 0) {
    zerados++;
  }
  if (quantidade > maior) {
    maior = quantidade;
  }
}

console.log(`Itens em estoque: ${total}`);
console.log(`Produtos zerados: ${zerados}`);
console.log(`Maior estoque: ${maior}`);

No lab, a solução mostrou Itens em estoque: 37, Produtos zerados: 2 e Maior estoque: 15.

Resumo

  • for (const item of lista) { … } roda o bloco uma vez para cada item, do primeiro ao último, sem contador nem length.
  • Com uma variável criada antes do laço, você soma (acumulador), conta (contador) ou acha o maior.
  • Funciona com tudo que é iterável: arrays, strings (uma letra por volta) e outros. Um número não é iterável.
  • lista.entries() entrega [posição, item]: for (const [i, item] of lista.entries()).
  • break sai do laço; continue pula para o próximo item.
  • A variável do laço é uma cópia: mudá-la não muda o array.
  • for … in dá as posições (como texto); para os itens de um array, é of.
