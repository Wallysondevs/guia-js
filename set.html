JavaScript Set

Um array aceita qualquer coisa, inclusive o mesmo valor várias vezes: ["arroz", "arroz", "arroz"] é um array válido. Às vezes é exatamente isso que você quer (a lista de visitas da loja, com a Ana aparecendo três vezes). Outras vezes, a repetição atrapalha: a lista de convidados de uma festa, as figurinhas que você já colou no álbum, as palavras diferentes de um texto. Para guardar valores sem repetição, o JavaScript tem o Set (em inglês, "conjunto").

Você vai aprender
  • Como criar um conjunto com new Set() e colocar valores com add ("adicionar").
  • Como perguntar se um valor está lá (has), tirar um valor (delete), esvaziar (clear) e contar (size).
  • Como percorrer um conjunto com for … of e forEach, e transformá-lo de volta em array.
  • O truque mais usado do Set: tirar os repetidos de um array numa linha.
  • Como o Set decide que dois valores são "iguais" (e por que dois objetos com o mesmo conteúdo não são).
  • As operações de conjunto que chegaram no ES2025: juntar (union), o que há em comum (intersection), a diferença (difference) e as perguntas "está contido?".
  • Os erros reais mais comuns: esquecer o new, usar push, procurar a posição [0].

A ideia: o álbum de figurinhas

Pense num álbum de figurinhas da Copa. Cada jogador tem um espaço no álbum. Quando você abre um pacotinho:

  1. Saiu o Pelé, que você ainda não tinha? Cola no álbum.
  2. Saiu a Marta? Cola também.
  3. Saiu o Pelé de novo? Não tem onde colar: ele já está lá. A repetida vai para o bolo de trocas, e o álbum continua igual.

O Set é esse álbum. Ele guarda cada valor uma vez só. Se você tenta pôr um valor que já está lá, ele simplesmente ignora, sem erro e sem aviso. E ele responde rápido à pergunta mais importante do colecionador: "eu já tenho essa?".

Duas diferenças em relação ao array, para guardar desde já:

  • O array é uma fila numerada (posição 0, 1, 2…). O conjunto não tem posições: não existe "a figurinha número 0".
  • O array deixa repetir. O conjunto, não.

1. Criar um conjunto e colocar valores (new Set e add)

const album = new Set();
album.add("Pelé");
album.add("Marta");
album.add("Pelé");
album.add("Ronaldo");
console.log(album);
console.log(album.size);
new Set()
Cria um conjunto vazio. O new ("novo") é obrigatório: ele diz "fabrique um conjunto novo". Sem ele, dá erro (veja Quando dá errado).
const album
A variável que guarda o conjunto. É const porque a variável vai apontar sempre para o mesmo álbum; o que muda é o conteúdo dele, e isso o const permite (como num array, veja Constantes).
album.add("Pelé")
add = "adicionar". Coloca o valor no conjunto, se ele ainda não estiver lá.
album.add("Pelé") de novo
O "Pelé" já está lá: o add não faz nada. Não dá erro.
album.size
"Tamanho": quantos valores diferentes o conjunto tem. Repare que é size, e não length como no array. E é uma propriedade, sem parênteses.
$ node figurinhas.js
Set(3) { 'Pelé', 'Marta', 'Ronaldo' }
3

Foram 4 chamadas de add, mas o álbum tem 3 figurinhas: o segundo Pelé foi ignorado. Repare em como o Node mostra um conjunto:

  • Set(3): "é um Set, com 3 valores";
  • entre { }, os valores, na ordem em que entraram, com os textos entre aspas simples (é o jeito do Node mostrar textos dentro de uma estrutura, como em [ 'a', 'b' ]).

Encadeando add

O add devolve o próprio conjunto. Por isso dá para escrever vários add grudados, um depois do outro (isso se chama encadear):

const cores = new Set().add("azul").add("verde").add("azul");
console.log(cores);
const resultado = cores.add("rosa");
console.log(resultado === cores);

$ node encadear.js

O true da última linha confirma: o que o add devolveu é o mesmo conjunto cores. Funciona, mas um add por linha costuma ser mais fácil de ler.

2. Criar a partir de um array

Quase sempre você já tem os valores num array. Basta entregar o array ao new Set(…): ele passa por todos os itens e guarda cada valor uma vez.

const lista = ["arroz", "feijão", "leite", "arroz", "café", "leite"];
const semRepetir = new Set(lista);
console.log(semRepetir);
console.log(`Itens na lista: ${lista.length}`);
console.log(`Itens diferentes: ${semRepetir.size}`);

$ node compras.js
Set(4) { 'arroz', 'feijão', 'leite', 'café' }
Itens na lista: 6
Itens diferentes: 4

O array tinha 6 itens; o conjunto ficou com 4. O segundo "arroz" e o segundo "leite" ficaram de fora, e a ordem é a da primeira vez que cada um apareceu. O array lista continua igual: o new Set faz uma coleção nova, não mexe no original.

O que o new Set(…) aceita

Entre os parênteses vai uma coisa só, que dê para percorrer: um array, outro Set, um texto… (os programadores chamam isso de iterável; veja Iteradores). Vazio, new Set(), cria um conjunto vazio. new Set(1, 2, 3) não funciona: são três coisas, e um número não dá para percorrer. A seção Quando dá errado mostra a mensagem.

Por que usar has e não o includes do array?

Os dois respondem a mesma pergunta. A diferença é a velocidade com muitos valores: o includes do array olha item por item, do começo até achar (com 1 milhão de itens, pode olhar 1 milhão); o has do conjunto vai direto ao lugar certo, como um índice no fim de um livro. Para listas pequenas, tanto faz; para "esse e-mail já está cadastrado?" num cadastro grande, o Set ganha longe.

4. Percorrer um conjunto

O conjunto não tem posições, então o for com contador (i = 0, 1, 2…) não serve. Use o for … of (veja for … of) ou o forEach (veja forEach), do mesmo jeito que num array:

const turma = new Set(["Ana", "Bia", "Caio"]);
for (const aluno of turma) {
  console.log(`Chamada: ${aluno}`);
}
turma.forEach((aluno) => {
  console.log(`Prova entregue por ${aluno}`);
});
console.log([...turma]);
console.log(Array.from(turma));

$ node percorrer.js

Chamada: Bia
Chamada: Caio
Prova entregue por Ana
Prova entregue por Bia
Prova entregue por Caio
[ 'Ana', 'Bia', 'Caio' ]
[ 'Ana', 'Bia', 'Caio' ]
for (const aluno of turma)
"Para cada aluno de turma". A cada volta, aluno recebe um valor do conjunto, na ordem em que entraram.
turma.forEach((aluno) => { … })
"Para cada um", com uma arrow function que recebe cada valor.
[...turma]
O espalhamento (...) tira os valores do conjunto e os põe dentro de [ ]: vira um array de novo.
Array.from(turma)
"Array a partir de turma": outro jeito de fazer o mesmo array.

Transformar em array é útil quando você precisa de algo que só o array tem: a posição [0], o sort, o map, o join.

A ordem é a de entrada

O conjunto lembra a ordem em que cada valor entrou. Ele não coloca em ordem alfabética, e um valor que sai e volta vai para o fim da fila:

const s = new Set();
s.add("c");
s.add("a");
s.add("b");
s.add("a");
console.log(s);
s.delete("c");
s.add("c");
console.log(s);

$ node ordem.js
Set(3) { 'c', 'a', 'b' }
Set(3) { 'a', 'b', 'c' }

O segundo add("a") não mudou nada (o "a" já estava lá, e continuou no seu lugar). Já o "c" saiu com delete e entrou de novo: agora é o último.

5. O truque mais usado: tirar os repetidos de um array

A professora tem as notas de uma prova e quer saber quais notas diferentes apareceram. Juntando o que você já viu (array → conjunto → array):

const notas = [7, 9, 7, 10, 9, 7];
const unicas = [...new Set(notas)];
console.log(unicas);
const unicas2 = Array.from(new Set(notas));
console.log(unicas2);
const unicas3 = notas.filter((nota, i) => notas.indexOf(nota) === i);
console.log(unicas3);

$ node repetidos.js
[ 7, 9, 10 ]
[ 7, 9, 10 ]
[ 7, 9, 10 ]

Leia [...new Set(notas)] de dentro para fora:

  1. new Set(notas): cria um conjunto com as notas; as repetidas ficam de fora → Set(3) { 7, 9, 10 }.
  2. [... ]: espalha esse conjunto dentro de um array novo → [ 7, 9, 10 ].

As três formas dão o mesmo resultado. A terceira, com filter e indexOf ("fica o item se esta for a primeira posição em que ele aparece"), é a que se usava antes do Set existir; você ainda vai encontrá-la em código antigo. Ela é mais difícil de ler e fica lenta com arrays grandes.

6. Quando dois valores são "o mesmo"?

Para decidir se um valor já está no conjunto, o Set compara quase como o === (veja Comparação). Veja o que acontece com valores parecidos:

const s = new Set([1, "1", 1, NaN, NaN, 0, -0]);
console.log(s);
console.log(s.size);
const pessoas = new Set();
pessoas.add({ nome: "Ana" });
pessoas.add({ nome: "Ana" });
console.log(pessoas);
console.log(pessoas.has({ nome: "Ana" }));
const ana = { nome: "Ana" };
const amigas = new Set([ana, ana]);
console.log(amigas.size, amigas.has(ana));

$ node igualdade.js
Set(4) { 1, '1', NaN, 0 }
4
Set(2) { { nome: 'Ana' }, { nome: 'Ana' } }
false
1 true
  • 1 e "1" são diferentes: um é número, o outro é texto. Os dois ficaram (o texto aparece com aspas).
  • NaN entrou uma vez só. Isso é curioso, porque NaN === NaN dá false (veja NaN e Infinity). O Set abre essa exceção de propósito: para ele, NaN é igual a NaN.
  • 0 e -0 contam como o mesmo valor (ficou só o 0).
  • Dois objetos com o mesmo conteúdo são dois objetos diferentes: cada { nome: "Ana" } escrito no código fabrica um objeto novo. Por isso entraram os dois, e o has({ nome: "Ana" }) deu false (ele perguntou por um terceiro objeto, novinho). É a mesma regra de Objetos são Referências.
  • Com a mesma variável ana duas vezes, é o mesmo objeto: entrou uma vez só, e has(ana) deu true.
Para não repetir pessoas, guarde algo simples

Se você quer um conjunto de "pessoas sem repetição", guarde algo que identifica a pessoa e é um texto ou número, como o nome, o CPF ou o e-mail: new Set(["ana@email.com", "bia@email.com"]). Objetos só são "iguais" se forem o mesmo objeto na memória.

7. Operações de conjunto ES2025

Na escola, você talvez tenha desenhado conjuntos como círculos (os "diagramas de Venn") e aprendido a união, a interseção e a diferença. Desde o ECMAScript 2025, o Set faz essas contas sozinho. O Node.js 24 já tem todas elas.

console.log(segunda.intersection(terca));
console.log(segunda.difference(terca));
console.log(terca.difference(segunda));
console.log(segunda.symmetricDifference(terca));

Três detalhes:

  • Todos devolvem um conjunto novo; segunda e terca continuam iguais.
  • Na difference, a ordem importa: "segunda menos terça" é diferente de "terça menos segunda". Nas outras, não.
  • O que vai entre os parênteses tem de ser outro Set (ou algo que se pareça muito com um). Com um array, dá erro: veja Quando dá errado.

Resumo

  • O Set ("conjunto") guarda valores sem repetição. Repetir um add não dá erro: o valor só não entra de novo.
  • Crie com new Set() (vazio) ou new Set(array). O new é obrigatório.
  • add coloca, has pergunta, delete tira, clear esvazia, size conta (não é length).
  • O conjunto não tem posições: percorra com for … of ou forEach (na ordem de entrada) e transforme em array com [...s] quando precisar.
  • [...new Set(array)] tira os repetidos de um array.
  • Valores iguais pelo === são iguais no Set (e NaN também); objetos só são iguais se forem o mesmo objeto.
  • ES2025 union, intersection, difference, symmetricDifference criam conjuntos novos; isSubsetOf, isSupersetOf, isDisjointFrom respondem sim ou não.
