JavaScript Novidades Recentes

Como você viu em Versões, o JavaScript ganha uma edição nova todo ano. Esta aula é uma vitrine das novidades dos últimos anos: do ES2023 ao ES2026, e um pouco do que já está aprovado para o ES2027. Cada recurso aparece com um exemplo pequeno, rodado no Node.js 24, e com a marca do ano em que entrou na linguagem. Muitos você já usou neste guia sem saber que eram tão novos; outros são para guardar na memória e usar quando aparecer a ocasião.

Você vai aprender
  • ES2023 Os métodos de array que não estragam o original: toSorted, with, findLast.
  • ES2024 Object.groupBy: separar uma lista em grupos.
  • ES2025 Operações de conjunto no Set, ajudantes de iteradores, Promise.try, RegExp.escape e importar JSON.
  • ES2026 Error.isError, Array.fromAsync, e o que o Node 24 ainda não tem desta edição.
  • O que vem por aí: using (já funciona no Node 24) e o Temporal, a nova API de datas (chega no Node 26).

A ideia: a caixa de ferramentas que cresce

Quando a Ana montou a lojinha, ela tinha uma caixa com martelo, chave de fenda e alicate, e fazia tudo com eles. Com o tempo, ganhou uma parafusadeira: o que levava dez minutos agora leva um. O martelo continua na caixa (nada é jogado fora), mas para parafusos ela usa a ferramenta nova. As novidades do JavaScript são assim: quase tudo dava para fazer antes, com mais linhas; o recurso novo faz o mesmo de um jeito mais curto e com menos chance de erro.

1. ES2023 Arrays: mudar sem estragar

O sort e o reverse mudam o próprio array, o que já causou muito defeito (veja Ordenando). O ES2023 trouxe versões que devolvem uma cópia, e o findLast, que procura de trás para a frente:

const notas = [7, 10, 5, 8];

console.log(notas.toSorted((a, b) => a - b));
console.log(notas.with(0, 9));
console.log(notas.findLast((n) => n >= 7));
console.log(notas);

$ node es2023.js
[ 5, 7, 8, 10 ]
[ 9, 10, 5, 8 ]
8
[ 7, 10, 5, 8 ]
toSorted(…)
Uma cópia ordenada. Os irmãos: toReversed() e toSpliced(…).
with(0, 9)
Uma cópia com a posição 0 trocada por 9 (o "notas[0] = 9" que não estraga).
findLast(…)
O último item que passa no teste: 8 (o find daria 7, o primeiro). Tem também o findLastIndex.
notas no fim
Continua [ 7, 10, 5, 8 ]: nada mudou o original.

Mais sobre isso em Imutabilidade. O ES2023 também passou a aceitar símbolos como chave de WeakMap.

2. ES2024 Object.groupBy: separando em grupos

Separar uma lista em grupos (os produtos por tipo, os alunos por situação) antes exigia um reduce de várias linhas. Agora é uma chamada:

const produtos = [
  { nome: "Pão francês", tipo: "salgado" },
  { nome: "Sonho", tipo: "doce" },
  { nome: "Coxinha", tipo: "salgado" },
  { nome: "Brigadeiro", tipo: "doce" },
];

const porTipo = Object.groupBy(produtos, (p) => p.tipo);
console.log(porTipo);
console.log(porTipo.doce.length);

$ node es2024.js
[Object: null prototype] {
  salgado: [
    { nome: 'Pão francês', tipo: 'salgado' },
    { nome: 'Coxinha', tipo: 'salgado' }
  ],
  doce: [
    { nome: 'Sonho', tipo: 'doce' },
    { nome: 'Brigadeiro', tipo: 'doce' }
  ]
}
2

O Object.groupBy(lista, função) chama a função para cada item; o que ela devolve ("salgado" ou "doce") vira o nome do grupo. O resultado é um objeto com um array por grupo. O [Object: null prototype] no começo é o Node avisando que esse objeto foi criado "puro", sem os métodos herdados de um objeto comum (veja Protótipos); para usar, nada muda: porTipo.doce. Existe também o Map.groupBy, que devolve um Map. Outra novidade do ES2024: Promise.withResolvers().

3. ES2025 Conjuntos de verdade

O Set existia desde o ES2015, mas sem as operações de conjunto da escola. O ES2025 trouxe todas:

const turmaA = new Set(["Ana", "Bia", "Caio"]);
const turmaB = new Set(["Caio", "Duda"]);

console.log(turmaA.union(turmaB));
console.log(turmaA.intersection(turmaB));
console.log(turmaA.difference(turmaB));
console.log(new Set(["Ana"]).isSubsetOf(turmaA));

4. ES2025 Ajudantes de iteradores

Os geradores e outros iteradores ganharam os métodos que antes só os arrays tinham: map, filter, take ("pegar só os N primeiros"), drop ("pular os N primeiros"), toArray e outros. A vantagem: eles funcionam até numa sequência sem fim, porque só calculam o que for pedido:

function* numeros() {
  let n = 1;
  while (true) {
    yield n;
    n++;
  }
}

const pares = numeros()
  .filter((n) => n % 2 === 0)
  .map((n) => n * 10)
  .take(3)
  .toArray();

console.log(pares);

$ node es2025-iter.js
[ 20, 40, 60 ]

O gerador numeros conta para sempre (while (true)), mas o take(3) para depois de 3 resultados: o programa calculou só até o 6. Com um array, isso seria impossível (um array infinito não cabe na memória).

5. ES2025 Mais três

console.log(RegExp.escape("R$ 4.50"));

const r = Promise.try(() => 2 + 2);
r.then((v) => console.log("Promise.try:", v));

$ node es2025-outros.js
\x52\$\x204\.50
Promise.try: 4
  • RegExp.escape(texto) protege um texto para ser usado dentro de uma expressão regular: o $ e o ., que têm significado especial na regex, ganharam uma \ na frente. O R virou \x52 e o espaço virou \x20 (o código de cada caractere): é só o jeito seguro que a regra escolheu, e a regex continua procurando "R$ 4.50" ao pé da letra. Uso: new RegExp(RegExp.escape(oQueOUsuarioDigitou)).
  • Promise.try(função) roda a função e sempre devolve uma Promise, mesmo que a função não seja assíncrona ou lance um erro na hora.
  • Importar JSON direto num módulo, com with { type: "json" }:
import precos from "./precos.json" with { type: "json" };

console.log(precos.sonho);

$ cat precos.json
{ "pao": 0.75, "sonho": 4.5 }
$ node importar-json.mjs
4.5

O with { type: "json" } (os "atributos de importação") avisa que o arquivo é JSON, e o precos já chega como objeto, sem fs nem JSON.parse (compare com JSON e Lendo Arquivos). O ES2025 trouxe ainda o Float16Array e o Math.f16round (números com menos precisão, para gráficos e inteligência artificial), grupos com o mesmo nome em regex alternativas e modificadores de regex.

6. ES2026 A edição mais nova

O ES2026 foi publicado em junho de 2026. O Node 24 já tem dois dos recursos dele:

console.log(Error.isError(new TypeError("ops")));
console.log(Error.isError({ message: "parece erro" }));

async function* entregas() {
  yield "pão";
  yield "leite";
}
Array.fromAsync(entregas()).then((lista) => console.log(lista));

$ node es2026.js
true
false
[ 'pão', 'leite' ]
  • Error.isError(valor): "isto é um erro de verdade?". Um objeto que só parece erro (tem message) dá false. Útil num catch, porque em JavaScript dá para lançar qualquer coisa (throw "texto").
  • Array.fromAsync(…): o Array.from para fontes assíncronas: junta tudo o que um gerador assíncrono entrega num array (e devolve uma Promise).

7. O que vem por aí

using: limpeza automática

Aprovado para o ES2027 (proposta "Explicit Resource Management"), mas o V8 do Node 24 já tem. Uma variável declarada com using chama sozinha um método de "limpeza" (Symbol.dispose) quando o bloco termina, como fechar um arquivo ou uma conexão, mesmo que dê erro no meio:

function abrirCaixa(nome) {
  console.log(`Abrindo o caixa ${nome}`);
  return {
    [Symbol.dispose]() {
      console.log(`Fechando o caixa ${nome}`);
    },
  };
}

{
  using caixa = abrirCaixa("1");
  console.log("Vendendo...");
}
console.log("Fim do expediente.");

$ node using.js
Abrindo o caixa 1
Vendendo...
Fechando o caixa 1
Fim do expediente.

Ninguém chamou o "fechar": o using chamou o [Symbol.dispose] sozinho, no } do bloco. É o mesmo papel do finally do try … catch … finally, sem precisar escrever um.

Temporal: datas sem sofrimento

O Date é famoso por ser confuso (meses que começam em 0, fuso horário escondido). O Temporal é a substituição completa, aprovada para o ES2027. No Node 24 ele ainda não existe:

console.log(typeof Temporal);
const hoje = Temporal.Now.plainDateISO();

A primeira linha do programa (console.log(typeof Temporal)) mostrou undefined, e a segunda deu ReferenceError: "Temporal não está definido" (um nome que não existe; veja Os Tipos de Erro). Segundo as notas de lançamento do Node 26, o Temporal vem ligado por padrão nele. Como o Node 26 vira LTS em 28 de outubro de 2026, o Temporal logo vai estar no Node recomendado para projetos novos.

Outras propostas que já chegaram ao stage 4 e devem sair no ES2027: Atomics.pause, e mais ajudantes de iteradores (para juntar, dividir em pedaços e procurar).

Quando dá errado

… is not a function ou … is not defined com um recurso novo

Como o Uint8Array.fromBase64 e o Temporal acima: o recurso existe na linguagem, mas não no motor que está rodando. Um método que falta dá TypeError: … is not a function; um nome global que falta dá ReferenceError: … is not defined. Como consertar: confira a tabela de compatibilidade da MDN, atualize o Node, ou use detecção de recurso (typeof), como em Versões.

Funciona no editor do guia, mas não no Node 24 (ou ao contrário)

O editor usa o motor do seu navegador, mas imita o Node 24. Um Chrome recente tem recursos que o V8 13.6 do Node 24 ainda não tem (Math.sumPrecise, Temporal, Uint8Array.fromBase64, Iterator.concat, getOrInsert): o editor os esconde, e eles dão no editor o mesmo erro do Node 24. Fora do editor (no Console do F12 de um Chrome novo), eles podem funcionar. E um Safari antigo pode não ter os métodos de Set, nem dentro do editor. Como evitar: para um programa que vai rodar no Node, confira no Node (node -p "typeof Map.prototype.getOrInsert").

O Object.groupBy devolveu undefined num grupo

Se nenhum item cair num grupo, a propriedade dele não existe: no exemplo da seção 2 sem nenhum doce, porTipo.doce seria undefined, e porTipo.doce.length daria TypeError: Cannot read properties of undefined (reading 'length'). Como consertar: porTipo.doce?.length ?? 0 (veja ?. e ??).

Missão final: quem está nas duas turmas?

Missão: a escola de informática tem uma turma de manhã e uma à tarde. Troque os dois new Set() vazios pelos métodos novos do Set: manha.intersection(tarde) (quem está nas duas) e manha.difference(tarde) (quem está só na manhã).

const manha = new Set(["Ana", "Bia", "Caio", "Duda"]);
const tarde = new Set(["Caio", "Duda", "Eva"]);

const nasDuas = new Set();
const soManha = new Set();

console.log(`Nas duas turmas: ${[...nasDuas].join(", ")}`);
console.log(`Só na manhã: ${[...soManha].join(", ")}`);

const manha = new Set(["Ana", "Bia", "Caio", "Duda"]);
const tarde = new Set(["Caio", "Duda", "Eva"]);

const nasDuas = manha.intersection(tarde);
const soManha = manha.difference(tarde);

console.log(`Nas duas turmas: ${[...nasDuas].join(", ")}`);
console.log(`Só na manhã: ${[...soManha].join(", ")}`);

No lab, a solução mostrou Nas duas turmas: Caio, Duda e Só na manhã: Ana, Bia.

Resumo

  • ES2023 toSorted, toReversed, with e findLast: trabalhar com arrays sem estragar o original.
  • ES2024 Object.groupBy e Map.groupBy: agrupar numa linha.
  • ES2025 Operações de conjunto no Set, ajudantes de iteradores (map, filter, take…), Promise.try, RegExp.escape e import … with { type: "json" }.
  • ES2026 Error.isError e Array.fromAsync já estão no Node 24; Math.sumPrecise, Base64, Iterator.concat e getOrInsert ainda não (os dois últimos chegam no Node 26).
  • Por vir: using (já funciona no Node 24) e o Temporal, ligado por padrão no Node 26, que vira LTS em 28/10/2026.
  • Recurso que falta no motor dá is not a function ou is not defined: confira com typeof e na MDN.
