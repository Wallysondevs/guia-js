JavaScript Spread e Rest (…)

Três pontinhos, ..., e dois trabalhos opostos. Como spread ("espalhar"), eles abrem um array ou objeto e despejam os itens num lugar novo. Como rest ("resto"), eles fazem o contrário: juntam vários valores soltos num array (ou objeto). Os dois aparecem em todo código JavaScript moderno, e você já viu o spread na aula Objetos são Referências, copiando um objeto com { ...ana }.

Você vai aprender
  • Spread em arrays: juntar, copiar e acrescentar itens; Math.max(...notas); separar as letras de um texto.
  • Spread em objetos: juntar, copiar e trocar uma propriedade (quem vem por último vence).
  • Rest nos parâmetros: uma função que aceita quantos argumentos vierem.
  • Rest na desestruturação: "o primeiro, e o resto"; "tudo menos a senha".
  • Como saber qual dos dois é, só olhando onde os pontinhos estão.
  • Os erros reais: is not iterable e Rest parameter must be last formal parameter.

Todos os programas desta aula rodaram no Node.js 24 da máquina da Ana (usuária ana, computador notebook), com node arquivo.js.

A ideia: despejar a sacola × juntar o que sobrou

  • Spread: a Ana vira a sacola de frutas dentro da cesta da feira. A cesta não ganha uma sacola; ganha cada fruta, solta.
  • Rest: no fim da feira, ela põe tudo o que sobrou em cima da mesa numa sacola só, para levar.

O símbolo é o mesmo; o que muda é onde ele está:

Onde os ... aparecemNomeO que fazem
Num valor: dentro de [ ] ou { } do lado direito, ou numa chamada f(...lista)spreadEspalham os itens
Num lugar que recebe: nos parâmetros de uma função ou do lado esquerdo de uma desestruturaçãorestJuntam o resto num array/objeto

1. Spread em arrays

Juntar arrays e acrescentar itens

const frutas = ["maçã", "banana"];
const verduras = ["alface", "couve"];
const feira = [...frutas, ...verduras];
console.log(feira);
const maisUma = ["pão", ...frutas, "leite"];
console.log(maisUma);
[ … ]
Os colchetes criam um array novo.
...frutas
"Ponha aqui cada item de frutas, um por um". Sem os pontinhos, o array inteiro entraria como um item só: [frutas, verduras] seria um array de dois arrays.
"pão", ...frutas, "leite"
Dá para misturar itens soltos e spreads, na ordem que quiser.
$ node juntar.js
[ 'maçã', 'banana', 'alface', 'couve' ]
[ 'pão', 'maçã', 'banana', 'leite' ]

Copiar um array

const compras = ["arroz", "feijão"];
const copia = [...compras];
copia.push("café");
console.log(compras);
console.log(copia);

$ node copiar.js
[ 'arroz', 'feijão' ]
[ 'arroz', 'feijão', 'café' ]

[...compras] é um array novo, então o push na cópia não mexe no original. Outras formas de copiar estão em Copiando Arrays.

Passar os itens como argumentos: Math.max(...notas)

Math.max devolve o maior dos números que recebe, mas espera números soltos (Math.max(7, 9.5, 6)), não um array. O spread resolve:

const notas = [7, 9.5, 6, 8];
console.log(Math.max(notas));
console.log(Math.max(...notas));
console.log(Math.min(...notas));

$ node maximo.js
NaN      « sem spread: recebeu um array, que não é número
9.5
6

Math.max(...notas) vira, na hora da chamada, Math.max(7, 9.5, 6, 8). NaN quer dizer "não é um número" (veja NaN, Infinity e a Precisão).

As letras de um texto

O spread funciona com qualquer coisa que dá para percorrer com for … of, inclusive textos:

const letras = [..."Ana"];
console.log(letras);

$ node letras.js
[ 'A', 'n', 'a' ]

Missão: a Ana quer a lista completa com "manteiga" no fim. Monte completa com spread, juntando manha, tarde e o item "manteiga".

const manha = ["pão", "leite"];
const tarde = ["café", "açúcar"];
const completa = [manha, tarde];
console.log(completa);

const manha = ["pão", "leite"];
const tarde = ["café", "açúcar"];
const completa = [...manha, ...tarde, "manteiga"];
console.log(completa);

2. Spread em objetos

Juntar objetos

const produto = { nome: "Pão", preco: 0.8 };
const detalhes = { estoque: 20, padaria: "Doce Pão" };
const completo = { ...produto, ...detalhes };
console.log(completo);

$ node objetos.js
{ nome: 'Pão', preco: 0.8, estoque: 20, padaria: 'Doce Pão' }

Copiar trocando uma propriedade: quem vem por último vence

Se a mesma propriedade aparece duas vezes, fica o valor da que vem depois. É o jeito mais comum de fazer "uma cópia, só que com o preço novo":

const produto = { nome: "Pão", preco: 0.8, estoque: 20 };
const reajustado = { ...produto, preco: 0.9 };
console.log(produto);
console.log(reajustado);
const errado = { preco: 0.9, ...produto };
console.log(errado);

$ node sobrescrever.js
{ nome: 'Pão', preco: 0.8, estoque: 20 }      « o original não mudou
{ nome: 'Pão', preco: 0.9, estoque: 20 }
{ preco: 0.8, nome: 'Pão', estoque: 20 }      « o spread veio depois e trouxe o preço velho

No errado, o preco: 0.9 foi escrito primeiro, e o ...produto, que vem depois, pôs preco: 0.8 por cima. A ordem importa.

O mesmo truque serve para configurações: os valores padrão primeiro, as escolhas da pessoa depois.

const padrao = { tema: "claro", fonte: 16, som: true };
const escolhaDaAna = { tema: "escuro" };
const config = { ...padrao, ...escolhaDaAna };
console.log(config);

$ node config.js
{ tema: 'escuro', fonte: 16, som: true }
Cópia rasa

Tanto [...lista] quanto { ...obj } copiam só o primeiro nível. Se o array tem objetos dentro, a cópia aponta para os mesmos objetos. No lab, const copia = [...turma]; copia[0].nota = 0; deixou o original como [ { nome: 'Ana', nota: 0 } ]. Para copiar tudo, structuredClone (veja Objetos são Referências).

3. Rest nos parâmetros: quantos argumentos vierem

Às vezes uma função precisa aceitar 2 valores, ou 4, ou nenhum. Com ... no último parâmetro, todos os argumentos que chegarem viram um array:

function somar(...numeros) {
  console.log(numeros);
  let total = 0;
  for (const n of numeros) {
    total += n;
  }
  return total;
}

console.log(somar(2, 3));
console.log(somar(10, 20, 30, 40));
console.log(somar());
function somar(...numeros)
O parâmetro rest: "junte todos os argumentos num array chamado numeros".
console.log(numeros)
Está aqui só para você ver o array que chegou.
for (const n of numeros)
Como numeros é um array de verdade, dá para percorrer com for … of (e usar map, reduce…).
$ node somar.js
[ 2, 3 ]
5
[ 10, 20, 30, 40 ]
100
[]       « sem argumentos: um array vazio, nunca undefined
0

Os parâmetros normais vêm antes e pegam os primeiros argumentos; o rest fica com o que sobrar:

function avisar(remetente, ...nomes) {
  for (const nome of nomes) {
    console.log(`${nome}, recado de ${remetente}: o pão saiu!`);
  }
}

avisar("Ana", "Bia", "Caio", "Davi");

$ node recado.js
Bia, recado de Ana: o pão saiu!
Caio, recado de Ana: o pão saiu!
Davi, recado de Ana: o pão saiu!

"Ana" foi para remetente; os outros três, para o array nomes.

Em código antigo: arguments

Antes do rest, funções declaradas com function usavam uma variável automática chamada arguments, parecida com um array (mas sem map, filter…). As arrow functions nem têm arguments. Hoje, use ...nomes: é um array de verdade e tem o nome que você escolheu.

4. Rest na desestruturação: "e o resto"

Na desestruturação, o ... no último lugar recolhe tudo o que não foi pedido:

const fila = ["Bia", "Caio", "Davi", "Eva"];
const [primeiro, ...resto] = fila;
console.log("Atendendo:", primeiro);
console.log("Esperando:", resto);

$ node restarray.js
Atendendo: Bia
Esperando: [ 'Caio', 'Davi', 'Eva' ]

Com objetos, o resto vira um objeto novo. Um uso clássico é "todas as propriedades, menos uma", por exemplo para nunca mostrar a senha:

const usuario = { nome: "Ana", email: "ana@exemplo.com", senha: "1234" };
const { senha, ...publico } = usuario;
console.log(publico);

$ node restobj.js
{ nome: 'Ana', email: 'ana@exemplo.com' }

A senha foi para uma variável própria (que não usamos), e publico recebeu o resto. O objeto usuario continua inteiro.

Missão: a função media só funciona com 3 notas. Troque os parâmetros por (aluno, ...notas) e calcule a média de quantas notas vierem (some com um for … of e divida por notas.length). media("Ana", 6, 9, 8, 9) deve mostrar media de Ana: 8.

function media(aluno, n1, n2, n3) {
  const resultado = (n1 + n2 + n3) / 3;
  console.log(`media de ${aluno}: ${resultado}`);
}

media("Ana", 6, 9, 8, 9);

function media(aluno, ...notas) {
  let soma = 0;
  for (const nota of notas) {
    soma += nota;
  }
  console.log(`media de ${aluno}: ${soma / notas.length}`);
}

media("Ana", 6, 9, 8, 9);

Formas diferentes de fazer a mesma coisa

TarefaCom ...Jeito antigo (ainda funciona)
Juntar arrays[...a, ...b]a.concat(b)
Copiar array[...a]a.slice()
Juntar/copiar objetos{ ...a, ...b }Object.assign({}, a, b)
Array como argumentosMath.max(...a)Math.max.apply(null, a)
Quantos argumentos vieremfunction f(...args)arguments

No lab, frutas.concat(verduras) deu o mesmo [ 'maçã', 'banana', 'alface', 'couve' ] e Object.assign({}, { a: 1 }, { b: 2 }) deu { a: 1, b: 2 }. Qual usar? Os três pontinhos: são mais curtos e mostram o formato do resultado (colchetes = array, chaves = objeto). Os jeitos antigos ficam para você reconhecer em código dos outros.

Arquivo e linha do problema.
const lista = [...produto]; e o ^
A linha, com o ^ embaixo do valor que não deu para espalhar.
TypeError: produto is not iterable
"produto não é iterável", isto é, não dá para percorrê-lo item por item. Dentro de [ ], o spread precisa de algo com ordem: array, texto, Set, Map. Um objeto comum não tem.
at Object.<anonymous> (/home/ana/objspread.js:2:19)
Linha 2, coluna 19 do seu arquivo; o resto é interno do Node.

Como consertar: se quer uma cópia do objeto, use chaves: { ...produto }. Se quer um array com os valores, Object.values(produto); com os pares, Object.entries(produto).

Espalhou uma variável undefined 
let extras;
const pedido = ["pão", ...extras];

$ node undef.js
/home/ana/undef.js:2
const pedido = ["pão", ...extras];
                          ^

TypeError: extras is not iterable
    at Object.<anonymous> (/home/ana/undef.js:2:27)    « (mais 7 linhas node:internal cortadas)

Node.js v24.22.0

extras foi criada sem valor, então vale undefined, que não é iterável. Curiosamente, em objetos isso não é erro: { item: "pão", ...extras } com extras undefined deu { item: 'pão' } no lab (o spread de objeto ignora undefined e null). Como consertar: comece a variável com um array vazio (let extras = [];) ou use uma reserva: ...(extras ?? []) (veja ?. e ??).

Pôs o rest antes de outro parâmetro 
function avisar(...nomes, remetente) {
  console.log(nomes, remetente);
}

$ node restmeio.js
/home/ana/restmeio.js:1

                        ^

SyntaxError: Rest parameter must be last formal parameter
    at wrapSafe (node:internal/modules/cjs/loader:1861:18)    « (mais 7 linhas node:internal cortadas)

Node.js v24.22.0

"O parâmetro rest tem de ser o último parâmetro." Faz sentido: se o rest pega todo o resto, não sobra nada para o remetente. Na desestruturação a regra é a mesma, com outra mensagem: const [...comeco, ultimo] = … dá SyntaxError: Rest element must be last element. Por ser erro de sintaxe, o programa nem começa. Como consertar: function avisar(remetente, ...nomes).

Esqueceu os pontinhos (ou pôs onde não devia)

Sem erro nenhum, mas com resultado errado: Math.max(notas) dá NaN (seção 1), e [manha, tarde] dá um array de arrays (a missão da seção 1). E Math.max(...[]), com o array vazio, dá -Infinity no lab: confira se a lista tem itens antes de procurar o maior.

Missão final: o pedido com adicionais

Missão: complete a função pedido(base, ...adicionais). Ela deve devolver um objeto novo com tudo de base (use { ...base }) e mais a propriedade adicionais, com o array que o rest juntou. O console.log do fim mostra que o padrao não mudou.

const padrao = { item: "Pizza", tamanho: "M" };

function pedido(base) {
  // devolva o objeto novo aqui
}

console.log(pedido({ ...padrao, tamanho: "G" }, "borda", "bacon", "cebola"));
console.log(pedido(padrao));
console.log(padrao);

const padrao = { item: "Pizza", tamanho: "M" };

function pedido(base, ...adicionais) {
  return { ...base, adicionais };
}

console.log(pedido({ ...padrao, tamanho: "G" }, "borda", "bacon", "cebola"));
console.log(pedido(padrao));
console.log(padrao);

No lab, a solução mostrou:

$ node pizza.js
{
  item: 'Pizza',
  tamanho: 'G',
  adicionais: [ 'borda', 'bacon', 'cebola' ]
}
{ item: 'Pizza', tamanho: 'M', adicionais: [] }
{ item: 'Pizza', tamanho: 'M' }

O primeiro objeto saiu em várias linhas porque não cabia numa linha só: quando o objeto ficaria comprido demais para uma linha, o console.log do Node o quebra em várias. O último mostra o padrao intacto. (Escrever só adicionais dentro das chaves é o atalho para adicionais: adicionais.)

Resumo

  • ... num valor é spread: espalha os itens de um array/texto (em [ ] ou numa chamada) ou as propriedades de um objeto (em { }).
  • ... num lugar que recebe é rest: junta os argumentos que sobram (parâmetros) ou os itens/propriedades que sobram (desestruturação). Sempre por último.
  • { ...obj, chave: novo } copia trocando uma propriedade: quem vem depois vence.
  • As cópias com spread são rasas.
  • Em [ ], só dá para espalhar o que é iterável; objeto comum ou undefined dão is not iterable.
