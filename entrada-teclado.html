JavaScript Lendo o Teclado no Node

Até agora, todos os valores dos seus programas estavam escritos no próprio código: o nome "Ana", o preço 0.5. Para mudar, só editando o arquivo. Nesta aula, o programa vai perguntar, esperar a pessoa digitar no terminal e apertar Enter, e usar a resposta. No Node, quem faz isso é o módulo readline ("ler linha"), que já vem com o Node: não precisa instalar nada.

Você vai aprender
  • As quatro linhas que fazem um programa perguntar algo no terminal: import, createInterface, await rl.question(…) e rl.close().
  • Por que o await está ali (só o necessário, por enquanto).
  • Que a resposta chega sempre como texto, e como transformá-la em número.
  • Como perguntar várias vezes, num laço, até a pessoa digitar "sair".
  • O que acontece com Ctrl+C e Ctrl+D no meio de uma pergunta.
  • Os erros reais mais comuns: o [object Promise], o programa que não termina, e o require misturado com await.

Todos os programas desta aula rodaram no Node.js 24 (v24.22.0) da máquina da Ana, num terminal de verdade, com a Ana digitando as respostas. Nas caixas "Experimente", quem digita é você, no terminal da própria caixa.

E no navegador?

Isto é só do Node. Numa página web, o jeito simples de perguntar é a caixinha do prompt(), que é do navegador e não existe no Node: é a próxima aula, prompt() e alert().

A ideia: o atendente com um bloquinho

Pense num atendente de lanchonete. Para anotar um pedido ele precisa de três coisas:

  1. Pegar o bloquinho antes de começar (no programa: criar o "leitor" ligado ao teclado e à tela).
  2. Perguntar e esperar: "o que vai ser?". Ele não sai anotando antes de o cliente responder (no programa: await rl.question(…)).
  3. Guardar o bloquinho no fim do atendimento (no programa: rl.close()). Se ele esquecer, fica parado no balcão, esperando um pedido que não vem.

1. A primeira pergunta

import { createInterface } from "node:readline/promises";

const rl = createInterface({ input: process.stdin, output: process.stdout });

const nome = await rl.question("Qual é o seu nome? ");
console.log(`Olá, ${nome}!`);

rl.close();

A Ana rodou e, quando apareceu a pergunta, digitou Ana e apertou Enter:

$ node pergunta.js
Qual é o seu nome? Ana
Olá, Ana!
import { createInterface } from "node:readline/promises";
"Traga a ferramenta createInterface do módulo node:readline/promises". Um módulo é um pacote de código pronto; este já vem com o Node (o node: na frente avisa isso). Por enquanto, copie a linha como está; o import é explicado em Módulos.
createInterface({ input: …, output: … })
Cria o "leitor" (o bloquinho do atendente). input ("entrada") diz de onde ler: process.stdin, o teclado. output ("saída") diz onde escrever as perguntas: process.stdout, a tela.
const rl
Guarda o leitor numa constante. O nome rl (de readline) é o que todo mundo usa, inclusive a documentação do Node.
rl.question("Qual é o seu nome? ")
Mostra a pergunta e fica esperando a pessoa digitar e apertar Enter ("question" = "pergunta"). O espaço no fim do texto separa a pergunta do que vai ser digitado.
await
"Espere". A resposta só existe depois que a pessoa digitar, e isso pode levar 1 segundo ou 10 minutos. O await faz o programa esperar a resposta chegar antes de seguir para a próxima linha.
const nome = …
Guarda o que a pessoa digitou (sem o Enter).
rl.close();
"Feche" o leitor: avisa que o programa não vai perguntar mais nada. Sem isso, o programa não termina (veja em Quando dá errado).
O await, em uma frase

Algumas operações demoram e não podem parar o computador inteiro enquanto esperam: ler o teclado, baixar algo da internet, ler um arquivo grande. Elas devolvem uma "promessa" de resultado (uma Promise), e o await espera a promessa ser cumprida e entrega o valor. Por enquanto, basta lembrar: toda rl.question leva um await na frente. O porquê completo está em Promises e async e await.

2. A resposta é sempre texto

Duas perguntas são duas linhas com await rl.question, uma depois da outra. Mas cuidado com números:

import { createInterface } from "node:readline/promises";

const rl = createInterface({ input: process.stdin, output: process.stdout });

const nome = await rl.question("Qual é o seu nome? ");
const idade = await rl.question("Quantos anos você tem? ");
console.log(`Olá, ${nome}! Daqui a 10 anos você terá ${idade + 10}.`);
console.log(typeof idade);

rl.close();

$ node idade_texto.js
Qual é o seu nome? Ana
Quantos anos você tem? 30
Olá, Ana! Daqui a 10 anos você terá 3010.
string

3010? O rl.question devolve sempre uma string (texto), mesmo que a pessoa digite só algarismos: o typeof confirma (veja typeof). E "30" + 10 não soma: junta os textos, "3010" (veja Conversão Automática). A solução é converter a resposta com Number() (veja Conversão):

import { createInterface } from "node:readline/promises";

const rl = createInterface({ input: process.stdin, output: process.stdout });

const nome = await rl.question("Qual é o seu nome? ");
const idade = Number(await rl.question("Quantos anos você tem? "));
console.log(`Olá, ${nome}! Daqui a 10 anos você terá ${idade + 10}.`);

rl.close();

$ node idade.js
Qual é o seu nome? Ana
Quantos anos você tem? 30
Olá, Ana! Daqui a 10 anos você terá 40.

O Number(await rl.question(…)) se lê de dentro para fora: pergunta, espera a resposta ("30") e converte para número (30).

E se a pessoa digitar letras?

Number("dez") dá NaN ("não é um número"; veja NaN). Um programa cuidadoso confere com Number.isNaN antes de fazer contas:

import { createInterface } from "node:readline/promises";

const rl = createInterface({ input: process.stdin, output: process.stdout });

const quantidade = Number(await rl.question("Quantos pães? "));
const preco = Number(await rl.question("Preço de cada um: "));

if (Number.isNaN(quantidade) || Number.isNaN(preco)) {
  console.log("Isso não é um número.");
} else {
  console.log(`Total: R$ ${(quantidade * preco).toFixed(2)}`);
}

rl.close();

A Ana rodou duas vezes: na primeira digitou 10 e 0.5; na segunda, dez e 0.5:

$ node compra.js
Quantos pães? 10
Preço de cada um: 0.5
Total: R$ 5.00
$ node compra.js
Quantos pães? dez
Preço de cada um: 0.5
Isso não é um número.

Para casas decimais, digite com ponto (0.5): Number("0,5") também dá NaN.

3. Perguntar num laço, até a pessoa digitar "sair"

O await rl.question funciona dentro de laços. Com o while (true) e o break da aula break e continue, o programa pergunta quantas vezes for preciso:

import { createInterface } from "node:readline/promises";

const rl = createInterface({ input: process.stdin, output: process.stdout });

let itens = 0;
while (true) {
  const item = await rl.question("Item (ou sair): ");
  if (item === "sair") {
    break;
  }
  itens++;
  console.log(`  anotado: ${item}`);
}
console.log(`A lista tem ${itens} itens.`);

rl.close();

$ node lista.js
Item (ou sair): pão
  anotado: pão
Item (ou sair): leite
  anotado: leite
Item (ou sair): café
  anotado: café
Item (ou sair): sair
A lista tem 3 itens.

O rl.close() fica depois do laço: o leitor só pode ser fechado quando não houver mais perguntas.

Parece assustador, mas a linha que importa é AbortError: Aborted with Ctrl+C: "erro de aborto: abortado com Ctrl+C". Formas diferentes de fazer a mesma coisa

Com require e uma função async. Em muitos programas Node você vai ver o módulo trazido com require (o jeito antigo do Node, o CommonJS; veja require e module.exports). Nesse formato o await não pode ficar solto no arquivo: ele tem de estar dentro de uma função marcada com async:

const { createInterface } = require("node:readline/promises");

async function main() {
  const rl = createInterface({ input: process.stdin, output: process.stdout });
  const nome = await rl.question("Qual é o seu nome? ");
  console.log(`Olá, ${nome}!`);
  rl.close();
}

main();

$ node cjs.js
Qual é o seu nome? Ana
Olá, Ana!

Com uma função de retorno (o jeito mais antigo). O módulo node:readline, sem o /promises, não usa await: você passa para o question uma função, que o Node chama quando a resposta chegar (veja Callbacks Assíncronos):

const readline = require("node:readline");

const rl = readline.createInterface({ input: process.stdin, output: process.stdout });

rl.question("Qual é o seu nome? ", (nome) => {
  console.log(`Olá, ${nome}!`);
  rl.close();
});

$ node callback.js
Qual é o seu nome? Ana
Olá, Ana!

Sem perguntar nada: argumentos na linha de comando. Às vezes nem é preciso perguntar: a pessoa já passa os valores ao rodar, como em node saudar.js Ana. É o assunto de process.argv.

Quando dá errado

Esqueceu o await: [object Promise] 
import { createInterface } from "node:readline/promises";

const rl = createInterface({ input: process.stdin, output: process.stdout });

const nome = rl.question("Qual é o seu nome? ");
console.log(`Olá, ${nome}!`);

rl.close();

$ node semawait.js
Qual é o seu nome? Olá, [object Promise]!

A Ana nem teve tempo de digitar. Sem o await, o programa não esperou: guardou em nome a promessa da resposta (uma Promise, que dentro de um texto aparece como [object Promise]), mostrou a saudação logo em seguida e fechou o leitor. Como consertar: const nome = await rl.question(…);. Se aparecer [object Promise] em qualquer programa, procure um await esquecido.

Esqueceu o rl.close(): o programa não termina 
import { createInterface } from "node:readline/promises";

const rl = createInterface({ input: process.stdin, output: process.stdout });

const nome = await rl.question("Qual é o seu nome? ");
console.log(`Olá, ${nome}!`);

$ node semclose.js
Qual é o seu nome? Ana
Olá, Ana!   « o programa ficou parado aqui, sem voltar ao $, até a Ana apertar Ctrl+C
$ echo $?
0

A saudação apareceu, mas o $ do terminal não voltou: o leitor continuava aberto, esperando mais linhas do teclado. Quando a Ana apertou Ctrl+C, o programa saiu sem mensagem (e, como não havia pergunta em andamento, com código 0). Como consertar: rl.close(); depois da última pergunta.

Mandou as respostas por um "cano" (pipe)

Quem já conhece o terminal pode tentar responder sem digitar, mandando as respostas por um "cano" (o |) com o printf. Com uma pergunta só, funciona (a resposta não aparece na tela, porque ninguém digitou):

Resumo

  • No Node, o teclado se lê com o módulo node:readline/promises: import, createInterface, await rl.question(…) e rl.close().
  • O await faz o programa esperar a pessoa digitar; sem ele, aparece [object Promise].
  • A resposta é sempre texto: use Number() para fazer contas, e Number.isNaN para conferir.
  • Dá para perguntar num laço (while (true) + break no "sair").
  • Sem rl.close(), o programa não termina. Ctrl+C durante a pergunta encerra com AbortError.
  • No navegador, o equivalente é o prompt().
