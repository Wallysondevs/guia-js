Projeto Jogo da Velha na Página

O último projeto do guia é um clássico: o jogo da velha, para a Ana jogar com o sobrinho no computador ou contra o próprio computador. Ele parece simples, e é por isso que é tão bom para treinar: o tabuleiro vira um array, cada jogada muda o array, e a página é redesenhada a partir dele. A parte mais interessante é ensinar o programa a reconhecer uma vitória e, no fim, a jogar.

Você vai praticar
  • Representar o tabuleiro num array de 9 casas e desenhá-lo com botões e CSS grid.
  • Alternar a vez com o operador ternário.
  • Guardar as 8 linhas vencedoras num array de arrays e percorrê-lo com for … of e desestruturação.
  • Detectar o empate com every e a casa livre com find e indexOf (veja some, every…).
  • Manter um placar num objeto e recomeçar a partida.
  • Escrever as regras de um adversário de computador.

O que vamos construir

A página mostra de quem é a vez ("Vez de X"), o tabuleiro de 3 × 3 botões, uma caixinha "Jogar contra o computador", o botão Novo jogo e o placar. Quando alguém completa uma linha, as três casas ficam douradas e aparece "X venceu!" (ou "O venceu!"); se o tabuleiro enche sem vencedor, "Deu velha! (empate)". No Chromium do computador da Ana, numa partida contra o computador em que ela jogou mal de propósito (casas 1, 2 e 4), o computador ganhou pela diagonal, e o Console mostrou:

> casas.join(",")
'X,X,O,X,O,,O,,'
> [...document.querySelectorAll("#tabuleiro button")].map((b) => b.className).join(",")
',,vitoria,,vitoria,,vitoria,,'

O status dizia O venceu! e o placar, X: 0 · O: 1 · Empates: 0. Vamos chegar lá em quatro versões:

  1. O tabuleiro e as jogadas (array, botões, a vez).
  2. Quem venceu? (as 8 linhas, o empate).
  3. Placar, Novo jogo e destaque (objeto, fill, classList).
  4. Contra o computador (ganhar, bloquear, centro, canto).

Antes de começar

Crie a pasta velha com o index.html, o style.css e o script.js, e abra o index.html no navegador (veja JavaScript na Página). Nas caixas Experimente, jogue clicando nas casas do quadro Resultado. As casas são numeradas assim, e a numeração do JavaScript (a posição no array) começa do zero:

Versão 2 · Quem venceu?

Como saber se alguém ganhou? Há só 8 maneiras de completar três em linha: 3 linhas, 3 colunas e 2 diagonais. Em vez de escrever oito if, o programa guarda as oito como uma lista de trios de posições e confere cada trio: se as três casas têm a mesma marca, e ela não é vazia, alguém venceu.

const tabuleiro = document.querySelector("#tabuleiro");
const elStatus = document.querySelector("#status");

const casas = Array(9).fill("");
let vez = "X";
let fim = false;

// As 8 maneiras de ganhar: as posições de cada trio
const LINHAS = [
  [0, 1, 2], [3, 4, 5], [6, 7, 8],  // linhas
  [0, 3, 6], [1, 4, 7], [2, 5, 8],  // colunas
  [0, 4, 8], [2, 4, 6],             // diagonais
];

// Devolve "X" ou "O" se alguém completou um trio; senão, null
function vencedor() {
  for (const [a, b, c] of LINHAS) {
    if (casas[a] !== "" && casas[a] === casas[b] && casas[a] === casas[c]) {
      return casas[a];
    }
  }
  return null;
}

function desenhar() {
  tabuleiro.replaceChildren();
  casas.forEach((marca, i) => {
    const botao = document.createElement("button");
    botao.textContent = marca;
    botao.addEventListener("click", () => jogar(i));
    tabuleiro.append(botao);
  });
}

function jogar(i) {
  if (fim || casas[i] !== "") {
    return;  // jogo acabado ou casa ocupada
  }
  casas[i] = vez;

  const ganhou = vencedor();
  if (ganhou !== null) {
    fim = true;
    elStatus.textContent = `${ganhou} venceu!`;
  } else if (casas.every((marca) => marca !== "")) {
    fim = true;
    elStatus.textContent = "Deu velha! (empate)";
  } else {
    vez = vez === "X" ? "O" : "X";
    elStatus.textContent = `Vez de ${vez}`;
  }
  desenhar();
}

Versão 3 · Placar, Novo jogo e destaque

Três melhorias de uma vez, todas pequenas: um botão para recomeçar sem recarregar a página, um placar que soma as partidas, e o trio vencedor pintado de dourado. Para pintar, o programa precisa saber quais casas venceram, então a função passa a devolver o trio (por exemplo, [0, 1, 2]) em vez da marca. No HTML, depois do tabuleiro:

  <p><button id="novo">Novo jogo</button></p>
  <p id="placar"></p>

No CSS, a classe das casas vencedoras:

#tabuleiro button.vitoria {
  background: gold;
}

E o script.js completo:

const tabuleiro = document.querySelector("#tabuleiro");
const elStatus = document.querySelector("#status");
const elPlacar = document.querySelector("#placar");
const botaoNovo = document.querySelector("#novo");

const casas = Array(9).fill("");
let vez = "X";
let fim = false;
let trioVencedor = null;  // as 3 posições que ganharam, para pintar
const placar = { X: 0, O: 0, empates: 0 };

const LINHAS = [
  [0, 1, 2], [3, 4, 5], [6, 7, 8],  // linhas
  [0, 3, 6], [1, 4, 7], [2, 5, 8],  // colunas
  [0, 4, 8], [2, 4, 6],             // diagonais
];

// Devolve o trio que alguém completou (ex.: [0, 1, 2]); senão, null
function procurarTrio() {
  for (const [a, b, c] of LINHAS) {
    if (casas[a] !== "" && casas[a] === casas[b] && casas[a] === casas[c]) {
      return [a, b, c];
    }
  }
  return null;
}

function desenhar() {
  tabuleiro.replaceChildren();
  casas.forEach((marca, i) => {
    const botao = document.createElement("button");
    botao.textContent = marca;
    if (trioVencedor !== null && trioVencedor.includes(i)) {
      botao.classList.add("vitoria");
    }
    botao.addEventListener("click", () => jogar(i));
    tabuleiro.append(botao);
  });
  elPlacar.textContent = `X: ${placar.X} · O: ${placar.O} · Empates: ${placar.empates}`;
}

function jogar(i) {
  if (fim || casas[i] !== "") {
    return;
  }
  casas[i] = vez;

  trioVencedor = procurarTrio();
  if (trioVencedor !== null) {
    fim = true;
    placar[vez]++;
    elStatus.textContent = `${vez} venceu!`;
  } else if (casas.every((marca) => marca !== "")) {
    fim = true;
    placar.empates++;
    elStatus.textContent = "Deu velha! (empate)";
  } else {
    vez = vez === "X" ? "O" : "X";
    elStatus.textContent = `Vez de ${vez}`;
  }
  desenhar();
}

function novoJogo() {
  casas.fill("");
  vez = "X";
  fim = false;
  trioVencedor = null;
  elStatus.textContent = `Vez de ${vez}`;
  desenhar();
}

botaoNovo.addEventListener("click", novoJogo);

Um objeto com uma contagem para cada resultado. As chaves X e O são as mesmas marcas do jogo, de propósito: veja a linha abaixo.
placar[vez]++;
Com vez valendo "X", é o mesmo que placar.X++. Os colchetes usam o valor da variável como nome da chave (veja Propriedades).

No desenhar: se a posição do botão está no trio, ele ganha a classe vitoria.
casas.fill("");
Esvazia as 9 casas do mesmo array (por isso casas pode ser const).
botaoNovo.addEventListener("click", novoJogo);
Entrega a função novoJogo, sem parênteses: ela roda no clique.
novoJogo();
No fim do arquivo: começar a primeira partida é o mesmo que um Novo jogo.

Versão 4 · Contra o computador

Para jogar sozinha, a Ana quer um adversário. Um computador que joga bem não precisa de nada mágico: basta seguir, em ordem, as regras que uma pessoa experiente segue. 1. Se dá para ganhar agora, ganhe. 2. Se o outro vai ganhar na próxima, bloqueie. 3. Pegue o centro. 4. Pegue um canto. 5. Pegue o que sobrar. No HTML, a caixinha, antes do Novo jogo:

  <p><label><input type="checkbox" id="contra"> Jogar contra o computador (ele é o O)</label></p>

No script.js, uma constante nova (const caixaContra = document.querySelector("#contra");), os botões passam a chamar clicar(i) em vez de jogar(i), e entram duas funções:

// A jogada do computador: ganhar, senão bloquear, senão o centro, senão um canto, senão o que sobrar
function escolherJogada() {
  for (const marca of ["O", "X"]) {
    for (const trio of LINHAS) {
      const marcas = trio.filter((i) => casas[i] === marca);
      const vazias = trio.filter((i) => casas[i] === "");
      if (marcas.length === 2 && vazias.length === 1) {
        return vazias[0];
      }
    }
  }
  if (casas[4] === "") {
    return 4;
  }
  const cantoLivre = [0, 2, 6, 8].find((i) => casas[i] === "");
  if (cantoLivre !== undefined) {
    return cantoLivre;
  }
  return casas.indexOf("");
}

// O clique da pessoa; contra o computador, ele responde na hora
function clicar(i) {
  if (caixaContra.checked && vez === "O") {
    return;  // é a vez do computador
  }
  jogar(i);
  if (caixaContra.checked && !fim && vez === "O") {
    jogar(escolherJogada());
  }
}
PeçaO que faz
for (const marca of ["O", "X"])Primeiro procura com "O" (as próprias marcas: regra 1, ganhar); depois com "X" (as do adversário: regra 2, bloquear). A ordem importa: ganhar vale mais que bloquear.
trio.filter((i) => casas[i] === marca)As posições do trio que já têm a marca.
marcas.length === 2 && vazias.length === 1Duas marcas iguais e uma casa vazia: falta uma para fechar o trio. A casa vazia é a jogada.
[0, 2, 6, 8].find(…)O primeiro canto livre, ou undefined se não houver (veja find).
casas.indexOf("")A primeira casa vazia que sobrou.
caixaContra.checkedtrue se a caixinha está marcada.
jogar(escolherJogada());Logo depois da jogada da pessoa, se o jogo continua e é a vez do O, o computador joga. É a mesma função jogar: as regras de vitória, empate e placar valem para os dois.

Com a caixinha marcada, a Ana jogou na casa 1, e o computador respondeu no centro. Ela jogou na casa 2, ameaçando fechar a primeira linha, e o computador bloqueou na casa 3:

> casas.join(",")
'X,X,O,,O,,,,'

Aí ela jogou na casa 4, e o computador, que tinha O nas posições 2 e 4, fechou a diagonal na casa 7 (posição 6): é a partida do começo da página, com O venceu!.

Ele é imbatível?

Quase. Com essas cinco regras, o computador nunca perde uma jogada óbvia, mas uma pessoa esperta consegue armar uma "dupla ameaça" (duas linhas para fechar ao mesmo tempo), e ele só bloqueia uma. Um computador perfeito no jogo da velha existe e usa um algoritmo chamado minimax, que testa todas as continuações possíveis com recursão: é um ótimo próximo passo para quem terminar o guia.

Missão (versão 4): a função escolherJogada está pronta, mas ninguém a chama: marcando a caixinha, o computador não joga. No clicar, depois do jogar(i), faça o computador jogar quando a caixinha estiver marcada, o jogo não tiver acabado e a vez for do O. Rode, marque a caixinha e jogue na casa 1: o computador deve pegar o centro.

  } else if (casas.every((marca) => marca !== "")) {
    fim = true;
    placar.empates++;
    elStatus.textContent = "Deu velha! (empate)";
  } else {
    vez = vez === "X" ? "O" : "X";
    elStatus.textContent = `Vez de ${vez}`;
  }
  desenhar();
}

// A jogada do computador: ganhar, senão bloquear, senão o centro, senão um canto, senão o que sobrar
function escolherJogada() {
  for (const marca of ["O", "X"]) {
    for (const trio of LINHAS) {
      const marcas = trio.filter((i) => casas[i] === marca);
      const vazias = trio.filter((i) => casas[i] === "");
      if (marcas.length === 2 && vazias.length === 1) {
        return vazias[0];
      }
    }
  }
  if (casas[4] === "") {
    return 4;
  }
  const cantoLivre = [0, 2, 6, 8].find((i) => casas[i] === "");
  if (cantoLivre !== undefined) {
    return cantoLivre;
  }
  return casas.indexOf("");
}

// O clique da pessoa; contra o computador, ele responde na hora
function clicar(i) {
  if (caixaContra.checked && vez === "O") {
    return;  // é a vez do computador
  }
  jogar(i);
  if (caixaContra.checked && !fim && vez === "O") {
    jogar(escolherJogada());
  }
}

function novoJogo() {
  casas.fill("");
  vez = partidas % 2 === 0 ? "X" : "O";  // alterna quem começa
  partidas++;
  fim = false;
  trioVencedor = null;
  elStatus.textContent = `Vez de ${vez}`;
  desenhar();
  if (caixaContra.checked && vez === "O") {
    jogar(escolherJogada());
  }
}

botaoNovo.addEventListener("click", novoJogo);

novoJogo();

Resumo

  • O tabuleiro é um array de 9 casas; o CSS grid o mostra em 3 × 3. A tela é redesenhada a partir do array a cada jogada.
  • As 8 vitórias possíveis ficam numa lista de trios; um laço com desestruturação confere todas. Três casas vazias também são "iguais": exclua o "".
  • every detecta o tabuleiro cheio; fim impede jogadas depois do resultado.
  • O placar é um objeto; placar[vez]++ usa o valor da variável como chave. fill("") recomeça a partida.
  • Um adversário de computador pode ser só uma lista de regras em ordem: ganhar, bloquear, centro, canto, o que sobrar.
