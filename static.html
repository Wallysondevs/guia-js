JavaScript static

Até aqui, tudo o que você pôs numa classe era de cada objeto: cada produto tem o seu nome, o seu preço e sabe se descrever. Mas algumas coisas não são de um produto em particular: quantos produtos a lojinha já cadastrou, a taxa de entrega que vale para todos os pedidos, uma função que formata dinheiro. Essas coisas são da classe, e se marcam com a palavra static.

Você vai aprender
  • A diferença entre o que é de cada objeto e o que é da classe.
  • Como escrever e chamar um método static: Moeda.formatar(5.49).
  • Que você já usou vários: Math.max, Number.isInteger, Array.isArray, Object.keys.
  • Como criar campos static: um contador de produtos e constantes da classe.
  • O método de fábrica, que cria objetos a partir de um texto, e o que acontece com static na herança.
  • Os erros reais: chamar o static pelo objeto, chamar o método normal pela classe, e o this que não é o que você esperava.

Todos os programas desta aula rodaram no Node.js 24 da máquina da Ana (usuária ana, computador notebook), com node arquivo.js. Você pode rodar cada um no editor do guia.

A ideia: o que está escrito em cada pote × o que está escrito na fábrica

Pense numa fábrica de potes de geleia. Cada pote tem a sua etiqueta: sabor, data, peso. Essas informações são do pote; dois potes podem ter sabores diferentes. Mas na parede da fábrica tem um quadro: "potes fabricados hoje: 312". Esse número não é de pote nenhum: é da fábrica. E a máquina que cola etiquetas também é da fábrica: os potes não carregam a máquina dentro deles.

static, em inglês, quer dizer "estático", "parado": algo que fica na classe e não vai junto para cada objeto.

1. O primeiro método static

A Ana mostra preços em vários lugares e quer sempre o mesmo formato, com vírgula: R$ 5,49. Uma função que formata não precisa de produto nenhum: recebe um número, devolve um texto. Ela agrupa essa função numa classe Moeda:

class Moeda {
  static formatar(valor) {
    return `R$ ${valor.toFixed(2).replace(".", ",")}`;
  }
}

console.log(Moeda.formatar(5.49));
console.log(Moeda.formatar(27.9));
console.log(typeof Moeda.formatar);
static formatar(valor) { … }
Um método como os da aula Classes, só que com static na frente. Ele passa a pertencer à classe Moeda, não aos objetos dela.
valor.toFixed(2).replace(".", ",")
Fixa 2 casas ("5.49") e troca o ponto pela vírgula ("5,49"). O replace está em Substituindo.
Moeda.formatar(5.49)
A chamada usa o nome da classe, sem new e sem criar objeto nenhum.
typeof Moeda.formatar
function: um método static é uma função guardada dentro da classe, como uma gaveta com etiqueta.
$ node moeda.js
R$ 5,49
R$ 27,90
function

Missão: este programa dá erro, porque formatar é um método normal (de objeto) e está sendo chamado pela classe. Rode para ver a mensagem e conserte com uma palavra, para aparecer R$ 5,49.

Você já usou vários métodos static

Desde o começo do guia, você chama métodos pelo nome de uma classe pronta do JavaScript, sem new. São todos static:

console.log(Number.isInteger(5.49));
console.log(Array.isArray([1, 2, 3]));

$ node prontos.js

true
[ 'nome', 'preco' ]
Ana

Compare: Number.isInteger(5.49) é static (chamado pelo Number), mas (5.49).toFixed(2) é de cada número (chamado pelo valor). Array.isArray(lista) é static, mas lista.push(4) é de cada array. O String.fromCharCode monta um texto a partir dos códigos das letras (65 é A, 110 é n, 97 é a). (O Math é um caso especial: ele nem é uma classe, é um objeto só com funções, e nunca se faz new Math().)

2. Campos static: um contador da classe

Campos também podem ser static. A Ana quer saber quantos produtos já cadastrou. Esse número é um só para a loja inteira, então mora na classe:

class Produto {
  static total = 0;

  constructor(nome, preco) {
    this.nome = nome;
    this.preco = preco;
    Produto.total = Produto.total + 1;
  }
}

console.log(`Cadastrados: ${Produto.total}`);
const arroz = new Produto("Arroz 5 kg", 27.9);
const leite = new Produto("Leite 1 L", 5.49);
const cafe = new Produto("Café 500 g", 19.9);
console.log(`Cadastrados: ${Produto.total}`);
console.log(leite);
console.log(leite.total);
static total = 0;
Um campo static: uma variável que pertence à classe, criada uma vez só, quando a classe é lida, com o valor 0.
Produto.total = Produto.total + 1;
Dentro do construtor, que roda a cada new, a classe soma 1 no seu contador. Repare que é Produto.total, e não this.total: o this do construtor é o produto novo, não a classe.
Cadastrados: 0 … Cadastrados: 3
Antes de qualquer new, o campo já existe e vale 0. Depois de três new, vale 3.
console.log(leite)
O leite não carrega o total: só tem nome e preço.
leite.total → undefined
Pelo objeto, o campo static não aparece. (Na seção Quando dá errado você vê o problema que isso causa.)
$ node contador.js
Cadastrados: 0
Cadastrados: 3
Produto { nome: 'Leite 1 L', preco: 5.49 }
undefined

Constantes da classe

Um uso muito comum de campo static é guardar um valor fixo que a classe usa, com um nome que explica o número. Os programadores costumam escrever essas constantes em MAIUSCULAS_COM_SUBLINHADO:

class Pedido {
  static TAXA_ENTREGA = 7.5;
  static PEDIDO_MINIMO = 20;

  constructor(valor) {
    this.valor = valor;
  }

  total() {
    if (this.valor >= Pedido.PEDIDO_MINIMO) {
      return this.valor;
    }
    return this.valor + Pedido.TAXA_ENTREGA;
  }
}

console.log(new Pedido(15).total());
console.log(new Pedido(42).total());
console.log(`Entrega grátis a partir de R$ ${Pedido.PEDIDO_MINIMO}`);

$ node constantes.js
22.5
42
Entrega grátis a partir de R$ 20

O pedido de R$ 15 ficou abaixo do mínimo e pagou a taxa (15 + 7,5 = 22,5); o de R$ 42 não pagou. Escrever Pedido.TAXA_ENTREGA em vez de 7.5 no meio da conta deixa claro o que o número é, e, se a taxa mudar, a Ana troca num lugar só. (Atenção: um campo static pode ser trocado por qualquer parte do programa, como o total da seção anterior. As maiúsculas são só um combinado entre programadores dizendo "não mexa".)

3. Método de fábrica: criar objetos a partir de um texto

A lista de preços do fornecedor chega como texto: Arroz 5 kg;27.90. Quem sabe transformar uma linha dessas em produto? Não é um produto (ele ainda não existe), é a classe. Um método static que cria e devolve um objeto é chamado de método de fábrica:

class Produto {
  constructor(nome, preco) {
    this.nome = nome;
    this.preco = preco;
  }

  static deTexto(linha) {
    const [nome, preco] = linha.split(";");
    return new Produto(nome, Number(preco));
  }

  descrever() {
    return `${this.nome}: R$ ${this.preco.toFixed(2)}`;
  }
}

const linhas = ["Arroz 5 kg;27.90", "Leite 1 L;5.49", "Café 500 g;19.90"];

for (const linha of linhas) {
  const produto = Produto.deTexto(linha);
  console.log(produto.descrever());
}

$ node fabrica.js
Arroz 5 kg: R$ 27.90
Leite 1 L: R$ 5.49
Café 500 g: R$ 19.90
linha.split(";")
Corta o texto no ;: ["Arroz 5 kg", "27.90"] (aula split e join). A desestruturação const [nome, preco] guarda as duas partes.
new Produto(nome, Number(preco))
Converte o preço de texto para número (aula Conversão) e cria o produto com o construtor de sempre.
Produto.deTexto(linha)
Quem usa a classe nem precisa saber como a linha é cortada: pede um produto "a partir do texto" e recebe um pronto. O nome de… (em inglês costuma ser from…, como em Array.from) diz de onde o objeto vem.

4. static e herança: o this de um método static

Os membros static também são herdados pelas classes filhas (aula Herança). E dentro de um método static, o this é a classe que foi usada na chamada. Com isso, a fábrica pode escrever new this(…) em vez de new Produto(…), e passa a servir também para as filhas:

class Produto {
  constructor(nome, preco) {
    this.nome = nome;
    this.preco = preco;
  }

  static deTexto(linha) {
    const [nome, preco] = linha.split(";");
    return new this(nome, Number(preco));
  }
}

class Brinde extends Produto {
  descrever() {
    return `${this.nome}: grátis!`;
  }
}

const caneta = Brinde.deTexto("Caneta da loja;0");
console.log(caneta);
console.log(caneta.descrever());
console.log(Produto.deTexto("Leite 1 L;5.49"));

$ node heranca-static.js
Brinde { nome: 'Caneta da loja', preco: 0 }
Caneta da loja: grátis!
Produto { nome: 'Leite 1 L', preco: 5.49 }
  • O Brinde não escreveu nenhum deTexto, mas Brinde.deTexto(…) funcionou: herdou do Produto.
  • Na chamada Brinde.deTexto(…), o this era Brinde, então new this(…) criou um Brinde (que sabe dizer grátis!). Na chamada Produto.deTexto(…), criou um Produto.
  • Com new Produto(…) escrito à mão, a caneta teria saído como um produto comum. O this em geral é o assunto da aula this, call, apply e bind.

5. O bloco static { } ES2022

Quando preparar os campos static dá mais trabalho que um =, existe o bloco static: um trecho de código que roda uma vez, no momento em que a classe é criada.

class Cardapio {
  static itens = [];

  static {
    Cardapio.itens.push("Pão francês");
    Cardapio.itens.push("Pão de queijo");
    console.log("Cardápio montado!");
  }
}

console.log(Cardapio.itens);

$ node bloco.js
Cardápio montado!
[ 'Pão francês', 'Pão de queijo' ]

Repare que Cardápio montado! apareceu antes, sem ninguém chamar nada e sem nenhum new: o bloco rodou quando o Node leu a classe. É um recurso pouco usado; você vai vê-lo mais em código de bibliotecas.

Formas diferentes de fazer a mesma coisa

Uma função que não precisa de objeto nenhum, como o formatar, não precisa morar numa classe. No JavaScript, as três formas abaixo funcionam:

// 1. método static numa classe
class Moeda {
  static formatar(valor) {
    return `R$ ${valor.toFixed(2).replace(".", ",")}`;
  }
}

// 2. função comum, solta no arquivo (ou exportada de um módulo)
function formatarMoeda(valor) {
  return `R$ ${valor.toFixed(2).replace(".", ",")}`;
}

// 3. um objeto comum com funções dentro (como o Math)
const moeda = {
  formatar(valor) {
    return `R$ ${valor.toFixed(2).replace(".", ",")}`;
  },
};
SituaçãoQual usar
Uma função solta, que só faz uma conta ou formataFunção comum (e, se for usada em vários arquivos, um módulo)
Uma função que tem tudo a ver com uma classe e cria objetos dela (Produto.deTexto)Método static
Um valor que é da classe toda (contador, taxa, lista de opções)Campo static
Algo que muda de um objeto para outro (nome, preço)Campo e método normais (sem static)

Resumo

  • static marca o que é da classe, e não de cada objeto. Acesse pelo nome da classe: Moeda.formatar(…), Produto.total.
  • Métodos static servem para funções que não precisam de um objeto, como formatar e criar objetos (métodos de fábrica: Produto.deTexto(…)). Você já usava vários: Math.max, Number.isInteger, Array.isArray.
  • Campos static guardam um valor único para a classe: um contador, uma taxa, uma lista de opções.
  • Dentro de um método static, this é a classe; dentro de um método normal, é o objeto. Por isso this.total num método normal dá undefined.
  • Os static são herdados pelas filhas; com new this(…), a fábrica cria objetos da classe que foi chamada.
  • Chamar o static pelo objeto, ou o normal pela classe, dá TypeError: … is not a function.
