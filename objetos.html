JavaScript Objetos

Um array é ótimo para uma lista de coisas do mesmo tipo: os nomes da turma, os preços do carrinho. Mas, para descrever uma coisa com várias informações diferentes, como uma pessoa (nome, idade, cidade) ou um produto (nome, preço, estoque), você precisa de outra estrutura: o objeto. Um objeto guarda vários valores, cada um com um nome. É, de longe, a estrutura mais usada do JavaScript: quase tudo na linguagem é objeto ou se parece com um.

Você vai aprender
  • A ideia da ficha: cada informação tem um nome (a chave) e um valor.
  • Como criar um objeto com { } e ler um valor com o ponto: ana.nome.
  • O que cabe num objeto: textos, números, booleanos, null, arrays e até outros objetos.
  • Quando a chave precisa de aspas, o objeto vazio {} e o atalho { nome, idade }.
  • Arrays de objetos: a forma mais comum de guardar dados de verdade.
  • Quando usar objeto e quando usar array.
  • Os erros reais: a vírgula esquecida, o = no lugar dos dois-pontos, o [object Object].

Todos os programas desta aula rodaram no Node.js 24 da máquina da Ana (usuária ana, computador notebook), salvos na pasta pessoal dela e executados com node arquivo.js. Você pode rodar cada um no editor do guia.

A ideia: a ficha de cadastro

Quando a Ana se matriculou na academia, preencheu uma ficha:

CampoValor
NomeAna
Idade30
CidadeRecife
Tem animal de estimação?Sim

Cada linha da ficha tem duas partes: o nome do campo ("Idade") e o valor ("30"). Ninguém pergunta "qual é o 2º dado da Ana?"; pergunta "qual é a idade da Ana?". Um objeto do JavaScript é exatamente essa ficha: um conjunto de pares chave → valor. Cada par se chama propriedade.

1. O primeiro objeto

const ana = {
  nome: "Ana",
  idade: 30,
  cidade: "Recife",
  temPet: true,
};
console.log(ana);
console.log(ana.nome);
console.log(`${ana.nome} tem ${ana.idade} anos e mora em ${ana.cidade}.`);
console.log(typeof ana);

$ node ficha.js
{ nome: 'Ana', idade: 30, cidade: 'Recife', temPet: true }
Ana
Ana tem 30 anos e mora em Recife.
object
const ana = { … };
As chaves { } criam um objeto. Escrever o objeto direto no código assim se chama literal de objeto. A variável ana guarda o objeto inteiro.
nome: "Ana"
Uma propriedade: a chave nome, os dois-pontos e o valor "Ana". A chave é escrita sem aspas quando é um nome simples (letras, números, _ e $, sem começar com número), como os nomes de variáveis.
, (vírgula)
Separa uma propriedade da outra. A vírgula depois da última (temPet: true,) é opcional; o guia usa, porque facilita acrescentar outra linha depois.
uma propriedade por linha
Não é obrigatório ({ nome: "Ana", idade: 30 } numa linha também vale), mas com muitas propriedades fica mais fácil de ler. Os 2 espaços na frente mostram que elas estão dentro do objeto.
ana.nome
O ponto lê uma propriedade: "o nome da ana". Leia em voz alta como "ana ponto nome".
typeof ana → object
O tipo de um objeto é "object" (aula typeof).

Repare como o Node mostra o objeto: entre chaves, com chave: valor, e os textos com aspas simples. É só o jeito de exibir; no código, o guia usa aspas duplas.

Por que não variáveis soltas?

Sem objetos, a ficha da Ana e a do Caio virariam seis variáveis:

const nomeDaAna = "Ana";
const idadeDaAna = 30;
const cidadeDaAna = "Recife";
const nomeDoCaio = "Caio";
const idadeDoCaio = 25;
const cidadeDoCaio = "Natal";
console.log(nomeDaAna, idadeDaAna, cidadeDaAna);
console.log(nomeDoCaio, idadeDoCaio, cidadeDoCaio);

$ node separado.js
Ana 30 Recife
Caio 25 Natal

Funciona, mas nada "amarra" a idade da Ana à Ana. Com 100 pessoas, seriam 300 variáveis. Com objetos, cada pessoa é um valor, que dá para guardar numa lista, passar para uma função ou salvar num arquivo de uma vez.

Missão: o objeto livro está sem o número de páginas, e a frase mostra undefined páginas. Acrescente a propriedade paginas com o valor 256 dentro do objeto (não esqueça a vírgula).

const livro = {
  titulo: "Dom Casmurro",
  autor: "Machado de Assis",
};
console.log(`${livro.titulo}, de ${livro.autor}: ${livro.paginas} páginas`);

const livro = {
  titulo: "Dom Casmurro",
  autor: "Machado de Assis",

};

No lab, a solução mostrou Dom Casmurro, de Machado de Assis: 256 páginas. Antes de você consertar, a propriedade não existia, e ler uma propriedade que não existe dá undefined, sem erro.

3. O que cabe dentro de um objeto

Qualquer valor do JavaScript pode ser o valor de uma propriedade, inclusive um array ou outro objeto:

const produto = {
  nome: "Caderno universitário",
  preco: 18.9,
  emEstoque: true,
  cores: ["azul", "verde", "rosa"],
  fornecedor: { nome: "Papelaria Sol", cidade: "Olinda" },
  desconto: null,
};
console.log(produto);
console.log(produto.cores[0]);
console.log(produto.fornecedor.cidade);

$ node valores.js
{
  nome: 'Caderno universitário',
  preco: 18.9,
  emEstoque: true,
  cores: [ 'azul', 'verde', 'rosa' ],
  fornecedor: { nome: 'Papelaria Sol', cidade: 'Olinda' },
  desconto: null
}
azul
Olinda
nome, preco, emEstoque
Um texto, um número e um booleano.
cores: [ … ]
Um array dentro do objeto. Para ler a primeira cor: produto.cores (o array) e depois [0].
fornecedor: { … }
Um objeto dentro do objeto. Para ler a cidade do fornecedor, use dois pontos seguidos: produto.fornecedor.cidade, da esquerda para a direita.
desconto: null
null diz "este campo existe, mas está vazio de propósito" (aula null e undefined).

Com o objeto maior, o Node passou a mostrar uma propriedade por linha. É só a exibição: o objeto é o mesmo.

Objetos muito fundos: o [Object]

Quando há objetos dentro de objetos dentro de objetos, o console.log do Node para de abrir depois de alguns níveis:

const escola = {
  nome: "Escola do Bairro",
  turma: {
    sala: "3B",
    professora: { nome: "Rita", materia: { nome: "Matemática", horas: 4 } },
  },
};
console.log(escola);
console.log(JSON.stringify(escola, null, 2));

$ node fundo.js
{
  nome: 'Escola do Bairro',
  turma: { sala: '3B', professora: { nome: 'Rita', materia: [Object] } }
}
{
  "nome": "Escola do Bairro",
  "turma": {
    "sala": "3B",
    "professora": {
      "nome": "Rita",
      "materia": {
        "nome": "Matemática",
        "horas": 4
      }
    }
  }
}

O [Object] não quer dizer que a matéria sumiu: o Node só resumiu a exibição (ele abre 2 níveis de objetos dentro do primeiro). Para ver tudo, o JSON.stringify(objeto, null, 2) transforma o objeto num texto completo, com 2 espaços de recuo (aula JSON).

4. Chaves com espaço, hífen ou número

Se a chave não for um nome simples (tem espaço, hífen, acento no começo…), ela precisa de aspas. E, para ler, o ponto não funciona: use colchetes com o texto da chave:

const contato = {
  nome: "Bia",
  "data-nascimento": "12/03/1998",
  "telefone celular": "(81) 90000-0000",
  2025: "ano da formatura",
};
console.log(contato);
console.log(contato["telefone celular"]);

$ node chaves.js
{
  '2025': 'ano da formatura',
  nome: 'Bia',
  'data-nascimento': '12/03/1998',
  'telefone celular': '(81) 90000-0000'
}
(81) 90000-0000
  • As chaves com hífen e espaço aparecem entre aspas também na saída do Node.
  • A chave 2025 foi para o começo! Toda chave de objeto é, no fundo, um texto (por isso '2025' com aspas), e chaves que parecem números inteiros vêm sempre primeiro, em ordem crescente. A aula Percorrendo Objetos explica essa regra.
  • Os colchetes contato["telefone celular"] são o outro jeito de ler propriedades; a próxima aula, Propriedades, mostra os dois jeitos em detalhe.

Dica: sempre que puder, prefira chaves simples em camelCase (dataNascimento, telefoneCelular): sem aspas, e o ponto funciona.

5. O objeto vazio e o atalho

Um objeto pode começar vazio e ganhar propriedades depois, atribuindo com o ponto:

const carrinho = {};
console.log(carrinho);
carrinho.pao = 2;
carrinho.leite = 1;
console.log(carrinho);

$ node vazio.js
{}
{ pao: 2, leite: 1 }

Mesmo com const, dá para acrescentar propriedades: o const só impede de trocar o objeto inteiro por outro (aula Constantes). Mudar e apagar propriedades é assunto da próxima aula.

Quando você já tem variáveis com os nomes certos, existe um atalho: escrever só o nome, sem os dois-pontos.

const nome = "Caio";
const idade = 25;
const pessoa = { nome, idade };
console.log(pessoa);

$ node atalho.js
{ nome: 'Caio', idade: 25 }

{ nome, idade } é o mesmo que { nome: nome, idade: idade }: "uma propriedade nome com o valor da variável nome". Você vai ver esse atalho em muito código moderno.

6. Arrays de objetos

Juntando as duas estruturas, você tem o formato de quase todo dado do mundo real: uma lista (array) de fichas (objetos). Uma turma, um estoque, uma lista de contatos:

const turma = [
  { nome: "Ana", nota: 7 },
  { nome: "Bia", nota: 9 },
  { nome: "Caio", nota: 6 },
];
console.log(turma.length);
console.log(turma[1]);
console.log(turma[1].nome);
for (const aluno of turma) {
  console.log(`${aluno.nome}: ${aluno.nota}`);
}

$ node lista.js
3
{ nome: 'Bia', nota: 9 }
Bia
Ana: 7
Bia: 9
Caio: 6
turma[1]
O item 1 do array: o objeto inteiro da Bia.
turma[1].nome
Primeiro a posição no array, depois a chave no objeto.
for (const aluno of turma)
O for … of entrega um objeto por volta; aluno.nome e aluno.nota leem as propriedades dele.

Com arrays de objetos, todos os métodos que você aprendeu funcionam: filter para os aprovados, map para pegar só os nomes, reduce para a soma das notas, toSorted para o ranking.

Dentro de uma template string ou com +, o objeto é transformado em texto, e o texto padrão de um objeto é [object Object] ("objeto do tipo Object"), que não diz nada. Como consertar: mostre as propriedades que interessam (${ana.nome}), passe o objeto separado por vírgula no console.log (terceira linha) ou use JSON.stringify(ana).

Nome da propriedade errado: undefined 
const ana = { nome: "Ana", idade: 30 };
console.log(ana.nmoe);
console.log(ana.Nome);

$ node naoexiste.js

undefined

Ler uma propriedade que não existe não dá erro: dá undefined. Um erro de digitação (nmoe) ou uma maiúscula (Nome; o JavaScript diferencia maiúsculas de minúsculas) passa em silêncio. Como consertar: quando aparecer undefined onde devia ter um valor, compare letra por letra o nome da propriedade com o do objeto.

Resumo

  • Um objeto guarda várias informações sobre uma coisa, cada uma com um nome: { chave: valor, … }. Cada par é uma propriedade.
  • Dentro de { }: dois-pontos entre chave e valor, vírgula entre propriedades.
  • obj.chave lê uma propriedade; se ela não existe, o resultado é undefined, sem erro.
  • Os valores podem ser qualquer coisa: textos, números, booleanos, null, arrays e outros objetos (obj.interno.chave, obj.lista[0]).
  • Chave com espaço ou hífen vai entre aspas e se lê com colchetes; prefira chaves em camelCase.
  • Array = lista de coisas, pela posição; objeto = uma coisa, pelas chaves. Array de objetos = o formato da maioria dos dados reais.
  • Para mostrar um objeto, passe-o separado no console.log; dentro de uma template string ele vira [object Object].
