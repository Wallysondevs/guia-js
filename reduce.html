JavaScript reduce

O map transforma cada item de um array e devolve outro array. O filter escolhe alguns itens e devolve outro array. Mas muitas perguntas do dia a dia pedem uma resposta só: quanto deu o carrinho inteiro? Qual é a média da turma? Qual foi a maior temperatura da semana? Para isso existe o reduce (em inglês, "reduzir"): ele passa por todos os itens e vai acumulando um resultado, até sobrar um valor só.

Você vai aprender
  • A ideia do acumulador: o valor que vai sendo carregado de um item para o outro.
  • Como se escreve um reduce: a função com (acumulador, item) e o valor inicial.
  • Como acompanhar, volta por volta, o que o reduce faz.
  • Usos práticos: somar, tirar a média, multiplicar, achar o maior, contar, juntar textos, montar um placar.
  • O reduceRight, que começa pelo fim.
  • Quando o reduce é a melhor escolha, e quando um for … of, um filter ou um Math.max deixam o código mais claro.
  • Os erros reais: o array vazio sem valor inicial, o return esquecido, os números que eram textos.

Todos os programas desta aula rodaram no Node.js 24 da máquina da Ana (usuária ana, computador notebook), salvos na pasta pessoal dela e executados com node arquivo.js (veja Rodando um Programa). Você pode rodar cada um no editor do guia.

A ideia: a calculadora do caixa

Na padaria do bairro, a Ana passa as compras de um cliente no caixa: pão (R$ 8), leite (R$ 6), café (R$ 15) e queijo (R$ 22). A calculadora faz assim:

  1. O visor começa em 0.
  2. Passa o pão: o visor mostra 0 + 8 = 8.
  3. Passa o leite: o visor mostra 8 + 6 = 14.
  4. Passa o café: 14 + 15 = 29.
  5. Passa o queijo: 29 + 22 = 51. Acabaram os itens: o total é 51.

Repare em três coisas, porque elas são exatamente as três peças do reduce:

  • O visor guarda o resultado parcial e passa de um item para o outro. Ele se chama acumulador.
  • Para cada item, a calculadora faz a mesma conta: "o que está no visor + o preço deste item". Essa conta é a função que você entrega ao reduce.
  • O visor precisou de um valor inicial (o 0) antes do primeiro item.

1. Primeiro, sem reduce

Você já sabe somar um array com o for … of: uma variável começa em 0 e recebe cada preço.

const precos = [8, 6, 15, 22];
let total = 0;
for (const preco of precos) {
  total = total + preco;
}
console.log("Total:", total);

$ node total-for.js
Total: 51

A variável total é o visor da calculadora: um acumulador. Ela precisa ser let, porque muda a cada volta. O reduce faz o mesmo trabalho, mas cuida sozinho do laço e da variável que muda.

2. O mesmo total com reduce

const precos = [8, 6, 15, 22];
const total = precos.reduce((soma, preco) => soma + preco, 0);
console.log("Total:", total);

$ node total-reduce.js
Total: 51

Mesmo resultado, numa linha só. Vamos desmontar essa linha peça por peça:

precos.reduce(…)
Chama o método reduce do array precos. Como o map e o filter, ele não muda o array original.
(soma, preco) => soma + preco
A função que o reduce vai chamar uma vez para cada item (é uma arrow function). Ela recebe dois valores, nesta ordem:
soma
O acumulador: o resultado parcial até aqui (o visor). O nome é você quem escolhe; soma, total ou acumulado deixam claro o que ele guarda. Ele vem sempre primeiro.
preco
O item atual do array, o que está passando no caixa agora.
soma + preco
O que a função devolve. Esse valor vira o acumulador da próxima volta. Na arrow function sem chaves, o valor depois do => é devolvido sozinho, sem precisar escrever return.
, 0
O segundo argumento do reduce: o valor inicial do acumulador (o visor zerado). Fica depois da função, antes do ) final. É fácil esquecer; a seção Quando dá errado mostra o que acontece.
const total = …
O que o reduce devolve no fim: o valor do acumulador depois do último item. Como esse valor não muda mais, pode ser const.
PeçaNa calculadoraNo código
AcumuladorO visorsoma (1º parâmetro)
Item atualO produto passandopreco (2º parâmetro)
A conta de cada item"visor + preço"soma + preco (o que a função devolve)

Passo a passo: o que o reduce fez

Para ver o acumulador andando, a Ana trocou a arrow function curta por uma com chaves e pôs um console.log dentro dela. Com chaves, o return passa a ser obrigatório:

const precos = [8, 6, 15, 22];
const total = precos.reduce((soma, preco) => {
  console.log(`soma = ${soma}, preco = ${preco}, devolve ${soma + preco}`);
  return soma + preco;
}, 0);
console.log("Total:", total);

A regra de ouro do reduce: o que a função devolve numa volta é o que ela recebe como acumulador na volta seguinte. Quatro itens, quatro chamadas da função, um valor no fim.

3. Somar e depois dividir: a média

A média é a soma dividida pela quantidade. O reduce faz a soma; o length dá a quantidade:

const notas = [7, 8.5, 6, 9];
const soma = notas.reduce((acumulado, nota) => acumulado + nota, 0);
const media = soma / notas.length;
console.log(`Soma: ${soma}, média: ${media}`);

$ node media.js
Soma: 30.5, média: 7.625

Para mostrar com uma casa decimal só, use media.toFixed(1) (aula Formatando Números).

4. O valor inicial depende da conta

Para somar, o visor começa em 0, porque somar 0 não muda nada. Para multiplicar, o certo é começar em 1: multiplicar por 1 não muda nada, mas multiplicar por 0 zera tudo.

const fatores = [2, 3, 4];
const produto = fatores.reduce((resultado, n) => resultado * n, 1);
console.log("Produto:", produto);
const errado = fatores.reduce((resultado, n) => resultado * n, 0);
console.log("Com 0 no começo:", errado);

$ node multiplicar.js
Produto: 24
Com 0 no começo: 0

Com o 0 no começo, a primeira volta faz 0 * 2, que dá 0, e daí em diante tudo é 0. Não aparece erro nenhum: só uma resposta errada. A tabela abaixo resume o valor inicial "neutro" de cada tipo de acumulador:

O que você está acumulandoValor inicialExemplo de função
Uma soma (total, quantidade)0(soma, x) => soma + x
Um produto1(prod, x) => prod * x
Um texto"" (texto vazio)(texto, x) => texto + x
Um objeto (um placar){}veja a seção 7

5. Achar o maior: sem valor inicial

O acumulador não precisa ser uma soma. Ele pode guardar "o maior que eu vi até agora". A Ana anotou as temperaturas máximas da semana:

const temperaturas = [22, 27, 19, 31, 25];
const maior = temperaturas.reduce((maiorAteAgora, t) => (t > maiorAteAgora ? t : maiorAteAgora));
console.log("Maior:", maior);
console.log("Com Math.max:", Math.max(...temperaturas));

$ node maior.js
Maior: 31
Com Math.max: 31
t > maiorAteAgora ? t : maiorAteAgora
O operador ternário: "se esta temperatura for maior que a campeã até agora, ela vira a campeã; senão, a campeã continua". Os parênteses em volta são só para ler melhor.
(sem o , 0)
Aqui não há valor inicial. Quando você não passa um, o reduce usa o primeiro item (22) como acumulador e começa a função pelo segundo (27). Faz sentido: a primeira temperatura é a maior que você viu até ali. Começar em 0 também daria certo nesta semana, mas daria errado num inverno: no lab, com as temperaturas [-3, -1, -7], o valor inicial 0 devolveu 0, uma temperatura que nem estava na lista; sem valor inicial, saiu o certo, -1.
Math.max(...temperaturas)
O jeito pronto de achar o maior número (aula Math). Os três pontinhos espalham os itens do array como argumentos separados (aula Spread e Rest). Para números, é mais curto que o reduce.

Sem valor inicial, há um risco: se o array estiver vazio, o reduce não tem primeiro item para usar e dá erro (veja Quando dá errado). Por isso, a regra prática é: passe sempre o valor inicial, a não ser que o acumulador precise ser um dos itens, como aqui.

6. Contar e juntar textos

Para contar quantos alunos passaram (nota 7 ou mais), o acumulador é um contador que só sobe quando o item interessa:

const notas = [7, 4.5, 8.5, 6, 9, 5];
const aprovados = notas.reduce((quantos, nota) => (nota >= 7 ? quantos + 1 : quantos), 0);
console.log("Aprovados:", aprovados);
console.log("Com filter:", notas.filter((nota) => nota >= 7).length);

$ node contar.js
Aprovados: 3
Com filter: 3

Quando a nota não interessa, a função devolve o quantos do jeito que chegou, sem somar. A segunda linha faz o mesmo de outro jeito: o filter separa os aprovados e o .length conta. As duas estão certas; muita gente acha a do filter mais fácil de ler.

O acumulador também pode ser um texto, que começa vazio e vai crescendo:

const nomes = ["Ana", "Bia", "Caio"];
const lista = nomes.reduce((texto, nome) => texto + nome + "; ", "");
console.log(lista);
console.log(nomes.join("; "));

$ node juntar.js
Ana; Bia; Caio;
Ana; Bia; Caio

O reduce deixou um "; " sobrando no fim. O join (aula split e join) põe o separador só entre os itens e já existe pronto: para juntar textos, prefira ele.

7. Acumulando a partir de objetos

Na vida real, os itens de um array costumam ser objetos, com várias informações juntas, como { nome: "pão", preco: 8, quantidade: 2 }. Os objetos têm aula própria (Objetos); por enquanto, basta saber que item.preco lê o preço do item e item.quantidade lê a quantidade.

const carrinho = [
  { nome: "pão", preco: 8, quantidade: 2 },
  { nome: "leite", preco: 6, quantidade: 3 },
  { nome: "café", preco: 15, quantidade: 1 },
];
const total = carrinho.reduce((soma, item) => soma + item.preco * item.quantidade, 0);
console.log(`Total da compra: R$ ${total}`);

$ node carrinho.js
Total da compra: R$ 49

O 2 × 8 + 3 × 6 + 1 × 15 dá 16 + 18 + 15 = 49. Aqui o valor inicial é obrigatório. A Ana apagou o , 0 para ver o que acontecia:

$ node carrinho-sem.js
Total da compra: R$ [object Object]1815

Sem valor inicial, o primeiro acumulador foi o objeto inteiro do pão, e não um número. Somar um objeto com 18 vira o texto "[object Object]18", e daí em diante o + só junta textos. Por isso, com objetos, passe sempre o 0.

O acumulador como placar

Na festa da escola, a turma votou na comida. A Ana quer saber quantos votos cada uma recebeu. O acumulador agora é um objeto vazio {}, que ganha uma "linha" para cada comida nova:

const votos = ["pizza", "lasanha", "pizza", "sushi", "pizza", "lasanha"];
const placar = votos.reduce((contagem, voto) => {
  contagem[voto] = (contagem[voto] || 0) + 1;
  return contagem;
}, {});
console.log(placar);

$ node votos.js
{ pizza: 3, lasanha: 2, sushi: 1 }
contagem[voto]
A contagem da comida votada (por exemplo, contagem["pizza"]). Na primeira vez que uma comida aparece, ela ainda não existe no placar e vale undefined.
(contagem[voto] || 0) + 1
"O que já tinha, ou 0 se não tinha nada, mais 1". O || troca o undefined por 0 (aula Operadores Lógicos).
return contagem;
Devolve o mesmo placar, agora atualizado, para a próxima volta. Esquecer este return é o erro mais comum desse tipo de reduce.

8. reduceRight: começando pelo fim

O reduce anda da esquerda para a direita (do índice 0 até o último). O reduceRight ("reduzir pela direita") faz o mesmo, mas do último item para o primeiro:

const letras = ["a", "b", "c"];
console.log(letras.reduce((texto, letra) => texto + letra, ""));
console.log(letras.reduceRight((texto, letra) => texto + letra, ""));

$ node direita.js
abc
cba

Para somar, a ordem não muda o resultado; ela só importa quando a conta depende da ordem, como juntar textos. Ele aparece pouco no dia a dia.

Mais dois parâmetros, raramente usados

Além do acumulador e do item, a função do reduce também recebe o índice do item e o array inteiro: (acumulador, item, indice, array), como no map e no filter. Você só escreve os parâmetros que for usar.

Formas diferentes de fazer a mesma coisa

O reduce é poderoso: dá para fazer quase tudo com ele. Isso não quer dizer que ele seja sempre a forma mais clara. Somar os preços, quatro jeitos:

const precos = [8, 6, 15, 22];

// 1) for … of com um acumulador let
let total1 = 0;
for (const preco of precos) {
  total1 = total1 + preco;
}

// 2) forEach com um acumulador let
let total2 = 0;
precos.forEach((preco) => {
  total2 += preco;
});

// 3) reduce, sem let nenhum
const total3 = precos.reduce((soma, preco) => soma + preco, 0);

// 4) for clássico
let total4 = 0;
for (let i = 0; i < precos.length; i++) {
  total4 += precos[i];
}

console.log(total1, total2, total3, total4);

$ node formas.js
51 51 51 51

Os quatro chegam a 51. O reduce é o único que não precisa de uma variável let mudando por fora. A tabela ajuda a escolher:

SituaçãoQual usar
Somar, multiplicar, montar um placar: juntar todos os itens num valorreduce (ou for … of, se achar mais claro)
Achar o maior ou o menor númeroMath.max(...lista) / Math.min(...lista)
Achar o item "campeão" de uma lista de objetos (o mais caro, o mais velho)reduce sem valor inicial
Contar quantos itens passam num testefilter(…).length (ou reduce)
Juntar textos com um separadorjoin
Transformar cada item / escolher alguns itensmap / filter
A conta tem muitos passos, ifs ou breakfor … of: fica mais fácil de ler e de parar no meio

  soma + preco;

Nenhuma mensagem de erro, só uma resposta sem sentido. Quando a arrow function tem chaves, ela só devolve alguma coisa se houver return (aula Retornando Valores). Os números eram textos

Dados que vêm do teclado ou de um arquivo chegam como texto. Olhe o que o + faz com eles:

const precos = ["8", "6", "15", "22"];
const total = precos.reduce((soma, preco) => soma + preco, 0);
console.log("Total:", total);
const certo = precos.reduce((soma, preco) => soma + Number(preco), 0);
console.log("Total certo:", certo);

$ node textos.js
Total: 0861522
Total certo: 51

Na primeira volta, 0 + "8" dá o texto "08": com um texto no meio, o + junta em vez de somar (aula Conversão Automática). Daí em diante tudo vira texto: "086", "08615", "0861522". Como consertar: converta cada item com Number(preco) (aula Conversão).

Resumo

  • O reduce passa por todos os itens e acumula um resultado só: lista.reduce((acumulador, item) => novoAcumulador, valorInicial).
  • O que a função devolve numa volta vira o acumulador da volta seguinte; o que ela devolve na última volta é o resultado.
  • O valor inicial depende da conta: 0 para somar, 1 para multiplicar, "" para texto, {} para um placar. Passe-o sempre, a não ser que o acumulador precise ser um dos itens (o maior, o mais caro).
  • Sem valor inicial, um array vazio dá TypeError: Reduce of empty array with no initial value.
  • Função com chaves precisa de return; sem ele, o resultado é undefined.
  • O reduce não muda o array original. O reduceRight faz o mesmo do fim para o começo.
  • Nem tudo precisa de reduce: Math.max, filter(…).length, join e um for … of às vezes dizem a mesma coisa de forma mais clara.
