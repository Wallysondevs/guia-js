JavaScript for

Na aula while você viu o laço que repete "enquanto" uma condição for verdadeira. Quando você sabe quantas voltas quer (de 1 a 10, os 30 alunos da turma, os 12 meses do ano), existe um laço mais prático: o for (em inglês, "para"). Ele junta numa linha só as três coisas de que todo laço com contador precisa: onde começa, até onde vai e de quanto em quanto anda.

Você vai aprender
  • As três partes do for: início, condição e passo, separadas por ponto e vírgula.
  • Como contar de 1 a 5, de 5 a 1 e de 5 em 5.
  • Como usar o contador numa conta: a tabuada e a soma de 1 a 100.
  • Como percorrer uma lista de compras pela posição de cada item.
  • Por que o contador do for só existe dentro do laço.
  • O laço infinito e o Ctrl+C, e os erros reais mais comuns.

Todos os programas desta aula rodaram no Node.js 24 (v24.22.0) da máquina da Ana (usuária ana, computador notebook), salvos na pasta pessoal dela e executados com node arquivo.js (veja Rodando um Programa). Você pode rodar cada um no editor do guia.

A ideia: "regue os vasos, do 1 ao 5"

A Ana vai viajar e deixa um bilhete para a vizinha: "Comece pelo vaso 1. Enquanto não passar do vaso 5, regue o vaso e vá para o próximo." O bilhete tem três partes, e todo for também:

  1. Início: "comece pelo vaso 1". Acontece uma vez só, antes de tudo.
  2. Condição: "enquanto não passar do vaso 5". É perguntada antes de cada volta.
  3. Passo: "vá para o próximo". Acontece no fim de cada volta.

E o trabalho de cada volta ("regue o vaso") é o corpo do laço. No while, essas três partes ficam espalhadas pelo programa; no for, elas ficam juntas, no alto, onde dá para ver tudo de uma vez.

1. O primeiro for: contar de 1 a 5

for (let i = 1; i <= 5; i++) {
  console.log(`Volta ${i}`);
}
console.log("Fim!");
for
A palavra-chave do laço: "para".
( … )
Os parênteses guardam as três partes, separadas por ponto e vírgula (;), não por vírgula.
let i = 1
O início: cria a variável contadora i valendo 1. Roda uma vez só. O nome i (de "índice") é uma tradição para contadores; poderia ser vaso ou volta. Use let, porque o valor vai mudar (veja Variáveis).
i <= 5
A condição: "enquanto i for menor ou igual a 5". É testada antes de cada volta; quando dá false, o laço acaba (veja Comparação).
i++
O passo: soma 1 em i no fim de cada volta. É o mesmo que i = i + 1 (veja Incremento e Decremento).
{ … }
As chaves guardam o corpo: o que se repete. Os 2 espaços na frente mostram que a linha está dentro do laço.
console.log(`Volta ${i}`)
Mostra o valor atual de i dentro de um texto (veja Template Strings).
console.log("Fim!")
Depois da }, fora do laço: roda uma vez, quando o laço termina.
$ node contar.js
Volta 1
Volta 2
Volta 3
Volta 4
Volta 5
Fim!

2. Contar para trás e de 5 em 5

As três partes podem ser o que você quiser. Para uma contagem regressiva, comece do maior, use a condição "maior que zero" e diminua com --:

for (let segundos = 5; segundos > 0; segundos--) {
  console.log(`${segundos}...`);
}
console.log("Já!");

$ node regressiva.js

4...
3...
2...
1...
Já!

Quando segundos chega a 0, a pergunta 0 > 0 dá false e o laço termina. Aqui o contador se chama segundos: um nome que diz o que ele conta deixa o programa mais fácil de ler.

Para andar de 5 em 5, o passo vira valor += 5 ("some 5 em valor"; veja Atribuição):

for (let valor = 0; valor <= 20; valor += 5) {
  console.log(`R$ ${valor}`);
}

3. Usando o contador numa conta

O i não serve só para contar voltas: ele é um número como outro qualquer e pode entrar em contas. A tabuada do 7 é o exemplo clássico:

const numero = 7;
for (let i = 1; i <= 10; i++) {
  console.log(`${numero} x ${i} = ${numero * i}`);
}

Acumulando: a soma de 1 a 100

Uma variável criada antes do laço pode ir juntando um valor a cada volta. Ela se chama acumulador:

let soma = 0;
for (let n = 1; n <= 100; n++) {
  soma += n;
}
console.log(`A soma de 1 a 100 é ${soma}`);

$ node soma.js
A soma de 1 a 100 é 5050

Na 1ª volta, soma vira 0 + 1 = 1; na 2ª, 1 + 2 = 3; na 3ª, 3 + 3 = 6… e, depois de 100 voltas, 5050. O console.log está fora do laço, por isso mostra só o resultado final. Se ele estivesse dentro das chaves, você veria 100 linhas, uma por volta.

4. Percorrendo uma lista pela posição

Um uso muito comum do for é passar por todos os itens de uma lista. No JavaScript, uma lista entre colchetes se chama array (você vai estudá-la a fundo em Arrays). Por enquanto, basta saber três coisas: os itens são numerados a partir do 0, compras[0] é o primeiro item e compras.length ("comprimento") é quantos itens existem.

const compras = ["pão", "leite", "café", "manteiga"];
for (let i = 0; i < compras.length; i++) {
  console.log(`${i + 1}. ${compras[i]}`);
}

$ node compras.js
1. pão
2. leite
3. café
4. manteiga
let i = 0
Começa do 0, porque o primeiro item é o compras[0].
i < compras.length
A lista tem 4 itens, nas posições 0, 1, 2 e 3. Por isso a condição é menor que 4 (<), e não "menor ou igual" (a seção Quando dá errado mostra o que acontece com <=).
compras[i]
O item na posição i: "pão" na volta com i 0, "leite" com i 1…
i + 1
Só para a Ana ler "1." em vez de "0.". O i continua igual: a conta não muda a variável.

Se a Ana acrescentar "ovos" na lista, o compras.length passa a valer 5 e o laço dá 5 voltas sozinho: nada mais precisa mudar.

5. O contador só existe dentro do laço

Uma variável criada com let no início do for pertence ao laço: depois da } ela some. Tentar usá-la lá fora dá erro:

6. O laço infinito, e como pará-lo

Se a condição nunca ficar falsa, o laço não termina. O jeito mais comum de criar um sem querer é errar o passo: aqui a Ana escreveu i-- em vez de i++, e o i vai para 0, -1, -2… sempre menor ou igual a 5.

for (let i = 1; i <= 5; i--) {
  console.log(`Volta ${i}`);
}
console.log("Fim!");

A Ana deixou o programa rodar só 1 segundo (com o comando timeout 1), mostrando as 3 primeiras linhas com o head -3 e depois contando as linhas com o wc -l:

$ timeout 1 node infinito.js | head -3
Volta 1
Volta 0
Volta -1
$ timeout 1 node infinito.js | wc -l
443088

Mais de 440 mil linhas em um segundo (o número muda de um computador para outro), e o Fim! nunca chega.

No terminal: Ctrl+C

Para interromper um programa que não termina, segure Ctrl e aperte C. O laço infinito também pode ser silencioso: este aqui só faz contas, e o terminal parece "travado":

let total = 0;
for (let i = 1; i <= 5; i--) {
  total += i;
}
console.log(`Total: ${total}`);

$ node travado.js
^C
$ echo $?
130

O ^C é o terminal mostrando que você apertou Ctrl+C. O Node para na hora, sem mensagem nenhuma, e o código de saída (echo $?) é 130, o número que o terminal usa para "interrompido com Ctrl+C" (0 seria "terminou bem").

No editor do guia, enquanto o programa roda, o botão Rodar vira ■ Parar: é o Ctrl+C do editor (veja O Editor do Guia).

Experimente: rode este programa e clique em ■ Parar. Depois conserte o passo (i++) e rode de novo: deve aparecer Total: 15.

let total = 0;
for (let i = 1; i <= 5; i--) {
  total += i;
}

Formas diferentes de fazer a mesma coisa

Contar de 1 a 5 com while dá o mesmo resultado: as três partes só ficam em lugares diferentes.

let i = 1;            // início
while (i <= 5) {      // condição
  console.log(`Volta ${i}`);
  i++;                // passo
}

$ node comwhile.js
Volta 1
Volta 2
Volta 3
Volta 4
Volta 5

Para passar por todos os itens de uma lista, quando você não precisa da posição, existe o for … of ("para cada … de"), que entrega cada item direto, sem i, sem length, sem risco de passar do fim. Ele tem aula própria: Percorrendo com for … of.

const compras = ["pão", "leite", "café", "manteiga"];
for (const item of compras) {
  console.log(item);
}

$ node forof.js
pão
leite
café
manteiga

Por fim, quando o corpo tem uma linha só, as chaves podem ser omitidas. Funciona, mas é fácil se confundir ao acrescentar uma segunda linha (ela ficaria fora do laço). Neste guia, use sempre as chaves.

for (let i = 1; i <= 3; i++) console.log(`Volta ${i}`);

Quando dá errado

Vírgula no lugar do ponto e vírgula 
for (let i = 1, i <= 5, i++) {
  console.log(`Volta ${i}`);
}

SyntaxError: Identifier 'i' has already been declared
    at wrapSafe (node:internal/modules/cjs/loader:1861:18)   « mais 7 linhas "at … node:internal" cortadas

Node.js v24.22.0

"Erro de sintaxe: o identificador i já foi declarado". A mensagem parece não ter nada a ver com vírgulas, e é por isso que este erro confunde. O que aconteceu: com vírgulas, o JavaScript leu let i = 1, i … como "crie i e crie outro i" (a vírgula serve para criar várias variáveis num let só), e duas variáveis com o mesmo nome não pode. É um SyntaxError: o programa nem começou, por isso nenhum Volta apareceu. Como consertar: as três partes se separam com ponto e vírgula: for (let i = 1; i <= 5; i++).

const no contador 
for (const i = 1; i <= 3; i++) {
  console.log(`Volta ${i}`);
}

Volta 1

                           ^

TypeError: Assignment to constant variable.
    at Object.<anonymous> (/home/ana/constante.js:1:28)   « mais 7 linhas "at … node:internal" cortadas

Node.js v24.22.0

"Erro de tipo: atribuição a uma variável constante". A primeira volta rodou (Volta 1); o erro veio no passo, o i++ (o ^ aponta para ele), porque uma const não pode mudar de valor. Como consertar: o contador do for é sempre let. (No for … of o const funciona, porque lá cada volta cria uma variável nova.)

Usar o contador depois do laço

É o ReferenceError: i is not defined da seção 5. Como consertar: se precisa do valor depois, crie a variável antes do for.

A condição já começa falsa: zero voltas 
for (let i = 1; i >= 5; i++) {
  console.log(`Volta ${i}`);
}
console.log("Fim!");

$ node zero.js
Fim!

Nenhum erro, e nenhuma volta. A Ana quis dizer "até 5", mas escreveu i >= 5 ("enquanto i for maior ou igual a 5"). Logo no primeiro teste, 1 >= 5 dá false, e o laço é pulado inteiro. Como consertar: leia a condição em voz alta com "enquanto": ela tem de ser verdadeira para o laço continuar. Aqui, i <= 5.

Passou do fim da lista: undefined 
const compras = ["pão", "leite", "café", "manteiga"];
for (let i = 0; i <= compras.length; i++) {
  console.log(`${i + 1}. ${compras[i]}`);
}

$ node passou.js
1. pão
2. leite
3. café
4. manteiga
5. undefined

Com <=, o laço dá uma volta a mais: i chega a 4, e não existe item na posição 4 (as posições vão de 0 a 3). O JavaScript não reclama: compras[4] só vale undefined ("indefinido"; veja null e undefined). Esse erro de "uma volta a mais ou a menos" é tão comum que tem até apelido em inglês: off-by-one. Como consertar: com let i = 0, use i < compras.length.

O passo errado: laço infinito

É o i-- no lugar de i++ da seção 6: o JavaScript não acusa nada, o programa simplesmente não termina. Como consertar: aperte Ctrl+C e confira se o passo leva o contador na direção que faz a condição ficar falsa: contando para cima com <=, o passo é ++; contando para baixo com >, é --.

Missão: este programa não roda. Leia a mensagem de erro, conserte e rode de novo até aparecer Volta 5. (São dois erros: o JavaScript mostra um de cada vez.)

  console.log(`Volta ${i}`);
}

  console.log(`Volta ${i}`);

Resumo

  • for (início; condição; passo) { … } junta numa linha as três partes de um laço com contador, separadas por ponto e vírgula.
  • O início roda uma vez; depois, a cada volta: condição → corpo → passo. Quando a condição dá false, o laço acaba.
  • O contador é let (nunca const) e só existe dentro do laço.
  • O passo pode ser i++, i--, i += 5… e tem de levar o contador na direção que encerra o laço; senão, é laço infinito (Ctrl+C no terminal, ■ Parar no editor).
  • Para percorrer uma lista pela posição: for (let i = 0; i < lista.length; i++). Sem precisar da posição, prefira o for … of.
  • Para sair do laço no meio ou pular uma volta, veja a próxima aula: break e continue.
