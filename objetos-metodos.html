JavaScript: Métodos e this

Até agora, os objetos guardaram dados: nome, preço, estoque. Mas um objeto também pode guardar ações. O cofrinho da Ana não tem só o saldo: ele sabe receber um depósito. O carrinho de compras não tem só os itens: ele sabe calcular o total. Uma função guardada dentro de um objeto se chama método. E, para o método mexer nos dados do próprio objeto, existe uma palavra especial: this ("este").

Você vai aprender
  • O que é um método: uma propriedade cujo valor é uma função.
  • As duas formas de escrever: saudar: function () { } e a curta, saudar() { }.
  • O this: dentro de um método, ele é o objeto que veio antes do ponto na chamada.
  • Métodos que mudam o objeto (depositar) e que devolvem um valor (total).
  • Que você já usa métodos desde o começo: console.log, push, toUpperCase…
  • Por que a arrow function não serve como método, mas serve dentro de um.
  • Os erros reais: chamar o que não é função, esquecer os parênteses, esquecer o this, o método "solto".

Todos os programas desta aula rodaram no Node.js 24 da máquina da Ana (usuária ana, computador notebook), salvos na pasta pessoal dela e executados com node arquivo.js. Você pode rodar cada um no editor do guia.

A ideia: o cofrinho que sabe contar

Imagine um cofrinho eletrônico. Ele tem coisas que ele é (de quem é, quanto tem dentro) e coisas que ele faz (receber moedas, dizer se já juntou o suficiente). Quando a Ana aperta o botão "depositar R$ 50", o cofrinho soma os 50 no saldo dele mesmo, e não no cofrinho do irmão.

  • O que o objeto é → propriedades com valores: saldo: 0.
  • O que o objeto faz → propriedades com funções: os métodos.
  • "O saldo dele mesmo" → this.saldo.

1. Uma função dentro do objeto

const ana = {
  nome: "Ana",
  saudar: function () {
    console.log("Oi! Tudo bem?");
  },
};
ana.saudar();
console.log(typeof ana.saudar);

$ node primeiro.js
Oi! Tudo bem?
function
saudar: function () { … }
Uma propriedade como qualquer outra: a chave saudar, os dois-pontos e o valor. Só que o valor é uma função (em inglês, function). Funções são valores no JavaScript, como números e textos (aula Funções como Valores).
ana.saudar()
Lê a propriedade saudar (a função) e a chama com os parênteses. Lê-se "ana, saude!".
typeof ana.saudar → function
Sem os parênteses, você só lê o valor: uma função.

2. A escrita curta (a recomendada)

Como métodos são muito comuns, existe uma forma mais curta: tire os dois-pontos e a palavra function.

const ana = {
  nome: "Ana",
  saudar() {
    console.log("Oi! Tudo bem?");
  },
};
ana.saudar();
console.log(ana);

$ node curto.js
Oi! Tudo bem?
{ nome: 'Ana', saudar: [Function: saudar] }

O resultado é o mesmo. Repare como o Node mostra o objeto: o método aparece como [Function: saudar] ("função chamada saudar"). Daqui em diante, o guia usa sempre a forma curta.

3. O this: "este objeto aqui"

Um método que só escreve "Oi!" não precisa do objeto. Mas, para dizer o próprio nome, o método precisa ler a propriedade nome do objeto onde ele está. Para isso serve o this:

const ana = {
  nome: "Ana",
  cidade: "Recife",
  apresentar() {
    console.log(`Oi, eu sou a ${this.nome} e moro em ${this.cidade}.`);
  },
};
const bia = {
  nome: "Bia",
  cidade: "Natal",
  apresentar: ana.apresentar,
};
ana.apresentar();
bia.apresentar();

$ node this.js
Oi, eu sou a Ana e moro em Recife.
Oi, eu sou a Bia e moro em Natal.
this.nome
"O nome deste objeto". Quem é "este"? O objeto que aparece antes do ponto na hora de chamar o método.
ana.apresentar()
Antes do ponto está ana, então, nesta chamada, this é a ana, e this.nome é "Ana".
apresentar: ana.apresentar
A Bia ganhou a mesma função da Ana (sem copiar o código; é a mesma função, guardada em dois objetos).
bia.apresentar()
A mesma função, mas agora antes do ponto está bia: o this é a Bia, e a frase sai com "Bia" e "Natal".
A regra do ponto

Para descobrir quem é o this num método, olhe a chamada, não a definição: o this é o que está à esquerda do ponto em objeto.metodo(). A aula this, call, apply e bind mostra os casos especiais.

Por que não escrever ana.nome dentro do método, já que ele está dentro da ana? Porque aí a Bia diria "Oi, eu sou a Ana". O this faz o mesmo método servir para qualquer objeto que o use.

Missão: o método apresentar está com o nome escrito "na mão" e errado. Troque o "fulana" por uma leitura do nome do próprio objeto, com this, para aparecer Oi, eu sou a Bia!.

const bia = {
  nome: "Bia",
  apresentar() {
    console.log(`Oi, eu sou a ${"fulana"}!`);
  },
};
bia.apresentar();

const bia = {
  nome: "Bia",
  apresentar() {
    console.log(`Oi, eu sou a ${this.nome}!`);
  },
};
bia.apresentar();

4. Métodos que mudam o objeto e métodos que devolvem valores

const cofrinho = {
  dono: "Ana",
  saldo: 0,
  depositar(valor) {
    this.saldo += valor;
    console.log(`Depositou R$ ${valor}. Saldo: R$ ${this.saldo}`);
  },
  estaRico() {
    return this.saldo >= 100;
  },
};
cofrinho.depositar(50);
cofrinho.depositar(70);
console.log(cofrinho.saldo);
console.log(cofrinho.estaRico());

$ node cofrinho.js
Depositou R$ 50. Saldo: R$ 50
Depositou R$ 70. Saldo: R$ 120
120
true
depositar(valor)
Um método com parâmetro, como qualquer função. Na chamada cofrinho.depositar(50), o valor é 50.
this.saldo += valor
O método muda uma propriedade do próprio objeto. Depois das duas chamadas, o saldo do cofrinho ficou 120, e a linha console.log(cofrinho.saldo) confirma.
estaRico() { return … }
Um método que não muda nada: ele calcula e devolve uma resposta (aula Retornando Valores). Aqui, true, porque 120 ≥ 100.

Um método pode usar outras propriedades e métodos do mesmo objeto, inclusive arrays. Um carrinho de compras que guarda os itens e calcula o total:

const carrinho = {
  itens: [],
  adicionar(nome, preco) {
    this.itens.push({ nome, preco });
  },
  total() {
    return this.itens.reduce((soma, item) => soma + item.preco, 0);
  },
};
carrinho.adicionar("pão", 8);
carrinho.adicionar("café", 15);
console.log(carrinho.itens.length, "itens");
console.log(`Total: R$ ${carrinho.total()}`);

$ node carrinho.js
2 itens
Total: R$ 23

Quem usa o carrinho não precisa saber como o total é calculado: chama carrinho.total() e pronto. Juntar os dados e as ações que mexem neles num só lugar é a ideia central da programação orientada a objetos, que você vai ver com classes. (O { nome, preco } é o atalho da aula Objetos; o reduce, o da aula reduce.)

5. Você já usava métodos

Lembra de nome.toUpperCase(), lista.push(4) e do próprio console.log? Todos têm a mesma forma: objeto.metodo(…).

const nome = "ana";
console.log(nome.toUpperCase());
const lista = [3, 1, 2];
lista.push(4);
console.log(lista);
console.log(typeof console.log);
console.log(typeof Math.max);

$ node jaconhece.js
ANA
[ 3, 1, 2, 4 ]
function
function
  • console é um objeto, e log é um método dele. O mesmo para Math e max (aula Math).
  • lista.push(4): o push usa o this para saber em qual array acrescentar, exatamente como o seu depositar sabe em qual cofrinho somar.
  • Textos, arrays e números ganham métodos prontos do JavaScript (aula Protótipos explica de onde eles vêm).

6. Arrow function e this

As arrow functions (() => …) não têm um this próprio: elas usam o this do lugar onde foram escritas. Isso as torna ruins como método, e ótimas dentro de um método.

const ana = {
  nome: "Ana",
  apresentarArrow: () => {
    console.log(`Oi, eu sou a ${this.nome}.`);
  },
  apresentar() {
    console.log(`Oi, eu sou a ${this.nome}.`);
  },
};
ana.apresentarArrow();
ana.apresentar();

$ node arrow.js
Oi, eu sou a undefined.
Oi, eu sou a Ana.

A arrow function foi escrita no nível de fora do objeto, onde o this não é a ana; por isso o this.nome deu undefined, mesmo chamando ana.apresentarArrow(). Para métodos, use a escrita curta apresentar() { }.

Já dentro de um método, a arrow function é a escolha certa, justamente porque ela "herda" o this do método:

const turma = {
  professora: "Rita",
  alunos: ["Ana", "Bia"],
  chamada() {
    this.alunos.forEach((aluno) => {
      console.log(`${this.professora} chama: ${aluno}`);
    });
  },
};
turma.chamada();

$ node arrow-dentro.js
Rita chama: Ana
Rita chama: Bia

A função passada ao forEach é uma arrow; dentro dela, this continua sendo a turma, e this.professora funciona.

Arrow function como método

Sem erro: o this.nome sai undefined (seção 6). Como consertar: troque apresentar: () => { … } por apresentar() { … }.

O método "solto" perde o this 
const ana = {
  nome: "Ana",
  apresentar() {
    console.log(`Oi, eu sou a ${this.nome}.`);
  },
};
const falar = ana.apresentar;
falar();

$ node solto.js
Oi, eu sou a undefined.

A função foi guardada numa variável e chamada sem objeto antes do ponto. Pela regra do ponto, não há "este objeto", e o this.nome não acha a Ana. Com o modo estrito ligado (aula "use strict", que vale sempre dentro de classes e módulos), o mesmo código quebra:

$ node solto-strict.js

                                     ^

TypeError: Cannot read properties of undefined (reading 'nome')
    at apresentar (/home/ana/solto-strict.js:5:38)
    at Object.<anonymous> (/home/ana/solto-strict.js:9:1)   « mais 7 linhas "at … node:internal/…" cortadas

(O solto-strict.js é o mesmo programa com "use strict"; na primeira linha, por isso as linhas estão uma abaixo.) Aqui o this é undefined, e ler .nome de undefined quebra. Como consertar: chame sempre com o objeto: ana.apresentar(). Para passar um método adiante sem perder o this, existe o bind (aula this, call, apply e bind).

Resumo

  • Um método é uma propriedade cujo valor é uma função. Escreva na forma curta: nome() { … }.
  • Chame com parênteses: obj.metodo(). Sem eles, você tem a função, e não o resultado.
  • Dentro do método, this é o objeto que está antes do ponto na chamada. Use this.propriedade para ler e mudar os dados do próprio objeto.
  • Métodos podem mudar o objeto (depositar) ou devolver um valor (total).
  • console.log, push e toUpperCase também são métodos.
  • Não escreva métodos com arrow function (o this não funciona); use arrow functions dentro dos métodos, nos callbacks.
  • Um método guardado numa variável e chamado sozinho perde o this.
