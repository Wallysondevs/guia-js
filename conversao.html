JavaScript Conversão

O número 3 e o texto "3" parecem a mesma coisa para nós, mas para o JavaScript são tipos diferentes: um serve para fazer contas, o outro para escrever. E muitos dados chegam ao programa como texto: o que a pessoa digita no teclado, o que vem de um formulário, de um arquivo. Antes de fazer conta com eles, é preciso converter, isto é, transformar de um tipo em outro. Esta aula mostra como fazer isso de propósito, com Number(), parseInt(), parseFloat() e String().

Você vai aprender
  • Por que "3" + 1 dá "31", e por que isso é um problema.
  • Como transformar texto em número com Number(), e o que acontece quando o texto não é um número.
  • Como tirar o número do começo de um texto, como "30 anos", com parseInt() e parseFloat().
  • O que fazer com a vírgula brasileira ("3,5").
  • Como reconhecer um NaN com Number.isNaN().
  • O caminho de volta: número para texto com String() e .toString().

Todos os programas desta aula rodaram no Node.js 24 da máquina da Ana (usuária ana, computador notebook), salvos na pasta pessoal dela e executados com node arquivo.js (veja Rodando um Programa). Você pode rodar cada um no editor do guia.

A ideia: o número escrito no papel

No caixa da padaria, um cliente entrega um bilhete: "3 pães". Para cobrar, a atendente precisa ler o bilhete e transformar aquele "3" desenhado no papel no número 3, que ela consegue multiplicar pelo preço. Ninguém multiplica um pedaço de papel.

No programa é igual. O texto "3" é o bilhete: um desenho do número. Para fazer conta, você precisa pedir ao JavaScript que leia o desenho e devolva o número. É isso que as funções desta aula fazem. E, às vezes, o caminho é o contrário: pegar o número e escrevê-lo num texto, para mostrar na tela.

1. O problema: o texto que parece número

const quantidade = "3";
const preco = 2.5;
console.log(quantidade + 1);
console.log(quantidade * preco);
console.log(typeof quantidade);

$ node problema.js
31
7.5
string
const quantidade = "3";
Com aspas, "3" é um texto (uma string), como se tivesse vindo do teclado. O typeof confirma: string.
quantidade + 1 → 31
Com um texto, o + não soma: ele junta (veja Strings). O 1 virou o texto "1" e foi colado no fim: "31". Era para dar 4.
quantidade * preco → 7.5
Já o * só sabe multiplicar, então o JavaScript transformou o "3" em 3 sozinho, e a conta deu certo.

Esse comportamento, em que o JavaScript converte sozinho e às vezes de um jeito inesperado, é o assunto da próxima aula, Conversão Automática. A lição aqui é: não conte com a sorte. Se o valor é um texto e você vai fazer conta, converta você mesmo, antes.

2. Texto para número: Number()

A função Number() recebe um valor e devolve o número que ele representa:

console.log(Number("30"));
console.log(Number("3.75"));
console.log(Number("  42  "));
console.log(Number(""));
console.log(Number("30 anos"));
console.log(Number("3,5"));
console.log(Number("abc"));
console.log(typeof Number("30"));

$ node number.js

3.75

0
NaN
NaN

number
Number("30") → 30
O texto virou número. Repare que o Node mostra 30 sem aspas, e o typeof da última linha confirma: number.
Number("3.75") → 3.75
Números com casas decimais também, desde que usem ponto.
Number(" 42 ") → 42
Espaços antes e depois são ignorados.
Number("") → 0
Uma pegadinha: o texto vazio vira 0, e não um erro. Se a pessoa não digitou nada, o programa vai achar que ela digitou zero.
Number("30 anos") → NaN
O Number() é exigente: o texto inteiro tem de ser um número. Sobrou " anos", então o resultado é NaN ("Not a Number", "não é um número"; veja NaN, Infinity e a Precisão).
Number("3,5") → NaN
Para o JavaScript, a vírgula não separa casas decimais. Veja a seção 5.
Number("abc") → NaN
Nada ali é número.

Repare que nenhuma dessas linhas deu erro. Quando a conversão falha, o Number() não para o programa: ele devolve NaN e segue em frente. Por isso, depois de converter algo que veio de fora, vale conferir (seção 6).

Missão: o preço, a quantidade e a taxa de entrega chegaram como texto. A multiplicação até funciona sozinha, mas a soma da taxa, não: o programa mostra Total: R$ 13.52, um valor sem sentido. Converta os três textos com Number() na linha do total para ele dar Total: R$ 15.5 (3 × 4,50 = 13,50, mais a taxa de 2).

const precoTexto = "4.50";
const quantidadeTexto = "3";
const taxaTexto = "2";
const total = precoTexto * quantidadeTexto + taxaTexto;
console.log(`Total: R$ ${total}`);

const precoTexto = "4.50";
const quantidadeTexto = "3";
const taxaTexto = "2";
const total = Number(precoTexto) * Number(quantidadeTexto) + Number(taxaTexto);
console.log(`Total: R$ ${total}`);

3. O número no começo do texto: parseInt() e parseFloat()

Às vezes o texto tem o número e mais alguma coisa: "30 anos", "3.75 kg", "12px". O Number() desiste (NaN), mas existem duas funções mais tolerantes, que leem o texto da esquerda para a direita e param no primeiro caractere que não serve:

  • parseInt() ("analisar inteiro"): pega só a parte inteira.
  • parseFloat() ("analisar número com vírgula"; float é o nome técnico do número com casas decimais): pega também as casas depois do ponto.
console.log(parseInt("30 anos"));
console.log(parseInt("3.99"));
console.log(parseFloat("3.75 kg"));
console.log(parseFloat("3,75"));
console.log(parseInt("R$ 10"));
console.log(parseInt(""));
console.log(parseInt("  12abc"));

parseInt("30 anos") → 30
Leu 3, 0, chegou no espaço e parou. Ficou com 30.
parseInt("3.99") → 3
O ponto não serve para um inteiro: parou ali. Atenção: ele corta, não arredonda (3,99 vira 3, e não 4).
parseFloat("3.75 kg") → 3.75
O parseFloat aceita o ponto e as casas decimais, e para no espaço.
parseFloat("3,75") → 3
A vírgula não serve: parou nela e ficou com 3. Sem aviso nenhum. Cuidado com isso (seção 5).
parseInt("R$ 10") → NaN
O texto começa com R, que não é número: ele para logo no primeiro caractere e não acha nada. O número precisa estar no começo.
parseInt("") → NaN
Diferente do Number(""), que dava 0: texto vazio aqui é NaN.
parseInt(" 12abc") → 12
Os espaços do começo são pulados.
A base: o segundo valor do parseInt

O parseInt aceita um segundo valor, a base do número: parseInt("10", 10) lê na base 10, a nossa de todo dia (deu 10). Com outras bases ele lê números binários e hexadecimais: parseInt("101", 2) deu 5 e parseInt("ff", 16) deu 255. Você vai ver muito código escrito parseInt(texto, 10): é só alguém deixando claro que quer a base 10. Sem o segundo valor, a base 10 já é a usada para textos comuns como "30".

5. A vírgula brasileira

No Brasil escrevemos 3,5; o JavaScript só entende 3.5. Se a pessoa digitar com vírgula, troque a vírgula por ponto antes de converter. O .replace(",", ".") faz isso: "substitua a vírgula por um ponto" (ele tem aula própria: Substituindo):

const digitado = "3,5";
console.log(Number(digitado.replace(",", ".")));

$ node virgula.js
3.5

E se o número tiver separador de milhar, como "1.234,56"? Aí o ponto atrapalha: parseFloat("1.234,56") deu 1.234 no lab (leu "um vírgula dois três quatro" e parou na vírgula), um valor mil vezes menor. Para esse formato é preciso tirar os pontos e depois trocar a vírgula, assunto da aula Substituindo.

6. Conferindo se deu certo: Number.isNaN()

Como a conversão que falha devolve NaN em silêncio, o programa precisa perguntar: "deu um número?". E aqui mora uma pegadinha:

const digitado = "dez";
const numero = Number(digitado);
console.log(numero);
console.log(numero === NaN);
console.log(Number.isNaN(numero));
console.log(numero + 5);

$ node nan.js
NaN
false
true
NaN
numero === NaN → false
O NaN é o único valor do JavaScript que não é igual a si mesmo. Comparar com === NaN dá sempre false, mesmo quando o valor é NaN. Não funciona.
Number.isNaN(numero) → true
O jeito certo de perguntar "isto é NaN?".
numero + 5 → NaN
O NaN "contamina" as contas: qualquer conta com ele dá NaN. Se você vir NaN no fim de um cálculo, procure a conversão que falhou lá no começo.

Com o if (aula if), o programa pode avisar: if (Number.isNaN(numero)) { console.log("Digite só números!"); }.

7. O caminho de volta: número para texto

Para transformar um número em texto, há vários jeitos, todos com o mesmo resultado:

const idade = 30;
console.log(String(idade));
console.log(idade.toString());
console.log(`${idade}`);
console.log(idade + "");
console.log(typeof String(idade));
console.log(String(true), String(null), String(undefined));
console.log(String(1.50));
console.log((255).toString(2));

$ node string.js

String(idade)
A função String(): o jeito mais claro. Funciona com qualquer valor, até com null e undefined.
idade.toString()
O método .toString() ("para texto"), chamado com um ponto depois da variável. Funciona com números, mas quebra se a variável for null ou undefined (veja Quando dá errado).
`${idade}`
A template string (veja Template Strings) também converte. É o jeito do dia a dia quando o número vai dentro de uma frase.
idade + ""
Juntar com um texto vazio também converte, aproveitando o + que cola textos. Funciona, mas é um truque: quem lê não entende de cara que a intenção era converter.
String(1.50) → 1.5
O zero no fim das casas decimais some: o número 1.50 é o mesmo que 1.5. Para mostrar dinheiro com duas casas, use o toFixed (aula Formatando Números).

Com um valor entre os parênteses, o toString escreve o número em outra base: 11111111 é 255 em binário. É o contrário do parseInt("…", 2).

Conferiu o NaN com ===

Como você viu na seção 6, numero === NaN é sempre false. Um if (numero === NaN) nunca entra, e o programa deixa passar o valor inválido sem avisar. Como consertar: if (Number.isNaN(numero)).

Usou parseInt para arredondar

parseInt("3.99") dá 3: ele corta, não arredonda. Se a ideia era o inteiro mais próximo, o certo é Math.round(Number("3.6")), que deu 4 no lab.

Missão final: o troco da padaria

Missão: o cliente pagou com "20" reais e a compra deu "13,50", os dois como texto, e o segundo com vírgula. O programa mostra Troco: R$ NaN. Converta os dois valores (troque a vírgula por ponto no preço) para mostrar Troco: R$ 6.5.

const pagoTexto = "20";
const compraTexto = "13,50";
const pago = Number(pagoTexto);
const compra = Number(compraTexto);
console.log(`Troco: R$ ${pago - compra}`);

const pagoTexto = "20";
const compraTexto = "13,50";
const pago = Number(pagoTexto);
const compra = Number(compraTexto.replace(",", "."));
console.log(`Troco: R$ ${pago - compra}`);

O troco certo é 6.5, que para dinheiro a gente escreveria R$ 6,50. Mostrar com duas casas e vírgula é assunto da aula Formatando Números.

Resumo

  • Texto que parece número ("3") não é número: com ele, o + junta em vez de somar. Converta antes de fazer conta.
  • Number(texto) converte o texto inteiro; se sobrar algo, dá NaN. Atenção: Number("") é 0.
  • parseInt e parseFloat leem o número do começo do texto e param no primeiro caractere que não serve; o parseInt corta as casas decimais.
  • O JavaScript usa ponto nas casas decimais: troque a vírgula com .replace(",", "."). Confira o resultado com Number.isNaN(), nunca com === NaN.
  • Número para texto: String(valor), valor.toString() ou `${valor}`.
