JavaScript Truthy e Falsy

A condição de um if não precisa ser um booleano. Você pode escrever if (nome), if (quantidade), if (lista.length), e o JavaScript decide sozinho se aquilo conta como verdadeiro ou falso. Os valores que contam como falso são chamados de falsy (em inglês, "falso-ish", "meio falso"); todos os outros são truthy ("meio verdadeiro"). A lista de falsy é curta, e vale a pena decorar.

Você vai aprender
  • O que acontece quando a condição do if não é true nem false.
  • Os 8 valores falsy do JavaScript; todo o resto é truthy.
  • As surpresas: "0", "false", " ", [] e {} são truthy.
  • Como ver a decisão do JavaScript com Boolean(valor) e com !!valor.
  • Os usos do dia a dia: testar se um texto foi preenchido, se uma lista tem itens.
  • As armadilhas: o estoque 0 tratado como "não informado", o || que troca o 0, e comparar com == true.

A ideia: "tem alguma coisa aí?"

A Ana pergunta para o irmão: "Tem leite na geladeira?". Ele não responde "sim" nem "não": ele responde "tem meia caixa", ou "tem zero", ou só dá de ombros. Mesmo assim, ela entende: meia caixa quer dizer "sim"; zero, nada ou o ombro quer dizer "não".

O if faz a mesma coisa. Ele precisa de um sim ou não, mas aceita qualquer resposta e a "traduz": valores que dão a ideia de vazio, nada, zero viram false; o resto vira true.

3. Os usos do dia a dia

O texto foi preenchido?

O jeito mais comum de usar truthy/falsy: saber se um texto não está vazio. A Ana pede o apelido no cadastro, que é opcional:

const nome = "Beatriz";
const apelido = "";

if (apelido) {
  console.log(`Oi, ${apelido}!`);
} else {
  console.log(`Oi, ${nome}!`);
}

$ node apelido.js
Oi, Beatriz!

if (apelido) se lê "se tem apelido". Ele cobre de uma vez o texto vazio "", o undefined (o apelido nem foi informado) e o null.

A lista tem itens?

Como [] é truthy, if (lista) não serve para saber se a lista está vazia. Use o tamanho dela, o length: 0 é falsy, qualquer outro número é truthy.

const compras = [];

if (compras) {
  console.log("if (compras): entrou");
}
if (compras.length) {
  console.log("if (compras.length): entrou");
} else {
  console.log("A lista de compras está vazia.");
}

$ node lista.js
if (compras): entrou
A lista de compras está vazia.

4. ! e !!

O "não" (!; veja Operadores Lógicos) também traduz o valor antes de inverter. !valor dá true para os falsy. E dois "não" seguidos, !!valor, invertem duas vezes: o resultado é o mesmo do Boolean(valor). Você vai ver muito !! em código dos outros:

const apelido = "";
console.log(!apelido);
console.log(!!apelido);
console.log(!!"Bia");

if (!apelido) {
  console.log("Sem apelido.");
}

$ node negacao.js

false
true
Sem apelido.

if (!apelido) se lê "se não tem apelido".

Formas diferentes de fazer a mesma coisa

Testar se o apelido foi preenchido pode ser escrito de forma curta (confiando no truthy) ou explícita (dizendo exatamente o que você quer):

const apelido = "Bia";

if (apelido) console.log("1. curto");
if (apelido !== "") console.log("2. diferente de vazio");
if (apelido.length > 0) console.log("3. tamanho maior que zero");
if (Boolean(apelido)) console.log("4. Boolean()");

$ node formas.js
1. curto
2. diferente de vazio
3. tamanho maior que zero
4. Boolean()

Com "Bia" os quatro concordam. A diferença aparece com outros valores: com undefined, a forma 2 entra no bloco (undefined é diferente de "") e a forma 3 dá erro (veja Quando dá errado). A forma 1 trata os três "vazios" ("", undefined, null) igual.

SituaçãoQual usar
Texto preenchido ou não (vazio, undefined e null contam como "não")if (texto)
Lista com itensif (lista.length > 0) ou if (lista.length)
Número que pode ser 0 de verdade (estoque, nota, preço)Compare explicitamente: if (estoque !== undefined), if (nota >= 0)
Guardar a decisão numa variável booleanaBoolean(valor) (mais legível) ou !!valor

Quando dá errado

Truthy e falsy quase nunca dão mensagem de erro: dão resultado errado, em silêncio. Por isso estes cenários merecem atenção.

O zero que "não existe"

A Ana mostra o estoque, ou um aviso se o estoque ainda não foi contado:

const estoque = 0;

if (estoque) {
  console.log(`Estoque: ${estoque} unidades`);
} else {
  console.log("Estoque ainda não informado.");
}

$ node estoque.js
Estoque ainda não informado.

Mas o estoque foi informado: é zero, o produto acabou! O if (estoque) não distingue "não sei" (undefined) de "sei, e é zero" (0). Como consertar: quando o 0 é um valor válido, compare com o que você quer evitar: if (estoque !== undefined). Assim, com 0 aparece Estoque: 0 unidades.

O || que troca o zero

Um atalho popular para "valor padrão" é o ||: a || b dá a se a for truthy, senão b (veja Operadores Lógicos). Ele cai na mesma armadilha:

const desconto = 0;
console.log(desconto || 10);
console.log(desconto ?? 10);

$ node ou.js
10
0

A Ana queria desconto zero, e o || trocou por 10, porque 0 é falsy. O ?? só troca null e undefined, e manteve o 0. Como consertar: para valor padrão, prefira ??; ele tem aula própria em ?. e ??.

Comparar com == true 
const quantidade = 2;

if (quantidade) {
  console.log("if (quantidade): entrou");
}
if (quantidade == true) {
  console.log("if (quantidade == true): entrou");
}

$ node igualtrue.js
if (quantidade): entrou

O 2 é truthy, mas 2 == true é false: o == transforma o true no número 1 e compara 2 com 1 (é uma das pegadinhas de Conversão Automática). "Ser truthy" e "ser igual a true" são coisas diferentes. Como consertar: nunca compare com true nem com false: escreva só if (quantidade) ou uma comparação de verdade, como if (quantidade > 0).

Missão final: o recado

Missão: o mural da padaria mostra o recado do dia, se houver. Escreva um if … else usando o próprio recado como condição (sem === nem length): se tiver recado, mostre Recado: …; senão, Sem recados hoje.. Com o recado vazio, deve aparecer Sem recados hoje.. Depois teste com um recado de verdade.

const recado = "";

// escreva o if … else aqui

  console.log(`Recado: ${recado}`);
} else {
  console.log("Sem recados hoje.");
}

Resumo

  • Quando a condição não é booleana, o JavaScript a traduz para true ou false.
  • Só 8 valores são falsy: false, 0, -0, 0n, "", null, undefined e NaN. Todo o resto é truthy, inclusive "0", "false", " ", [] e {}.
  • Boolean(valor) e !!valor mostram a decisão; !valor a inverte.
  • if (texto) testa se o texto foi preenchido; para listas, use if (lista.length).
  • Cuidado com o 0 válido (estoque, nota, desconto): compare explicitamente e prefira ?? a || para valor padrão.
  • Nunca compare com == true: truthy não é o mesmo que igual a true.
