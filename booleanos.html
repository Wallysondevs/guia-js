JavaScript Booleanos

A loja está aberta? O aluno passou? Tem pão de queijo no estoque? Muitas perguntas que um programa faz têm só duas respostas possíveis: sim ou não. Para guardar essas respostas, o JavaScript tem um tipo de valor próprio, o booleano (em inglês, boolean), que só tem dois valores: true ("verdadeiro") e false ("falso"). Ele é a base de todas as decisões que o seu programa vai tomar.

Você vai aprender
  • O que é um booleano e os seus dois únicos valores: true e false.
  • Como guardar um booleano numa variável, e como dar a ela um nome que soa como pergunta.
  • Que toda comparação (idade >= 18) produz um booleano.
  • Como virar o valor ao contrário com o !.
  • A diferença entre true e "true" (com aspas), e o que o Boolean() faz.
  • Os erros mais comuns: True com letra maiúscula, verdadeiro em português e o texto "false" que vale como verdadeiro.

Todos os programas desta aula rodaram no Node.js 24 da máquina da Ana (usuária ana, computador notebook), salvos na pasta pessoal dela e executados com node arquivo.js (veja Rodando um Programa). Você pode rodar cada um no editor do guia.

A ideia: o interruptor de luz

Um interruptor de luz tem só duas posições: ligado ou desligado. Não existe "meio ligado", nem "ligado 37%". O booleano é exatamente isso: um interruptor dentro do programa.

  • true é a posição "ligado": sim, verdadeiro, está aberto, tem estoque.
  • false é a posição "desligado": não, falso, está fechado, acabou.

O nome vem do matemático inglês George Boole, que no século XIX estudou uma álgebra feita só de "verdadeiro" e "falso". É dela que saem as condições de todos os programas de computador.

Só existem esses dois valores booleanos. Qualquer variável booleana guarda um dos dois, sempre.

Dê ao booleano um nome que soa como pergunta

Uma boa variável booleana se lê como uma pergunta de sim ou não: lojaAberta ("a loja está aberta?"), temEstoque ("tem estoque?"), alunoAprovado, estaChovendo, podeEntrar. Quando você ler if (temEstoque) lá na frente, o código vai parecer uma frase. Evite nomes vagos como status ou flag, que não dizem o que true quer dizer.

2. Toda comparação dá um booleano

Você raramente vai escrever true ou false à mão. Na maior parte das vezes, o booleano nasce de uma pergunta que o programa faz, uma comparação: "a idade é maior ou igual a 18?". A resposta dessa pergunta é sempre true ou false.

const idade = 17;
const maiorDeIdade = idade >= 18;
console.log(maiorDeIdade);
console.log(10 > 3);
console.log(5 === 5);
console.log("Ana" === "ana");
console.log(typeof (10 > 3));
idade >= 18
"A idade é maior ou igual a 18?". Como a idade é 17, a resposta é false, e esse false é guardado em maiorDeIdade.
10 > 3
"10 é maior que 3?" Sim: true.
5 === 5
"5 é igual a 5?" O === (três sinais de igual) é a pergunta "é igual?". Sim: true.
"Ana" === "ana"
"O texto Ana é igual ao texto ana?" Não: para o computador, a letra maiúscula faz diferença. false.
typeof (10 > 3)
O tipo do resultado da comparação: boolean.
$ node comparar.js

true
true
false

Os sinais de comparação (>, <, >=, <=, ===, !==) têm uma aula só para eles: Comparação. Por enquanto, guarde a ideia: comparação entra, booleano sai.

3. Para que serve: decidir

O grande trabalho do booleano é escolher o caminho do programa. O if (em inglês, "se") recebe um booleano entre parênteses e só roda o bloco quando ele é true. O if tem aula própria (if); aqui, veja só como o booleano manda nele:

const lojaAberta = true;
if (lojaAberta) {
  console.log("Pode entrar!");
}
const chovendo = false;
if (chovendo) {
  console.log("Leve o guarda-chuva.");
}
console.log("Fim.");

$ node if.js
Pode entrar!
Fim.

lojaAberta era true: o Pode entrar! apareceu. chovendo era false: o Leve o guarda-chuva. foi pulado. Repare como os nomes ajudam: if (lojaAberta) se lê "se a loja está aberta".

4. Mudando o valor e virando ao contrário com !

Um booleano guardado com let (veja Variáveis) pode mudar ao longo do programa, como o interruptor que alguém aperta. E o sinal ! (lê-se "não") inverte um booleano: !true é false, e !false é true.

let luzAcesa = false;
console.log(luzAcesa);
luzAcesa = true;
console.log(luzAcesa);
luzAcesa = !luzAcesa;
console.log(luzAcesa);
let luzAcesa = false;
Começa com a luz apagada. É let, e não const, porque o valor vai mudar.
luzAcesa = true;
Alguém acendeu a luz: o valor passa a ser true.
luzAcesa = !luzAcesa;
"A luz passa a ser o contrário do que é agora". Como era true, vira false. É o jeito de escrever "aperte o interruptor", sem precisar saber em que posição ele está.
$ node muda.js
false
true
false

O ! e os seus parceiros && ("e") e || ("ou") estão na aula Operadores Lógicos.

Experimente: o programa aperta o interruptor uma vez. Copie as duas últimas linhas (a que inverte e a que mostra) mais duas vezes, para a luz piscar: apagada, acesa, apagada, acesa.

5. Booleano junto com texto

Quando um booleano entra numa frase, ele aparece escrito como true ou false:

const lojaAberta = true;
console.log("A loja está aberta? " + lojaAberta);
console.log(`A loja está aberta? ${lojaAberta}`);
console.log("Aberta:", lojaAberta);
console.log(String(false));

$ node texto.js
A loja está aberta? true
A loja está aberta? true
Aberta: true
false

Os três primeiros jeitos dão o mesmo resultado: juntar com +, a template string com ${} (veja Template Strings) e a vírgula do console.log. O String(false) transforma o booleano no texto "false" (veja Conversão). Para mostrar "sim" e "não" em vez de true e false, você vai usar o if ou o operador ternário.

Dentro de objetos e arrays, o Node mostra os booleanos do mesmo jeito, sem aspas:

const produto = { nome: "Pão de queijo", disponivel: true };
console.log(produto);
console.log([true, false, true]);

$ node objeto.js
{ nome: 'Pão de queijo', disponivel: true }
[ true, false, true ]

Repare: o texto 'Pão de queijo' aparece entre aspas; o booleano true, não. É assim que você distingue um do outro na saída do Node.

6. true não é "true"

Com aspas, "true" é um texto de quatro letras, que só por acaso se parece com o booleano. Para o JavaScript, são coisas completamente diferentes:

const comAspas = "true";
const semAspas = true;
console.log(comAspas);
console.log(semAspas);
console.log(typeof comAspas);
console.log(typeof semAspas);
console.log(comAspas === semAspas);
console.log(["true", true]);

$ node aspas.js
true
true
string
boolean
false
[ 'true', true ]

Mostrados sozinhos, os dois aparecem como true e enganam. O typeof desmascara: um é string (texto), o outro é boolean. A comparação === diz que não são iguais. E dentro de um array o Node mostra as aspas do texto ('true'), o que ajuda a perceber a diferença.

De onde vem o "true" com aspas

Tudo o que a pessoa digita no teclado, tudo o que vem de um arquivo ou de um formulário chega como texto. Se a pessoa digitar true, o programa recebe "true", com aspas. Para ter o booleano, compare: const resposta = digitado === "true";.

7. Transformando outros valores em booleano: Boolean()

A função Boolean() responde a uma pergunta curiosa: "este valor conta como verdadeiro ou como falso?". Números e textos também têm essa resposta:

console.log(Boolean(1));
console.log(Boolean(0));
console.log(Boolean("Ana"));
console.log(Boolean(""));
console.log(Boolean("false"));

$ node boolean.js
true
false
true
false
true

O 0 e o texto vazio "" contam como falso; o 1 e o texto "Ana" contam como verdadeiro. E a pegadinha: Boolean("false") dá true, porque "false" é um texto com letras dentro, e todo texto que não está vazio conta como verdadeiro. O Boolean() não lê a palavra; ele só olha se tem alguma coisa ali.

A lista completa do que conta como falso (os valores falsy) está na aula Truthy e Falsy.

E o contrário: booleano virando número

Numa conta, true vale 1 e false vale 0. No lab, Number(true) deu 1, Number(false) deu 0 e true + true deu 2. Funciona, mas é confuso de ler; é uma das conversões automáticas da aula Conversão Automática.

Formas diferentes de fazer a mesma coisa

Para guardar se um aluno passou (nota 6 ou mais), dá para escrever de vários jeitos. Os três abaixo guardam o mesmo booleano:

const nota = 7.5;

// 1. A comparação direto na variável (o melhor)
const aprovado1 = nota >= 6;

// 2. Com if/else, escrevendo true e false à mão
let aprovado2;
if (nota >= 6) {
  aprovado2 = true;
} else {
  aprovado2 = false;
}

// 3. Com Boolean(): só para transformar outro tipo de valor
const temNome = Boolean("Ana");

console.log(aprovado1, aprovado2, temNome);

true true true

O new Boolean(false) não cria um booleano: cria um objeto (o typeof diz object) que embrulha o false. E todo objeto conta como verdadeiro, então o if entrou. Você pode encontrar isso em código antigo; não use. Como consertar: escreva false direto, ou use Boolean(…) sem o new.

Resumo

  • O booleano tem só dois valores: true (verdadeiro) e false (falso), sem aspas e em minúsculas. O typeof deles é boolean.
  • Toda comparação (idade >= 18, a === b) produz um booleano, e é assim que eles nascem quase sempre.
  • O booleano decide o caminho do programa: o if só roda o bloco quando recebe true.
  • O ! inverte: x = !x aperta o interruptor. Dê nomes que soam como pergunta: lojaAberta, temEstoque.
  • "true" com aspas é texto, não booleano. Boolean(valor) diz se um valor conta como verdadeiro, e Boolean("false") é true.
