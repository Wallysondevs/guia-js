JavaScript Procurando em Strings

O e-mail tem @? A lista de ingredientes tem "amendoim"? O arquivo termina com .pdf? Em que posição está o hífen do código do produto? Procurar um pedaço dentro de um texto é uma das tarefas mais comuns da programação. As strings do JavaScript têm métodos prontos para isso: includes, startsWith, endsWith, indexOf e lastIndexOf.

Você vai aprender
  • includes(): o texto tem este pedaço? (true ou false)
  • startsWith() e endsWith(): o texto começa ou termina com este pedaço?
  • indexOf() e lastIndexOf(): em que posição está o pedaço? E o -1, que quer dizer "não achei".
  • Como procurar a partir de uma posição, e como procurar sem ligar para maiúsculas.
  • Os erros reais: o contains de outras linguagens, o Includes com I maiúsculo e o 0 do indexOf que parece "não achou".

Todos os programas desta aula rodaram no Node.js 24 da máquina da Ana (usuária ana, computador notebook), com node arquivo.js. Você pode rodar cada um no editor do guia.

A ideia: procurar uma palavra no caça-palavras

Num caça-palavras, há duas perguntas diferentes que você pode fazer:

  1. "A palavra GATO está aí?" A resposta é sim ou não.
  2. "Onde ela está?" A resposta é uma posição: "começa na quinta letra".

Os métodos desta aula se dividem do mesmo jeito: includes, startsWith e endsWith respondem "sim ou não" (um booleano); indexOf e lastIndexOf respondem "onde" (um número). Para entender as posições, lembre da aula Strings: cada caractere tem um número, e a contagem começa do zero.

const ingredientes = "farinha, ovos, leite, amendoim, açúcar";

console.log(ingredientes.includes("chocolate"));
console.log(ingredientes.includes("ovo"));
console.log(ingredientes.includes("Leite"));
console.log("ana@email.com".includes("@"));

console.log(arquivo.endsWith(".PDF"));

startsWith ("começa com") só olha o começo do texto, e endsWith ("termina com"), só o fim. O telefone tem 81, mas não começa com ele: por isso a última linha deu false. São os métodos certos para conferir extensão de arquivo, código de país, prefixo de código de produto.

Missão: a lojinha só aceita e-mails que tenham @ e terminem com .com.br. O programa já confere o @. Complete a condição com && e endsWith, e troque o e-mail para bia@padaria.com.br, até aparecer Parece e-mail? true.

const email = "bia.padaria.com";
const pareceEmail = email.includes("@");
console.log("Parece e-mail?", pareceEmail);

const email = "bia@padaria.com.br";
const pareceEmail = email.includes("@") && email.endsWith(".com.br");
console.log("Parece e-mail?", pareceEmail);

3. Em que posição: indexOf()

O indexOf (em inglês, "índice de", isto é, "a posição de") procura o pedaço e devolve a posição do primeiro caractere dele. Se não achar, devolve -1:

const frase = "pão quente, pão doce";

console.log(frase.indexOf("quente"));
console.log(frase.indexOf("pão"));
console.log(frase.indexOf("doce"));
console.log(frase.indexOf("bolo"));
console.log(frase.indexOf("Pão"));

indexOf("quente") → 4
O q de quente está na posição 4 (confira na tabela do começo da aula).
indexOf("pão") → 0
pão aparece duas vezes; o indexOf devolve a primeira, que está bem no começo, na posição 0.
indexOf("bolo") → -1
Não achou. Como nenhuma posição é negativa, o -1 é o jeito de dizer "não está aqui".
indexOf("Pão") → -1
Com P maiúsculo, não acha: o texto só tem pão minúsculo.
O 0 quer dizer "achei no começo"

Posição 0 é a primeira posição, não "nada". Quem quer só saber se o pedaço existe deve perguntar texto.indexOf("x") !== -1, ou, melhor ainda, usar o includes. Na seção Quando dá errado você vê o que acontece quando alguém trata o 0 como "não achou".

A última vez e a partir de uma posição

const frase = "pão quente, pão doce";

console.log(frase.lastIndexOf("pão"));
console.log(frase.indexOf("pão", 1));
console.log(frase.includes("pão", 13));

$ node outras.js
12
12
false
  • lastIndexOf ("último índice de") procura de trás para a frente e devolve a posição da última ocorrência: o segundo pão, na 12.
  • indexOf("pão", 1): o segundo argumento é de onde começar a procurar. Começando da posição 1, o primeiro pão (na 0) já ficou para trás, e o próximo é o da 12.
  • includes, startsWith e endsWith também aceitam esse número. A partir da posição 13, não há mais nenhum pão inteiro: false.

Para descobrir quantas vezes um pedaço aparece, você repete o indexOf começando logo depois da última posição achada, até ele devolver -1. Isso precisa de um laço, como o while.

4. Procurando sem ligar para maiúsculas

Todos os métodos de busca diferenciam maiúsculas e minúsculas. O truque é o mesmo da aula Métodos de String: passe os dois lados para minúsculas antes de procurar.

const ingredientes = "Farinha de TRIGO, ovos e Leite";
const procurado = "Trigo";

console.log(ingredientes.includes(procurado));
console.log(ingredientes.toLowerCase().includes(procurado.toLowerCase()));

$ node semcaixa.js
false
true

A segunda linha compara "farinha de trigo, ovos e leite" com "trigo": tudo minúsculo dos dois lados, e a busca acha. O texto original não mudou: o toLowerCase() fez uma cópia só para a busca.

Experimente: troque o texto e o pedaço procurado. Tente procurar um espaço (" "), uma letra só, uma palavra que aparece duas vezes, e uma com maiúscula diferente.

const texto = "pão quente, pão doce";
const procurado = "pão";

console.log("Tem?", texto.includes(procurado));
console.log("Primeira posição:", texto.indexOf(procurado));
console.log("Última posição:", texto.lastIndexOf(procurado));
console.log("Começa com ele?", texto.startsWith(procurado));
console.log("Termina com ele?", texto.endsWith(procurado));

Formas diferentes de fazer a mesma coisa

A pergunta "tem @?" pode ser escrita de três jeitos, e "começa com +55?" de dois:

const email = "ana@email.com";

console.log(email.includes("@"));
console.log(email.indexOf("@") !== -1);
console.log(email.indexOf("@") >= 0);

const fone = "+55 81 99999-0000";
console.log(fone.startsWith("+55"));
console.log(fone.indexOf("+55") === 0);

O includes, o startsWith e o endsWith chegaram ao JavaScript em ES2015. Antes deles, tudo era feito com indexOf, e você vai encontrar muito indexOf(…) !== -1 em código antigo. Hoje, para perguntas de sim ou não, prefira os métodos que já devolvem um booleano: eles dizem o que você quer em português.

Quando dá errado

O 0 do indexOf tratado como "não achou" 
const frase = "pão quente";

console.log(Boolean(frase.indexOf("pão")));
console.log(Boolean(frase.indexOf("bolo")));
console.log(frase.includes("pão"));

$ node zero.js

Nenhuma mensagem de erro, e as duas primeiras respostas estão trocadas. Quem usa o resultado do indexOf direto como "sim ou não" (num if, por exemplo) cai nisso: o 0 (achou no começo) conta como falso, e o -1 (não achou) conta como verdadeiro (veja Truthy e Falsy). Como consertar: use includes, ou compare: frase.indexOf("pão") !== -1.

Os nomes dos métodos também diferenciam maiúsculas: é indexOf, com O maiúsculo; includes, tudo minúsculo; startsWith e endsWith, com W maiúsculo. Como consertar: confira a grafia (no modo interativo, o Tab mostra os nomes certos).

Esqueceu o que procurar 
const frase = "o valor é undefined";
console.log(frase.includes());
console.log("pão".includes());

$ node vazio.js

Sem nada entre os parênteses, o JavaScript procura o texto "undefined" (o valor que "falta" vira esse texto). Por isso a primeira linha deu true e a segunda, false: nada de erro, só respostas sem sentido. Como consertar: diga o que procurar: frase.includes("valor").

Resumo

  • includes(p), startsWith(p) e endsWith(p) respondem true ou false: o texto tem, começa com, termina com p?
  • indexOf(p) devolve a posição da primeira ocorrência; lastIndexOf(p), a da última. As posições começam em 0; não achou = -1.
  • Um segundo número diz de onde começar a procurar: indexOf("pão", 1).
  • Todas as buscas diferenciam maiúsculas: para ignorar, texto.toLowerCase().includes(p.toLowerCase()).
  • Para "tem ou não tem", use includes: o 0 do indexOf parece falso e o -1 parece verdadeiro.
  • Erros comuns: contains (não existe em JavaScript), indexof/Includes com a caixa errada, includes() sem argumento.
