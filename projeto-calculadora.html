Projeto Calculadora

Uma calculadora que roda no terminal: ela pede um número, a operação e outro número, mostra o resultado e pergunta se você quer fazer outra conta. A conta em si é a parte fácil: o JavaScript já sabe somar. O desafio é fazer o programa não responder bobagem quando alguém divide por zero, escolhe uma operação que não existe ou digita "seis" no lugar de um número. E, no JavaScript, há uma pegadinha logo no começo: o + pode juntar textos em vez de somar.

Você vai praticar
  • Ler o que a pessoa digita no Node (veja Lendo o Teclado no Node) com await (veja async e await).
  • Transformar o texto em número com Number() (e descobrir o que ele faz com "seis": NaN).
  • Escolher a conta com if e else if.
  • Recusar a divisão por zero, que no JavaScript dá Infinity.
  • Repetir tudo com while e sair com break.
  • Separar o programa em funções que devolvem valores com return, e avisar um problema com throw e try … catch.
  • Limpar o texto com trim, toLowerCase e replace (veja Métodos de String).

Vamos chegar lá em quatro versões. No fim de cada uma, o programa roda; cada versão acrescenta uma coisa só:

  1. Dois números e um operador (Number, if/else if).
  2. A divisão por zero (que no JavaScript não dá erro: dá Infinity).
  3. Repetir até a pessoa sair (while (true) e break).
  4. Funções e entrada validada (async function, return, Number.isNaN, throw).

Antes de começar

Você precisa saber criar e rodar um arquivo .js (Rodando um Programa), usar variáveis com const e montar frases com template strings. No seu computador, crie a pasta do projeto; o arquivo vai se chamar calculadora.js:

$ mkdir -p projetos/calculadora
$ cd projetos/calculadora

Em cada versão há também uma caixa Experimente, que roda o JavaScript de verdade aqui na página. Nas missões deste projeto, quem responde às perguntas é você: depois de Rodar, digite as respostas no terminal da própria caixa, uma por linha, apertando Enter (a missão diz quais digitar).

A peça que lê o teclado

O console.log escreve; para ler o que a pessoa digita, o Node tem o módulo node:readline ("ler linha"). É o jeito que você aprendeu em Lendo o Teclado no Node: todas as versões da calculadora começam com as mesmas duas linhas:

import { createInterface } from "node:readline/promises";

const rl = createInterface({ input: process.stdin, output: process.stdout });
import { createInterface } from "node:readline/promises";
Traz a ferramenta createInterface do módulo readline, que vem junto com o Node (o node: na frente diz isso). Veja Módulos.
createInterface({ input: …, output: … })
Cria o "leitor": lê do teclado (process.stdin) e escreve as perguntas na tela (process.stdout).

Depois, cada pergunta é um await rl.question("Primeiro número: "): mostra a pergunta, espera a pessoa digitar e apertar Enter e devolve o que ela digitou, sempre como texto. O await ("aguardar") é o que faz o programa esperar a resposta (veja async e await). No fim do programa vem um rl.close(), que fecha o leitor. Sem ele, o Node continua esperando o teclado e o programa não termina.

Curiosidade: respostas pelo |

Quem conhece o terminal pode querer mandar as respostas de uma vez, sem digitar (printf "10\n+\n5\n" | node calculadora.js). Com várias perguntas, isso não funciona com o rl.question: a primeira pergunta engole todas as linhas e a segunda fica sem resposta (a aula Lendo o Teclado mostra o aviso Detected unsettled top-level await). Para testar a calculadora, digite as respostas.

Antes da versão 1: o + que junta textos

O jeito mais curto de pedir dois números e somar seria este (as duas linhas de cima ficam no começo do arquivo; daqui para a frente elas aparecem sempre):

import { createInterface } from "node:readline/promises";

const rl = createInterface({ input: process.stdin, output: process.stdout });

console.log("=== Calculadora da Ana ===");
const a = await rl.question("Primeiro número: ");
const b = await rl.question("Segundo número: ");
console.log(`${a} + ${b} = ${a + b}`);

rl.close();

$ node calculadora.js
=== Calculadora da Ana ===
Primeiro número: 10
Segundo número: 5
10 + 5 = 105

105! O programa não deu erro, mas a resposta está errada. O que a pessoa digita chega sempre como texto (uma string), mesmo que sejam só algarismos: a vale "10" e b vale "5". E o + do JavaScript tem dois trabalhos: com números, soma; com textos, junta (concatena). "10" + "5" é "105". Conferindo no modo interativo:

$ node
Welcome to Node.js v24.22.0.
Type ".help" for more information.
> "10" + "5"
'105'
> "10" * "5"
50
> .exit

Repare que o * converteu sozinho e deu 50: só o + tem esse duplo sentido (veja Conversão Automática). Por isso a calculadora converte o que foi digitado logo na entrada, com Number(), e passa a trabalhar só com números. É o primeiro passo da versão 1.

Versão 1 · Dois números e um operador

A calculadora pede o primeiro número, a operação e o segundo número. Os números passam pelo Number(), que transforma o texto num número. A operação fica como texto mesmo: "+", "-", "*" ou "/". Para escolher a conta, uma escada de if e else if.

import { createInterface } from "node:readline/promises";

const rl = createInterface({ input: process.stdin, output: process.stdout });

console.log("=== Calculadora da Ana ===");
const a = Number(await rl.question("Primeiro número: "));
const op = await rl.question("Operação (+ - * /): ");
const b = Number(await rl.question("Segundo número: "));

if (op === "+") {
  console.log(`${a} + ${b} = ${a + b}`);
} else if (op === "-") {
  console.log(`${a} - ${b} = ${a - b}`);
} else if (op === "*") {
  console.log(`${a} * ${b} = ${a * b}`);
} else if (op === "/") {
  console.log(`${a} / ${b} = ${a / b}`);
} else {
  console.log(`Operação desconhecida: ${op}`);
}

rl.close();

A versão 4 conserta isso: pergunta de novo enquanto não vier um número.

Versão 2 · A divisão por zero

Em muitas linguagens, dividir por zero para o programa com um erro. No JavaScript, não: o resultado é um valor especial. Veja a versão 1 recebendo um zero:

$ node calculadora.js
=== Calculadora da Ana ===
Primeiro número: 1
Operação (+ - * /): /
Segundo número: 0
1 / 0 = Infinity
$ node calculadora.js
=== Calculadora da Ana ===
Primeiro número: -1
Operação (+ - * /): /
Segundo número: 0
-1 / 0 = -Infinity
$ node calculadora.js
=== Calculadora da Ana ===
Primeiro número: 0
Operação (+ - * /): /
Segundo número: 0
0 / 0 = NaN

Infinity é "infinito" e NaN, de novo, "não é um número". O programa não quebrou, mas a resposta não serve para a Ana. Na matemática, dividir por zero não tem resposta: a calculadora deve avisar. A mudança é um if dentro do caso da divisão (o resto do arquivo fica igual):

Um if comum, dentro do caso: se o divisor for zero, avisa em vez de dividir. Um bloco pode ter qualquer coisa dentro, inclusive outro if (veja Condições Aninhadas).

Senão, faz a conta como antes. As chaves { } e a indentação de 2 espaços mostram qual } fecha o quê.
$ node calculadora.js
=== Calculadora da Ana ===

Segundo número: 0

$ node calculadora.js

Operação (+ - * /): -
Segundo número: 12
9 - 12 = -3

Em vez de Infinity, uma frase que a Ana entende. Isso é prevenir: o programa confere antes de fazer a conta perigosa.

Por que o Number é importante aqui

Sem o Number, o b seria o texto "0", e "0" === 0 dá false: o === nunca converte, um texto nunca é igual a um número. O if não pegaria o zero e a calculadora mostraria Infinity do mesmo jeito. Por isso: converta na entrada.

Missão (versão 2): o caso da divisão ainda divide sem olhar, e com as respostas 1, /, 0 ele mostra 1 / 0 = Infinity. Dentro do caso "/", confira se b === 0: se for, mostre Não dá para dividir por zero.; senão, faça a conta.

Versão 3 · Repetir até a pessoa sair

Até agora, cada conta exige rodar o programa de novo. A Ana quer fazer várias contas seguidas. A solução é colocar tudo dentro de um laço while ("enquanto") e, no fim de cada volta, perguntar se ela quer continuar. As duas linhas do teclado continuam no começo do arquivo; daqui para baixo, muda isto:

console.log("=== Calculadora da Ana ===");

while (true) {
  const a = Number(await rl.question("Primeiro número: "));
  const op = await rl.question("Operação (+ - * /): ");
  const b = Number(await rl.question("Segundo número: "));

  if (op === "+") {
    console.log(`${a} + ${b} = ${a + b}`);
  } else if (op === "-") {
    console.log(`${a} - ${b} = ${a - b}`);
  } else if (op === "*") {
    console.log(`${a} * ${b} = ${a * b}`);
  } else if (op === "/") {
    if (b === 0) {
      console.log("Não dá para dividir por zero.");
    } else {
      console.log(`${a} / ${b} = ${a / b}`);
    }
  } else {
    console.log(`Operação desconhecida: ${op}`);
  }

  const continuar = await rl.question("Outra conta? (s/n): ");
  if (continuar !== "s") {
    break;
  }
}

console.log("Até logo!");
rl.close();

Versão 4 · Funções e entrada validada

A versão 3 já faz várias contas, mas ainda responde NaN para seis e para 2,5, aceita o Enter vazio como zero, termina com erro no Ctrl+C e no Ctrl+D e não aceita o S maiúsculo. E o programa ficou comprido: está tudo misturado num bloco só. A versão 4 resolve as duas coisas de uma vez: cada tarefa vira uma função com nome, e a função que lê números insiste até receber um número de verdade.

// Calculadora da Ana, versão 4: funções e entrada validada

// Pergunta até a pessoa digitar um número; aceita vírgula ou ponto.
async function lerNumero(pergunta) {

    const texto = await ler(pergunta);
    const numero = Number(texto.replace(",", "."));
    if (texto !== "" && !Number.isNaN(numero)) {
      return numero;
    }
    console.log(`"${texto}" não é um número. Tente de novo.`);
  }
}

async function lerOperacao() {

      return op;

  return String(Number(numero.toFixed(10)));

Formas diferentes de escolher a conta

A calculadora usou uma escada de if/else if. O JavaScript tem mais duas formas comuns de escolher entre vários valores: o switch e um objeto que liga cada símbolo a uma função. Esta última funciona porque, no JavaScript, funções são valores: dá para guardá-las num objeto como se fossem números.

const a = 10;
const op = "*";
const b = 3;

// Forma 1: if / else if
if (op === "+") {
  console.log("if/else if:", a + b);
} else if (op === "*") {
  console.log("if/else if:", a * b);
}

// Forma 2: switch
switch (op) {
  case "+":
    console.log("switch:", a + b);
    break;
  case "*":
    console.log("switch:", a * b);
    break;
  default:
    console.log("switch: operação desconhecida");
}

// Forma 3: um objeto de funções
const contas = {
  "+": (x, y) => x + y,
  "-": (x, y) => x - y,
  "*": (x, y) => x * y,
  "/": (x, y) => x / y,
};
console.log("objeto:", contas[op](a, b));
console.log("existe '%'?", contas["%"]);

$ node formas.js
if/else if: 30
switch: 30
objeto: 30
existe '%'? undefined

Na forma 3, contas[op] busca no objeto a função guardada na chave "*", e o (a, b) logo depois a chama com os dois números. Uma operação que não existe dá undefined: if (contas[op] === undefined) faz o papel do else. As funções são arrow functions: (x, y) => x + y quer dizer "recebe x e y e devolve x + y".

Resumo

  • O que a pessoa digita chega sempre como texto. Converta na entrada com Number(): com textos, o + junta ("10" + "5" é "105") e o === nunca é igual a um número.
  • Number devolve NaN para o que não é número ("seis", "2,5") e 0 para o texto vazio: confira com Number.isNaN antes de fazer conta.
  • if/else if/else escolhem a conta; o switch e o objeto de funções são as alternativas.
  • Dividir por zero não dá erro no JavaScript: dá Infinity ou NaN. Previna com if (b === 0).
  • while (true) com break repete até a pessoa pedir para sair; trim e toLowerCase deixam a resposta tolerante.
  • Função que usa await precisa de async; quem a chama precisa de await. E o rl.close() no fim deixa o programa terminar.
  • throw + try … catch avisam "não deu" sem derrubar o programa.
  • Nunca rode com eval o que a pessoa digita.
