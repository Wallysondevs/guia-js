JavaScript Caracteres Especiais

Como escrever um texto que tem aspas dentro, se as aspas marcam o fim do texto? Como pular linha numa string de aspas comuns? Como alinhar uma tabelinha de preços? A resposta para as três perguntas é a mesma: a barra invertida \. Dentro de uma string, ela avisa o JavaScript: "o próximo caractere é especial". Essas combinações se chamam sequências de escape.

Você vai aprender
  • O que a barra invertida \ faz dentro de um texto.
  • \" e \': aspas dentro de aspas.
  • \n: pular linha; \t: a tabulação, para alinhar colunas.
  • \\: a própria barra invertida (caminhos do Windows).
  • \u: qualquer caractere pelo código Unicode (acentos, símbolos, emojis).
  • Por que o modo interativo mostra 'a\nb' e o console.log mostra duas linhas.
  • Os erros reais: a barra no fim do texto, o caminho que vira duas linhas, o \u incompleto e o /n.

Todos os programas desta aula rodaram no Node.js 24 da máquina da Ana (usuária ana, computador notebook), com node arquivo.js. Você pode rodar cada um no editor do guia.

A ideia: o aviso "isto não é o que parece"

Num ditado na escola, a professora fala "vírgula" e você escreve ,, não a palavra "vírgula". Se ela quiser que você escreva a palavra, ela avisa antes: "agora, escreva por extenso: vírgula".

A barra invertida é esse aviso. Dentro das aspas, o JavaScript lê cada caractere ao pé da letra, menos quando encontra uma \. Aí ele olha o caractere seguinte e o trata de um jeito especial:

  • \" = "esta aspa é só uma letra, não fecha o texto";
  • \n = "aqui, pule uma linha" (o n é de new line, "linha nova");
  • \t = "aqui, uma tabulação" (o t é de tab, a tecla Tab).

A barra e o caractere seguinte, juntos, viram um único caractere no texto final.

1. Aspas dentro do texto: \" e \'

const fala = "Ana disse: \"Bom dia!\"";
const apelido = 'O pão d\'água acabou';

console.log(fala);
console.log(apelido);
console.log(fala.length);
"Ana disse: \"Bom dia!\""
A primeira e a última aspa (sem barra) abrem e fecham o texto. As duas \" do meio são letras: aparecem na tela como ".
'O pão d\'água acabou'
O mesmo com aspas simples: o apóstrofo de d'água precisa da barra para não fechar o texto.
fala.length
O tamanho conta cada \" como um caractere: a barra não fica no texto.
$ node aspas.js
Ana disse: "Bom dia!"
O pão d'água acabou
21

Na aula Strings você viu outra saída: trocar o tipo de aspa de fora ('Ana disse: "Bom dia!"'), ou usar crase. A barra é útil quando o texto tem os dois tipos de aspa, ou quando o projeto pede sempre aspas duplas.

2. Pular linha: \n

console.log("Lista de compras:\n- pão\n- leite\n- café");
console.log("Linha 1\n\nLinha 3");
console.log("a\nb".length);

$ node linhas.js
Lista de compras:
- pão
- leite
- café
Linha 1

Linha 3
3

Um único console.log mostrou quatro linhas: cada \n virou uma quebra de linha. Dois \n seguidos deixam uma linha em branco. E o tamanho de "a\nb" é 3: a, a quebra de linha (um caractere só, mesmo escrito com dois) e b.

O que o modo interativo mostra

No modo interativo, o Node mostra o valor da string do jeito que se escreveria no código, com as sequências de escape. O console.log mostra o texto pronto:

$ node
Welcome to Node.js v24.22.0.
Type ".help" for more information.
> "Lista:\n- pão"
'Lista:\n- pão'
> console.log("Lista:\n- pão")
Lista:
- pão
undefined
> "Ana disse: \"oi\""
'Ana disse: "oi"'
> .exit

É a mesma string nos dois casos. O 'Lista:\n- pão' do modo interativo é o "código" do texto; o console.log mostra o resultado, como apareceria num papel. Repare também no 'Ana disse: "oi"': para mostrar o valor, o Node escolheu aspas simples por fora, e assim não precisou de barra nenhuma.

3. Alinhar em colunas: \t

A tabulação (o Tab) pula para a próxima "parada" da linha. No terminal, as paradas ficam a cada 8 colunas, o que ajuda a alinhar textos curtos em colunas:

console.log("Produto\tPreço");
console.log("Pão\tR$ 0.75");
console.log("Leite\tR$ 6");
console.log("Café\tR$ 18");

$ node tabela.js
Produto	Preço
Pão	R$ 0.75
Leite	R$ 6
Café	R$ 18

A segunda coluna começou sempre na mesma posição (a coluna 9), mesmo com nomes de tamanhos diferentes. Se um texto da primeira coluna passar de 7 letras (como Pão de queijo), ele empurra a tabulação para a parada seguinte e a coluna desalinha. Para tabelas de verdade, o Node tem o console.table (aula console.error, warn e table) e o padEnd (aula Métodos de String).

Missão: o caderno de encomendas da padaria deveria mostrar uma encomenda por linha, com o produto e a quantidade separados por tabulação. Hoje está tudo numa linha só, separado por espaços. Use \n e \t numa string só para sair assim:
Pão(Tab)2
Bolo(Tab)1

console.log("Pão 2 Bolo 1");

console.log("Pão\t2\nBolo\t1");

4. A própria barra: \\

Se a barra invertida é o "aviso", como escrever uma barra invertida de verdade? Com duas: \\. Isso aparece nos caminhos de pasta do Windows:

const pasta = "C:\\Users\\ana\\Documentos";
console.log(pasta);
console.log("Barra invertida: \\");
console.log("\\".length);

$ node barra.js
C:\Users\ana\Documentos
Barra invertida: \
1

Cada \\ no código vira uma barra no texto (e o tamanho de "\\" é 1). No Linux e no macOS, os caminhos usam a barra normal / (/home/ana/Documentos), que não precisa de nada disso.

5. Qualquer caractere pelo código: \u

Todo caractere do mundo (letras, acentos, símbolos, emojis) tem um número no padrão Unicode. Com \u e o número em hexadecimal (base 16), você escreve o caractere sem precisar dele no teclado:

console.log("Caf\u00e9");
console.log("Temperatura: 30\u00b0C");
console.log("Copyright \u00a9 2026");
console.log("Bolo de anivers\u00e1rio \u{1F382}");

$ node unicode.js
Café
Temperatura: 30°C
Copyright © 2026
Bolo de aniversário 🎂
\u00e9
\u seguido de exatamente 4 dígitos hexadecimais: 00e9 é o é.
\u00b0 e \u00a9
O símbolo de grau ° e o de direitos autorais ©.
\u{1F382}
Para números com mais de 4 dígitos (como os emojis), ponha o número entre chaves. 1F382 é o bolo de aniversário.

Você não precisa decorar códigos: hoje dá para digitar é e ° direto no texto, e o Node lê sem problemas. O \u é útil para caracteres que não estão no teclado, ou que são invisíveis (como o espaço que não quebra linha, \u00a0).

6. Na crase, as mesmas sequências valem

Num template string (crase), \n, \t e \\ funcionam igual. E surgem duas novas, para os caracteres que são especiais só na crase:

const nome = "Ana";
console.log(`Olá, ${nome}!\tTudo bem?`);
console.log(`Use \`crase\` para templates`);
console.log(`Escreva \${nome} para encaixar o nome`);

$ node crase.js
Olá, Ana!	Tudo bem?
Use `crase` para templates
Escreva ${nome} para encaixar o nome

\` é uma crase que não fecha o template, e \${ é um ${ que não abre lacuna: sai ao pé da letra.

Formas diferentes de fazer a mesma coisa

// Aspas dentro do texto
console.log("Ela disse \"oi\"");
console.log('Ela disse "oi"');
console.log(`Ela disse "oi"`);

// Duas linhas
console.log("Linha 1\nLinha 2");
console.log(`Linha 1
Linha 2`);

// Caminho do Windows
console.log("C:\\Users\\ana");
console.log(String.raw`C:\Users\ana`);

$ node formas.js
Ela disse "oi"
Ela disse "oi"
Ela disse "oi"
Linha 1
Linha 2
Linha 1
Linha 2
C:\Users\ana
C:\Users\ana

A última linha usa o String.raw (do inglês raw, "cru"), colado antes de uma crase: ele desliga as sequências de escape e mantém cada barra como ela está. É prático para caminhos do Windows e para as expressões regulares.

Quando dá errado

O caminho que virou duas linhas: "C:\novos\tabela" 
const arquivo = "C:\novos\tabela.txt";
console.log(arquivo);

$ node caminho.js

"Erro de sintaxe: sequência de escape Unicode inválida". As setinhas apontam o \usuar: depois de \u, o JavaScript esperava 4 dígitos hexadecimais (de 0 a 9 e de a a f), mas encontrou suar. Ao contrário do \n escondido do exemplo anterior, este o Node não deixa passar: o programa nem começa. Como consertar: dobre as barras: "C:\\usuarios\\ana".

Barra normal no lugar da invertida: /n 
console.log("Linha 1/nLinha 2");
console.log("Linha 1\nLinha 2");

$ node barra-normal.js
Linha 1/nLinha 2
Linha 1
Linha 2

A barra normal / é só uma letra comum: /n são dois caracteres, e aparecem na tela. A sequência de escape usa sempre a barra invertida \ (no teclado ABNT, a tecla à esquerda do Z). Como consertar: \n.

Resumo

  • Dentro de uma string, a barra invertida \ avisa que o próximo caractere é especial. A dupla vira um caractere só.
  • \" e \' põem aspas dentro do texto; \n pula linha; \t é a tabulação; \\ é a própria barra.
  • \u00e9 (4 dígitos) e \u{1F382} (entre chaves) escrevem qualquer caractere Unicode.
  • Na crase, valem as mesmas, mais \` e \${. String.raw`…` desliga todas.
  • O modo interativo mostra o valor com as sequências ('a\nb'); o console.log mostra o texto pronto.
  • Cuidado com caminhos do Windows: "C:\novos" tem um \n escondido; "C:\Users\" não fecha; "C:\usuarios" é um \u inválido.
