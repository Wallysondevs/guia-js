JavaScript break e continue

Até agora, um laço só terminava quando a condição ficava falsa, e toda volta rodava o corpo inteiro. Às vezes você quer mais controle: parar no meio, porque já achou o que procurava, ou pular só esta volta, porque o item não interessa. Para isso existem duas palavras: break ("quebrar", sair do laço) e continue ("continuar", ir direto para a próxima volta).

Você vai aprender
  • Como o break encerra o laço na hora, e onde o programa continua depois dele.
  • Como usar while (true) com break, o laço "infinito" com saída no meio.
  • Como o continue pula o resto de uma volta, e por que no for o passo ainda acontece.
  • A armadilha do continue no while, que trava o programa.
  • O que acontece com break num laço dentro de outro laço.
  • Os erros reais: break e continue fora de um laço.

Todos os programas desta aula rodaram no Node.js 24 (v24.22.0) da máquina da Ana, com node arquivo.js. Você pode rodar cada um no editor do guia.

A ideia: procurar a chave na gaveta

A Ana procura a chave de casa numa gaveta cheia de coisas. Ela tira um objeto de cada vez:

  • Quando acha a chave, ela para de procurar. Não faz sentido olhar o resto da gaveta. Isso é o break.
  • Quando pega um papel de bala, ela nem olha direito: joga de lado e pega o próximo objeto. Isso é o continue.

Os dois só fazem sentido dentro de um laço (for, while, do … while).

1. break: parar quando achar

A Ana quer saber em que posição o café está na lista de compras. Assim que achar, não precisa olhar o resto:

const compras = ["pão", "leite", "café", "manteiga", "ovos"];
for (let i = 0; i < compras.length; i++) {
  console.log(`Olhando: ${compras[i]}`);
  if (compras[i] === "café") {
    console.log(`Achei o café na posição ${i}!`);
    break;
  }
}
console.log("Fim da busca.");

Olhando: leite
Olhando: café
Achei o café na posição 2!
Fim da busca.

A pergunta de cada volta: "este item é o café?" (o === compara; veja Comparação).

A primeira linha depois do laço. É para cá que o break pula.

Numa lista de 5 itens, tanto faz. Numa lista de 1 milhão de itens, parar cedo economiza muito trabalho.

2. while (true) com break

Às vezes é mais fácil escrever "repita para sempre" e decidir a saída no meio do corpo. A condição true nunca fica falsa, então o único jeito de sair é o break. Quantos dias leva para R$ 1, dobrando todo dia, passar de R$ 1000?

let valor = 1;
let dias = 0;
while (true) {
  valor *= 2;
  dias++;
  if (valor > 1000) {
    break;
  }
}
console.log(`Passou de R$ 1000 em ${dias} dias: R$ ${valor}`);

$ node dobra.js
Passou de R$ 1000 em 10 dias: R$ 1024

O valor *= 2 é "o valor passa a ser o dobro" (veja Atribuição). A cada volta, o programa dobra, conta o dia e pergunta: "já passou de 1000?". Na 10ª volta, 1024 > 1000 dá true, o break roda, e o programa segue para o console.log.

Todo while (true) precisa de um break que um dia aconteça

Se a condição do if nunca for verdadeira, é um laço infinito de verdade (no terminal, Ctrl+C; veja for). Esse formato é muito usado para ler o teclado até a pessoa digitar "sair", como você vai ver em Lendo o Teclado.

3. continue: pular esta volta

O continue não sai do laço: ele abandona só a volta atual e vai para a próxima. Este programa mostra os números de 1 a 10, pulando os pares:

for (let i = 1; i <= 10; i++) {
  if (i % 2 === 0) {
    continue;
  }
  console.log(i);
}

$ node impares.js
1
3
5
7
9
i % 2 === 0
"O resto da divisão de i por 2 é zero?", ou seja, "i é par?" (o % é o resto; veja Operadores Aritméticos).
continue;
"Continue com a próxima volta". O resto do corpo (o console.log) é pulado. No for, o JavaScript vai para o passo (i++) e depois testa a condição, como numa volta normal.

Um uso real: pular as notas que faltam

Na lista de notas da turma, a professora marcou com -1 quem faltou à prova. Essas notas não podem entrar na média:

const notas = [8, -1, 7, 10, -1, 6];
let soma = 0;
let quantas = 0;
for (let i = 0; i < notas.length; i++) {
  if (notas[i] < 0) {
    console.log(`Posição ${i}: faltou, pulando`);
    continue;
  }
  soma += notas[i];
  quantas++;
}
console.log(`Média de ${quantas} notas: ${soma / quantas}`);

$ node notas.js
Posição 1: faltou, pulando
Posição 4: faltou, pulando
Média de 4 notas: 7.75

Nas posições 1 e 4, o continue pulou o soma += … e o quantas++. Ficaram 8, 7, 10 e 6: soma 31, dividida por 4, dá 7.75.

4. A armadilha do continue no while

No for, o passo (i++) fica no alto e roda mesmo depois de um continue. No while, o passo é uma linha comum do corpo, e o continue pode pular por cima dela:

let i = 0;
while (i < 5) {
  if (i === 2) {
    continue;
  }
  console.log(i);
  i++;
}
console.log("Fim!");

$ timeout 2 node continue_while.js
0
1
$ echo $?
124

O programa mostrou 0 e 1 e travou. Quando i chegou a 2, o continue pulou o i++; na volta seguinte, i ainda era 2, o continue pulou de novo… para sempre. A Ana rodou com timeout 2, que mata o programa depois de 2 segundos; o 124 do echo $? é o código que o timeout devolve quando precisou matar (sem ele, seria o Ctrl+C).

Como consertar: faça o passo antes do continue. Aqui, mudando o i++ para o começo do corpo (repare que agora os números mostrados vão de 1 a 5):

let i = 0;
while (i < 5) {
  i++;
  if (i === 2) {
    continue;
  }
  console.log(i);
}
console.log("Fim!");

$ node continue_while_ok.js
1
3
4
5
Fim!

Experimente: rode o programa travado e clique em ■ Parar. Depois mova o i++ para a primeira linha do corpo e rode de novo.

5. break num laço dentro de outro

Um laço pode ficar dentro de outro (é o assunto da próxima aula, Laços Aninhados). Nesse caso, o break sai só do laço mais de dentro, aquele em que ele está:

for (let fila = 1; fila <= 3; fila++) {
  for (let cadeira = 1; cadeira <= 3; cadeira++) {
    if (cadeira === 2) {
      break;
    }
    console.log(`Fila ${fila}, cadeira ${cadeira}`);
  }
}

$ node aninhado.js
Fila 1, cadeira 1
Fila 2, cadeira 1
Fila 3, cadeira 1

Em cada fila, o laço das cadeiras parou na cadeira 2, mas o laço das filas continuou: fila 1, 2 e 3. Como sair dos dois laços de uma vez fica para a aula Laços Aninhados.

E o break do switch?

É a mesma palavra, que você viu em switch: lá ela encerra o switch. Se um switch estiver dentro de um laço, o break dentro do case sai só do switch, não do laço.

Formas diferentes de fazer a mesma coisa

Tudo o que o break e o continue fazem dá para fazer sem eles. A busca do café pode guardar numa variável se já achou, e pôr isso na condição do laço:

const compras = ["pão", "leite", "café", "manteiga", "ovos"];
let achou = false;
for (let i = 0; i < compras.length && !achou; i++) {
  console.log(`Olhando: ${compras[i]}`);
  if (compras[i] === "café") {
    console.log(`Achei o café na posição ${i}!`);
    achou = true;
  }
}
console.log("Fim da busca.");

$ node procura_cond.js
Olhando: pão
Olhando: leite
Olhando: café
Achei o café na posição 2!
Fim da busca.

A condição agora é "ainda tem item e não achou" (&& e !; veja Operadores Lógicos). E os ímpares podem ser mostrados com um if que pergunta o contrário, sem continue:

for (let i = 1; i <= 10; i++) {
  if (i % 2 !== 0) {
    console.log(i);
  }
}

A saída é a mesma do impares.js (1, 3, 5, 7 e 9). Qual escolher?

Quando dá errado

break fora de um laço 
const estoque = 0;
if (estoque === 0) {
  console.log("Acabou o pão!");
  break;
}
console.log("Pode vender.");

$ node fora_break.js
/home/ana/fora_break.js:4
  break;
  ^^^^^

SyntaxError: Illegal break statement
    at wrapSafe (node:internal/modules/cjs/loader:1861:18)   « mais 7 linhas "at … node:internal" cortadas

Node.js v24.22.0

Linha por linha: o arquivo e a linha 4; o código dessa linha, com ^^^^^ marcando a palavra break inteira; e SyntaxError: Illegal break statement, "erro de sintaxe: instrução break ilegal". O if não é um laço: não tem de onde "sair". Por ser erro de sintaxe, o programa nem começou (o Acabou o pão! não apareceu). Como consertar: para parar o programa inteiro existe o process.exit() (veja process.env e process.exit); para não rodar o resto, use um else (veja else e else if).

continue fora de um laço 
const nota = -1;
if (nota < 0) {
  continue;
}
console.log(`Nota: ${nota}`);

$ node fora_continue.js

  continue;
  ^^^^^^^^

SyntaxError: Illegal continue statement: no surrounding iteration statement
    at wrapSafe (node:internal/modules/cjs/loader:1861:18)   « mais 7 linhas "at … node:internal" cortadas

Node.js v24.22.0

"Instrução continue ilegal: não há uma instrução de repetição em volta". A mensagem diz exatamente o problema: iteration statement é o nome técnico de um laço. Como consertar: o continue só vale dentro de for, while ou do … while.

O programa travou depois de um continue

É a armadilha da seção 4: num while, o continue pulou a linha que faz o laço andar. Como consertar: mude o contador antes do continue, ou use um for, em que o passo nunca é pulado.

O break não parou tudo

Num laço dentro de outro, o break sai só do de dentro (seção 5, o exemplo das filas e cadeiras). Não é erro do JavaScript; é a regra. Como consertar: veja a aula Laços Aninhados.

}

Resumo

  • break sai do laço na hora; o programa continua na primeira linha depois dele.
  • continue pula o resto da volta atual; no for, o passo ainda roda.
  • while (true) com break é o laço com a saída no meio; o break tem de acontecer um dia.
  • Num while, mude o contador antes do continue, senão o programa trava.
  • Num laço dentro de outro, o break sai só do de dentro.
  • Fora de um laço, os dois dão SyntaxError e o programa nem começa.
