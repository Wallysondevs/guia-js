JavaScript Arrays

Até agora, cada variável guardou um valor: um nome, um preço, uma nota. Mas a vida da Ana é cheia de listas: a lista de compras da semana, as notas da turma, os pães que a padaria vendeu hoje. Criar uma variável para cada item (item1, item2, item3…) não dá certo: e se a lista tiver 50 itens? Para isso existe o array (em inglês, "arranjo", "fileira"; no Brasil também se diz vetor ou, simplesmente, lista): uma variável só que guarda vários valores em fila, um atrás do outro.

Você vai aprender
  • O que é um array e como criar um com colchetes: ["arroz", "feijão", "café"].
  • Que um array pode guardar textos, números, booleanos, tudo misturado, ou nada (o array vazio []).
  • Que cada item tem uma posição (o índice), e que a primeira posição é a 0.
  • A contar os itens com length.
  • Como o console.log do Node mostra um array (e por que as aspas viram simples).
  • A descobrir se um valor é um array: typeof engana, Array.isArray não.
  • Outras formas de criar arrays (Array.of, Array.from) e a pegadinha do new Array(3).
  • Os erros reais mais comuns: a vírgula esquecida, o colchete que não fechou, o lenght escrito errado e a const que não aceita outro array.

Todos os programas desta aula rodaram no Node.js 24 da máquina da Ana (usuária ana, computador notebook), salvos na pasta pessoal dela e executados com node arquivo.js (veja Rodando um Programa). Você pode rodar cada um no editor do guia.

A ideia: a lista de compras na porta da geladeira

Pense na lista de compras que a Ana prende na geladeira com um ímã. É uma folha só, mas nela cabem vários itens, um embaixo do outro, numa ordem:

  1. arroz
  2. feijão
  3. café

Três coisas dessa folha valem para todo array:

  • É uma coisa só com um nome (a "lista de compras"), não três papeizinhos soltos. No JavaScript, é uma variável só.
  • Os itens têm ordem: o arroz vem antes do feijão. Dá para dizer "o primeiro item", "o terceiro item".
  • A lista pode crescer e diminuir: dá para acrescentar o pão no fim ou riscar o café. (Isso é assunto de push, pop, shift e unshift.)

1. O primeiro array

const compras = ["arroz", "feijão", "café"];
console.log(compras);
const compras
Uma variável comum, criada com const (veja Constantes). O nome no plural (compras, notas, alunos) é um costume que ajuda a lembrar que ali dentro há vários valores.
[ e ]
Os colchetes abrem e fecham o array. Tudo o que estiver entre eles é um item da lista.
"arroz", "feijão", "café"
Os itens (também chamados de elementos), separados por vírgula. Aqui são três strings, cada uma com as suas aspas.
;
O ponto e vírgula fecha a instrução inteira, depois do ], como em qualquer outra linha.
console.log(compras)
Mostra o array inteiro de uma vez (veja console.log()).
$ node compras.js
[ 'arroz', 'feijão', 'café' ]

Repare em dois detalhes da saída:

  • O Node mostra o array do jeito que ele foi escrito: entre colchetes, itens separados por vírgula, com um espaço depois do [ e antes do ].
  • No código as aspas eram duplas; na saída, o Node mostra simples ('arroz'). Não é erro, nem mudou nada no seu array: é só o jeito que o console.log do Node escolheu para mostrar que aqueles itens são textos. No JavaScript, "arroz" e 'arroz' são exatamente a mesma string.

Um array grande pode ser escrito em várias linhas, um item por linha. Fica mais fácil de ler e de mexer depois:

const compras = [
  "arroz",
  "feijão",
  "café",
  "leite",
];
console.log(compras);

$ node compras_linhas.js
[ 'arroz', 'feijão', 'café', 'leite' ]

Viu a vírgula depois de "leite", o último item? Ela se chama vírgula final (em inglês, trailing comma) e é permitida: o JavaScript a ignora. Muita gente prefere deixá-la, porque assim, para acrescentar um item no fim, basta escrever uma linha nova, sem mexer na de cima.

Missão: acrescente "pão" no fim da lista de compras (não esqueça a vírgula antes dele) e clique em Rodar.

const compras = ["arroz", "feijão", "café"];
console.log(compras);

const compras = ["arroz", "feijão", "café", "pão"];
console.log(compras);

2. O que cabe num array

Um array guarda qualquer tipo de valor (veja Os Tipos de Dados). As notas da turma são números; a resposta "a loja está aberta?" de cada dia da semana, booleanos:

const notas = [7.5, 8, 6.5, 9, 10];
const aberta = [true, true, true, true, true, true, false];
const ficha = ["Ana", 30, true];
const vazio = [];

console.log(notas);
console.log(aberta);
console.log(ficha);
console.log(vazio);

$ node tipos.js
[ 7.5, 8, 6.5, 9, 10 ]
[
  true,  true,
  true,  true,
  true,  true,
  false
]
[ 'Ana', 30, true ]
[]
notas
Números vão sem aspas, como em qualquer lugar. O Node os mostra sem aspas também: é assim que você distingue o número 8 do texto '8' na saída.
aberta
Sete booleanos, um por dia da semana (domingo fechado). Repare que o Node os mostrou em colunas, dois por linha: quando um array tem mais de 6 itens curtos, o console.log arruma a saída assim (você vai ver isso de novo na seção 5). Os valores são os mesmos; só a arrumação na tela mudou.
ficha
Tipos misturados: um texto, um número e um booleano. O JavaScript deixa. Na prática, é melhor que todos os itens de um array sejam do mesmo tipo (só nomes, só preços), porque aí você trata todos do mesmo jeito. Para guardar "nome, idade, ativo" de uma pessoa existe um lugar melhor, o objeto.
vazio
Um array sem nenhum item: []. Parece inútil, mas é como a folha da lista ainda em branco: o programa começa com ela vazia e vai acrescentando itens depois.

Um array pode guardar até outros arrays (uma lista de listas). Esse assunto tem aula própria: Arrays de Arrays.

3. As posições: a primeira é a 0

Cada item do array mora numa posição numerada, o índice. E aqui vem a surpresa de todo iniciante: a contagem começa do zero.

Índice012
Item"arroz""feijão""café"

Para pegar um item, escreva o nome do array e, entre colchetes, o índice:

const compras = ["arroz", "feijão", "café"];
console.log(compras[0]);
console.log(compras[1]);
console.log(compras[2]);

$ node posicoes.js
arroz
feijão
café

Agora as aspas sumiram: compras[0] não é um array, é um item, a string arroz, e o console.log mostra uma string sozinha sem aspas (como sempre fez). Pense no índice como "quantos passos andar a partir do começo": o primeiro item está a 0 passos do começo, o segundo a 1 passo. Ler, trocar e pegar o último item são o assunto da próxima aula, Acessando e Alterando Itens.

4. Quantos itens? length

Todo array sabe o próprio tamanho. Basta escrever .length (em inglês, "comprimento") depois do nome:

const compras = ["arroz", "feijão", "café"];
const vazio = [];

console.log(compras.length);
console.log(vazio.length);
console.log(`A lista tem ${compras.length} itens.`);

$ node tamanho.js
3
0
A lista tem 3 itens.
compras.length
O número de itens. O ponto quer dizer "a propriedade length deste array". Repare: não tem parênteses, porque length não é uma ação, é uma informação que o array guarda.
vazio.length
Um array vazio tem tamanho 0.
`A lista tem ${…} itens.`
O tamanho dentro de uma template string.
O tamanho é 3, mas o último índice é 2

Como a contagem das posições começa em 0, o último item de um array de 3 itens está na posição 2. Em qualquer array, o último índice é sempre length - 1. Essa diferença de um causa tantos erros que tem até nome: o "erro de um a mais" (em inglês, off-by-one). Você vai encontrá-lo de novo na próxima aula e em for.

Você já viu o length nas strings (veja Strings): lá ele conta letras, aqui conta itens. Uma string se parece com uma fileira de letras, e por isso várias ideias deste grupo de aulas valem para as duas.

Missão: a professora lançou mais uma nota, 5.5. Acrescente-a no array notas e rode: a frase tem de mostrar A turma tem 6 notas. sem você trocar o número na mão.

const notas = [7.5, 8, 6.5, 9, 10];
console.log(`A turma tem ${notas.length} notas.`);

const notas = [7.5, 8, 6.5, 9, 10, 5.5];
console.log(`A turma tem ${notas.length} notas.`);

6. Isto é um array? typeof engana

Na aula typeof você aprendeu a perguntar o tipo de um valor. Com arrays, a resposta decepciona:

const compras = ["arroz", "feijão", "café"];
console.log(typeof compras);
console.log(Array.isArray(compras));
console.log(Array.isArray("arroz"));

$ node tipo.js
object
true
false
typeof compras → 'object'
Para o JavaScript, um array é um tipo especial de objeto (o assunto do grupo Objetos). Por isso o typeof responde object, a mesma resposta que daria para qualquer objeto, e não ajuda a saber se é uma lista.
Array.isArray(compras) → true
"É um array?". A pergunta certa: devolve true para arrays e false para todo o resto, como a string "arroz".

7. Arrays no modo interativo

No modo interativo do Node (veja O Modo Interativo), você nem precisa do console.log: o Node mostra o valor de cada expressão sozinho. É um ótimo lugar para brincar com arrays:

$ node
Welcome to Node.js v24.22.0.
Type ".help" for more information.
> const compras = ["arroz", "feijão", "café"]
undefined
> compras
[ 'arroz', 'feijão', 'café' ]
> compras.length
3
> compras[0]
'arroz'
> [1, 2, 3].length
3
> Array.isArray(compras)
true
> .exit

Repare que a linha do const respondeu undefined: criar uma variável não "dá" nenhum valor para mostrar (o modo interativo sempre faz isso com const e let). As outras linhas são expressões, e o Node mostra o resultado de cada uma. Repare também em compras[0]: no modo interativo, a string aparece com aspas ('arroz'), para você ver que é um texto; o console.log a mostraria sem aspas.

Formas diferentes de criar um array

Os colchetes ([ … ], chamados de literal de array) são o jeito do dia a dia. Mas você vai encontrar outros em código pronto:

const a = ["arroz", "feijão"];
const b = new Array("arroz", "feijão");
const c = Array.of(7, 8, 9);
const d = Array.from("Ana");
const e = "arroz,feijão,café".split(",");

console.log(a);
console.log(b);
console.log(c);
console.log(d);
console.log(e);

$ node formas.js
[ 'arroz', 'feijão' ]
[ 'arroz', 'feijão' ]
[ 7, 8, 9 ]
[ 'A', 'n', 'a' ]
[ 'arroz', 'feijão', 'café' ]
new Array("arroz", "feijão")
O jeito antigo, com o "construtor" Array (o new quer dizer "crie um novo"). Dá o mesmo resultado dos colchetes, só que mais comprido e com uma pegadinha (logo abaixo).
Array.of(7, 8, 9)
"Array de": cria um array com os valores que você passar.
Array.from("Ana")
"Array a partir de": transforma outra coisa que tenha "uma fileira de partes" num array. Uma string vira um array de letras.
"arroz,feijão,café".split(",")
Corta uma string em pedaços a cada vírgula, e os pedaços viram um array. É o que você faz quando lê uma lista de um arquivo ou do teclado (veja split e join).

A pegadinha do new Array(3)

const x = new Array(3);
const y = Array.of(3);
console.log(x);
console.log(x.length);
console.log(y);

$ node pegadinha.js
[ <3 empty items> ]
3
[ 3 ]

Com um número só, o new Array(3) não cria o array [3]: cria um array de tamanho 3 com três buracos vazios (<3 empty items>, "3 itens vazios"). Com dois ou mais valores, ou com um texto, ele se comporta como os colchetes. Essa mudança de comportamento confunde todo mundo, e foi por isso que o Array.of foi criado: ele sempre faz o que parece.

SituaçãoQual usar
Escrever uma lista de valores no código (quase sempre)["arroz", "feijão"]
Começar uma lista vazia e encher depois[]
Transformar uma string em array de letrasArray.from("Ana")
Cortar um texto com separador num array de pedaçostexto.split(",")
Criar um array com newEvite: new Array(3) faz buracos. Reconheça em código antigo.

8. O array numa const

Uma dúvida comum: se compras é uma const, como a lista pode crescer? A resposta é que a const protege a variável, não o conteúdo. Voltando à geladeira: a const cola a folha com supercola, então você não pode trocá-la por outra folha; mas pode escrever e riscar itens na mesma folha.

const compras = ["arroz", "feijão"];
compras.push("café");
console.log(compras);
compras = ["pão"];

"Erro de sintaxe: ; inesperado". O Node ainda estava dentro do array, esperando uma vírgula e mais um item ou o ], e encontrou o ponto e vírgula; o ^ aponta exatamente para ele. O Node não diz "faltou o colchete": ele diz o que encontrou no lugar. Quando a mensagem for Unexpected token, olhe o que falta antes do ^. Como consertar: feche o array com ] antes do ponto e vírgula.

Escreveu lenght em vez de length 
const compras = ["arroz", "feijão", "café"];

$ node lenght.js

Nenhuma mensagem de erro, e por isso é traiçoeiro. lenght (com o h trocado de lugar) não existe no array, e no JavaScript ler uma propriedade que não existe dá undefined ("indefinido"; veja null e undefined), sem reclamar. Como consertar: length, com o t antes do h (de "leng-th"). Se aparecer undefined onde você esperava um tamanho, desconfie da escrita.

Missão: crie um array alunos com quatro nomes: "Ana", "Bia", "Caio" e "Duda". Depois, mostre o array inteiro com console.log e a frase A turma tem 4 alunos. usando o length numa template string.

Resumo

  • Um array guarda vários valores em fila numa variável só. Cria-se com colchetes e vírgulas: ["arroz", "feijão", "café"]; o array vazio é [].
  • Os itens podem ser de qualquer tipo, mas o melhor é que todos sejam do mesmo tipo.
  • Cada item tem um índice, que começa em 0: compras[0] é o primeiro. O último é length - 1.
  • lista.length diz quantos itens o array tem (sem parênteses).
  • O console.log do Node mostra os textos com aspas simples, quebra arrays grandes em colunas e mostra no máximo 100 itens.
  • typeof de um array é 'object'; para saber se é array, use Array.isArray.
  • Prefira os colchetes; evite new Array(n), que cria buracos vazios.
  • Numa const, o array pode mudar por dentro, mas a variável não aceita outro array.
