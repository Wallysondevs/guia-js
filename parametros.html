JavaScript Parâmetros e Argumentos

Na aula Funções, cada função fazia sempre a mesma coisa: mostrarLinha() mostrava sempre a mesma linha. Uma função fica muito mais útil quando você pode mandar informações para ela: saudar("Ana"), saudar("Bia"). Essas informações entram pelos parênteses. Na declaração, elas se chamam parâmetros; na chamada, argumentos.

Você vai aprender
  • Como declarar uma função com um parâmetro e chamá-la com argumentos diferentes.
  • A diferença entre parâmetro e argumento.
  • Funções com vários parâmetros, e por que a ordem importa.
  • O que acontece quando falta argumento (undefined) ou sobra.
  • Que o parâmetro é uma variável nova, que só existe dentro da função.
  • Os erros reais mais comuns ao escrever e chamar funções com parâmetros.

Todos os programas desta aula rodaram no Node.js 24 (v24.22.0) da máquina da Ana, com node arquivo.js. Você pode rodar cada um no editor do guia.

A ideia: o liquidificador

Um liquidificador faz sempre o mesmo trabalho: bater. Mas o que sai depende do que você põe no copo: morango vira suco de morango; laranja vira suco de laranja. O copo é o parâmetro: um lugar reservado, com uma etiqueta ("fruta"). A fruta que você põe numa vez específica é o argumento.

  • Parâmetro: o nome que aparece na declaração da função. É uma variável que espera um valor: function saudar(nome).
  • Argumento: o valor que você manda na chamada: saudar("Ana").

Na prática, muita gente usa as duas palavras como se fossem a mesma coisa. Não tem problema; mas saber a diferença ajuda a entender as mensagens de erro e a documentação.

1. Um parâmetro

function saudar(nome) {
  console.log(`Olá, ${nome}! Bem-vinda à padaria.`);
}

saudar("Ana");
saudar("Bia");
saudar("Carla");

$ node saudar.js
Olá, Ana! Bem-vinda à padaria.
Olá, Bia! Bem-vinda à padaria.
Olá, Carla! Bem-vinda à padaria.
function saudar(nome)
nome é o parâmetro: uma variável que só existe dentro da função e que, a cada chamada, recebe um valor novo. Não se escreve let nem const antes dele.
${nome}
Dentro do corpo, o parâmetro é usado como qualquer variável.
saudar("Ana")
A chamada com o argumento "Ana". Antes de rodar o corpo, o JavaScript faz, por baixo dos panos, algo como nome = "Ana".
saudar("Bia")
Outra chamada, outro argumento: agora nome vale "Bia". Uma função, três saudações diferentes.

Missão: a Dona Rosa chegou à padaria. Acrescente uma chamada para ela aparecer cumprimentada: Olá, Dona Rosa! Bem-vinda à padaria.

function saudar(nome) {
  console.log(`Olá, ${nome}! Bem-vinda à padaria.`);
}

saudar("Ana");

function saudar(nome) {
  console.log(`Olá, ${nome}! Bem-vinda à padaria.`);
}

saudar("Ana");
saudar("Dona Rosa");

2. Vários parâmetros

Para mandar mais de uma informação, separe os parâmetros com vírgula, na declaração e na chamada:

function mostrarItem(produto, preco) {
  console.log(`${produto} custa R$ ${preco.toFixed(2)}`);
}

mostrarItem("Pão francês", 0.8);
mostrarItem("Café", 4.5);
mostrarItem("Bolo de fubá", 18);

$ node item.js
Pão francês custa R$ 0.80
Café custa R$ 4.50
Bolo de fubá custa R$ 18.00
(produto, preco)
Dois parâmetros, separados por vírgula.
mostrarItem("Café", 4.5)
Dois argumentos, na mesma ordem: o primeiro vai para o primeiro parâmetro (produto = "Café"), o segundo para o segundo (preco = 4.5). O JavaScript liga um ao outro pela posição, não pelo nome.
preco.toFixed(2)
Mostra o número com 2 casas decimais (4.5 vira 4.50). Os detalhes ficam para Formatando Números.

A ordem importa

Como a ligação é pela posição, trocar a ordem dos argumentos troca os valores, sem erro nenhum:

function mostrarPedido(produto, quantidade) {
  console.log(`Pedido: ${quantidade} x ${produto}`);
}

mostrarPedido("pão francês", 10);
mostrarPedido(10, "pão francês");

$ node trocado.js
Pedido: 10 x pão francês
Pedido: pão francês x 10

Na segunda chamada, produto recebeu 10 e quantidade recebeu "pão francês". O JavaScript não sabe o que "faz sentido": ele só segue a ordem. Por isso, vale dar nomes claros aos parâmetros e conferir a ordem na declaração.

O argumento pode ser uma variável ou uma conta

O argumento é um valor, e qualquer coisa que produza um valor serve: um texto, um número, uma variável, uma conta. O JavaScript calcula o valor antes de entrar na função:

function mostrarItem(produto, preco) {
  console.log(`${produto} custa R$ ${preco.toFixed(2)}`);
}

const cafe = "Café";
const precoDoCafe = 4.5;
mostrarItem(cafe, precoDoCafe);
mostrarItem("10 pães", 0.8 * 10);
mostrarItem(`Pão de ${"queijo"}`, 2 + 1.5);

$ node expressoes.js
Café custa R$ 4.50
10 pães custa R$ 8.00
Pão de queijo custa R$ 3.50

Repare na primeira chamada: a variável de fora se chama precoDoCafe, e o parâmetro se chama preco. Os nomes não precisam ser iguais: o que passa para dentro é o valor (4.5).

Missão: acrescente um terceiro parâmetro, preco (o preço de uma unidade), e mostre o total do pedido: Pedido: 12 x pão francês = R$ 9.60. A chamada já manda os três argumentos.

function mostrarPedido(produto, quantidade) {
  console.log(`Pedido: ${quantidade} x ${produto}`);
}

mostrarPedido("pão francês", 12, 0.8);

function mostrarPedido(produto, quantidade, preco) {
  const total = quantidade * preco;
  console.log(`Pedido: ${quantidade} x ${produto} = R$ ${total.toFixed(2)}`);
}

mostrarPedido("pão francês", 12, 0.8);

3. Faltou argumento? Sobrou?

Muitas linguagens reclamam quando o número de argumentos não bate com o de parâmetros. O JavaScript, não:

function saudar(nome) {
  console.log(`Olá, ${nome}!`);
}

saudar();
saudar("Ana", "Bia");

$ node faltou.js
Olá, undefined!
Olá, Ana!
  • Faltou: na primeira chamada não veio nenhum argumento, e o parâmetro nome ficou valendo undefined ("indefinido"; veja null e undefined). Sem erro, mas com um texto estranho.
  • Sobrou: na segunda, o "Bia" não tinha parâmetro para ocupar e foi simplesmente ignorado.

Com dois parâmetros, o que falta é sempre o do fim:

function mostrarItem(produto, preco) {
  console.log(`${produto} custa R$ ${preco}`);
}

mostrarItem("Café");

$ node faltou2.js
Café custa R$ undefined

Esse silêncio pode virar erro quando a função usa o parâmetro que faltou para fazer alguma coisa (veja em Quando dá errado). Para evitar o undefined, dá para dar um valor padrão ao parâmetro: o valor que ele recebe quando o argumento não vem.

function saudar(nome = "cliente") {
  console.log(`Olá, ${nome}!`);
}

saudar("Ana");
saudar();

$ node padrao.js
Olá, Ana!
Olá, cliente!

O = "cliente" na declaração diz: "se ninguém mandar um nome, use "cliente"". O assunto tem aula própria: Parâmetros Padrão.

4. O parâmetro é uma variável nova

O parâmetro recebe uma cópia do valor do argumento. Mudar o parâmetro dentro da função não muda a variável de fora:

function dobrar(numero) {
  numero = numero * 2;
  console.log(`Dentro da função: ${numero}`);
}

let pedidos = 5;
dobrar(pedidos);
console.log(`Fora da função: ${pedidos}`);

$ node copia.js
Dentro da função: 10
Fora da função: 5

Na chamada, numero recebeu o valor 5. Dentro, ele passou a 10, mas pedidos, lá fora, continuou 5: são duas variáveis diferentes. E o parâmetro só existe dentro da função; fora dela, o nome numero não existe (é o mesmo caso das variáveis criadas dentro da função, da aula Funções). Para trazer um resultado de dentro para fora, a função usa return: o assunto da próxima aula, Retornando Valores.

Com arrays e objetos é diferente

Isso vale para números, textos e booleanos. Com arrays e objetos, a função recebe uma referência para a mesma lista, e mudar a lista lá dentro muda a de fora. Você vai ver o porquê em Objetos são Referências.

Parâmetros e laços: a tabuada de qualquer número

Com um parâmetro, a mesma função serve para qualquer número:

function mostrarTabuada(numero) {
  for (let i = 1; i <= 3; i++) {
    console.log(`${numero} x ${i} = ${numero * i}`);
  }
}

mostrarTabuada(2);
mostrarTabuada(5);

$ node tabuada.js
2 x 1 = 2
2 x 2 = 4
2 x 3 = 6
5 x 1 = 5
5 x 2 = 10
5 x 3 = 15

Formas diferentes de fazer a mesma coisa

Quando a função precisa de uma informação, há alguns caminhos:

  • Um parâmetro para cada informação: mostrarItem(produto, preco). É o normal, para até 3 ou 4 informações.
  • Parâmetro com valor padrão: saudar(nome = "cliente"), quando a informação é opcional (aula Parâmetros Padrão).
  • Um objeto com várias informações: mostrarItem({ produto: "Café", preco: 4.5 }), quando são muitas e a ordem confundiria. Você vai ver em Objetos e Desestruturação.
  • Quantidade variável: function somar(...numeros), que recebe quantos argumentos vierem, numa lista (aula Spread e Rest).
  • Usar uma variável de fora, sem parâmetro. Funciona, mas a função fica presa àquela variável e é mais difícil de entender e de reaproveitar. Prefira o parâmetro.
SituaçãoQual usar
1 a 3 informações, todas necessáriasParâmetros comuns, na ordem
Uma informação que pode faltarValor padrão: nome = "cliente"
Muitas informações, várias opcionaisUm objeto (Nível 2)
Não se sabe quantos valores virãoRest: ...numeros (Nível 2)

Resumo

  • Parâmetros são os nomes entre parênteses na declaração; argumentos são os valores na chamada.
  • Vários parâmetros e argumentos se separam com vírgula e se ligam pela posição.
  • O argumento pode ser qualquer valor: texto, número, variável, conta. O valor é calculado antes de entrar.
  • Argumento que falta vira undefined; argumento que sobra é ignorado. Um valor padrão (nome = "cliente") evita o undefined.
  • O parâmetro é uma variável nova, só da função: mudá-lo não muda a variável de fora.
  • Para trazer um resultado de volta, a função usa return.
