JavaScript replace e replaceAll

Todo editor de texto tem a função Localizar e substituir: você diz o que procurar, diz o que pôr no lugar, e ele troca. Em JavaScript, toda string tem dois métodos que fazem isso: o replace (em inglês, "substituir"), que troca a primeira vez que o pedaço aparece, e o replaceAll ("substituir todos"), que troca todas.

Você vai aprender
  • Como trocar um pedaço de texto com replace(procurado, novo), e por que ele troca só a primeira vez.
  • Como trocar todas as vezes com replaceAll.
  • Que a string original não muda: o resultado é uma string nova, que você precisa guardar.
  • Que maiúsculas e minúsculas fazem diferença na busca.
  • Como apagar um pedaço (trocando por "") e como fazer várias trocas seguidas.
  • Um uso do dia a dia: transformar o preço "12,50" num número.
  • Os erros reais: replaceAll com uma regex sem o g, replace num número e numa variável undefined.

Todos os programas desta aula rodaram no Node.js 24 da máquina da Ana (usuária ana, computador notebook), salvos na pasta pessoal dela e executados com node arquivo.js (veja Rodando um Programa). Você pode rodar cada um no editor do guia.

A ideia: o corretivo no bilhete

A Ana escreveu um bilhete para a vizinha: "Bolo de cenoura no sábado". Mudou de ideia: vai ser de chocolate. Ela não rasga o bilhete; ela pega o papel, encontra a palavra cenoura e escreve chocolate no lugar.

O JavaScript faz quase isso, com uma diferença importante: ele não rabisca o bilhete original. Ele copia o bilhete inteiro para um papel novo, já com a troca feita, e te entrega esse papel novo. O original continua igualzinho. Guarde essa diferença: ela é a causa do erro mais comum desta aula.

1. replace: trocar um pedaço

const bilhete = "Bolo de cenoura no sábado";
const novoBilhete = bilhete.replace("cenoura", "chocolate");
console.log(novoBilhete);
bilhete

.replace(…)
O método "substituir". Como todo método de string, ele vem depois de um ponto (veja Métodos de String).
"cenoura"
O primeiro argumento: o pedaço procurado.
"chocolate"
O segundo argumento: o que vai no lugar.
const novoBilhete = …
O replace devolve uma string nova, com a troca feita. Aqui ela fica guardada em novoBilhete.
$ node bilhete.js
Bolo de chocolate no sábado

O pedaço procurado pode ter qualquer tamanho: uma letra, uma palavra, uma frase inteira. E o pedaço novo não precisa ter o mesmo tamanho do antigo: "cenoura" tem 7 letras e "chocolate" tem 9.

E se o pedaço não existir?

Nada acontece, e nenhum erro aparece: o replace devolve uma cópia igual à original.

const bilhete = "Bolo de cenoura no sábado";
console.log(bilhete.replace("morango", "chocolate"));

$ node nao-achou.js
Bolo de cenoura no sábado

Se você precisa saber se o pedaço existe antes de trocar, use o includes da aula Procurando em Strings.

2. A string original não muda

Este é o ponto mais importante da aula. Veja o que acontece quando a Ana chama o replace e não guarda o resultado:

const bilhete = "Bolo de cenoura no sábado";
bilhete.replace("cenoura", "chocolate");
console.log(bilhete);

$ node esqueceu.js
Bolo de cenoura no sábado

Continua cenoura. A linha 2 até fez a troca, mas a string nova não foi guardada em lugar nenhum e se perdeu. Em JavaScript, as strings são imutáveis (não podem ser mudadas por dentro): todo método de string devolve uma string nova e deixa a original como estava.

Você tem duas saídas:

  • guardar o resultado numa variável nova, como na seção 1 (const novoBilhete = bilhete.replace(…));
  • ou, se a variável foi criada com let, guardar o resultado nela mesma:
let bilhete = "Bolo de cenoura no sábado";
bilhete = bilhete.replace("cenoura", "chocolate");
console.log(bilhete);

$ node mesma.js
Bolo de chocolate no sábado

Repare que, aqui, a string antiga continua não tendo mudado: a variável bilhete é que passou a guardar outra string (veja Variáveis). Com const isso não daria certo, porque uma constante não pode receber outro valor (veja Constantes).

Missão: este programa mostra "cenoura" porque esqueceu de guardar a troca. Conserte: guarde o resultado do replace (numa variável nova ou na própria bilhete, trocando o const por let) e mostre o bilhete corrigido.

const bilhete = "Bolo de cenoura no sábado";
bilhete.replace("cenoura", "chocolate");
console.log(bilhete);

const bilhete = "Bolo de cenoura no sábado";
const novoBilhete = bilhete.replace("cenoura", "chocolate");
console.log(novoBilhete);

3. replace troca só a primeira vez

A Ana fez a lista de compras e escreveu "pao" sem til duas vezes. Ela tenta consertar com replace:

const lista = "pao, leite, pao de queijo, café";
console.log(lista.replace("pao", "pão"));

$ node primeira.js
pão, leite, pao de queijo, café

Só o primeiro "pao" foi corrigido. É assim de propósito: quando o primeiro argumento é um texto, o replace procura da esquerda para a direita, troca a primeira ocorrência que encontrar e para.

4. replaceAll: trocar todas as vezes

Para trocar todas, use o replaceAll. Ele recebe os mesmos dois argumentos:

const lista = "pao, leite, pao de queijo, café";
console.log(lista.replaceAll("pao", "pão"));

$ node todas.js
pão, leite, pão de queijo, café

Os dois "pao" viraram "pão". O replaceAll chegou ao JavaScript no ES2021; antes dele, as pessoas usavam outros truques, que você vai reconhecer em código antigo (veja Formas diferentes).

MétodoO que troca"a-b-c" trocando "-" por "/"

replaceAllTodas as ocorrênciasa/b/c

Missão: a data veio escrita com hífens. Faça o programa mostrar 01/02/2026, trocando todos os hífens por barras.

const data = "01-02-2026";
console.log(data.replace("-", "/"));

const data = "01-02-2026";
console.log(data.replaceAll("-", "/"));

5. Maiúsculas e minúsculas fazem diferença

Para o JavaScript, "P" e "p" são letras diferentes. A busca só acha o pedaço escrito exatamente igual:

const frase = "Pão quentinho. Pão de queijo.";
console.log(frase.replaceAll("pão", "bolo"));
console.log(frase.replaceAll("Pão", "Bolo"));

$ node maiusculas.js
Pão quentinho. Pão de queijo.
Bolo quentinho. Bolo de queijo.

Na primeira linha, nada mudou: no texto não existe "pão" com p minúsculo. Se você não sabe como o texto vai chegar (a pessoa pode ter digitado "PÃO", "pão" ou "Pão"), um caminho simples é passar tudo para minúsculas antes de trocar, com o toLowerCase() da aula Métodos de String. O outro caminho, a busca que ignora maiúsculas, usa uma expressão regular com a flag i, assunto de Regex na Prática.

6. Apagar um pedaço: trocar por ""

Para apagar, troque o pedaço por uma string vazia, "" (duas aspas sem nada no meio). O telefone que a Ana anotou tem traços e espaços, e o sistema da loja quer só os números:

const telefone = "11 98765-4321";
const soNumeros = telefone.replaceAll(" ", "").replaceAll("-", "");
console.log(soNumeros);
console.log(soNumeros.length);

$ node telefone.js
11987654321
11
telefone.replaceAll(" ", "")
Troca todo espaço por nada, ou seja, apaga os espaços. O resultado é "1198765-4321".
.replaceAll("-", "")
Este segundo método é chamado no resultado do primeiro. Como o replaceAll devolve uma string, dá para pendurar outro método logo em seguida. Isso se chama encadear.
soNumeros.length
O tamanho do resultado: 11 caracteres (veja Strings).

Pode encadear quantos quiser. Para não ficar uma linha comprida demais, cada método pode ir numa linha própria, começando pelo ponto:

const recado = "Oi, Bia! Amanha tem bolo. Nao esqueca.";
const corrigido = recado
  .replace("Amanha", "Amanhã")
  .replace("Nao", "Não")
  .replace("esqueca", "esqueça");
console.log(corrigido);

$ node encadear.js
Oi, Bia! Amanhã tem bolo. Não esqueça.

7. Uso do dia a dia: o preço com vírgula

No Brasil a gente escreve 12,50, com vírgula. O JavaScript escreve números com ponto: 12.5. Se o preço chega como o texto "12,50" (digitado no teclado, lido de uma planilha), o Number não entende a vírgula (veja Conversão):

const precoTexto = "12,50";
console.log(Number(precoTexto));

const preco = Number(precoTexto.replace(",", "."));
console.log(preco);
console.log(preco * 3);

$ node preco.js
NaN
12.5
37.5

Sem a troca, o resultado é NaN ("não é um número"; veja NaN, Infinity e a Precisão). Trocando a vírgula por ponto antes de converter, vira o número 12.5, e as contas funcionam. Aqui o replace basta, porque um preço tem uma vírgula só.

Missão: a Ana comprou 3 potes de doce de leite a "12,50" cada. O programa mostra Total: NaN. Use o replace para trocar a vírgula por ponto antes do Number, até aparecer Total: 37.5.

const precoTexto = "12,50";
const preco = Number(precoTexto);
console.log(`Total: ${preco * 3}`);

const precoTexto = "12,50";
const preco = Number(precoTexto.replace(",", "."));
console.log(`Total: ${preco * 3}`);

8. Um cuidado: o $ no texto novo

No segundo argumento, algumas combinações com o cifrão têm significado especial. A mais comum de aparecer sem querer é o $$, que vira um cifrão só. E o $& quer dizer "o pedaço que foi encontrado":

console.log("Preço: X".replace("X", "R$ 10"));
console.log("Preço: X".replace("X", "R$$ 10"));
console.log("bolo".replace("bolo", "[$&]"));

$ node cifrao.js
Preço: R$ 10
Preço: R$ 10
[bolo]

R$ 10 funciona normalmente: um cifrão seguido de espaço não é especial. Mas R$$ 10 também virou R$ 10, com um cifrão a menos. No dia a dia isso quase nunca atrapalha; só lembre dele se um cifrão "sumir" depois de uma troca. Os outros códigos com $ são usados com expressões regulares (aula Regex na Prática).

Formas diferentes de fazer a mesma coisa

Trocar todos os hífens de "01-02-2026" por barras dá para fazer de três jeitos:

const data = "01-02-2026";
console.log(data.replaceAll("-", "/"));
console.log(data.split("-").join("/"));
console.log(data.replace(/-/g, "/"));

$ node formas.js
01/02/2026
01/02/2026
01/02/2026
data.replaceAll("-", "/")
O jeito moderno e mais fácil de ler.
data.split("-").join("/")
Corta a string em todo hífen, formando a lista [ '01', '02', '2026' ], e junta de novo com barras (veja split e join). Era o truque comum antes do replaceAll.
data.replace(/-/g, "/")
O que está entre as barras, /-/, é uma expressão regular (um padrão de busca); o g no fim quer dizer "global", ou seja, todas as ocorrências. É o outro jeito antigo, e o mais poderoso. Aula própria: Expressões Regulares.
SituaçãoQual usar
Trocar só a primeira ocorrência (ou você sabe que só existe uma)texto.replace("a", "b")
Trocar todas as ocorrências de um texto fixotexto.replaceAll("a", "b")
Trocar um padrão (qualquer número, qualquer espaço, ignorando maiúsculas)replace/replaceAll com expressão regular (aula Regex na Prática)
Código antigo, de antes de 2021Você vai ver split(…).join(…) e replace(/…/g, …) fazendo o papel do replaceAll

Resumo

  • texto.replace(procurado, novo) troca a primeira ocorrência; texto.replaceAll(procurado, novo) ES2021 troca todas.
  • As strings são imutáveis: os dois métodos devolvem uma string nova. Guarde o resultado numa variável, ou ele se perde.
  • A busca diferencia maiúsculas de minúsculas; se o pedaço não existir, nada muda e não há erro.
  • Para apagar, troque por "". Para várias trocas, encadeie: t.replace(…).replace(…).
  • Number(preco.replace(",", ".")) transforma o preço brasileiro "12,50" no número 12.5.
  • No texto novo, $$ vira um cifrão só e $& é o pedaço encontrado.
  • Erros comuns: replaceAll com regex sem g, replace num número (is not a function) ou em undefined (Cannot read properties of undefined).
