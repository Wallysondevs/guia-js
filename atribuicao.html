JavaScript Atribuição

Desde a primeira variável, você usa o sinal =. Ele parece o "igual" da matemática, mas no JavaScript quer dizer outra coisa: "guarde este valor nesta variável". Isso se chama atribuição (dar um valor a alguém). Esta aula mostra o que o = faz de verdade, como mudar o valor de uma variável a partir do valor que ela já tem, e os atalhos que encurtam isso: +=, -=, *= e companhia.

Você vai aprender
  • O que o = faz: primeiro calcula a direita, depois guarda na esquerda.
  • Por que pontos = pontos + 5 faz sentido (e não é uma equação impossível).
  • Os atalhos +=, -=, *=, /=, %= e **=.
  • O += com textos, para ir montando uma frase.
  • Os atalhos ??= e ||=, para dar um valor só quando falta.
  • Os erros reais: mudar uma const, o lado esquerdo errado, o = no lugar do === e o =+ trocado.

Todos os programas desta aula rodaram no Node.js 24 da máquina da Ana (usuária ana, computador notebook), salvos na pasta pessoal dela e executados com node arquivo.js (veja Rodando um Programa). Você pode rodar cada um no editor do guia.

A ideia: a lousa do placar

Na gincana da escola, o placar de cada equipe é escrito numa lousa. Quando a equipe ganha 5 pontos, a professora faz três coisas, nesta ordem:

  1. Lê o que está escrito na lousa agora: 25.
  2. Faz a conta de cabeça: 25 + 5 = 30.
  3. Apaga o 25 e escreve o 30 no lugar.

A atribuição é exatamente isso. A variável é a lousa; o = é "apague o que está lá e escreva isto". E a conta do lado direito é feita antes, com o valor antigo.

1. O =: guardar um valor

let pontos = 10;
console.log(pontos);
pontos = 25;
console.log(pontos);
pontos = pontos + 5;
console.log(pontos);
let pontos = 10;
Cria a variável e já guarda o 10 nela (veja Variáveis). O let aparece só na criação.
pontos = 25;
Uma nova atribuição: apaga o 10 e guarda o 25. Sem let, porque a variável já existe.
pontos = pontos + 5;
Na matemática, "x = x + 5" seria impossível. Aqui, ela se lê da direita para a esquerda: "pegue o valor atual de pontos (25), some 5 (30) e guarde o resultado em pontos".
$ node guardar.js
10
25
30
Leia o = como "recebe"

pontos = 25 se lê "pontos recebe 25". Assim você nunca confunde com o "igual" da matemática. Para perguntar se dois valores são iguais, o JavaScript usa outro sinal, o === (aula Comparação).

2. Os atalhos: +=, -=, *=…

Mudar uma variável a partir do valor que ela já tem é tão comum que existe um atalho para cada operador aritmético (veja Operadores Aritméticos). Em vez de repetir o nome da variável, você escreve o operador colado no =:

let saldo = 100;
saldo += 50;
console.log("depois de += 50:", saldo);
saldo -= 30;
console.log("depois de -= 30:", saldo);
saldo *= 2;
console.log("depois de *= 2:", saldo);
saldo /= 4;
console.log("depois de /= 4:", saldo);
saldo %= 7;
console.log("depois de %= 7:", saldo);
saldo **= 2;
console.log("depois de **= 2:", saldo);

$ node compostos.js

O operador vem antes do =, colado nele, sem espaço no meio: +=. (A seção Quando dá errado mostra o que acontece com =+ e com + =.)

O acumulador: o caixa da padaria

O uso mais comum do += é acumular: começar um total em zero e ir somando cada valor. No caixa da padaria:

let total = 0;
total += 4.5;
total += 12.9;
total += 3.25;
console.log(`Total da compra: R$ ${total}`);

$ node caixa.js
Total da compra: R$ 20.65

A variável total começa em 0 e "engorda" a cada linha. Repare que ela é let: uma const não poderia mudar. Quando você aprender os laços (for, while), o total += preco vai ficar dentro do laço, somando quantos preços houver.

3. O += com textos

Com textos, o + junta (veja Strings), e o += também: ele cola um pedaço no fim do texto que já está na variável.

let lista = "Compras:";
lista += " pão";
lista += ", leite";
lista += ", café";
console.log(lista);

$ node texto.js
Compras: pão, leite, café

Cuidado com o caso contrário: se a variável guarda um número como texto, o += junta em vez de somar. Com let contador = "1";, o contador += 1 deixa o contador valendo "11" (no lab, saiu 11). É a pegadinha da aula Conversão Automática. Os outros atalhos (-=, *=…) não juntam: eles convertem o texto para número.

4. Dar um valor só se faltar: ??= e ||=

Desde o ECMAScript 2021, há também atalhos que só atribuem em certas condições:

let apelido = null;
apelido ??= "sem apelido";
console.log(apelido);
apelido ??= "outro";
console.log(apelido);
let desconto = 0;
desconto ||= 10;
console.log(desconto);
let quantidade = 0;
quantidade ??= 10;
console.log(quantidade);

$ node logicos.js
sem apelido
sem apelido
10
0
apelido ??= "sem apelido"
"Se apelido for null ou undefined, guarde "sem apelido"; senão, deixe como está". Na primeira vez ele era null e recebeu o valor; na segunda, já tinha valor, e o "outro" foi ignorado. É o ?? da aula null e undefined, em forma de atribuição.
desconto ||= 10
"Se desconto contar como falso, guarde 10". O 0 conta como falso (veja Truthy e Falsy), então o desconto zero virou 10.
quantidade ??= 10
Com o ??=, o 0 fica: ele só troca null e undefined. Para valores padrão, o ??= é quase sempre o certo.

Existe também o &&= ("se tiver valor, troque"), bem menos usado. Os três dependem dos operadores lógicos, explicados em Operadores Lógicos.

5. Detalhes que aparecem em código de outras pessoas

A atribuição também devolve um valor

Uma atribuição, além de guardar, devolve o valor guardado. É por isso que dá para encadear várias numa linha só:

let a, b, c;
a = b = c = 0;
console.log(a, b, c);

$ node encadeado.js
0 0 0

A linha a = b = c = 0 é resolvida da direita para a esquerda: c recebe 0, esse 0 vai para b, e depois para a. Funciona, mas é mais claro escrever uma variável por linha. Esse "devolver um valor" também explica um dos erros mais traiçoeiros da seção Quando dá errado: o = dentro do if.

Atribuição não é igualdade para sempre

Uma atribuição copia o valor daquele momento. Se você escreve let total = preco * 2; e depois muda o preco, o total não muda sozinho: ele guardou o resultado da conta, e não a conta. Como numa lousa: o que foi escrito fica lá até alguém apagar.

"Lado esquerdo inválido na atribuição". O lado esquerdo do = tem de ser um lugar onde se possa guardar algo, uma variável. O 10 é um valor, e não dá para guardar nada "dentro do 10". Na matemática, 10 = x e x = 10 são a mesma coisa; no JavaScript, não. Como consertar: a variável vai sempre à esquerda: preco = 10;.

Usou = no lugar do === dentro do if 
let nota = 4;
if (nota = 10) {
  console.log("Nota máxima!");
}
console.log("A nota agora é", nota);

$ node ifigual.js
Nota máxima!
A nota agora é 10

Nenhum erro, e dois estragos. A Ana queria perguntar "a nota é 10?", mas escreveu um = só, que guarda 10 na nota. A atribuição devolve o valor guardado (o 10), e 10 conta como verdadeiro: o if entrou. Resultado: um 4 virou "nota máxima", e a variável foi alterada para sempre. Como consertar: para perguntar, use ===: if (nota === 10) (aula Comparação).

Trocou a ordem: =+ no lugar de += 
let saldo = 100;
saldo =+ 50;
console.log(saldo);

$ node espaco.js
50

O saldo deveria ir para 150, e foi para 50. Sem erro nenhum: o JavaScript leu saldo = +50, "saldo recebe mais cinquenta", ou seja, 50. O antigo 100 foi apagado. Como consertar: o operador vem antes do igual: saldo += 50;. (E com espaço no meio, saldo + = 50;, o Node recusa com SyntaxError: Unexpected token '=', "símbolo = inesperado": os dois sinais têm de estar colados.)

Acumulou numa variável sem valor inicial 
let total;
total += 10;
console.log(total);

$ node undef.js
NaN

A variável começou como undefined (veja null e undefined), e undefined + 10 é NaN. Daí para a frente, toda soma dá NaN. Como consertar: todo acumulador começa com um valor: let total = 0; (ou let lista = "";, para texto).

Errou o nome na atribuição 
let total = 0;
totl = total + 10;
console.log(total);

$ node semdeclarar2.js
0

O total continuou 0, e o Node não reclamou. Num arquivo .js comum, atribuir a um nome que não existe (totl, com a letra faltando) cria uma variável nova, em silêncio: um resto dos tempos antigos do JavaScript. Em modo estrito (com a linha "use strict"; no topo do arquivo, ou em módulos, aula Módulos), o mesmo erro para o programa com ReferenceError: totl is not defined, que é bem mais útil. Como consertar: confira o nome: total = total + 10;.

Resumo

  • O = é a atribuição: "recebe". Primeiro o JavaScript calcula o lado direito, depois guarda o resultado na variável da esquerda, apagando o valor antigo.
  • x = x + 5 não é equação: é "pegue o valor de x, some 5, guarde em x". O atalho é x += 5; há também -=, *=, /=, %= e **=.
  • O += com texto junta no fim. Acumuladores começam com valor: let total = 0;.
  • x ??= padrão dá um valor só quando x é null ou undefined.
  • Uma const não aceita atribuição (Assignment to constant variable.); a variável fica sempre à esquerda; para perguntar se é igual, use ===, nunca =; e é +=, não =+.
