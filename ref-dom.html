JavaScript DOM e Eventos

Esta é a página de consulta rápida do DOM (Document Object Model, "modelo de objetos do documento": a página vista pelo JavaScript como uma árvore de objetos) e dos eventos (cliques, teclas, digitação). Aqui estão os jeitos de encontrar um elemento, mudar o texto, os atributos, as classes e o estilo, criar e remover elementos, reagir ao que a pessoa faz e guardar dados no navegador.

Só no navegador

Tudo nesta página é do navegador: o document, o window, o localStorage. No Node não existe página, e document.querySelector(…) dá ReferenceError: document is not defined (veja Mensagens de Erro Comuns). Para praticar, use as caixas "Experimente" desta página ou o Console do navegador (O Console do Navegador (F12)).

Prefira textContent

Para pôr um texto que veio da pessoa (um nome, um comentário), use textContent: ele mostra o texto como está. Com innerHTML, um texto com < vira tag, e isso abre brecha para alguém injetar código na página.

Eventos

el.addEventListener("tipo", funcao) ("adicionar um ouvinte de evento") manda o navegador chamar a função toda vez que o evento acontecer naquele elemento. Aula: Eventos (addEventListener).

O objeto do evento

A função recebe um objeto (costuma se chamar evento ou e) com os detalhes do que aconteceu. O script.js da lojinha tem três ouvintes:

const botao = document.querySelector("#botao");
botao.addEventListener("click", (evento) => {
  console.log("clicou em", evento.target.textContent);
  console.log(evento.type, evento.target.id);
});
document.querySelector("#busca").addEventListener("input", (e) => {
  console.log("digitou:", e.target.value);
});
document.addEventListener("keydown", (e) => {
  if (e.key === "Enter") console.log("tecla:", e.key);
});

No lab, a Ana digitou pão no campo, apertou Enter e clicou em Comprar. O Console mostrou (no navegador, à direita de cada linha aparece também o arquivo e a linha do console.log, como script.js:7):

Um formulário que não recarrega a página, colhido no lab (a Ana digitou Ana e apertou Enter):

const form = document.querySelector("#cadastro");
form.addEventListener("submit", (evento) => {
  evento.preventDefault();
  const nome = document.querySelector("#nome").value;
  document.querySelector("#saida").textContent = `Bem-vinda, ${nome}!`;
  console.log("enviado sem recarregar");
});

enviado sem recarregar

E o parágrafo #saida passou a mostrar Bem-vinda, Ana!. Sem o preventDefault(), o navegador recarregaria a página e o texto sumiria na hora.

Resumo

  • Encontrar: querySelector (o primeiro ou null), querySelectorAll (todos, uma NodeList com forEach), getElementById.
  • Mudar: textContent (texto, o mais seguro), innerHTML (HTML), value (campos), setAttribute, dataset.
  • Aparência: classList.add/remove/toggle/contains; style.corDeFundo em camelCase.
  • Criar e tirar: createElement + append/prepend; remove().
  • Reagir: addEventListener("click" | "input" | "submit" | "keydown", (e) => …); e.target, e.key, e.preventDefault().
  • Guardar: localStorage.setItem/getItem, com JSON.stringify/JSON.parse para arrays e objetos.
  • O erro mais comum: null do querySelector (seletor errado ou script cedo demais).
