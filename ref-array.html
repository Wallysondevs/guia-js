JavaScript Métodos de Array

Esta é a página de consulta rápida dos métodos de array: as funções que toda lista já traz consigo, chamadas com um ponto depois dela (compras.push("café")). Elas acrescentam e tiram itens, procuram, filtram, transformam, somam, ordenam e juntam. A informação mais importante de cada linha é se o método muda o array original ou devolve um novo.

Como ler as tabelas
  • Nos exemplos, nums é const nums = [5, 1, 10, 2] e compras é const compras = ["pão", "leite", "café"]. Quando o exemplo muda o array, ele usa um array a próprio, e a tabela mostra como a ficou depois.
  • Exemplo é o que você digitaria depois do > do modo interativo do Node; Resultado é o que o Node.js v24.22.0 respondeu no computador da Ana, no formato do Node: [ 1, 2, 3 ], com espaços dentro dos colchetes e textos entre aspas simples.
  • A coluna Muda? diz se o array original é alterado: sim (cuidado!) ou não (devolve um valor novo e deixa o original como estava).
  • Muitos métodos recebem uma função como argumento (n => n > 4): ela é chamada uma vez para cada item. Se a seta => ainda é novidade, veja Arrow Functions e Funções como Valores.

Pule direto para o grupo que você procura:

  • Tamanho e acesso: length [i] at
  • Acrescentar e tirar (mudam o array): push pop unshift shift splice fill
  • Pedaços e cópias: slice concat ... structuredClone
  • Procurar: indexOf includes find findIndex findLast some every
  • Percorrer e transformar: forEach map filter reduce flat flatMap
  • Ordenar e inverter: sort reverse toSorted toReversed toSpliced with
  • Virar texto: join toString
  • Criar arrays: Array.from Array.of new Array Array.isArray entries keys
  • Quando dá errado

Ordenar e inverter

O sort() sem função ordena números como texto

Sem argumento, o sort compara os itens como se fossem textos, letra a letra: "10" vem antes de "2" porque "1" vem antes de "2". Para números, passe sempre a função (x, y) => x - y.

Resumo

  • Mudam o array: push, pop, unshift, shift, splice, sort, reverse, fill, a[i] = v.
  • Devolvem um novo: slice, concat, map, filter, flat, toSorted, toReversed, toSpliced, with, [...a].
  • Procurar: includes (sim/não), indexOf (posição ou -1), find (o item ou undefined), some/every.
  • Transformar: map transforma, filter filtra, reduce acumula (com valor inicial!).
  • Números: sort((x, y) => x - y) ou toSorted((x, y) => x - y). Sem a função, ordena como texto.
  • join transforma em texto; Array.from e Array.isArray criam e conferem arrays.
