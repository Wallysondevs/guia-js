JavaScript Seu Primeiro Programa

É tradição: o primeiro programa em qualquer linguagem mostra na tela a frase "Olá, mundo!". Em JavaScript, ele tem uma linha só. Nesta aula você vai escrever esse programa, entender cada pedaço dele e, a partir dele, montar um programa de verdade: o recibo da padaria da Ana, com textos, números e contas. E vai ver, com as mensagens reais, os erros que todo mundo comete no primeiro dia.

Você vai aprender
  • A escrever e rodar o console.log("Olá, mundo!");, e o que é cada parte.
  • Os três tipos de aspas do JavaScript: "duplas", 'simples' e `crase`.
  • Que o programa roda de cima para baixo, uma linha da saída por console.log, e a linha em branco com console.log().
  • A mostrar números e o resultado de contas, e por que "2 + 3" e 2 + 3 são diferentes.
  • A juntar texto e número, com + e com vírgula.
  • Os erros reais: aspa sem fechar, aspas trocadas, aspas curvas, parêntese sem fechar, texto sem aspas, e a conta que dá 87 em vez de 15.

Os programas foram rodados com o Node.js 24 LTS na máquina fictícia da Ana, na pasta /home/ana/js (aula Rodando um Programa). As caixas "Experimente" rodam o JavaScript do seu navegador, imitando o Node.js.

A ideia: o recado no quadro de avisos

Na padaria há um quadro de avisos. A Ana escreve um recado num papel e prega no quadro, e o recado aparece para todo mundo, do jeitinho que foi escrito. Para pregar outro recado, outro papel, embaixo do primeiro.

No seu programa, o quadro de avisos é a tela (o terminal), e quem prega os recados é o console.log. Cada console.log prega um papel: uma linha na tela, embaixo da anterior.

1. Olá, mundo!

console.log("Olá, mundo!");

$ node ola.js
Olá, mundo!

Uma linha de código, uma linha na tela. Vamos olhar cada pedaço:

console
O console é a "mesa de controle" do programa: a ferramenta que o JavaScript oferece para escrever mensagens. No Node.js, o que ela escreve vai para o terminal; no navegador, para o Console do F12. Escreve-se em minúsculas.
.
O ponto quer dizer "a parte de dentro". console.log é "o log que fica dentro do console".
log
Em inglês, "registrar, anotar" (como o diário de bordo de um navio). console.log é uma função: um comando com nome que faz um trabalho. O trabalho dela é escrever na tela.
( )
Os parênteses chamam (põem para trabalhar) a função. O que vai dentro deles é o que você entrega a ela.
"Olá, mundo!"
Um texto, que em programação se chama string ("cordão": letras enfileiradas). As aspas marcam onde o texto começa e termina, e não aparecem na tela. Dentro delas, tudo sai igualzinho: espaços, vírgula, acentos, o ponto de exclamação.
;
O ponto e vírgula marca o fim da instrução, como o ponto final de uma frase. O JavaScript até consegue adivinhar onde a instrução termina se você esquecer, mas este guia sempre escreve o ; (o porquê está na próxima aula, Instruções, Ponto e Vírgula e Blocos).

2. Três tipos de aspas

O JavaScript aceita textos entre aspas duplas, simples ou crase (o acento grave, `, que no teclado brasileiro fica perto do Enter, junto com o ´). Para ele, os três são o mesmo texto. A regra é uma só: feche com a mesma aspa que abriu.

console.log("Bom dia, Ana!");
console.log('Bom dia, Ana!');
console.log(`Bom dia, Ana!`);
console.log("Padaria D'Ouro");
console.log('Ela disse: "Que pão cheiroso!"');

$ node aspas.js
Bom dia, Ana!
Bom dia, Ana!
Bom dia, Ana!
Padaria D'Ouro
Ela disse: "Que pão cheiroso!"

As três primeiras linhas saíram iguais. A escolha da aspa fica útil quando o texto tem aspas dentro: o nome Padaria D'Ouro tem um apóstrofo (que é a aspa simples), então vai entre aspas duplas; a frase com aspas duplas dentro vai entre aspas simples.

Qual aspa usar?

Este guia usa aspas duplas para textos comuns, e a crase quando precisa encaixar valores no meio do texto (as template strings, com ${ }, da aula Template Strings). As simples aparecem quando o texto tem aspas duplas dentro. O importante é ser coerente.

3. Várias linhas, na ordem

Um programa pode ter quantos console.log você quiser. Eles rodam de cima para baixo, e cada um escreve uma linha. Um console.log() vazio, sem nada nos parênteses, escreve uma linha em branco. Este é o cartão de visitas da Ana:

console.log("Ana Souza");
console.log("Confeiteira");
console.log();
console.log("Padaria do Bairro");
console.log("Rua das Flores, 123");

$ node cartao.js
Ana Souza
Confeiteira

Padaria do Bairro
Rua das Flores, 123

Cinco console.log, cinco linhas na saída: quatro com texto e a do meio em branco. Repare que "Rua das Flores, 123" é um texto só, com a vírgula e o número dentro das aspas: para o JavaScript, tudo ali é letra.

4. Números e contas

Números se escrevem sem aspas. E, se você puser uma conta dentro do console.log, o JavaScript primeiro calcula e depois mostra o resultado:

console.log(42);
console.log(3.5);
console.log(2 + 3);
console.log("2 + 3");
console.log(10 * 4);
console.log(10 / 4);
console.log(7 - 10);

$ node contas.js
42
3.5
5
2 + 3
40
2.5
-3
42 e 3.5
Números. A casa decimal se separa com ponto, nunca com vírgula.
2 + 3 → 5
Uma conta: o JavaScript soma e entrega o resultado ao console.log.
"2 + 3" → 2 + 3
Entre aspas, não é conta: é um texto com cinco caracteres, mostrado como está.
10 * 4 → 40
O * (asterisco) é a multiplicação.
10 / 4 → 2.5
A / é a divisão. O resultado pode ter casas decimais.
7 - 10 → -3
A subtração; o resultado pode ser negativo. Todas as contas estão em Operadores Aritméticos.
Com aspas é texto, sem aspas é valor

"2 + 3" é um recado escrito num papel; 2 + 3 é uma conta que o JavaScript resolve. Essa diferença volta o guia inteiro; a aula Os Tipos de Dados conta a história toda.

5. Juntando texto e número

Para mostrar "Pães: 12", há dois jeitos simples:

console.log("Pães: " + 12);
console.log("Pães:", 12);
console.log("Total: R$ " + 3 * 2.5);
console.log("2" + 3);

$ node juntar.js
Pães: 12
Pães: 12
Total: R$ 7.5
23
"Pães: " + 12
Quando um dos lados do + é um texto, o + junta (em vez de somar): o 12 vira texto e gruda no fim. O espaço depois dos dois-pontos foi escrito dentro das aspas; o + não põe espaço nenhum.
"Pães:", 12
A vírgula entrega dois valores ao console.log, e ele os mostra lado a lado, com um espaço entre eles, por conta própria (mais em console.log()).
"Total: R$ " + 3 * 2.5
A multiplicação acontece antes do + (como na escola: primeiro vezes, depois mais). 3 * 2.5 dá 7.5, que depois é juntado ao texto.
"2" + 3 → 23
Cuidado: "2" entre aspas é texto, então o + junta: 2 grudado com 3, 23. Não é vinte e três: é o texto "2" seguido do "3". Essa pegadinha tem aula própria: Conversão Automática.

Quando dá errado

As mensagens saem em inglês; aqui, explicadas em português. Para não repetir, as linhas at … do próprio Node.js foram cortadas (a aula Introdução mostra uma mensagem inteira, lida linha por linha).

Aspa que não fecha 
console.log("Olá, mundo!);

$ node e1.js
/home/ana/js/e1.js:1
console.log("Olá, mundo!);
            ^^^^^^^^^^^^^^

SyntaxError: Invalid or unexpected token
    at wrapSafe (node:internal/modules/cjs/loader:1861:18)
    «  mais 7 linhas "at … (node:internal/…)" cortadas

Node.js v24.22.0

"Símbolo (token) inválido ou inesperado". O JavaScript achou a aspa que abriu o texto e procurou outra " para fechar; a linha acabou sem ela (os ^^^^ sublinham o texto que ficou aberto, que engoliu até o );). Um texto entre aspas duplas ou simples não pode atravessar a linha. É um SyntaxError: nada do arquivo roda. Como consertar: feche a aspa: console.log("Olá, mundo!");.

Aspas trocadas 
console.log("Olá, mundo!');

$ node e2.js
/home/ana/js/e2.js:1
console.log("Olá, mundo!');
            ^^^^^^^^^^^^^^^

SyntaxError: Invalid or unexpected token
    «  8 linhas "at …" cortadas

Node.js v24.22.0

Abriu com aspa dupla, fechou com simples. A simples não fecha um texto que começou com dupla: para o JavaScript, ela é só mais uma letra dentro do texto, que continua aberto. Mesma mensagem do cenário anterior. Como consertar: feche com a mesma aspa que abriu.

Aspas curvas, copiadas do Word ou do WhatsApp 
console.log(“Olá, mundo!”);

$ node e3.js
/home/ana/js/e3.js:1
console.log(“Olá, mundo!”);
                                         « a linha do ^ veio vazia

SyntaxError: Invalid or unexpected token
    «  8 linhas "at …" cortadas

Node.js v24.22.0

Olhe bem as aspas: são as curvas (“ ”), que editores de texto como o Word, o Google Docs e alguns aplicativos de celular colocam sozinhos "para ficar bonito". Para o JavaScript, elas não são aspas: são símbolos estranhos. Aqui o Node.js nem conseguiu desenhar os ^. Como consertar: escreva o código num editor de código (aula Instalar o Node.js, seção 9) e troque as curvas pelas retas: ".

Parêntese que não fecha 
console.log("Padaria do Bairro"
console.log("Pão às 7h");

$ node e4.js
/home/ana/js/e4.js:1
console.log("Padaria do Bairro"
            ^^^^^^^^^^^^^^^^^^^

SyntaxError: missing ) after argument list
    «  8 linhas "at …" cortadas

Node.js v24.22.0

"Faltou ) depois da lista de argumentos". Os argumentos são o que vai dentro dos parênteses; depois de "Padaria do Bairro", o JavaScript esperava o ) e encontrou outra coisa (o console da linha 2). Nenhuma das duas linhas rodou. Como consertar: feche o parêntese, e ponha o ;: console.log("Padaria do Bairro");.

Texto sem aspas 
console.log(Ola);

$ node e5.js
/home/ana/js/e5.js:1
console.log(Ola);
            ^

ReferenceError: Ola is not defined
    at Object.<anonymous> (/home/ana/js/e5.js:1:13)
    «  mais 7 linhas "at … (node:internal/…)" cortadas

Node.js v24.22.0

Sem aspas, Ola não é um texto: o JavaScript acha que é o nome de alguma coisa (uma variável, aula Variáveis). Como ninguém criou nada com esse nome, vem o ReferenceError: "Ola não está definido". Repare no :1:13: linha 1, coluna 13, exatamente onde está o O. Como consertar: console.log("Ola");.

A conta que dá 87 em vez de 15 
console.log("Total: " + 10 * 0.8 + 2 * 3.5);
console.log("Total: " + (10 * 0.8 + 2 * 3.5));

$ node e6.js
Total: 87
Total: 15

Nenhuma mensagem de erro, e mesmo assim a primeira linha está errada. O JavaScript fez as multiplicações primeiro (8 e 7) e depois os +, da esquerda para a direita: "Total: " + 8 deu o texto "Total: 8", e "Total: 8" + 7 juntou o 7 no fim: "Total: 87". Uma vez que virou texto, o + só junta. Como consertar: parênteses em volta da conta (segunda linha), para ela ser feita antes de juntar; ou use a vírgula: console.log("Total:", 10 * 0.8 + 2 * 3.5);.

Uma conta solta: não aparece nada 
console.log("Calculando...");
2 + 3;

$ node e7.js
Calculando...

A linha 2 não é erro: o JavaScript calculou 5 e jogou fora, porque ninguém pediu para mostrar. No modo interativo, 2 + 3 mostra 5 sozinho; num arquivo, só o console.log mostra. Como consertar: console.log(2 + 3);.

Vírgula no lugar do ponto decimal 
console.log(18,9);

$ node e8.js
18 9

A Ana queria dezoito e noventa. Para o JavaScript, a vírgula separa valores: ele entendeu dois números e mostrou os dois, com um espaço. Sem erro nenhum. Como consertar: decimal com ponto: console.log(18.9);.

Resumo

  • console.log(...) mostra na tela o que está nos parênteses e pula para a linha de baixo. Cada console.log é uma linha, na ordem do arquivo; console.log() vazio dá uma linha em branco.
  • Textos vão entre aspas duplas, simples ou crase (feche com a mesma que abriu); as aspas não aparecem. Este guia usa duplas, e crase nas template strings.
  • Números e contas vão sem aspas, e o JavaScript calcula antes de mostrar. Decimal com ponto.
  • "texto" + número junta; "texto", número mostra os dois com um espaço. Depois que virou texto, o + só junta: use parênteses nas contas.
  • Termine cada instrução com ;.
  • Erros comuns: aspa sem fechar, trocada ou curva → Invalid or unexpected token; parêntese → missing ) after argument list; texto sem aspas → is not defined. Com SyntaxError, nada roda.
