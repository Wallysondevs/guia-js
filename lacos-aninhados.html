JavaScript Laços Aninhados

O corpo de um laço pode ter qualquer instrução, inclusive outro laço. Quando um laço fica dentro de outro, dizemos que eles estão aninhados (como ovos num ninho, um dentro do outro). É assim que se percorre tudo o que tem "linhas e colunas": as fileiras e cadeiras do cinema, as tabuadas de vários números, uma tabela de notas.

Você vai aprender
  • Como um for dentro de outro funciona: o de dentro dá todas as voltas dele a cada volta do de fora.
  • Quantas vezes o corpo de dentro roda (a multiplicação).
  • Como montar uma linha de texto no laço de dentro e mostrá-la no de fora: cadeiras do cinema, triângulo de estrelas.
  • Como sair dos dois laços de uma vez, com um rótulo (break busca).
  • Os erros mais comuns: o passo do laço errado, o rótulo que não existe e o var que mistura os contadores.

Todos os programas desta aula rodaram no Node.js 24 (v24.22.0) da máquina da Ana, com node arquivo.js. Antes, convém conhecer bem o for e o break e continue.

A ideia: o relógio

Olhe um relógio de ponteiros. O ponteiro dos minutos dá uma volta inteira (60 minutos) para o ponteiro das horas andar um passo só. Depois, os minutos dão outra volta inteira, e a hora anda mais um passo. Laços aninhados funcionam assim:

  • o laço de fora é o ponteiro das horas: anda devagar;
  • o laço de dentro é o dos minutos: a cada passo do de fora, ele recomeça do zero e vai até o fim.

1. Um for dentro de outro: várias tabuadas

for (let numero = 1; numero <= 3; numero++) {
  console.log(`Tabuada do ${numero}:`);
  for (let i = 1; i <= 4; i++) {
    console.log(`  ${numero} x ${i} = ${numero * i}`);
  }
}
console.log("Fim!");

Cada laço empurra o seu corpo 2 espaços para a direita. Em laços aninhados, isso é o que deixa ver de longe quem está dentro de quem.

Quantas vezes o corpo de dentro roda?

O de fora deu 3 voltas; em cada uma, o de dentro deu 4. Total: 3 × 4 = 12 linhas de conta. Confira contando com uma variável:

let voltas = 0;
for (let fora = 1; fora <= 3; fora++) {
  for (let dentro = 1; dentro <= 4; dentro++) {
    voltas++;
  }
}
console.log(`O corpo de dentro rodou ${voltas} vezes`);

$ node voltas.js
O corpo de dentro rodou 12 vezes

É uma multiplicação, e ela cresce rápido: dois laços de 1000 voltas cada fazem o corpo de dentro rodar 1 milhão de vezes. Laços aninhados são ótimos, mas vale lembrar disso quando o programa ficar lento.

2. Montar uma linha no laço de dentro

O console.log sempre pula de linha. Para mostrar várias coisas na mesma linha, o laço de dentro vai juntando os pedaços num texto, e o de fora mostra o texto pronto. As cadeiras do cinema do bairro:

const filas = ["A", "B", "C"];
for (let f = 0; f < filas.length; f++) {
  let linha = "";
  for (let cadeira = 1; cadeira <= 5; cadeira++) {
    linha += `${filas[f]}${cadeira} `;
  }
  console.log(linha);
}

$ node cinema.js
A1 A2 A3 A4 A5
B1 B2 B3 B4 B5
C1 C2 C3 C4 C5
let linha = ""
Um texto vazio, criado dentro do laço de fora: cada fila começa com a sua própria linha em branco.
linha += `${filas[f]}${cadeira} `
A cada cadeira, gruda no fim do texto a letra da fila, o número e um espaço (o += em textos junta; veja Atribuição).
console.log(linha)
Fica depois do laço de dentro e dentro do de fora: roda uma vez por fila, quando a linha já está completa.

Se o let linha = "" ficasse antes do laço de fora, as filas iam se acumulando: a segunda linha teria A1 até B5, e a terceira, tudo. Se o console.log ficasse dentro do laço de dentro, sairiam 15 linhas, uma por cadeira, cada uma maior que a anterior.

O laço de dentro pode depender do de fora

O número de voltas do laço de dentro não precisa ser fixo: ele pode usar o contador do de fora. Aqui, a linha 1 tem 1 estrela, a linha 2 tem 2…

for (let linha = 1; linha <= 5; linha++) {
  let estrelas = "";
  for (let i = 1; i <= linha; i++) {
    estrelas += "*";
  }
  console.log(estrelas);
}

3. Todas as combinações

A Ana tem 2 camisetas e 3 calças. Quantos jeitos de se vestir existem? O laço de fora passa pelas camisetas; para cada uma, o de dentro passa por todas as calças:

const camisetas = ["branca", "preta"];
const calcas = ["jeans", "bege", "cinza"];
for (let c = 0; c < camisetas.length; c++) {
  for (let k = 0; k < calcas.length; k++) {
    console.log(`camiseta ${camisetas[c]} + calça ${calcas[k]}`);
  }
}

4. Sair dos dois laços de uma vez: o rótulo

Na aula break e continue, você viu que o break sai só do laço mais de dentro. Veja o problema: a Ana procura o primeiro par de números de 1 a 9 cuja multiplicação dá 24.

for (let a = 1; a <= 9; a++) {
  for (let b = 1; b <= 9; b++) {
    if (a * b === 24) {
      console.log(`${a} x ${b} = 24`);
      break;
    }
  }
}

$ node par_sem_rotulo.js
3 x 8 = 24
4 x 6 = 24
6 x 4 = 24
8 x 3 = 24

Ela queria só o 3 x 8. O break parou o laço do b, mas o do a seguiu para o 4, o 5, o 6… Para sair dos dois, dê um nome ao laço de fora, um rótulo (em inglês, label), e diga ao break qual laço quebrar:

busca: for (let a = 1; a <= 9; a++) {
  for (let b = 1; b <= 9; b++) {
    if (a * b === 24) {
      console.log(`${a} x ${b} = 24`);
      break busca;
    }
  }
}
console.log("Fim da busca.");

$ node par_rotulo.js
3 x 8 = 24
Fim da busca.
busca:
O rótulo: um nome qualquer (as mesmas regras de nome de variável) seguido de dois-pontos, logo antes do laço. Ele não muda nada no laço; só dá um nome a ele.
break busca;
"Quebre o laço chamado busca". O JavaScript sai do laço de dentro e do de fora, e vai para a primeira linha depois do laço busca.

O continue também aceita rótulo: continue busca; pula o resto da volta do laço de dentro e vai direto para a próxima volta do laço busca.

Formas diferentes de fazer a mesma coisa

Rótulos funcionam, mas aparecem pouco no código do dia a dia: muita gente nem sabe que existem. Duas outras formas de sair dos dois laços:

Com uma variável "achou" na condição do laço de fora (e um break comum no de dentro):

let achou = false;
for (let a = 1; a <= 9 && !achou; a++) {
  for (let b = 1; b <= 9; b++) {
    if (a * b === 24) {
      console.log(`${a} x ${b} = 24`);
      achou = true;
      break;
    }
  }
}
console.log("Fim da busca.");

$ node par_flag.js
3 x 8 = 24
Fim da busca.

Com uma função e return: pondo os dois laços dentro de uma função, o return sai da função inteira, com laços e tudo. É a forma mais usada na prática; você vai vê-la em Funções e Retornando Valores.

E para repetir um texto, em vez de um laço de dentro, existe o método repeat ("repetir") das strings (veja Métodos de String). O triângulo fica assim, com um laço só:

for (let linha = 1; linha <= 5; linha++) {
  console.log("*".repeat(linha));
}

Quando dá errado

O passo do laço errado: laço infinito 
for (let i = 1; i <= 3; i++) {
  for (let j = 1; j <= 3; i++) {
    console.log(`${i}-${j}`);
  }
}

$ timeout 1 node passo_errado.js | head -4
1-1
2-1
3-1
4-1

Copiando a linha do laço de fora, a Ana trocou o i por j no início e na condição, mas esqueceu o passo: o laço de dentro faz i++. O j fica em 1 para sempre, então j <= 3 nunca fica falso, e o i cresce sem parar (4, 5, 6…, bem além do 3). O JavaScript não acusa nada. Como consertar: confira as três partes de cada laço: o laço do j testa e anda com j (j++). (Para parar um programa assim no terminal: Ctrl+C.)

var nos dois contadores (código antigo)

Em código antigo você vai achar laços com var (veja var: o Jeito Antigo). Com var, usar o mesmo nome nos dois laços faz os dois dividirem a mesma variável:

for (var i = 1; i <= 3; i++) {
  for (var i = 1; i <= 2; i++) {
    console.log(`dentro: ${i}`);
  }
  console.log(`fora: ${i}`);
}

$ node var_i.js
dentro: 1
dentro: 2
fora: 3

Era para o laço de fora dar 3 voltas, e ele deu uma só. O laço de dentro deixou o i valendo 3; o de fora fez i++ (4), testou 4 <= 3 e parou. Com let, cada laço tem o seu próprio i e o programa dá as 3 voltas (no lab, saíram 9 linhas, de dentro: 1 até fora: 3). Como consertar: use let e, de preferência, nomes diferentes para cada contador (linha e coluna, i e j): o código fica mais fácil de ler.

A linha saiu toda grudada, ou picada demais

Não é erro do JavaScript: é a posição do let linha = "" e do console.log(linha) (veja a seção 2 e o parágrafo logo depois das cadeiras do cinema). O texto se cria no começo do corpo do laço de fora e se mostra no fim dele, depois do laço de dentro.

Resumo

  • Um laço pode ficar dentro de outro: a cada volta do de fora, o de dentro recomeça e dá todas as voltas dele.
  • O corpo de dentro roda (voltas de fora) × (voltas de dentro) vezes.
  • Para escrever na mesma linha, monte um texto no laço de dentro e mostre no de fora.
  • O laço de dentro pode usar o contador do de fora (i <= linha).
  • Cada laço com o seu contador, com let e nomes diferentes; confira as três partes de cada um.
  • break sai só do laço de dentro; para sair dos dois, use um rótulo (break busca;), uma variável achou ou uma função com return.
