Projeto Lista de Tarefas (JSON)

A Ana vive esquecendo as coisas: comprar pão, pagar a conta de luz, ligar para a vó. Neste projeto ela faz a própria lista de tarefas, que roda no terminal com comandos curtos (node tarefas.js adicionar Comprar pão, node tarefas.js listar) e, o mais importante, lembra das tarefas de um dia para o outro, guardando tudo num arquivo tarefas.json.

Você vai praticar
  • Receber comandos na linha de comando com process.argv.
  • Guardar a lista num array de objetos e mostrá-la com forEach.
  • Transformar o array em texto e de volta com JSON.stringify e JSON.parse.
  • Ler e gravar o arquivo com fs.readFileSync e fs.writeFileSync.
  • Remover um item com splice e contar com filter.
  • Organizar os comandos com switch e funções, e proteger o programa com try … catch.

O que vamos construir

Esta é a lista pronta, no computador da Ana (Node.js v24.22.0). Cada linha com $ é um comando que ela digitou; o resto foi o programa que escreveu:

3. [ ] Estudar JavaScript

Tarefa adicionada: Regar as plantas

1. [x] Comprar pão

  listar             mostra as tarefas
  adicionar TEXTO    acrescenta uma tarefa
  feito N            marca a tarefa N como feita

Vamos chegar lá em quatro versões:

  1. Os comandos e a lista (process.argv, array de objetos, forEach).
  2. Guardar no tarefas.json (JSON.stringify, JSON.parse, fs).
  3. Marcar como feita e remover (splice e o número validado).
  4. Funções, switch e arquivo protegido (try … catch, import.meta.dirname).

Antes de começar

Você precisa saber rodar um programa (Rodando um Programa) e o que são arrays e objetos. Crie a pasta do projeto; o programa vai se chamar tarefas.js:

$ mkdir -p projetos/tarefas
$ cd projetos/tarefas

Nas caixas Experimente deste projeto, o comando (o listar, o adicionar Comprar leite…) já vem pronto, como se você o tivesse digitado depois de node tarefas.js; a missão diz qual é. Quando a caixa tem uma aba tarefas.json, o programa a lê e grava de verdade, numa pasta só da caixa. Cada Rodar começa com o arquivo como ele está na aba.

Versão 1 · Os comandos e a lista

Cada tarefa tem duas informações: o texto e se já foi feita. Um objeto guarda as duas juntas ({ texto: "Comprar pão", feita: false }), e um array guarda todas as tarefas, em ordem. O que a Ana quer fazer chega pela linha de comando: tudo o que ela escreve depois de node tarefas.js fica no array process.argv.

const tarefas = [
  { texto: "Comprar pão", feita: false },
  { texto: "Pagar a conta de luz", feita: true },
];

const comando = process.argv[2];
const texto = process.argv[3];

if (comando === "listar") {
  console.log("Tarefas da Ana:");
  tarefas.forEach((tarefa, i) => {
    const marca = tarefa.feita ? "x" : " ";
    console.log(`${i + 1}. [${marca}] ${tarefa.texto}`);
  });
} else if (comando === "adicionar") {
  tarefas.push({ texto: texto, feita: false });
  console.log(`Tarefa adicionada: ${texto}`);
  console.log(`Agora são ${tarefas.length} tarefas.`);
} else {
  console.log("Comandos: listar, adicionar");
}
const tarefas = [ … ];
A lista: um array com dois objetos. Cada objeto tem as propriedades texto (uma string) e feita (um booleano, true ou false).
process.argv[2]
O process.argv é um array com a linha de comando inteira: na posição 0 fica o caminho do node, na 1 o do programa, e a partir da 2 o que a Ana escreveu. Em node tarefas.js adicionar Pão, o [2] é "adicionar" e o [3] é "Pão".
tarefas.forEach((tarefa, i) => { … })
Para cada tarefa, roda o bloco, recebendo a tarefa e a posição dela (i, que começa em 0). Por isso o número mostrado é i + 1: as pessoas contam a partir de 1.
tarefa.feita ? "x" : " "
O operador ternário: "se feita for verdadeiro, "x"; senão, um espaço". Fica [x] ou [ ], como uma caixinha de marcar.
tarefas.push({ texto: texto, feita: false })
Acrescenta um objeto novo no fim do array (veja push). Toda tarefa nova começa por fazer.

Funcionou… até a Ana listar de novo: a tarefa nova sumiu. O array tarefas vive na memória do programa, e a memória é apagada quando o programa termina. Cada node tarefas.js começa do zero, com as duas tarefas escritas no código. A versão 2 resolve isso guardando a lista num arquivo. Sem nenhum comando, o process.argv[2] é undefined e o programa cai no else, que mostra a ajuda.

Texto com espaços sem aspas: só a primeira palavra

O terminal separa a linha de comando nos espaços: "adicionar", "Ligar", "para", "a" e "vó" viraram cinco itens do process.argv, e o programa só pegou o [3]. Com aspas ("Levar o cachorro ao veterinário"), o texto inteiro vira um item só. A versão 2 junta as palavras sozinha, para a Ana não precisar das aspas.

Versão 2 · Guardar no tarefas.json

Para a lista sobreviver ao fim do programa, ela precisa ir para um arquivo. Mas um arquivo só guarda texto, e a lista é um array de objetos. O JSON (JavaScript Object Notation, "notação de objetos do JavaScript") resolve isso: é um jeito de escrever arrays e objetos como texto, quase igual ao código JavaScript. Duas funções fazem a ponte:

FunçãoDePara
JSON.stringify(tarefas, null, 2)o array (na memória)texto, com recuo de 2 espaços, para gravar
JSON.parse(texto)o texto (lido do arquivo)o array de volta

E o módulo node:fs (file system, "sistema de arquivos") lê e grava o arquivo. A versão 2 tira as tarefas escritas no código: a lista agora vem do arquivo.

import fs from "node:fs";

const ARQUIVO = "tarefas.json";

let tarefas = [];
if (fs.existsSync(ARQUIVO)) {
  tarefas = JSON.parse(fs.readFileSync(ARQUIVO, "utf8"));
}

const comando = process.argv[2];
const texto = process.argv.slice(3).join(" ");

if (comando === "listar") {
  if (tarefas.length === 0) {
    console.log("Nenhuma tarefa ainda.");
  } else {
    console.log("Tarefas da Ana:");
    tarefas.forEach((tarefa, i) => {
      const marca = tarefa.feita ? "x" : " ";
      console.log(`${i + 1}. [${marca}] ${tarefa.texto}`);
    });
  }
} else if (comando === "adicionar") {
  tarefas.push({ texto: texto, feita: false });
  fs.writeFileSync(ARQUIVO, JSON.stringify(tarefas, null, 2) + "\n");
  console.log(`Tarefa adicionada: ${texto}`);
} else {
  console.log("Comandos: listar, adicionar");
}
import fs from "node:fs";
Traz o módulo de arquivos do Node. Isso é só do Node: uma página no navegador não pode mexer nos arquivos do computador assim.
const ARQUIVO = "tarefas.json";
O nome do arquivo, numa constante em MAIÚSCULAS: um costume para valores fixos que o programa inteiro usa. Trocar o nome depois é mudar uma linha só.
let tarefas = [];
Começa vazia. É let (e não const) porque a linha de baixo pode trocar o array pelo que veio do arquivo.
fs.existsSync(ARQUIVO)
"O arquivo existe?": true ou false. Na primeira vez que a Ana usa o programa, ainda não existe.
fs.readFileSync(ARQUIVO, "utf8")
Lê o arquivo inteiro e devolve o conteúdo como texto. O "utf8" diz como transformar os bytes em letras (sem ele, viria um Buffer de bytes). O Sync no nome quer dizer "síncrono": o programa espera a leitura terminar antes de seguir.
process.argv.slice(3).join(" ")
Pega do item 3 em diante (["Ligar", "para", "a", "vó"]) e junta com espaços: "Ligar para a vó". Agora não precisa de aspas (veja split e join).
fs.writeFileSync(ARQUIVO, …)
Grava o texto no arquivo. Se o arquivo não existe, cria; se existe, substitui o conteúdo inteiro. O + "\n" deixa uma quebra de linha no fim, como todo arquivo de texto bem-comportado.

Versão 3 · Marcar como feita e remover

Dois comandos novos: feito N marca a tarefa número N, e remover N a apaga. O jeito mais direto de marcar seria pegar a tarefa pela posição (N - 1, porque o array começa em 0) e mudar a propriedade:

const numero = Number(process.argv[3]);
tarefas[numero - 1].feita = true;
Um número que não existe: Cannot set properties of undefined

Com só 3 tarefas na lista, a Ana digitou um número errado:

$ node tarefas.js feito 9
file:///home/ana/projetos/tarefas/tarefas.js:15
  tarefas[numero - 1].feita = true;
                            ^

TypeError: Cannot set properties of undefined (setting 'feita')
    at file:///home/ana/projetos/tarefas/tarefas.js:15:29
    at ModuleJob.run (node:internal/modules/esm/module_job:561:25)
    at async node:internal/modules/esm/loader:647:26
    at async asyncRunEntryPointWithESMLoader (node:internal/modules/run_main:101:5)

Node.js v24.22.0

"Erro de tipo: não dá para definir propriedades de undefined (definindo 'feita')". A posição 8 não existe no array, então tarefas[8] é undefined, e undefined.feita = true é impossível. O ^ aponta para o = da linha 15. Com feito dois, o Number("dois") dá NaN, e tarefas[NaN] também é undefined: o mesmo erro. A solução é conferir o número antes de usar.

A versão 3 confere o número uma vez, logo no começo, e só mexe na lista se ele for válido:

import fs from "node:fs";

const ARQUIVO = "tarefas.json";

let tarefas = [];
if (fs.existsSync(ARQUIVO)) {
  tarefas = JSON.parse(fs.readFileSync(ARQUIVO, "utf8"));
}

const comando = process.argv[2];
const texto = process.argv.slice(3).join(" ");
const numero = Number(process.argv[3]);
const numeroValido = Number.isInteger(numero) && numero >= 1 && numero <= tarefas.length;

if (comando === "listar") {
  if (tarefas.length === 0) {
    console.log("Nenhuma tarefa ainda.");
  } else {
    console.log("Tarefas da Ana:");
    tarefas.forEach((tarefa, i) => {
      const marca = tarefa.feita ? "x" : " ";
      console.log(`${i + 1}. [${marca}] ${tarefa.texto}`);
    });
  }
} else if (comando === "adicionar") {
  tarefas.push({ texto: texto, feita: false });
  fs.writeFileSync(ARQUIVO, JSON.stringify(tarefas, null, 2) + "\n");
  console.log(`Tarefa adicionada: ${texto}`);
} else if (comando === "feito") {
  if (numeroValido) {
    tarefas[numero - 1].feita = true;
    fs.writeFileSync(ARQUIVO, JSON.stringify(tarefas, null, 2) + "\n");
    console.log(`Feito: ${tarefas[numero - 1].texto}`);
  } else {
    console.log(`Não existe a tarefa ${process.argv[3]}.`);
  }
} else if (comando === "remover") {
  if (numeroValido) {
    const [removida] = tarefas.splice(numero - 1, 1);
    fs.writeFileSync(ARQUIVO, JSON.stringify(tarefas, null, 2) + "\n");
    console.log(`Removida: ${removida.texto}`);
  } else {
    console.log(`Não existe a tarefa ${process.argv[3]}.`);
  }
} else {
  console.log("Comandos: listar, adicionar, feito, remover");
}
Number.isInteger(numero)
"É um número inteiro?" Dá false para NaN ("dois") e para 1.5.
numero >= 1 && numero <= tarefas.length
Entre 1 e a quantidade de tarefas. O && ("e") exige que as três condições sejam verdadeiras.
tarefas[numero - 1].feita = true;
Muda a propriedade do objeto que já está no array; depois é só gravar o array inteiro de novo.
tarefas.splice(numero - 1, 1)
"A partir da posição numero - 1, tire 1 item". O splice muda o próprio array e devolve um array com o que tirou (veja splice e slice).
const [removida] = …
Desestruturação: pega o primeiro (e único) item do array devolvido, a tarefa removida, para mostrar o texto dela.

// Lista de Tarefas da Ana, versão 4: funções, switch e arquivo protegido
import fs from "node:fs";
import path from "node:path";

// O tarefas.json fica sempre ao lado deste programa.
const ARQUIVO = path.join(import.meta.dirname, "tarefas.json");

// Lê a lista do arquivo; sem arquivo, a lista começa vazia.
function carregar() {
  if (!fs.existsSync(ARQUIVO)) {
    return [];
  }
  try {
    return JSON.parse(fs.readFileSync(ARQUIVO, "utf8"));
  } catch (erro) {
    console.error(`O arquivo ${path.basename(ARQUIVO)} está estragado: ${erro.message}`);
    process.exit(1);
  }
}

// Grava a lista no arquivo, com 2 espaços de recuo.
function salvar(tarefas) {
  fs.writeFileSync(ARQUIVO, JSON.stringify(tarefas, null, 2) + "\n");
}

// Mostra a lista e o resumo.
function listar(tarefas) {
  if (tarefas.length === 0) {
    console.log("Nenhuma tarefa ainda.");
    return;
  }
  console.log("Tarefas da Ana:");
  tarefas.forEach((tarefa, i) => {
    const marca = tarefa.feita ? "x" : " ";
    console.log(`${i + 1}. [${marca}] ${tarefa.texto}`);
  });
  const feitas = tarefas.filter((tarefa) => tarefa.feita).length;
  console.log(`${feitas} de ${tarefas.length} feitas.`);
}

// Devolve a posição (0, 1, 2…) da tarefa de número N, ou para o programa.
function posicao(tarefas, texto) {
  const numero = Number(texto);
  if (texto === "" || !Number.isInteger(numero) || numero < 1 || numero > tarefas.length) {
    console.error(`Não existe a tarefa "${texto}". Veja os números com: node tarefas.js listar`);
    process.exit(1);
  }
  return numero - 1;
}

const tarefas = carregar();
const [comando, ...resto] = process.argv.slice(2);
const texto = resto.join(" ");

switch (comando) {
  case "listar":
    listar(tarefas);
    break;
  case "adicionar":
    if (texto === "") {
      console.error("Escreva a tarefa: node tarefas.js adicionar TEXTO");
      process.exit(1);
    }
    tarefas.push({ texto: texto, feita: false });
    salvar(tarefas);
    console.log(`Tarefa adicionada: ${texto}`);
    break;

    tarefas[i].feita = true;
    salvar(tarefas);
    console.log(`Feito: ${tarefas[i].texto}`);
    break;
  }
  case "remover": {
    const i = posicao(tarefas, texto);
    const [removida] = tarefas.splice(i, 1);
    salvar(tarefas);
    console.log(`Removida: ${removida.texto}`);
    break;
  }
  case "limpar": {
    const pendentes = tarefas.filter((tarefa) => !tarefa.feita);
    const quantas = tarefas.length - pendentes.length;
    salvar(pendentes);
    console.log(`Removidas ${quantas} tarefas feitas.`);
    break;
  }
  default:
    console.log("Uso: node tarefas.js COMANDO");

Resumo

  • O que vem depois de node tarefas.js chega em process.argv, a partir da posição 2, separado nos espaços.
  • Variáveis vivem na memória e somem quando o programa termina; para lembrar, grave num arquivo.
  • JSON.stringify transforma arrays e objetos em texto; JSON.parse faz o caminho de volta. O JSON exige aspas duplas nos nomes e não aceita vírgula sobrando.
  • fs.readFileSync(arquivo, "utf8") lê, fs.writeFileSync grava (substituindo tudo), fs.existsSync confere. Ler um arquivo que não existe dá ENOENT.
  • Valide o número antes de usar tarefas[n - 1]: undefined.feita derruba o programa.
  • import.meta.dirname é a pasta do programa; um nome sem pasta é procurado na pasta do terminal.
  • try … catch em volta do JSON.parse transforma um arquivo estragado num aviso claro, sem perder as tarefas.
