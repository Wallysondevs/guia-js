JavaScript JSON (stringify e parse)

Um objeto do JavaScript vive na memória do programa: quando o programa termina, ele some. Para guardar dados num arquivo, ou mandar para outro computador pela internet, é preciso transformá-los em texto. O formato de texto mais usado no mundo para isso é o JSON (lê-se "jêison", de JavaScript Object Notation, "notação de objetos do JavaScript"). O JavaScript já vem com as duas ferramentas: JSON.stringify (objeto → texto) e JSON.parse (texto → objeto).

Você vai aprender
  • O que é JSON e as regras dele (aspas duplas, nada de vírgula sobrando, sem funções).
  • JSON.stringify: transformar um objeto em texto, e deixá-lo legível com JSON.stringify(obj, null, 2).
  • JSON.parse: transformar o texto de volta num objeto.
  • O que se perde no caminho: funções, undefined, NaN, datas.
  • Como salvar e ler um arquivo .json no Node.
  • Os erros reais: Expected property name, Unexpected end of JSON input, is not valid JSON e Converting circular structure to JSON.

Todos os programas desta aula rodaram no Node.js 24 da máquina da Ana (usuária ana, computador notebook), com node arquivo.js. JSON.stringify e JSON.parse existem igualzinhos no navegador; só a parte de arquivos (seção 5) é do Node.

A ideia: a receita escrita no papel

A avó da Ana sabe a receita do bolo de cabeça. Para a Ana fazer o bolo em outra cidade, a avó escreve a receita num papel, num formato que qualquer um entende, e manda pelo correio. A Ana lê o papel e monta o bolo de novo na cozinha dela.

  • Escrever no papel = JSON.stringify: o objeto vira texto.
  • O papel = o texto JSON: dá para salvar num arquivo, mandar pela internet, ler de outro programa (até em outra linguagem: Python, Java, PHP… todas leem JSON).
  • Ler o papel e montar o bolo = JSON.parse: o texto vira objeto de novo.

Deixando legível: JSON.stringify(obj, null, 2)

As regras do JSON

JSON parece objeto do JavaScript, mas é mais rígido:

No JSON…CertoErrado
Nomes das propriedades: sempre entre aspas duplas{"nome": "Ana"}{nome: "Ana"}, {'nome': 'Ana'}
Textos: só aspas duplas"Ana"'Ana', `Ana`
Sem vírgula depois do último item[1, 2][1, 2,]
Sem comentários—// isto não pode
Valores possíveistexto, número, true, false, null, array, objetofunção, undefined, NaN, Infinity, datas

Não só objetos viram JSON: qualquer um dos valores possíveis vira.

console.log(JSON.stringify(42));

3. O que se perde no caminho

Como o JSON só conhece aqueles valores, o stringify adapta ou joga fora o resto, sem avisar:

const loja = {
  nome: "Lojinha",
  aberta: undefined,
  saudar() {
    return "Oi";
  },
  nota: NaN,
  infinito: Infinity,
  abertura: new Date(Date.UTC(2026, 9, 19, 9, 0)),
};
console.log(JSON.stringify(loja));
console.log(JSON.stringify([undefined, () => 1]));

$ node perde.js
{"nome":"Lojinha","nota":null,"infinito":null,"abertura":"2026-10-19T09:00:00.000Z"}
[null,null]
ValorNum objetoNum array
undefined, funções (métodos)A propriedade some (aberta e saudar não aparecem)Vira null
NaN, InfinityVira nullVira null
Datas (Date)Viram texto ("2026-10-19T09:00:00.000Z")Viram texto

E na volta, o JSON.parse não sabe que aquele texto era uma data: ele devolve um texto. Se precisar de uma data, recrie: new Date(obj.abertura).

Cópia profunda com JSON

Em código antigo você vai ver JSON.parse(JSON.stringify(obj)) para copiar um objeto inteiro: vira texto e volta como um objeto novo, sem nada compartilhado (no lab, mudar a cidade na cópia deixou o original com Recife). Funciona para dados simples, mas perde tudo o que a tabela acima mostra. Hoje, prefira structuredClone(obj) (veja Objetos são Referências).

4. Escolhendo o que vai para o texto

O segundo argumento do stringify (o null da seção 1) pode ser uma lista de propriedades: só elas entram no texto. Útil para não mandar o que é secreto:

const usuario = { nome: "Ana", email: "ana@exemplo.com", senha: "1234" };
console.log(JSON.stringify(usuario, ["nome", "email"]));

$ node escolher.js
{"nome":"Ana","email":"ana@exemplo.com"}

(Outro jeito é tirar a senha antes, com rest: const { senha, ...publico } = usuario;, da aula Spread e Rest.)

5. Salvando e lendo um arquivo .json (Node)

É aqui que o JSON brilha: o programa da Ana pode guardar o estoque num arquivo e, na próxima vez que rodar, continuar de onde parou. O módulo fs ("file system", sistema de arquivos) é só do Node; ele tem aulas próprias em Escrevendo Arquivos e Lendo Arquivos. Aqui, só o básico:

const fs = require("node:fs");

const estoque = { pao: 20, leite: 8, cafe: 3 };
fs.writeFileSync("estoque.json", JSON.stringify(estoque, null, 2));
console.log("Estoque salvo.");

$ node salvar.js
Estoque salvo.
$ cat estoque.json
{
  "pao": 20,
  "leite": 8,
  "cafe": 3
}

O cat mostra o conteúdo do arquivo: é o texto JSON que o stringify produziu. Agora o caminho de volta, num segundo programa: ler o arquivo, transformar em objeto, vender 5 pães e salvar de novo.

const fs = require("node:fs");

const texto = fs.readFileSync("estoque.json", "utf8");
const estoque = JSON.parse(texto);
estoque.pao = estoque.pao - 5;
console.log(estoque);
fs.writeFileSync("estoque.json", JSON.stringify(estoque, null, 2));

$ node ler.js
{ pao: 15, leite: 8, cafe: 3 }
$ cat estoque.json
{
  "pao": 15,
  "leite": 8,
  "cafe": 3
}

O arquivo agora diz 15 pães. Rodando ler.js de novo, seriam 10: os dados sobrevivem entre uma execução e outra. (No navegador não há fs; lá, o JSON costuma ir para o localStorage ou chegar da internet com fetch.)

Experimente: rode: o programa salva o estoque, lê o arquivo de volta e mostra o conteúdo dele. Depois troque o 2 do stringify por 4, ou apague os dois últimos argumentos, e rode de novo para ver o formato mudar. (A caixa imita o fs do Node numa pasta só dela: o estoque.json gravado vale até o fim daquele Rodar; cada Rodar começa do zero.)

const fs = require("node:fs");

const estoque = { pao: 20, leite: 8, cafe: 3 };
fs.writeFileSync("estoque.json", JSON.stringify(estoque, null, 2));
const lido = JSON.parse(fs.readFileSync("estoque.json", "utf8"));
console.log(fs.readFileSync("estoque.json", "utf8"));
console.log(lido.pao);

Quando dá errado

Quase todo erro de JSON é um SyntaxError do JSON.parse: o texto não segue as regras. Repare que, nesses erros, a primeira linha não é o seu arquivo, e sim <anonymous_script>:1: o Node está mostrando o texto JSON que ele tentou ler, com o ^ no ponto onde desistiu. O seu arquivo aparece mais abaixo, numa linha at.

Aspas simples (ou nomes sem aspas)

const pessoa = JSON.parse(texto);

"Era esperado um nome de propriedade entre aspas duplas". Depois de uma vírgula, o JSON espera mais uma propriedade, e encontrou o }. No JavaScript a vírgula sobrando é permitida (e este guia até a usa nos objetos de várias linhas); no JSON, não. Como consertar: apague a última vírgula.

Texto vazio, ou undefined 
const texto = "";
const dados = JSON.parse(texto);

"Fim inesperado da entrada JSON": o texto acabou antes de começar (as duas linhas em branco são o texto vazio, sem nada para o ^ apontar). Acontece com um arquivo .json vazio. Com uma variável que ficou sem valor, JSON.parse(salvo) deu no lab SyntaxError: "undefined" is not valid JSON; e passando um objeto no lugar do texto, JSON.parse(produto) deu SyntaxError: "[object Object]" is not valid JSON (o objeto foi convertido no texto "[object Object]", que não é JSON; ele já era objeto, não precisava de parse). Como consertar: confira o que está chegando com console.log(texto) antes do parse.

Estrutura circular 
const ana = { nome: "Ana" };
const bia = { nome: "Bia", amiga: ana };
ana.amiga = bia;
console.log(JSON.stringify(ana));

$ node circular.js
/home/ana/circular.js:4
console.log(JSON.stringify(ana));
                 ^

TypeError: Converting circular structure to JSON
    --> starting at object with constructor 'Object'
    |     property 'amiga' -> object with constructor 'Object'
    --- property 'amiga' closes the circle
    at JSON.stringify (<anonymous>)
    at Object.<anonymous> (/home/ana/circular.js:4:18)    « (mais 7 linhas node:internal cortadas)

Node.js v24.22.0

"Convertendo uma estrutura circular para JSON". A Ana aponta para a Bia, que aponta de volta para a Ana: escrever isso em texto não teria fim. As três linhas com -->, | e --- desenham o círculo: começa no objeto da Ana, segue a propriedade amiga até a Bia, e a amiga da Bia fecha o círculo. Como consertar: guarde algo que identifique, e não o objeto inteiro (amiga: "Bia").

Protegendo o parse com try … catch

Quando o texto vem de fora (arquivo, internet, o que a pessoa digitou), ele pode estar errado, e você não quer que o programa inteiro caia por isso. O try … catch (aula try … catch … finally) captura o erro:

const texto = "{'nome': 'Ana'}";
try {
  const pessoa = JSON.parse(texto);
  console.log(pessoa.nome);
} catch (erro) {
  console.log("Texto inválido:", erro.message);
}

$ node trycatch.js
Texto inválido: Expected property name or '}' in JSON at position 1 (line 1 column 2)

Resumo

  • JSON é um formato de texto para guardar e trocar dados; quase todas as linguagens o leem.
  • JSON.stringify(obj) transforma em texto; com null, 2, fica legível.
  • JSON.parse(texto) transforma o texto em objeto (ou array, número…) de novo.
  • Regras: aspas duplas, sem vírgula sobrando, sem comentários. Funções e undefined somem; NaN vira null; datas viram texto.
  • No Node, fs.writeFileSync + stringify salva; fs.readFileSync + parse lê.
  • Texto que vem de fora pode estar errado: proteja o parse com try … catch.
