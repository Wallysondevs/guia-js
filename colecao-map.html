JavaScript Map

Na aula anterior, o Set guardava valores soltos, sem repetição. Muitas vezes, porém, cada coisa vem com uma informação junto: o produto e o seu preço, o nome e o telefone, a palavra e quantas vezes ela apareceu. Para guardar pares assim, o JavaScript tem o Map (em inglês, "mapa"), que funciona como um dicionário: você procura pela palavra e encontra o significado.

Você vai aprender
  • O que é um par chave → valor, e como criar um Map com new Map().
  • Os métodos do dia a dia: set (guardar), get (buscar), has (tem?), delete (apagar), clear (esvaziar) e size (quantos).
  • Como criar um Map já cheio, a partir de uma lista de pares.
  • Que no Map a chave pode ser de qualquer tipo: número, texto, até um objeto.
  • Como percorrer com for … of, forEach, keys(), values() e entries().
  • O uso clássico: contar quantas vezes cada coisa aparece.
  • Como converter entre Map e objeto, agrupar com Map.groupBy e quando usar cada um.
  • Os erros reais: esquecer o new, usar colchetes no lugar de set/get, trocar a ordem do forEach.

Todos os programas desta aula rodaram no Node.js 24 da máquina da Ana (usuária ana, computador notebook), com node arquivo.js. Você pode rodar cada um no editor do guia.

A ideia: a tabela de preços da padaria

Na parede da padaria do bairro tem uma tabela:

Produto (a chave)Preço (o valor)
pãoR$ 0,75
leiteR$ 5,49
caféR$ 18,90

Quando o cliente pergunta "quanto é o leite?", o caixa não lê a tabela inteira: vai direto na linha do leite e responde 5,49. Cada linha é um par:

  • a chave é o que você usa para procurar (o nome do produto). Ela não se repete: não existem duas linhas "leite";
  • o valor é o que você quer descobrir (o preço). Valores podem se repetir: dois produtos podem custar o mesmo.

Um Map é essa tabela dentro do programa. Você também pode pensar num dicionário (palavra → significado) ou na agenda do celular (nome → telefone).

1. Guardar e buscar (set e get)

const precos = new Map();
precos.set("pão", 0.75);
precos.set("leite", 5.49);
precos.set("café", 18.9);
console.log(precos);
console.log(precos.get("leite"));
console.log(precos.get("manteiga"));
console.log(precos.size);
new Map()
Cria um mapa vazio. Como no Set, o new é obrigatório.
precos.set("pão", 0.75)
set = "definir". Guarda o par: a chave "pão" com o valor 0.75. A chave vem primeiro, o valor depois. (Repare no ponto: em JavaScript, a casa decimal é com ponto, 0.75.)
precos.get("leite")
get = "pegar". Procura a chave "leite" e devolve o valor dela.
precos.get("manteiga")
Não tem manteiga na tabela: o get devolve undefined ("indefinido"), sem erro.
precos.size
Quantos pares o mapa tem. É size, como no Set (sem parênteses).
$ node precos.js
Map(3) { 'pão' => 0.75, 'leite' => 5.49, 'café' => 18.9 }
5.49
undefined
3

O Node mostra o mapa assim: Map(3) ("um Map com 3 pares") e, entre { }, cada par como chave => valor. A setinha => se lê "aponta para": 'pão' aponta para 0.75. Os pares aparecem na ordem em que foram guardados.

2. Mudar, perguntar e apagar (has, delete, clear)

O preço do pão subiu. Para mudar um valor, basta outro set com a mesma chave: o valor novo toma o lugar do antigo (a chave não se repete).

const precos = new Map();
precos.set("pão", 0.75);
precos.set("leite", 5.49);
precos.set("pão", 0.8);
console.log(precos);
console.log(precos.has("pão"));
console.log(precos.has("manteiga"));
console.log(precos.delete("leite"));
console.log(precos.delete("leite"));
console.log(precos);
precos.clear();
console.log(precos);

Para saber se uma chave existe, use has. Testar if (precos.get("x")) engana quando o valor guardado é 0, "" ou false: o valor existe, mas o if o trata como falso (veja Truthy e Falsy).

3. Criar um Map já cheio

Em vez de vários set, dá para entregar ao new Map(…) uma lista de pares. Cada par é um arrayzinho de dois itens: [chave, valor].

const telefones = new Map([
  ["Ana", "99999-1111"],
  ["Bia", "98888-2222"],
  ["Caio", "97777-3333"],
]);
console.log(telefones);
console.log(telefones.get("Bia"));

$ node criar.js
Map(3) {
  'Ana' => '99999-1111',
  'Bia' => '98888-2222',
  'Caio' => '97777-3333'
}
98888-2222

Repare nos colchetes: um par de fora (a lista) com vários pares de dentro (["Ana", "99999-1111"]). A vírgula depois do último par é permitida e facilita acrescentar outro depois. Quando a linha fica comprida, o Node mostra um par por linha; é só a apresentação, o mapa é o mesmo.

4. A chave pode ser de qualquer tipo

Esta é a grande diferença entre o Map e um objeto comum. No objeto, as chaves viram sempre texto. No Map, a chave fica do jeito que você deu: número, texto, booleano, até um objeto.

const salas = new Map();
salas.set(1, "Matemática");
salas.set("1", "Sala de leitura");
salas.set(true, "Ginásio");
console.log(salas);
console.log(salas.get(1));
console.log(salas.get("1"));
const ana = { nome: "Ana" };
const bia = { nome: "Bia" };
const notas = new Map();
notas.set(ana, 9.5);
notas.set(bia, 7);
console.log(notas.get(ana));
console.log(notas);
const obj = {};
obj[1] = "Matemática";
obj["1"] = "Sala de leitura";
console.log(obj);

$ node chaves.js
Map(3) {
  1 => 'Matemática',
  '1' => 'Sala de leitura',
  true => 'Ginásio'
}
Matemática
Sala de leitura
9.5
Map(2) { { nome: 'Ana' } => 9.5, { nome: 'Bia' } => 7 }
{ '1': 'Sala de leitura' }
  • No mapa salas, 1 (número) e "1" (texto) são duas chaves diferentes. O Node mostra o número sem aspas e o texto com aspas.
  • No mapa notas, a chave é o próprio objeto da aluna. Isso serve para "pendurar" uma informação num objeto sem mexer nele.
  • No objeto comum obj, o 1 virou o texto '1', e o segundo valor apagou o primeiro: sobrou só 'Sala de leitura'.

A regra de "chave igual" é a mesma do Set (veja Set): textos e números iguais pelo ===; objetos só se forem o mesmo objeto. Por isso o get(ana) funcionou com a variável ana, mas notas.get({ nome: "Ana" }) devolveria undefined (veja Quando dá errado).

5. Percorrer um Map

O estoque da papelaria da Ana:

const estoque = new Map([
  ["caneta", 40],
  ["caderno", 12],
  ["borracha", 25],
]);
for (const [produto, quantidade] of estoque) {
  console.log(`${produto}: ${quantidade} unidades`);
}
estoque.forEach((quantidade, produto) => {
  console.log(`${produto} -> ${quantidade}`);
});
console.log(estoque.keys());
console.log([...estoque.keys()]);
console.log([...estoque.values()]);
console.log([...estoque.entries()]);
let total = 0;
for (const quantidade of estoque.values()) {
  total += quantidade;
}
console.log(`Total de itens: ${total}`);

for (const [produto, quantidade] of estoque)
A cada volta, o for … of entrega um par [chave, valor]. Os colchetes em [produto, quantidade] abrem o par em duas variáveis (isso é a desestruturação): a primeira recebe a chave, a segunda o valor.
estoque.forEach((quantidade, produto) => …)
O forEach do Map entrega primeiro o valor e depois a chave. É o contrário do for … of, e é uma fonte clássica de confusão (veja Quando dá errado).
estoque.keys()
As chaves. Ele devolve um "iterador" ([Map Iterator]), uma fila que se percorre com for … of; com [... ] vira array.
estoque.values()
Os valores. Bom para somar, como no total de itens.
estoque.entries()
Os pares [chave, valor]. É o que o for … of usa quando você percorre o mapa direto.

6. O uso clássico: contar

Quantas vezes cada palavra aparece num texto? Para cada palavra, o programa pega a contagem atual (ou 0, se for a primeira vez) e guarda essa contagem mais 1:

const frase = "o rato roeu a roupa do rei de roma o rato fugiu";
const contagem = new Map();
for (const palavra of frase.split(" ")) {
  const atual = contagem.get(palavra) ?? 0;
  contagem.set(palavra, atual + 1);
}
console.log(contagem);
console.log(`"rato" apareceu ${contagem.get("rato")} vezes`);

$ node contar.js
Map(10) {
  'o' => 2,
  'rato' => 2,
  'roeu' => 1,
  'a' => 1,
  'roupa' => 1,
  'do' => 1,
  'rei' => 1,
  'de' => 1,
  'roma' => 1,
  'fugiu' => 1
}
"rato" apareceu 2 vezes
frase.split(" ")
Corta a frase nos espaços e devolve um array de palavras (veja split e join).
contagem.get(palavra) ?? 0
Na primeira vez que a palavra aparece, o get devolve undefined; o ?? troca esse undefined por 0 (veja ?. e ??).
contagem.set(palavra, atual + 1)
Guarda a contagem nova. Se a chave já existia, o valor é trocado.

Sem o ?? 0, a primeira conta seria undefined + 1, que dá NaN ("não é um número"). A missão final desta aula mostra exatamente isso.

7. Map e objeto: convertendo de um para o outro

Às vezes os dados chegam como objeto (de um JSON, por exemplo) e você quer um Map, ou o contrário:

const objeto = { pão: 0.75, leite: 5.49 };
const mapa = new Map(Object.entries(objeto));
console.log(mapa);
mapa.set("café", 18.9);
const deVolta = Object.fromEntries(mapa);
console.log(deVolta);
console.log(JSON.stringify(mapa));
console.log(JSON.stringify(Object.fromEntries(mapa)));

$ node objeto.js
Map(2) { 'pão' => 0.75, 'leite' => 5.49 }
{ 'pão': 0.75, leite: 5.49, 'café': 18.9 }
{}
{"pão":0.75,"leite":5.49,"café":18.9}
Object.entries(objeto)
Transforma o objeto numa lista de pares [chave, valor] (veja Percorrendo Objetos), exatamente o que o new Map aceita.
Object.fromEntries(mapa)
O caminho de volta: "objeto a partir dos pares". (O Node pôs aspas em 'pão' e 'café' por causa do acento; no objeto, a chave é o mesmo texto.)
JSON.stringify(mapa) → {}
Cuidado: o JSON.stringify não sabe escrever um Map e devolve {}, vazio, sem avisar. Para salvar ou enviar, converta antes para objeto.

Agrupar com Map.groupBy ES2024

O Map.groupBy separa os itens de um array em grupos e devolve um Map: a chave é o nome do grupo, e o valor é o array dos itens daquele grupo.

const alunos = [
  { nome: "Ana", turma: "A" },
  { nome: "Bia", turma: "B" },
  { nome: "Caio", turma: "A" },
  { nome: "Davi", turma: "B" },
  { nome: "Eva", turma: "A" },
];
const porTurma = Map.groupBy(alunos, (aluno) => aluno.turma);
console.log(porTurma);
console.log(porTurma.get("A").length);

$ node agrupar.js
Map(2) {
  'A' => [
    { nome: 'Ana', turma: 'A' },
    { nome: 'Caio', turma: 'A' },
    { nome: 'Eva', turma: 'A' }
  ],
  'B' => [ { nome: 'Bia', turma: 'B' }, { nome: 'Davi', turma: 'B' } ]
}
3

A função (aluno) => aluno.turma diz, para cada aluno, a que grupo ele pertence. A turma A tem 3 alunos. (Existe também o Object.groupBy, que faz o mesmo e devolve um objeto.)

Resumo

  • O Map guarda pares chave → valor, como um dicionário. A chave não se repete; o valor pode.
  • set guarda (ou troca), get busca (undefined se não achar), has pergunta, delete apaga, clear esvazia, size conta.
  • Crie já cheio com new Map([[chave, valor], …]). O new é obrigatório.
  • A chave pode ser de qualquer tipo; 1 e "1" são chaves diferentes; objetos só são a mesma chave se forem o mesmo objeto.
  • Percorra com for (const [k, v] of m); no forEach, o valor vem primeiro.
  • Para contar: m.set(x, (m.get(x) ?? 0) + 1).
  • Use objeto para registros e JSON; Map para chaves que surgem durante o programa, contagens e agrupamentos.
