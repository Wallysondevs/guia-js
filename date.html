JavaScript Date

A data da prova, o vencimento do boleto, quantos dias faltam para as férias, a idade de alguém, a hora em que um pedido chegou: quase todo programa lida com datas. No JavaScript, uma data é um objeto do tipo Date ("data", em inglês). Ele guarda um instante no tempo (dia e hora, até o milésimo de segundo) e tem métodos para ler e mudar cada parte. Tem também algumas pegadinhas famosas, como o mês que começa em 0. Esta aula mostra as duas coisas.

Você vai aprender
  • Como criar a data de agora e uma data escolhida: new Date() e new Date(2026, 2, 5).
  • Por que março é o mês 2, e como não errar por causa disso.
  • Como ler o ano, o mês, o dia, o dia da semana e a hora (getFullYear, getMonth, getDate, getDay…).
  • Como somar dias e meses (setDate, setMonth) e como a data "transborda" sozinha para o mês seguinte.
  • Como calcular quantos dias faltam entre duas datas, e o que é o número de milissegundos que fica por trás de toda data.
  • Como comparar datas, e por que o Node mostra as datas com um Z no fim e 3 horas de diferença.
  • Os erros reais: Invalid Date, RangeError: Invalid time value, a data em texto que "volta um dia" e o Date() sem new.

Todos os programas desta aula rodaram no Node.js 24 da máquina da Ana (usuária ana, computador notebook), que está no horário de Brasília, com node arquivo.js. O Date é da linguagem: existe igual no navegador. Mas fique atento: a data de "agora" muda a cada execução, e o fuso horário do seu computador pode mudar a hora mostrada. Por isso, quase todos os exemplos usam datas fixas.

A ideia: um relógio que conta desde 1970

Imagine um contador gigante que começou a contar à meia-noite do dia 1º de janeiro de 1970, no horário de Londres, e soma 1 a cada milésimo de segundo (1 milissegundo). Cada instante da história tem o seu número nesse contador: o instante em que você lê esta frase, a meia-noite do Natal, o seu aniversário.

Um Date é isso: um número de milissegundos desde 1970, com um monte de métodos em volta para traduzir esse número em coisas que as pessoas entendem (dia, mês, ano, hora) e de volta. Guardar a ideia do contador ajuda a entender por que dá para subtrair duas datas e por que o fuso horário importa.

1. A data de agora: new Date()

const agora = new Date();
console.log(agora);
console.log(String(agora));

$ node agora.js
2026-10-19T14:19:19.432Z
Mon Oct 19 2026 11:19:19 GMT-0300 (Horário Padrão de Brasília)
new Date()
O new fabrica um objeto novo a partir do molde Date (veja Classes). Sem nada entre os parênteses, a data criada é o instante de agora, lido do relógio do computador. A Ana rodou o programa em 19 de outubro de 2026, às 11h19; se você rodar, vai sair o seu agora.
2026-10-19T14:19:19.432Z
É assim que o console.log do Node mostra uma data: ano-mês-dia, a letra T (de time, "hora"), a hora, e um Z no fim. O Z quer dizer UTC, o horário de referência do mundo (o de Londres no inverno). Por isso aparece 14h19, e não 11h19: Brasília está 3 horas atrás do UTC.
String(agora)
Transformada em texto, a data aparece no horário local, o do computador: 11:19:19 GMT-0300 ("3 horas a menos que o horário de Greenwich", outro nome do UTC), com o nome do fuso entre parênteses.

As duas linhas são o mesmo instante, escrito em dois relógios diferentes. Guarde isso: quando o Node mostra uma data com Z e a hora parece errada, ela não está errada; está em UTC. Para mostrar datas do jeito brasileiro (19/10/2026), existe a aula Formatando Datas.

O mês é contado a partir do 0, como as posições de um array: janeiro é 0, fevereiro é 1, março é 2… julho é 6, dezembro é 11. O ano e o dia são contados normalmente. Data em texto sem hora: o dia que "volta"

4. Mudando a data: os métodos set e o "transbordo"

A Ana comprou uma geladeira no dia 20 de janeiro, e o boleto vence 30 dias depois. Para somar dias, leia o dia com getDate, some, e grave com setDate ("definir o dia"):

const compra = new Date(2026, 0, 20);
compra.setDate(compra.getDate() + 30);

console.log(`Vence em ${compra.getDate()}/${compra.getMonth() + 1}/${compra.getFullYear()}`);

$ node mudar.js
Vence em 19/2/2026

20 + 30 dá 50, e janeiro não tem dia 50. O Date não reclama: ele transborda para o mês seguinte, contando os 31 dias de janeiro, e chega a 19 de fevereiro. Isso é uma ajuda enorme: você não precisa saber quantos dias tem cada mês. Mais exemplos:

const data = new Date(2026, 0, 31);
data.setMonth(data.getMonth() + 1);
console.log(`${data.getDate()}/${data.getMonth() + 1}/${data.getFullYear()}`);

const virada = new Date(2026, 11, 31);
virada.setDate(virada.getDate() + 1);
console.log(`${virada.getDate()}/${virada.getMonth() + 1}/${virada.getFullYear()}`);

console.log(new Date(2026, 1, 0).getDate());
console.log(new Date(2028, 2, 0).getDate());

$ node transbordar.js
3/3/2026
1/1/2027
31
29
31 de janeiro + 1 mês → 3/3/2026
Cuidado: "31 de fevereiro" não existe; fevereiro de 2026 tem 28 dias, então o Date transborda 3 dias para março. Somar meses a dias 29, 30 e 31 pode pular um mês.
31 de dezembro + 1 dia → 1/1/2027
O transbordo também vira o ano.
new Date(2026, 1, 0).getDate() → 31
O dia 0 de um mês é o último dia do mês anterior: o dia 0 de fevereiro é 31 de janeiro. Um truque conhecido para saber quantos dias um mês tem.
new Date(2028, 2, 0).getDate() → 29
O dia 0 de março de 2028 é o último de fevereiro: 29, porque 2028 é ano bissexto.

Existe um set para cada get: setFullYear, setMonth, setDate, setHours, setMinutes… Todos mudam a própria data (o objeto), mesmo que ela esteja numa const: o const só impede trocar a variável por outra data (veja Quando dá errado).

5. Quantos dias faltam? Subtraindo datas

Lembra do contador de milissegundos? Uma data, usada numa conta, vira esse número. Então subtrair duas datas dá a distância entre elas, em milissegundos:

const hoje = new Date(2026, 2, 5);
const natal = new Date(2026, 11, 25);

const milissegundos = natal - hoje;
const umDia = 1000 * 60 * 60 * 24;
const dias = Math.round(milissegundos / umDia);

console.log(milissegundos);
console.log(`Faltam ${dias} dias para o Natal`);

$ node diferenca.js
25488000000
Faltam 295 dias para o Natal
natal - hoje
25 488 000 000 milissegundos entre as duas meias-noites.
const umDia = 1000 * 60 * 60 * 24;
Quantos milissegundos tem um dia: 1000 em um segundo, 60 segundos, 60 minutos, 24 horas. Escrever a conta, em vez do resultado (86 400 000), deixa claro de onde o número veio.
Math.round(…)
Arredonda (veja Math). Em países com horário de verão, um dia pode ter 23 ou 25 horas, e a divisão daria um número quebrado; o Math.round resolve.

Para ver o número direto, use getTime() ("pegar o tempo") ou Number(data). E o caminho de volta, do número para a data, é o new Date(numero):

const data = new Date(2026, 2, 5);

console.log(data.getTime());
console.log(Number(data));
console.log(new Date(1772679600000).getDate());

$ node gettime.js

Esse número é o jeito mais seguro de guardar uma data (num arquivo, num banco de dados): ele não depende de fuso nem de formato.

O instante de agora em número: Date.now()

Date.now() devolve o número de milissegundos de agora, sem criar um objeto. É o jeito clássico de medir quanto tempo um trecho do programa demora:

const inicio = Date.now();

let soma = 0;
for (let i = 0; i < 50_000_000; i++) {
  soma += i;
}

const fim = Date.now();
console.log(`A conta levou ${fim - inicio} ms`);

$ node cronometro.js
A conta levou 75 ms

(O 50_000_000 é o número 50 milhões; o _ só ajuda a ler. O tempo muda a cada execução e de um computador para outro.)

Idade: diferença de anos com cuidado

Subtrair os anos não basta: quem nasceu em julho ainda não fez aniversário em março. A função compara também o mês e o dia:

function calcularIdade(nascimento, hoje) {
  let idade = hoje.getFullYear() - nascimento.getFullYear();
  const aindaNaoFez =
    hoje.getMonth() < nascimento.getMonth() ||
    (hoje.getMonth() === nascimento.getMonth() && hoje.getDate() < nascimento.getDate());
  if (aindaNaoFez) {
    idade--;
  }
  return idade;
}

const nascimento = new Date(1998, 6, 14);
console.log(calcularIdade(nascimento, new Date(2026, 2, 5)));
console.log(calcularIdade(nascimento, new Date(2026, 6, 14)));

$ node idade.js
27
28

A função recebe o "hoje" como parâmetro, em vez de usar new Date() lá dentro. Assim ela dá sempre o mesmo resultado para as mesmas datas, e fica fácil de testar.

E o Temporal?

O Date é antigo e cheio de pegadinhas, e por isso a linguagem ganhou um substituto, o Temporal, que já começou a chegar a alguns navegadores. No Node 24 ele ainda não existe: no lab, typeof Temporal respondeu undefined. Por enquanto, o Date é o que funciona em todo lugar (veja Novidades Recentes).

Missão: hoje é 1º de junho de 2026 e as férias começam em 1º de julho. Crie as duas datas (lembre do mês!), calcule a diferença em milissegundos, transforme em dias com Math.round e mostre Faltam 30 dias para as férias.

const umDia = 1000 * 60 * 60 * 24;

const hoje = 0; // crie a data de 1º de junho de 2026
const ferias = 0; // crie a data de 1º de julho de 2026
const dias = 0; // calcule

console.log(`Faltam ${dias} dias para as férias`);

const umDia = 1000 * 60 * 60 * 24;

const hoje = new Date(2026, 5, 1);
const ferias = new Date(2026, 6, 1);
const dias = Math.round((ferias - hoje) / umDia);

console.log(`Faltam ${dias} dias para as férias`);

No lab, a solução mostrou Faltam 30 dias para as férias (junho tem 30 dias). Se você escrever os meses 6 e 7, vai dar 31: a distância de julho a agosto.

Resumo

  • Um Date é um instante: por dentro, os milissegundos desde 1º de janeiro de 1970 (UTC). new Date() é agora; new Date(2026, 2, 5) é 5 de março de 2026 à meia-noite local.
  • O mês vai de 0 a 11: janeiro é 0, dezembro é 11. Some 1 ao mostrar, subtraia 1 ao criar.
  • Leia com getFullYear, getMonth, getDate (dia do mês), getDay (dia da semana, 0 = domingo), getHours…; mude com os set, que transbordam para o mês e o ano seguintes.
  • b - a dá a distância em milissegundos; divida por 1000 * 60 * 60 * 24 e arredonde para ter dias.
  • O console.log do Node mostra as datas em UTC (o Z); String(data) e os get usam o horário local.
  • Cuidados: o texto "2026-03-05" é lido em UTC; "31/12/2026" vira Invalid Date; === não compara datas (use getTime()); para copiar, new Date(d); e nunca esqueça o new.
