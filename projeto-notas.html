Projeto Notas da Turma (CSV)

A Ana dá aula de reforço e guarda as notas dos alunos numa planilha. Toda planilha sabe se salvar como CSV, um arquivo de texto simples com uma linha por aluno e as colunas separadas por vírgula. Neste projeto ela escreve um programa que lê esse arquivo, calcula a média de cada aluno, diz quem passou, monta um relatório organizado e grava o resultado num CSV novo.

Você vai praticar
  • Ler um arquivo de texto com fs.readFileSync e quebrá-lo em linhas e colunas com split.
  • Separar o cabeçalho do resto com desestruturação e rest.
  • Converter as notas com map(Number) e somar com reduce.
  • Decidir a situação com uma função e if.
  • Alinhar colunas com padEnd/padStart e ordenar com toSorted.
  • Conferir linhas erradas e gravar o resultado com fs.writeFileSync.

A regra da escola: média 7 ou mais, Aprovado; de 5 a 7, Recuperação; abaixo de 5, Reprovado. Vamos chegar lá em quatro versões:

  1. Ler o CSV (readFileSync, split, a linha vazia do fim).
  2. Média e situação (map(Number), reduce, toFixed).
  3. O relatório (objetos, toSorted, padEnd/padStart).
  4. Conferir e gravar (linhas erradas, process.argv, writeFileSync).

Antes de começar

Crie a pasta do projeto e, dentro dela, o turma.csv (num editor de texto, ou salvando a planilha como "CSV"). O programa vai se chamar notas.js:

$ mkdir -p projetos/notas
$ cd projetos/notas

Nas caixas Experimente, o turma.csv fica numa aba ao lado do programa, e o programa o lê de verdade. Você pode mudar as notas na aba e rodar de novo.

Versão 1 · Ler o CSV

Para o programa, o turma.csv é só um texto comprido, com uma quebra de linha (\n) depois de cada aluno. O primeiro passo é ler o arquivo inteiro e cortar esse texto nas quebras de linha, para ver o que sai:

import fs from "node:fs";

const texto = fs.readFileSync("turma.csv", "utf8");
const linhas = texto.split("\n");
console.log(linhas);

$ node notas.js

  'nome,nota1,nota2,nota3',
  'Ana,8.5,7,9',
  'Bruno,5,6.5,4',
  'Carla,10,9.5,9',
  'Diego,6,5,7.5',
  'Elisa,3,4.5,5',
  ''
]

O split("\n") ("dividir") devolveu um array com uma string por linha. Duas coisas para reparar: a primeira linha é o cabeçalho (os nomes das colunas), não um aluno; e o último item é uma string vazia, ''. Ela aparece porque o arquivo termina com uma quebra de linha (todo arquivo de texto bem-feito termina assim), e depois da última quebra não há nada. Agora, cortando cada linha nas vírgulas:

import fs from "node:fs";

console.log("Colunas:", cabecalho);
for (const linha of linhas) {
  const [nome, nota1, nota2, nota3] = linha.split(",");
  console.log(`${nome}: ${nota1}, ${nota2} e ${nota3}`);
}

Versão 2 · Média e situação

A média é a soma das três notas dividida por 3. Mas cuidado: o que veio do split são textos ('8.5', '7', '9'), e já vimos no projeto da calculadora o que o + faz com textos. Primeiro, converta; depois, some:

import fs from "node:fs";

// Devolve a situação do aluno pela média.
function situacao(media) {
  if (media >= 7) {
    return "Aprovado";
  }
  if (media >= 5) {
    return "Recuperação";
  }
  return "Reprovado";
}

const texto = fs.readFileSync("turma.csv", "utf8");
const [cabecalho, ...linhas] = texto.trim().split("\n");

for (const linha of linhas) {
  const [nome, ...colunas] = linha.split(",");
  const notas = colunas.map(Number);
  const soma = notas.reduce((total, nota) => total + nota, 0);
  const media = soma / notas.length;
  console.log(`${nome}: média ${media.toFixed(1)} (${situacao(media)})`);
}
PeçaO que faz
function situacao(media)Recebe a média e devolve o texto da situação. Cada return encerra a função: se a média for 7 ou mais, o primeiro return responde e as linhas de baixo nem rodam. Por isso o segundo if não precisa conferir "menor que 7".
const [nome, ...colunas] = linha.split(",");O nome à parte; as notas, quantas forem, no array colunas.
colunas.map(Number)Passa cada texto pelo Number e devolve um array novo com os números: [ '8.5', '7', '9' ] vira [ 8.5, 7, 9 ] (veja map).
notas.reduce((total, nota) => total + nota, 0)Começa o total em 0 e soma cada nota a ele: 0 + 8.5 + 7 + 9 = 24.5 (veja reduce).
soma / notas.lengthDivide pela quantidade de notas, e não por um 3 fixo: se a escola passar a dar 4 provas, a conta continua certa.
media.toFixed(1)Mostra com 1 casa decimal, arredondando: 8.1666… vira '8.2' (veja Formatando Números).

Versão 3 · O relatório

A Ana quer um relatório de verdade: os alunos do melhor para o pior, as notas em colunas alinhadas, a média da turma e quem foi melhor. Para ordenar e calcular depois, cada linha passa a virar um objeto com tudo o que se sabe do aluno: { nome, notas, media }.

import fs from "node:fs";

function situacao(media) {
  if (media >= 7) {
    return "Aprovado";
  }
  if (media >= 5) {
    return "Recuperação";
  }
  return "Reprovado";
}

const texto = fs.readFileSync("turma.csv", "utf8");
const [cabecalho, ...linhas] = texto.trim().split("\n");

// Cada linha vira um objeto: { nome, notas, media }
const alunos = linhas.map((linha) => {
  const [nome, ...colunas] = linha.split(",");
  const notas = colunas.map(Number);
  const media = notas.reduce((total, nota) => total + nota, 0) / notas.length;
  return { nome, notas, media };
});

// Do maior para o menor, sem mexer no array original
const ranking = alunos.toSorted((a, b) => b.media - a.media);

console.log("Aluno     Nota 1  Nota 2  Nota 3   Média  Situação");

Transforma cada linha de texto num objeto. O { nome, notas, media } é a forma curta de { nome: nome, notas: notas, media: media }.
alunos.toSorted((a, b) => b.media - a.media)
Devolve uma cópia ordenada. A função compara dois alunos: um resultado positivo põe b antes de a. Com b.media - a.media, a maior média vem primeiro (veja Ordenando). O toSorted ES2023 não mexe em alunos, que continua na ordem do arquivo.
nota.toFixed(1).padStart(6)
Primeiro vira texto com 1 casa ('9.5'), depois ganha espaços à esquerda até ter 6 caracteres (' 9.5'). Números alinhados pela direita, como numa planilha.
aluno.nome.padEnd(8)
Espaços à direita até 8 caracteres: os nomes alinhados pela esquerda.
.join(" ")
Junta as três notas formatadas com dois espaços entre elas.

Versão 4 · Conferir e gravar

A Ana tem outras turmas, e os arquivos nem sempre vêm perfeitos. Num deles, alguém digitou uma nota com vírgula, outra pessoa deixou uma nota em branco e outra escreveu "dez" por extenso:

Elisa,3,4.5,5

Repare no Bruno: 6,5 com vírgula virou duas colunas, porque a vírgula é justamente o separador do CSV. (Por isso as planilhas em português costumam salvar o CSV com ; separando as colunas.) A versão 4 confere cada linha antes de usar, deixa a Ana escolher o arquivo na linha de comando e grava o resultado em relatorio.csv:

// Notas da Turma, versão 4: arquivo escolhido, linhas conferidas e relatório gravado
import fs from "node:fs";

function situacao(media) {
  if (media >= 7) {
    return "Aprovado";
  }
  if (media >= 5) {
    return "Recuperação";
  }
  return "Reprovado";
}

// Transforma uma linha do CSV num aluno, ou devolve null se a linha estiver errada.
function lerAluno(linha) {
  const [nome, ...colunas] = linha.split(",");
  const notas = colunas.map(Number);
  if (nome === "" || colunas.length !== 3 || colunas.includes("") || notas.some(Number.isNaN)) {
    return null;
  }
  const media = notas.reduce((total, nota) => total + nota, 0) / notas.length;
  return { nome, notas, media };
}

const arquivo = process.argv[2] ?? "turma.csv";
if (!fs.existsSync(arquivo)) {
  console.error(`Arquivo não encontrado: ${arquivo}`);
  process.exit(1);

const texto = fs.readFileSync(arquivo, "utf8");
const [cabecalho, ...linhas] = texto.trim().split("\n");

const alunos = [];

  const aluno = lerAluno(linha);

    console.warn(`Linha ${i + 2} ignorada: ${linha}`);

Formas diferentes de fazer

Converter as notas: map(Number) × map(parseInt)

$ node
Welcome to Node.js v24.22.0.
Type ".help" for more information.
> "Ana,8.5,7,9".split(",")
[ 'Ana', '8.5', '7', '9' ]
> const [nome, ...colunas] = "Ana,8.5,7,9".split(",")
undefined
> colunas.map(Number)
[ 8.5, 7, 9 ]
> colunas.map(parseInt)
[ 8, NaN, NaN ]
> .exit

O map(parseInt) é uma pegadinha famosa. O map chama a função com dois valores: o item e a posição (0, 1, 2). O Number ignora o segundo; o parseInt o entende como a base do número: parseInt('7', 1) e parseInt('9', 2) não fazem sentido e dão NaN. E mesmo o primeiro saiu errado: parseInt('8.5') corta as casas decimais e dá 8. Para notas, use map(Number) (ou map((texto) => parseFloat(texto))). Veja Conversão.

Ler o CSV: à mão × uma biblioteca

FormaQuando usar
split("\n") e split(","), como neste projetoArquivos simples, que você mesmo controla: sem vírgulas nem quebras de linha dentro dos valores.
Um pacote do npm para CSVArquivos de verdade, vindos de outras pessoas: o CSV permite valores entre aspas com vírgulas dentro ("Silva, Ana",8.5), e o split(",") cortaria no lugar errado. Veja npm.

Ordenar: toSorted × sort

O alunos.sort(…) também ordena, mas muda o próprio array alunos (e o devolve). O toSorted devolve uma cópia ordenada e deixa o original em paz. Neste projeto tanto faz; quando outra parte do programa ainda precisa da ordem do arquivo, prefira o toSorted.

Resumo

  • Um CSV é texto: readFileSync lê, split("\n") corta as linhas e split(",") corta as colunas. O trim() evita a linha vazia do fim.
  • const [cabecalho, ...linhas] separa o cabeçalho dos dados numa linha só.
  • Tudo o que vem de um arquivo é texto: converta com map(Number) antes de somar, ou o + junta em vez de somar.
  • reduce soma, toFixed arredonda para mostrar, padStart/padEnd alinham as colunas, toSorted ordena sem mexer no original.
  • Confira cada linha antes de usar: número de colunas, coluna vazia (Number("") é 0!) e NaN. Avise e ignore a linha, em vez de calcular errado.
  • writeFileSync grava o resultado; array.join("\n") + "\n" monta o texto do arquivo.
