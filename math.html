JavaScript Math

Os operadores aritméticos (+, -, *, /, %, **) fazem as contas de escola. Para o resto (arredondar um preço, achar a maior nota da turma, calcular a área de uma pizza, tirar uma raiz quadrada) o JavaScript traz uma caixa de ferramentas pronta, que já vem em todo programa, sem instalar nada: o objeto Math ("matemática", em inglês).

Você vai aprender
  • O que é o Math e como se usa uma ferramenta dele: Math.nome(valor).
  • Os quatro jeitos de arredondar: Math.round, Math.floor, Math.ceil e Math.trunc, e a diferença entre eles com números negativos.
  • Como arredondar para 2 casas decimais.
  • Como achar o maior e o menor valor com Math.max e Math.min, inclusive de um array.
  • Math.abs, Math.pow, Math.sqrt, Math.PI e outras ferramentas.
  • Os erros reais: math is not defined, Math is not a constructor e os NaN que aparecem sem erro.

Todos os programas desta aula rodaram no Node.js 24 da máquina da Ana (usuária ana, computador notebook), com node arquivo.js. O Math é da linguagem JavaScript: funciona igual no Node e no navegador.

A ideia: a calculadora científica na gaveta

Na gaveta da padaria tem uma calculadora científica. Ninguém precisa montar uma: ela já está lá, com os botões prontos (√, π, x²…). Você só aperta o botão certo e informa o número. O Math é essa calculadora:

  • ele já existe em todo programa (é um objeto embutido, em inglês built-in);
  • cada "botão" é uma função guardada dentro dele, que você chama com ponto: Math.round(2.7) quer dizer "o botão round da calculadora Math, aplicado a 2.7";
  • ele também guarda algumas constantes famosas, como o π: Math.PI (sem parênteses, porque não é um botão, é um valor).

O typeof Math responde 'object': o Math é um objeto, só que um objeto especial, que você não cria. O Object [Math] {} parece vazio porque o Node não lista as ferramentas embutidas, mas elas estão lá. Escreva sempre com M maiúsculo: o JavaScript diferencia maiúsculas de minúsculas.

1. Arredondar: round, floor, ceil e trunc

A balança da padaria marcou 2,7 kg de pão. Existem quatro jeitos de transformar isso num número inteiro, e cada um serve para uma coisa:

const peso = 2.7;

console.log(Math.round(peso));
console.log(Math.floor(peso));
console.log(Math.ceil(peso));
console.log(Math.trunc(peso));

$ node arredondar.js
3
2
3
2
Math.round(peso) → 3
round = "arredondar". O arredondamento da escola: vai para o inteiro mais perto. 2,7 está mais perto de 3. Quando está bem no meio (4.5), sobe: 5.
Math.floor(peso) → 2
floor = "chão". Sempre para baixo, para o inteiro menor ou igual.
Math.ceil(peso) → 3
ceil (de ceiling) = "teto". Sempre para cima, para o inteiro maior ou igual.
Math.trunc(peso) → 2
trunc (de truncate) = "cortar". Joga fora a parte depois do ponto, sem pensar em cima ou baixo.

Com números positivos, floor e trunc dão o mesmo resultado. A diferença aparece com negativos, como a temperatura de −2,7 °C numa madrugada fria:

const temperatura = -2.7;

console.log(Math.round(temperatura));
console.log(Math.floor(temperatura));
console.log(Math.ceil(temperatura));
console.log(Math.trunc(temperatura));
console.log(Math.round(2.5), Math.round(-2.5));

$ node negativos.js
-3
-3
-2
-2
3 -2

Pense numa régua (uma reta numérica): "para baixo" é para a esquerda, para o lado dos números menores. −3 é menor que −2,7, então o floor (chão) vai para −3. Já o trunc só corta o .7 e fica com −2. Veja também a última linha: no meio exato, o Math.round sempre vai para o lado maior, então 2.5 vira 3, mas -2.5 vira -2 (e não −3, como muita gente espera).

Para que serve cada um: os sacos de pão

A padaria precisa embalar 50 pães em sacos de 12. Quantos sacos usar? Aqui arredondar para o mais perto daria a resposta errada: o que sobra também precisa de saco.

const paes = 50;
const porSaco = 12;

const sacos = Math.ceil(paes / porSaco);
const sacosCheios = Math.floor(paes / porSaco);
const sobra = paes % porSaco;

console.log(`Sacos necessários: ${sacos}`);
console.log(`Sacos cheios: ${sacosCheios}, e sobram ${sobra} pães`);

$ node caixas.js
Sacos necessários: 5
Sacos cheios: 4, e sobram 2 pães

50 / 12 dá 4,1666…. O Math.ceil sobe para 5 sacos (4 cheios e 1 com os 2 pães que sobram); o Math.floor conta só os sacos cheios; e o % (o resto da divisão, veja Operadores Aritméticos) diz quantos pães sobram.

Missão: a Ana comprou 30 ovos e quer guardar em caixas de 12. O programa diz 2 caixas, mas aí sobram ovos fora da caixa. Troque o arredondamento para o programa responder Caixas: 3.

2. Arredondar para 2 casas decimais

O Math.round só arredonda para inteiro. Para dinheiro, a gente quer 2 casas. O truque: multiplicar por 100, arredondar, e dividir por 100 de volta.

const precoKg = 18.9;
const peso = 0.735;
const preco = precoKg * peso;

console.log(preco);
console.log(Math.round(preco * 100) / 100);
console.log(preco.toFixed(2));

$ node duas-casas.js
13.891499999999999
13.89
13.89
13.891499999999999
O preço de 735 g de um pão de R$ 18,90 o quilo, com todas as casas que a conta gerou (e um "999…" no fim, por causa da precisão dos números do computador: veja NaN, Infinity e a Precisão).
Math.round(preco * 100) / 100
preco * 100 = 1389,15 → Math.round = 1389 → dividido por 100 = 13.89. O resultado é um número, que você pode usar em outras contas.
preco.toFixed(2)
Outro caminho, que não é do Math: um método dos próprios números que devolve um texto ("13.89") com exatamente 2 casas. É o jeito de mostrar o valor; ele tem aula própria em Formatando Números.

Para 1 casa, troque o 100 por 10; para 3 casas, por 1000.

3. O maior e o menor: Math.max e Math.min

const notas = [7.5, 9, 4, 8.5];

console.log(Math.max(7.5, 9, 4, 8.5));
console.log(Math.min(7.5, 9, 4, 8.5));
console.log(Math.max(...notas));
console.log(Math.min(...notas));
console.log(Math.max(notas));
console.log(Math.max());

$ node maxmin.js
9
4
9
4
NaN
-Infinity
Math.max(7.5, 9, 4, 8.5) → 9
max = "máximo". Recebe quantos números você quiser, separados por vírgula, e devolve o maior. O Math.min ("mínimo") devolve o menor.
Math.max(...notas) → 9
Quando os números estão num array, os três pontinhos (..., o spread, "espalhar") tiram os itens de dentro do array e entregam um por um, como se você tivesse digitado Math.max(7.5, 9, 4, 8.5). Veja Spread e Rest.
Math.max(notas) → NaN
Sem os três pontos, o Math.max recebe um valor só, que é o array inteiro. Um array não é um número, então a resposta é NaN ("não é um número"). Não aparece erro: é um engano silencioso. Veja Quando dá errado.
Math.max() → -Infinity
Sem nenhum número, o "maior de nada" é -Infinity (menos infinito). Acontece com Math.max(...[]), um array vazio. O Math.min() vazio dá Infinity.

Um uso esperto: manter um valor dentro de um limite

Nota tem de ficar entre 0 e 10. Juntando max e min, dá para "prender" qualquer valor dentro de um intervalo:

function limitar(valor, minimo, maximo) {
  return Math.min(Math.max(valor, minimo), maximo);
}

console.log(limitar(12, 0, 10));
console.log(limitar(-3, 0, 10));
console.log(limitar(7.5, 0, 10));

$ node limitar.js
10
0
7.5

De dentro para fora: Math.max(valor, 0) não deixa passar nada abaixo de 0; depois, Math.min(…, 10) não deixa passar nada acima de 10.

4. Distância até o zero: Math.abs

abs vem de "absoluto": o valor absoluto é o número sem o sinal, a distância dele até o zero. Útil quando o sinal atrapalha a frase:

const saldoInicial = 120;
const gastos = 155.5;
const diferenca = saldoInicial - gastos;

console.log(`Diferença: ${diferenca}`);
console.log(`A Ana ficou devendo R$ ${Math.abs(diferenca)}`);

$ node saldo.js
Diferença: -35.5
A Ana ficou devendo R$ 35.5

Math.pow(2, 10) e 2 ** 10
pow de power, "potência": 2 elevado a 10. O operador ** faz a mesma coisa e é o jeito mais usado hoje.
Math.sqrt(81) → 9
sqrt de square root, "raiz quadrada". O Math.cbrt (cube root) é a raiz cúbica.

O "sinal": -1 para negativos, 0 para zero e 1 para positivos.

O Math.PI é o π (3,14159…), a razão entre o contorno e o diâmetro de qualquer círculo. A área de um círculo é π vezes o raio ao quadrado. Quanto de pizza vem numa pizza grande de 35 cm?

const diametro = 35;
const raio = diametro / 2;
const area = Math.PI * raio ** 2;

console.log(Math.PI);
console.log(`Área da pizza: ${area} cm²`);
console.log(`Área da pizza: ${Math.round(area)} cm²`);

$ node pizza.js
3.141592653589793
Área da pizza: 962.1127501618741 cm²
Área da pizza: 962 cm²

O raio ** 2 é calculado antes da multiplicação, porque a potência tem precedência maior (veja Precedência dos Operadores). Outras constantes: Math.E (o número de Euler, 2.718281828459045 no lab) e Math.SQRT2 (a raiz de 2).

"Math não é um construtor": não dá para fabricar outro Math, como se faz com new Date(). Existe uma calculadora só, e ela já está pronta. Como consertar: use direto: Math.round(…).

Passou o array sem os três pontos: NaN

Na seção 3, Math.max(notas) deu NaN sem nenhum erro. Como consertar: Math.max(...notas). Se o array puder estar vazio, lembre que o resultado será -Infinity: teste notas.length === 0 antes.

Mandou texto em vez de número 
console.log(Math.round("2.7"));
console.log(Math.round("2,7"));
console.log(Math.max(5, "10", 3));
console.log(Math.max(5, "dez", 3));

$ node texto.js

NaN

NaN

As ferramentas do Math tentam converter texto em número sozinhas (veja Conversão Automática). "2.7" (com ponto) dá certo; "2,7" (com vírgula, como se escreve no Brasil) e "dez" viram NaN, e um único NaN estraga o Math.max inteiro. Como consertar: converta e confira o que veio do teclado ou de um arquivo antes (Number(texto.replace(",", "."))), como em Conversão.

Esqueceu os parênteses 
console.log(Math.round);
console.log(Math.round + 1);

$ node sem-parenteses.js
[Function: round]
function round() { [native code] }1

Sem os parênteses, você não apertou o botão, só apontou para ele: o Node mostra a própria função ([Function: round]). Somada com 1, a função vira texto e sai essa linha esquisita. Como consertar: Math.round(valor). (Já o Math.PI não leva parênteses: ele é um valor, não uma função.)

Resumo

  • Math é um objeto embutido, pronto em todo programa (no Node e no navegador), com ferramentas de matemática: Math.nome(valor). Escreva com M maiúsculo e não use new.
  • Arredondar: round (o mais perto), floor (para baixo), ceil (para cima), trunc (corta). Com negativos, "para baixo" é para o lado dos menores: Math.floor(-2.7) é -3.
  • 2 casas: Math.round(x * 100) / 100 (número) ou x.toFixed(2) (texto, para mostrar).
  • Math.max e Math.min recebem números separados por vírgula; com um array, use ...: Math.max(...notas).
  • Math.abs tira o sinal, ** (ou Math.pow) faz potência, Math.sqrt tira a raiz, Math.PI é o π.
  • Muitos enganos com o Math não dão erro: dão NaN (array sem ..., texto com vírgula, raiz de negativo). Se aparecer NaN, confira o que entrou na função.
