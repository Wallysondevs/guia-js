JavaScript Funções como Valores (Callbacks)

No JavaScript, uma função é um valor, como um número ou um texto. Dá para guardá-la numa variável, colocá-la num objeto, passá-la para outra função e até devolvê-la com return. Quando você entrega uma função para outra função chamar depois, ela se chama callback (em inglês, "ligar de volta", como quem deixa o telefone para retorno). Você já usou callbacks sem saber: em lista.map(…) e lista.filter(…).

Você vai aprender
  • Que uma função pode ser guardada numa variável e mostrada com console.log ([Function: saudar]).
  • A diferença entre saudar (a função) e saudar() (o resultado de chamá-la).
  • Como escrever uma função que recebe outra função (o callback), com nome ou anônima.
  • Os callbacks dos arrays: forEach, map, filter, toSorted.
  • Funções que devolvem funções, e funções guardadas em objetos.
  • Os erros reais: acao is not a function, number 10 is not a function e o map que devolve undefined.

A ideia: entregar a receita, e não o bolo

A Ana vai viajar e deixa instruções para a vizinha que vai cuidar da padaria. Ela pode deixar duas coisas bem diferentes:

  • Um bolo pronto: a vizinha recebe o resultado. É o que acontece quando você escreve fazerBolo(), com parênteses: a função roda agora e o que chega é o que ela devolveu.
  • O cartão com a receita: a vizinha recebe as instruções, e decide quando e quantas vezes fazer o bolo (um por dia, dois no sábado). É o que acontece quando você escreve fazerBolo, sem parênteses: você entrega a função em si.

Passar uma função para outra é entregar o cartão da receita. Quem recebe é que vai "fazer o bolo" (chamar a função) na hora certa.

3. Passando uma função para outra: o callback

Esta função repete uma ação várias vezes. Qual ação? Quem chama é que decide, entregando uma função:

function repetir(vezes, acao) {
  for (let i = 1; i <= vezes; i++) {
    acao(i);
  }
}

function mostrarVolta(numero) {
  console.log("Volta", numero);
}

repetir(3, mostrarVolta);
function repetir(vezes, acao)
acao é um parâmetro como outro qualquer. A diferença é que esperamos que ele receba uma função.
acao(i);
Dentro do laço, repetir chama a função que recebeu, passando o número da volta. É aqui que o callback "liga de volta".
repetir(3, mostrarVolta);
Entrega mostrarVolta sem parênteses: o cartão da receita. Quem vai chamá-la (3 vezes) é o repetir.
$ node callback.js
Volta 1
Volta 2
Volta 3

Callbacks anônimos

Quando a função só é usada ali, é comum escrevê-la direto na chamada, sem nome (uma função anônima), com function ou com arrow:

function repetir(vezes, acao) {
  for (let i = 1; i <= vezes; i++) {
    acao(i);
  }
}

repetir(2, function (numero) {
  console.log(`Pão nº ${numero} saindo do forno`);
});

repetir(3, (numero) => console.log("*".repeat(numero)));

$ node anonima.js
Pão nº 1 saindo do forno
Pão nº 2 saindo do forno
*
**
***

Repare no fim da primeira chamada: });. A } fecha a função, o ) fecha a chamada do repetir, e o ; termina a instrução. É o formato que você mais vai ver em código JavaScript.

Um callback que devolve valor

O callback também pode devolver algo para quem o chamou. Aqui, a mesma calcular faz contas diferentes conforme a função que recebe:

function calcular(a, b, operacao) {
  const resultado = operacao(a, b);
  console.log(`Resultado: ${resultado}`);
}

const somar = (x, y) => x + y;
const multiplicar = (x, y) => x * y;

calcular(6, 3, somar);
calcular(6, 3, multiplicar);
calcular(6, 3, (x, y) => x - y);

$ node calcular.js
Resultado: 9
Resultado: 18
Resultado: 3

Missão: a função cumprimentarTodos recebe uma lista e um callback, e chama o callback para cada nome. Crie a função bomDia (que recebe um nome e mostra Bom dia, NOME!) e passe-a, sem parênteses, na chamada.

function cumprimentarTodos(nomes, callback) {
  for (const nome of nomes) {
    callback(nome);
  }
}

4. Os callbacks dos arrays

Os métodos de array que percorrem os itens são o uso mais comum de callbacks. Cada um chama a sua função uma vez por item e faz algo diferente com o que ela devolve:

const precos = [4.5, 12, 0.8, 25];

const caro = (preco) => preco > 10;
const comAumento = (preco) => preco + 1;

console.log(precos.filter(caro));
console.log(precos.map(comAumento));
console.log(precos.toSorted((a, b) => a - b));
precos.forEach((preco, i) => console.log(`${i}: R$ ${preco}`));

$ node arrays.js
[ 12, 25 ]              « filter: ficou com os itens em que o callback devolveu true
[ 5.5, 13, 1.8, 26 ]    « map: um array novo com o que o callback devolveu
[ 0.8, 4.5, 12, 25 ]    « toSorted: o callback compara dois itens
0: R$ 4.5               « forEach: só chama, para cada item (e passa também a posição)
1: R$ 12
2: R$ 0.8
3: R$ 25

5. Funções que devolvem funções

Se uma função é um valor, ela pode ser devolvida com return. Isto é uma "fábrica" de funções:

function criarMultiplicador(fator) {
  return (n) => n * fator;
}

const dobro = criarMultiplicador(2);
const triplo = criarMultiplicador(3);
console.log(dobro(10));
console.log(triplo(10));
console.log(typeof dobro);

$ node fabrica.js
20
30
function

criarMultiplicador(2) não multiplica nada: ela fabrica e devolve uma função nova, que multiplica por 2. Repare num detalhe curioso: quando dobro(10) roda, a criarMultiplicador já terminou faz tempo, e mesmo assim a função devolvida ainda lembra que fator era 2. Esse "lembrar" tem nome, closure, e é o assunto da próxima aula: Closures.

6. Funções dentro de objetos e arrays

Como qualquer valor, funções podem ser propriedades de um objeto (é isso que um método é) ou itens de um array. Um uso prático: uma "tabela" que escolhe a função pelo nome.

const operacoes = {
  "+": (a, b) => a + b,
  "-": (a, b) => a - b,
  "*": (a, b) => a * b,
  "/": (a, b) => a / b,
};

const sinal = "*";
console.log(operacoes[sinal](7, 6));
console.log(Object.keys(operacoes));

$ node tabela.js
42
[ '+', '-', '*', '/' ]

operacoes[sinal] pega a função guardada na chave "*", e o (7, 6) logo depois a chama. Uma calculadora sem nenhum if nem switch.

Callbacks que esperam: um gostinho do assíncrono

Alguns callbacks não são chamados na hora, e sim mais tarde. O setTimeout recebe uma função e a chama depois de um tempo (em milissegundos):

console.log("Pus o bolo no forno.");
setTimeout(() => {
  console.log("Bolo pronto!");
}, 1000);
console.log("Enquanto isso, lavo a louça.");

$ node timeout.js
Pus o bolo no forno.
Enquanto isso, lavo a louça.
Bolo pronto!     « apareceu 1 segundo depois

A terceira linha do código aparece antes da segunda! Esse é o mundo do código assíncrono, das aulas setTimeout e setInterval e Callbacks Assíncronos.

function relatorio(produtos) {
  // devolva um array com transformar(produto) para cada produto
}

const caros = relatorio(produtos.filter((p) => p.preco > 10), (p) => p.nome.toUpperCase());
console.log(caros);
console.log(relatorio(produtos, (p) => p.nome));

function relatorio(produtos, transformar) {

Resumo

  • Função é um valor: dá para guardar em variável, pôr em objeto/array, passar como argumento e devolver com return.
  • f é a função; f() é o resultado de chamá-la. Para entregar uma função, sem parênteses.
  • Callback é a função entregue para outra chamar: repetir(3, mostrarVolta), precos.filter(caro), setTimeout(() => …, 1000).
  • forEach, map, filter, find, toSorted e reduce chamam o seu callback uma vez por item.
  • Uma função pode fabricar e devolver outra, que lembra os valores de onde nasceu (próxima aula: Closures).
  • … is not a function = tentou chamar algo que não é função (quase sempre um () a mais na hora de passar o callback).
