JavaScript Date e Intl

Esta é a página de consulta rápida das datas no JavaScript: o objeto Date (criar uma data, ler o dia, o mês e a hora, somar dias, calcular quantos dias faltam) e o Intl (de internationalization, "internacionalização"), que escreve datas, listas e tempos relativos do jeito brasileiro: terça-feira, 10 de março de 2026, ontem, pão, leite e café.

Como ler as tabelas
  • Nos exemplos, d é const d = new Date(2026, 2, 10, 14, 30): 10 de março de 2026, às 14h30 (o 2 é março, porque os meses começam em 0; veja abaixo).
  • Exemplo é o que você digitaria depois do > do modo interativo do Node; Resultado é o que o Node.js v24.22.0 respondeu no computador da Ana, que está no horário de Brasília (3 horas atrás do UTC, o horário de referência mundial).
  • O modo interativo mostra uma data no formato do UTC, com um Z no fim: d aparece como 2026-03-10T17:30:00.000Z, que é 14h30 em Brasília. Não é erro: é a mesma hora, escrita no relógio de referência.
  • Os resultados que dependem do relógio (new Date() sem nada, Date.now()) mudam a cada vez; por isso as tabelas usam datas fixas.
Os meses começam em 0

Em new Date(ano, mes, dia), janeiro é 0, fevereiro é 1… dezembro é 11. O dia, não: dia 1 é 1. Esse é o erro mais comum com datas no JavaScript. O getMonth() segue a mesma regra: para mostrar o mês, some 1.

Pule direto para o grupo que você procura:

  • Criar uma data: new Date Date.now Date.UTC
  • Ler as partes: getFullYear getMonth getDate getDay getHours getTime
  • Mudar e calcular: setDate setMonth, diferença em dias, comparar
  • Formatar: toLocaleDateString toLocaleTimeString toISOString Intl.DateTimeFormat
  • Outros formatadores do Intl: RelativeTimeFormat ListFormat PluralRules Collator
  • Quando dá errado

Missão: o programa deveria dizer quantos dias faltam do dia 19 de outubro até o Natal, mas mostra um número enorme: são milissegundos. Divida a diferença por 1000 * 60 * 60 * 24 (um dia em milissegundos) e arredonde com Math.round, para que saia Faltam 67 dias.

const hoje = new Date(2026, 9, 19);
const natal = new Date(2026, 11, 25);

const diferenca = natal - hoje;
console.log(`Faltam ${diferenca} dias`);

const hoje = new Date(2026, 9, 19);
const natal = new Date(2026, 11, 25);

const diferenca = natal - hoje;
const dias = Math.round(diferenca / (1000 * 60 * 60 * 24));
console.log(`Faltam ${dias} dias`);

E o Temporal?

O Temporal é a nova API de datas do JavaScript, que corrige os problemas do Date (os meses começam em 1, os fusos são claros). Ele ainda não vem ligado no Node.js 24: no lab, typeof Temporal deu 'undefined'. Por enquanto, use o Date com os cuidados desta página. Veja Novidades Recentes.

Resumo

  • new Date(ano, mes, dia), com o mês de 0 a 11. Texto ISO com hora ("2026-03-10T14:30:00") é lido no horário local; só a data ("2026-03-10") é lida em UTC.
  • Ler: getFullYear, getMonth (+1 para mostrar), getDate, getDay (0 = domingo), getHours, getTime.
  • Somar dias: d.setDate(d.getDate() + n). Diferença em dias: Math.round((d2 - d1) / 86400000).
  • Comparar: < e > funcionam; para igualdade, compare getTime().
  • Formatar: toLocaleDateString("pt-BR"), com opções (weekday: "long", month: "long") ou Intl.DateTimeFormat. Para guardar: toISOString().
  • Intl também tem RelativeTimeFormat, ListFormat, PluralRules e Collator.
