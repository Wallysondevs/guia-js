JavaScript Métodos de String

Esta é a página de consulta rápida dos métodos de string: as funções que todo texto já traz consigo, chamadas com um ponto depois do texto (nome.toUpperCase()). Elas medem, procuram, cortam, mudam maiúsculas, tiram espaços, dividem e substituem. Cada linha tem um exemplo, o resultado real e a aula que explica com calma.

Como ler as tabelas
  • Nos exemplos, s é o texto const s = "Padaria do Bairro".
  • Exemplo é o que você digitaria depois do > do modo interativo do Node; Resultado é o que o Node.js v24.22.0 respondeu no computador da Ana. Textos aparecem entre aspas simples ('Padaria'): é o modo interativo avisando que o resultado é uma string.
  • As posições começam em 0: em "Padaria", o P é a posição 0, o primeiro a é a posição 1.
Nenhum método muda o texto original

Strings são imutáveis: não dá para mudar uma letra lá dentro. Todo método devolve um texto novo, e o original fica como estava. Para guardar o resultado, atribua de novo: nome = nome.trim();. Veja no lab:

let nome = "ana";
nome[0] = "A";
console.log(nome);

nome.toUpperCase();
console.log(nome);

nome = nome[0].toUpperCase() + nome.slice(1);
console.log(nome);

$ node imutavel.js
ana
ana
Ana

O nome[0] = "A" foi ignorado sem aviso, e o nome.toUpperCase() sozinho calculou "ANA" e jogou fora. Só a última forma, que guarda o resultado em nome, funcionou.

Prefira o slice: ele funciona igual nos arrays e aceita negativo. O substr (com r no fim) é ainda mais antigo e está marcado como obsoleto: evite.

Experimente

Missão: o nome chegou com espaços sobrando e em minúsculas, e a saudação saiu Olá, ana !. Use trim() e toUpperCase() dentro do ${ } para que saia Olá, ANA!.

const nome = "  ana  ";

console.log(`Olá, ${nome}!`);

const nome = "  ana  ";

console.log(`Olá, ${nome.trim().toUpperCase()}!`);

No lab, o programa original mostrou Olá, ana ! e a solução, Olá, ANA!. Repare que os dois métodos foram encadeados: o trim() devolve "ana", e o toUpperCase() é chamado nesse texto novo.

Livre: teste os métodos com o nome da sua rua, do seu bairro ou da sua loja preferida. Antes de rodar, tente adivinhar cada resultado.

const loja = "Padaria do Bairro";

console.log(loja.length);
console.log(loja.toUpperCase());
console.log(loja.slice(0, 7));
console.log(loja.includes("Bairro"));
console.log(loja.split(" "));
console.log(loja.replaceAll("a", "4"));
console.log("7".padStart(3, "0"));

Resumo

  • Os métodos nunca mudam o texto original: guarde o resultado (nome = nome.trim();).
  • Tamanho e letras: length, s[i], at(-1) para a última.
  • Procurar: includes, startsWith, endsWith (dão true/false); indexOf dá a posição ou -1.
  • Cortar: slice(ini, fim), com negativos contando do fim.
  • Transformar: toUpperCase, toLowerCase, trim, padStart, repeat.
  • Dividir e juntar: split (texto → array) e join (array → texto).
  • Substituir: replace (a primeira), replaceAll (todas); com regex, match e matchAll.
  • Ordem de dicionário com acentos: localeCompare, não <.
