JavaScript Métodos de String

Uma string não é só um texto parado: ela vem com uma caixa de ferramentas. Quer o nome todo em maiúsculas? nome.toUpperCase(). Quer tirar os espaços que a pessoa digitou sem querer? email.trim(). Cada ferramenta dessas se chama método. Nesta aula você aprende o que é um método e conhece os mais usados para arrumar um texto: maiúsculas e minúsculas, espaços, preenchimento e repetição.

Você vai aprender
  • O que é um método e como se chama um: texto.metodo().
  • toUpperCase() e toLowerCase(): tudo em maiúsculas ou minúsculas.
  • trim(), trimStart() e trimEnd(): tirar espaços das pontas.
  • padStart() e padEnd(): completar até um tamanho (o pedido 00042, a lista de preços com pontinhos).
  • repeat(): repetir um texto.
  • Como encadear métodos, e por que o texto original nunca muda.
  • Os erros reais: esquecer os parênteses, errar maiúscula no nome do método, chamar um método de texto num número ou em undefined.

A ideia: o canivete suíço

Um canivete suíço é um objeto só, mas guarda várias ferramentas: a faca, a tesoura, o abridor. Para usar uma, você pega o canivete e escolhe a ferramenta.

Toda string do JavaScript é um canivete. As ferramentas são os métodos, e a escrita é sempre a mesma:

texto.toUpperCase()
texto
O canivete: a string (ou a variável que guarda a string) em que você vai usar a ferramenta.
.
O ponto quer dizer "dele": "o toUpperCase do texto".
toUpperCase
O nome do método, a ferramenta. Os nomes estão em inglês e em camelCase: to upper case, "para caixa alta" (maiúsculas). Cada maiúscula do nome importa.
( )
Os parênteses mandam usar a ferramenta. Alguns métodos precisam de informações aqui dentro (como padStart(5, "0")); outros não precisam de nada, mas os parênteses continuam obrigatórios.

Você já conhece uma "irmã" disso: o .length da aula Strings. Ele também vem depois do ponto, mas não tem parênteses, porque não é uma ferramenta que faz algo: é uma informação que a string já tem (uma propriedade). Regra prática: propriedade é um dado (.length); método é uma ação, e leva ().

1. Maiúsculas e minúsculas

const nome = "Ana Souza";

console.log(nome.toUpperCase());
console.log(nome.toLowerCase());
console.log("pão de açúcar".toUpperCase());
console.log(nome);

$ node caixa.js
ANA SOUZA
ana souza
PÃO DE AÇÚCAR
Ana Souza
toUpperCase()
Devolve uma cópia do texto com todas as letras em maiúsculas. Acentos e cedilha são respeitados (ã → Ã, ç → Ç).
toLowerCase()
Devolve uma cópia em minúsculas (lower case, "caixa baixa").
console.log(nome)
A última linha mostra que nome continua Ana Souza. Os métodos não mudam a string original (ela é imutável, como você viu em Strings): eles devolvem um texto novo.

Para que serve: comparar sem ligar para maiúsculas

A Ana pergunta "Quer sacola? (sim/não)" e a pessoa pode digitar Sim, SIM ou sim. Com ===, maiúscula e minúscula são diferentes. O truque é passar a resposta para minúsculas antes de comparar:

const resposta = "SIM";

console.log(resposta === "sim");
console.log(resposta.toLowerCase() === "sim");

$ node resposta.js
false
true

2. Tirando espaços das pontas: trim()

Quem digita num formulário às vezes deixa um espaço antes ou depois sem perceber. Para o computador, " ana@email.com" e "ana@email.com" são textos diferentes. O trim() (em inglês, "aparar") corta os espaços das pontas:

const digitado = "   ana@email.com  ";

console.log(`[${digitado}]`);
console.log(`[${digitado.trim()}]`);
console.log(`[${digitado.trimStart()}]`);
console.log(`[${digitado.trimEnd()}]`);
console.log(digitado.length, digitado.trim().length);
console.log(`[${"  pão   de   queijo  ".trim()}]`);

$ node aparar.js
[   ana@email.com  ]
[ana@email.com]
[ana@email.com  ]
[   ana@email.com]
18 13
[pão   de   queijo]

Os colchetes [ ] do exemplo estão ali só para você ver onde o texto começa e termina; espaço no fim de uma linha é invisível na tela.

  • trim() corta das duas pontas; trimStart(), só do começo (start); trimEnd(), só do fim (end).
  • Os espaços do meio ficam: pão de queijo continuou com os espaços repetidos. Para mexer no meio, existe o replaceAll (aula Substituindo).
  • Além do espaço, o trim() também corta tabulações (\t) e quebras de linha (\n) das pontas (veja Caracteres Especiais). Isso é útil com o que vem do teclado.

Missão: a Ana digitou o e-mail com espaços e letras maiúsculas. Arrume o texto com trim() e toLowerCase() para aparecer E-mail: ana.souza@email.com.

const digitado = "  Ana.Souza@Email.com ";
const email = digitado;
console.log(`E-mail: ${email}`);

const digitado = "  Ana.Souza@Email.com ";
const email = digitado.trim().toLowerCase();
console.log(`E-mail: ${email}`);

3. Completando até um tamanho: padStart() e padEnd()

A padaria numera as encomendas com 5 dígitos: 00042, 00117. O padStart (em inglês, pad é "enchimento", e start, "começo") completa um texto pela esquerda até ele ter o tamanho pedido:

const pedido = "42";

console.log(pedido.padStart(5, "0"));
console.log("117".padStart(5, "0"));
console.log("123456".padStart(5, "0"));
console.log("7".padStart(3));
console.log(`[${"7".padStart(3)}]`);

$ node preencher.js
00042
00117
123456
  7
[  7]
padStart(5, "0")
Dois valores entre os parênteses, separados por vírgula (os argumentos): o tamanho final (5) e o texto de enchimento ("0"). "42" tem 2 caracteres; faltam 3, então entram três zeros na frente.
"123456".padStart(5, "0")
Se o texto já tem o tamanho (ou mais), ele volta como está. O padStart nunca corta.
"7".padStart(3)
Sem o segundo argumento, o enchimento é o espaço. Bom para alinhar números à direita numa coluna.

O padEnd faz o mesmo pela direita. Com ele a Ana monta a tabela de preços da vitrine, com pontinhos entre o produto e o preço:

console.log("Pão francês".padEnd(20, ".") + "R$ 0.75");
console.log("Bolo de fubá".padEnd(20, ".") + "R$ 25");
console.log("Café".padEnd(20, ".") + "R$ 6");

$ node vitrine.js
Pão francês.........R$ 0.75
Bolo de fubá........R$ 25
Café................R$ 6

Todos os nomes foram completados até 20 caracteres, então os preços começam na mesma coluna. É um jeito mais firme de alinhar do que o \t da aula Caracteres Especiais, que desalinha com nomes compridos.

4. Repetindo: repeat()

console.log("=".repeat(20));
console.log("ha".repeat(3));
console.log("[" + "#".repeat(7) + "-".repeat(3) + "] 70%");
console.log(`[${"ab".repeat(0)}]`);

$ node repetir.js
====================
hahaha
[#######---] 70%
[]

texto.repeat(n) devolve o texto emendado n vezes. A terceira linha monta uma barra de progresso com dois repeat. Com 0, sai a string vazia.

5. Encadeando métodos

Como cada método devolve uma string nova, dá para chamar outro método em cima do resultado, tudo na mesma linha. Isso se chama encadear:

const digitado = "   bia lima ";
const etiqueta = digitado.trim().toUpperCase().padEnd(12, "*");
console.log(`[${etiqueta}]`);

$ node encadear.js
[BIA LIMA****]

O JavaScript lê da esquerda para a direita, e cada passo trabalha no resultado do anterior:

PassoResultado
digitado" bia lima "
.trim()"bia lima"
.toUpperCase()"BIA LIMA"
.padEnd(12, "*")"BIA LIMA****"
Guardando o resultado

Como os métodos não mudam o original, para "ficar" com o texto arrumado você precisa guardar o resultado: numa variável nova (const email = digitado.trim();) ou na mesma, se ela for let (nome = nome.trim();).

Formas diferentes de fazer a mesma coisa

O número do pedido com zeros na frente pode ser montado de três jeitos:

const numero = 42;

const jeito1 = String(numero).padStart(5, "0");
const jeito2 = `${numero}`.padStart(5, "0");
const jeito3 = "0".repeat(5 - String(numero).length) + numero;

console.log(jeito1, jeito2, jeito3);

$ node formas.js
00042 00042 00042

O padStart é método de texto, e numero é um número: por isso os dois primeiros jeitos transformam o número em texto antes, com String(numero) (veja Conversão) ou com um template string. O terceiro calcula quantos zeros faltam e usa o repeat: funciona, mas é mais difícil de ler, e quebra se o número tiver mais de 5 dígitos (o repeat de um número negativo é erro).

Resumo

  • Um método é uma ferramenta que o valor carrega: texto.metodo(), sempre com parênteses. Propriedades, como .length, não têm parênteses.
  • toUpperCase()/toLowerCase() mudam a caixa das letras (bom para comparar respostas).
  • trim() tira espaços das pontas (trimStart/trimEnd, de uma ponta só); os do meio ficam.
  • padStart(n, "0") e padEnd(n, ".") completam até n caracteres; repeat(n) repete.
  • Os métodos devolvem um texto novo e não mudam o original: guarde o resultado. Dá para encadear: texto.trim().toLowerCase().
  • Erros comuns: sem parênteses ([Function: …]), maiúscula errada ou método de texto num número (is not a function), variável undefined (Cannot read properties of undefined).
