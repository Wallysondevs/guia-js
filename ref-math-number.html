JavaScript Math e Number

Esta é a página de consulta rápida das contas prontas do JavaScript. O Math é uma caixa de ferramentas matemáticas (arredondar, raiz quadrada, maior e menor, sorteio). O Number converte textos em números e responde perguntas sobre eles ("é inteiro?", "é NaN?"). E os métodos dos números formatam o resultado para gente ler: duas casas decimais, vírgula brasileira, R$.

Como ler as tabelas
  • Exemplo é o que você digitaria depois do > do modo interativo do Node; Resultado é o que o Node.js v24.22.0 respondeu no computador da Ana. Textos aparecem entre aspas simples ('3.14'): repare que toFixed e toLocaleString devolvem texto, não número.
  • Um número logo antes de um ponto precisa de parênteses: (3.14159).toFixed(2). Com uma variável, não: preco.toFixed(2).
  • O JavaScript escreve a casa decimal com ponto (3.5). A vírgula brasileira só aparece quando você formata com "pt-BR".

Missão: a Ana tem 25 ovos e cada caixa leva 12. O programa diz que ela precisa de 2 caixas, mas aí sobra 1 ovo fora! Troque o Math.floor pela função que arredonda para cima, para que saia Caixas: 3.

const ovos = 25;
const porCaixa = 12;

const caixas = Math.floor(ovos / porCaixa);
console.log(`Caixas: ${caixas}`);

const ovos = 25;
const porCaixa = 12;

const caixas = Math.ceil(ovos / porCaixa);
console.log(`Caixas: ${caixas}`);

No lab, com Math.floor saiu Caixas: 2; com Math.ceil, Caixas: 3.

O espaço do R$ não é um espaço comum

Entre o R$ e o número, o formatador põe um espaço que não quebra (o caractere de código 160, e não o espaço comum, de código 32), para o R$ nunca ficar sozinho no fim de uma linha. Na tela é igual, mas na comparação não: no lab, (19.9).toLocaleString("pt-BR", { style: "currency", currency: "BRL" }) === "R$ 19,90" (digitado com espaço comum) deu false. Leve isso em conta se for comparar ou testar textos formatados.

Missão: 3 cadernos de R$ 19,90 deram um total cheio de casas: Total: R$ 59.699999999999996. Use toFixed(2) dentro do ${ } para mostrar Total: R$ 59.70.

const preco = 19.9;
const quantidade = 3;

const total = preco * quantidade;
console.log(`Total: R$ ${total}`);

const preco = 19.9;
const quantidade = 3;

const total = preco * quantidade;
console.log(`Total: R$ ${total.toFixed(2)}`);

$ node total.js
Total: R$ 59.699999999999996
$ node total2.js
Total: R$ 59.70

Para o formato brasileiro completo (R$ 59,70, com vírgula), troque o toFixed(2) pelo toLocaleString da tabela acima.

Quando dá errado

A maioria das contas erradas não dá erro: dá NaN ou Infinity e o programa segue. Quando aparecer NaN, procure o valor que não era número (veja NaN, Infinity e a Precisão). Os erros de verdade mais comuns:

Resumo

  • Arredondar: Math.round (mais perto), Math.floor (para baixo), Math.ceil (para cima), Math.trunc (corta).
  • Math.max/min (com ... para arrays), Math.abs, Math.sqrt, Math.PI; sorteio: Math.floor(Math.random() * n) + 1.
  • Texto → número: Number (o texto todo), parseInt/parseFloat (o começo do texto). Vírgula decimal não funciona.
  • Perguntas: Number.isInteger, Number.isNaN (não o isNaN antigo), Number.isFinite.
  • 0.1 + 0.2 não é exatamente 0.3: compare com margem e formate só na hora de mostrar.
  • Formatar (devolvem texto): toFixed(2); em reais, toLocaleString("pt-BR", { style: "currency", currency: "BRL" }) ou Intl.NumberFormat.
  • Inteiros gigantes: BigInt (10n), sem misturar com números comuns.
