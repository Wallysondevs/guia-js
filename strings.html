JavaScript Strings

Nome de cliente, endereço, mensagem de boas-vindas, a lista de compras: boa parte do que um programa guarda e mostra é texto. Em programação, um texto se chama string (em inglês, "cordão", "fileira": uma fileira de letras, como contas num colar). Você já usou strings desde o primeiro programa, no console.log("Olá, mundo!"). Nesta aula você aprende o que elas são de verdade e o básico para trabalhar com elas.

Você vai aprender
  • Como criar uma string com aspas duplas "…", simples '…' ou crase `…`, e qual usar.
  • A string vazia "" e o typeof de um texto.
  • Como saber o tamanho de um texto com .length.
  • Como juntar textos com + e +=, e o que acontece quando um dos lados é número.
  • Como comparar textos (===, maiúsculas contam) e pegar uma letra com [0].
  • Por que uma string não muda depois de criada.
  • Os erros reais: aspas sem fechar, aspas dentro de aspas, e o .lenght escrito errado.

Todos os programas desta aula rodaram no Node.js 24 da máquina da Ana (usuária ana, computador notebook), com node arquivo.js. Você pode rodar cada um no editor do guia.

A ideia: o colar de contas com letras

Pense naqueles colares de contas com letras, que as crianças montam com o próprio nome. Cada conta tem uma letra (ou um espaço, ou um sinal), e a ordem importa: A-N-A é um colar, N-A-A é outro. Uma string é isso: uma fileira de caracteres em ordem.

  • O colar tem um tamanho: quantas contas tem.
  • Cada conta tem uma posição: a primeira, a segunda…
  • Dá para emendar dois colares num maior.
  • Um colar pode ter zero contas: só o fio. É a string vazia.

Para o JavaScript saber onde o texto começa e termina, ele vem entre aspas. As aspas não fazem parte do texto: são o "fecho" do colar.

1. Criando strings: três tipos de aspas

const nome = "Ana";
const cidade = 'Recife';
const bairro = `Boa Viagem`;

console.log(nome);
console.log(cidade);
console.log(bairro);
console.log(typeof nome);
"Ana"
Aspas duplas. É o jeito que este guia usa (e o mais comum em projetos).
'Recife'
Aspas simples (o apóstrofo). Para o JavaScript, é exatamente o mesmo texto que "Recife".
`Boa Viagem`
Crase (o acento grave, sozinho; no teclado ABNT, Shift + a tecla à direita do P, e depois a barra de espaço). Cria um template string, que tem poderes extras (encaixar variáveis com ${ } e quebrar linha). Eles têm aula própria: Template Strings.
typeof nome
O typeof diz o tipo do valor: string.
$ node aspas.js

Repare que o console.log mostra o texto sem as aspas: elas só servem para o JavaScript ler o código. A única regra é fechar com o mesmo tipo de aspa que abriu.

No modo interativo, as aspas aparecem

No modo interativo do Node (o >), quando você digita um texto sozinho, o Node mostra o valor, e não o texto impresso. Para deixar claro que é uma string, ele põe aspas simples em volta, mesmo que você tenha escrito com duplas:

$ node
Welcome to Node.js v24.22.0.
Type ".help" for more information.
> "Ana"
'Ana'
> 'Ana'
'Ana'
> console.log("Ana")
Ana
undefined
> "Ana".length
3
> .exit

O 'Ana' com aspas é o Node dizendo "isto é um texto". O console.log mostra o texto limpo (Ana) e depois o undefined, que é o "resultado" do próprio console.log, que não devolve nada (veja O Modo Interativo).

A string vazia

Duas aspas coladas, "", formam a string vazia: um texto com zero caracteres. É o que um campo de formulário tem antes de alguém digitar. Ela é diferente de um texto com um espaço (" "), que tem um caractere, e diferente de "não ter valor" (null e undefined, aula null e undefined).

2. O tamanho: .length

Toda string sabe quantos caracteres tem. Basta escrever .length ("comprimento") depois dela:

const nome = "Ana";
const completo = "Ana Souza";
const vazio = "";

console.log(nome.length);
console.log(completo.length);
console.log(vazio.length);
console.log("Pão de queijo".length);

$ node tamanho.js
3
9
0
13

O espaço do meio de "Ana Souza" conta como um caractere (3 + 1 + 5 = 9), e as letras com acento (ã) contam como uma cada. O .length não tem parênteses, porque não é um comando, é uma propriedade: uma informação que a string já carrega. Ele também funciona direto num texto, sem variável.

Para que serve o tamanho?

Para conferir se o nome não ficou em branco (nome.length === 0), se a senha tem pelo menos 8 caracteres (senha.length >= 8), se o tuíte cabe no limite… Você vai usar muito junto com o if.

3. Juntando textos: + e +=

O + entre dois textos emenda um no outro (o nome técnico é concatenar, "fazer uma corrente"):

const nome = "Ana";
const sobrenome = "Souza";

const completo = nome + " " + sobrenome;
console.log(completo);
console.log("Olá, " + nome + "!");

let lista = "Compras:";
lista += " pão";
lista += ", leite";
lista += ", café";
console.log(lista);

$ node juntar.js
Ana Souza
Olá, Ana!
Compras: pão, leite, café
nome + " " + sobrenome
Três pedaços emendados: "Ana", um espaço e "Souza". O + não põe espaço sozinho: sem o " " do meio, sairia AnaSouza.
"Olá, " + nome + "!"
O espaço depois da vírgula está dentro das aspas de "Olá, ". Só o que está dentro das aspas vira texto; os espaços fora delas são só para o código ficar legível.
let lista = "Compras:"
Aqui é let, não const, porque a variável vai receber textos novos (veja Variáveis).
lista += " pão"
Atalho para lista = lista + " pão": emenda no fim do que já estava lá (veja Atribuição).

Missão: junte as variáveis com + para o programa mostrar exatamente Ana mora em Recife. (com os espaços e o ponto final). Escreva no lugar do "?".

const nome = "Ana";
const cidade = "Recife";
const frase = "?";
console.log(frase);

const nome = "Ana";
const cidade = "Recife";
const frase = nome + " mora em " + cidade + ".";
console.log(frase);

Texto + número = texto

Quando um lado do + é texto e o outro é número, o JavaScript transforma o número em texto e emenda. Com os outros operadores (-, *, /) ele faz o contrário: tenta transformar o texto em número.

const idade = 30;
console.log("Idade: " + idade);
console.log("5" + 3);
console.log("5" - 3);
console.log("5" * "2");
console.log(5 + 3);

$ node misturar.js
Idade: 30
53
2
10
8

A segunda linha é a famosa pegadinha: "5" + 3 dá o texto 53, e não o número 8. Isso aparece muito quando o número vem do teclado ou de um formulário, que sempre entregam texto. O jeito de converter antes de somar (Number("5") + 3) está em Conversão, e as outras surpresas em Conversão Automática.

4. Comparando textos e pegando uma letra

const senha = "Pao123";

console.log(senha === "Pao123");
console.log(senha === "pao123");
console.log(senha[0]);
console.log(senha[1]);
console.log(senha[senha.length - 1]);
console.log(senha[50]);

$ node comparar.js
true
false
P
a

senha === "Pao123"
Dois textos são iguais quando têm os mesmos caracteres, na mesma ordem.
senha === "pao123"
false: maiúscula e minúscula são caracteres diferentes. Para comparar sem ligar para isso, a aula Métodos de String mostra o toLowerCase().
senha[0]
Os colchetes pegam a letra de uma posição. A contagem começa do zero: [0] é a primeira letra, [1] a segunda.
senha[senha.length - 1]
A última letra: o texto tem 6 caracteres, nas posições 0 a 5, então a última é a length - 1. (Há um jeito mais curto, o .at(-1), na aula Pedaços de String.)
senha[50]
Uma posição que não existe não dá erro: devolve undefined ("indefinido", nada ali).

5. Uma string não muda

Este é um detalhe importante: depois de criada, uma string não pode ser alterada por dentro. Os programadores dizem que ela é imutável. Olhe a tentativa de trocar a primeira letra:

let nome = "Ana";
nome[0] = "B";
console.log(nome);

nome = "Bia";
console.log(nome);

$ node imutavel.js
Ana
Bia

O nome[0] = "B" não deu erro, mas também não fez nada: o texto continuou Ana. O que dá para fazer é colocar na variável um texto novo (nome = "Bia"). Voltando ao colar: você não troca uma conta do colar pronto; você monta outro colar e guarda no lugar do antigo. Por isso, todos os métodos das próximas aulas (toUpperCase(), slice(), replace()…) devolvem um texto novo e deixam o original como estava.

Experimente: troque o texto da variável palavra pelo seu nome, ou por uma palavra com acentos e espaços, e veja o tamanho, a primeira e a última letra.

const palavra = "Pão de queijo";
console.log("Texto:", palavra);
console.log("Tamanho:", palavra.length);
console.log("Primeira letra:", palavra[0]);
console.log("Última letra:", palavra[palavra.length - 1]);

Formas diferentes de fazer a mesma coisa

As três aspas criam o mesmo tipo de valor. E para montar uma frase com variáveis há mais de um caminho:

const nome = "Ana";
const idade = 30;

console.log("Ana" === 'Ana' && 'Ana' === `Ana`);

console.log("Nome: " + nome + ", idade: " + idade);
console.log(`Nome: ${nome}, idade: ${idade}`);
console.log("Nome:", nome + ", idade:", idade);

$ node formas.js
true
Nome: Ana, idade: 30
Nome: Ana, idade: 30
Nome: Ana, idade: 30

A última linha usa as vírgulas do console.log, que separam os valores com um espaço (veja console.log()). Isso só funciona para mostrar na tela; para guardar a frase numa variável, use + ou o template string.

SituaçãoQual usar
Texto comumAspas duplas: "Bom dia" (padrão deste guia)
Texto que tem aspas duplas dentroAspas simples por fora: 'Ele disse "oi"' (ou o escape \", aula Caracteres Especiais)
Texto com variáveis ou contas no meioCrase com ${ }: `Olá, ${nome}!` (aula Template Strings)
Juntar dois ou três pedaços+ (ou += para ir emendando no fim)
Só mostrar vários valores na telaVírgulas no console.log(a, b)

Num mesmo projeto, escolha um tipo de aspa e use sempre o mesmo. Misturar "…" e '…' sem motivo não dá erro, mas deixa o código desarrumado (a aula Estilo de Código fala das ferramentas que arrumam isso sozinhas).

"Erro de sintaxe: nome inesperado oi". O JavaScript leu "Ele disse " como um texto completo (a segunda aspa dupla fechou o que a primeira abriu). Depois encontrou a palavra oi solta, fora de qualquer aspa, e não soube o que fazer com ela. Como consertar: use o outro tipo de aspa por fora, 'Ele disse "oi" para a Ana', ou avise que a aspa de dentro é só uma letra com a barra invertida: "Ele disse \"oi\" para a Ana" (aula Caracteres Especiais).

Escreveu .lenght (ou .Length) 
const nome = "Ana Souza";
console.log(nome.lenght);
console.log(nome.Length);
console.log(nome.length);

$ node lenght.js

9

Nenhuma mensagem de erro: o JavaScript procurou na string uma propriedade chamada lenght (com o "h" trocado de lugar), não achou, e devolveu undefined. O mesmo com Length, com L maiúsculo: no JavaScript, maiúsculas importam também nos nomes. Como consertar: length, tudo minúsculo, "l-e-n-g-t-h". Se aparecer undefined onde você esperava um número, confira a grafia.

Pôs a variável entre aspas 
const nome = "Ana";
console.log("Olá, nome!");
console.log("Olá, " + nome + "!");

$ node literal.js
Olá, nome!
Olá, Ana!

Dentro das aspas, tudo é texto ao pé da letra: "nome" é a palavra "nome", não a variável. Como consertar: deixe a variável fora das aspas e emende com + (ou use `Olá, ${nome}!`).

Missão: este programa nem roda. Leia a mensagem de erro, conserte as aspas, e faça aparecer Bem-vinda, Ana! com o nome vindo da variável.

const nome = "Ana';
console.log("Bem-vinda, nome!");

const nome = "Ana";
console.log("Bem-vinda, " + nome + "!");

Resumo

  • Uma string é um texto: uma fileira de caracteres entre aspas. Duplas "…", simples '…' e crase `…` criam o mesmo tipo (typeof → string); feche com a mesma aspa que abriu.
  • "" é a string vazia. texto.length dá o número de caracteres (espaços e acentos contam).
  • + emenda textos; += emenda no fim da variável. Texto + número vira texto: "5" + 3 → 53.
  • === compara caractere por caractere, e maiúsculas contam. texto[0] é o primeiro caractere; a contagem começa do zero.
  • Uma string não muda por dentro: para "mudar", crie um texto novo e guarde na variável.
  • Erros comuns: aspas sem fechar (Invalid or unexpected token), aspas iguais dentro do texto, .lenght (dá undefined) e variável dentro das aspas.
