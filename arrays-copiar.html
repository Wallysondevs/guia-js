JavaScript: Copiando Arrays

A Ana tem a lista de compras da casa e quer dar uma cópia para a Bia, que vai acrescentar umas coisas dela. Parece simples: const daBia = compras. Só que, quando a Bia acrescenta "chocolate", o chocolate aparece também na lista da Ana! Esta aula explica por quê, e mostra os jeitos certos de copiar um array: o spread (...), o slice e, quando o array tem coisas dentro de coisas, o structuredClone.

Você vai aprender
  • Por que const b = a não copia um array: dá só um segundo nome para o mesmo array.
  • Como fazer uma cópia de verdade: [...a], a.slice(), Array.from(a).
  • Como copiar e acrescentar itens de uma vez: [...a, "café"].
  • O limite da cópia "rasa": objetos e arrays de dentro continuam compartilhados.
  • A cópia "profunda" com structuredClone, e o que ela não consegue copiar.
  • Como comparar se duas cópias têm o mesmo conteúdo.

Todos os programas desta aula rodaram no Node.js 24 da máquina da Ana (usuária ana, computador notebook), salvos na pasta pessoal dela e executados com node arquivo.js. Você pode rodar cada um no editor do guia.

A ideia: a caixa e as etiquetas

Até aqui você imaginou uma variável como uma caixa com o valor dentro. Para números e textos, essa imagem funciona. Para arrays (e objetos), a imagem certa é outra:

  • O array é uma caixa guardada num depósito (a memória do computador).
  • A variável é uma etiqueta com o endereço da caixa.

Quando você escreve const daBia = compras, o JavaScript não faz uma caixa nova: ele cola uma segunda etiqueta na mesma caixa. Mexer na caixa pela etiqueta daBia é mexer na caixa da Ana. Para a Bia ter a própria lista, é preciso outra caixa, com os mesmos itens dentro: isso é copiar. (A aula Objetos são Referências aprofunda essa ideia.)

1. O = não copia

const compras = ["pão", "leite"];
const daBia = compras;
daBia.push("chocolate");
console.log("compras:", compras);
console.log("daBia:  ", daBia);
console.log(compras === daBia);

$ node igual.js
compras: [ 'pão', 'leite', 'chocolate' ]
daBia:   [ 'pão', 'leite', 'chocolate' ]
true
const daBia = compras;
Não cria array nenhum. A variável daBia passa a apontar para o mesmo array que compras.
daBia.push("chocolate")
Acrescenta o chocolate no array, que é um só. Por isso ele aparece nos dois console.log.
compras === daBia → true
Para arrays, o === não compara o conteúdo: pergunta "é a mesma caixa?". Aqui é.

Com números isso não acontece: let x = 5; let y = x; y = 6; deixa o x em 5. Números e textos são copiados de verdade no =; arrays e objetos, não.

2. A cópia de verdade: spread (...)

const compras = ["pão", "leite"];
const daBia = [...compras];
daBia.push("chocolate");
console.log("compras:", compras);
console.log("daBia:  ", daBia);
console.log(compras === daBia);

$ node spread.js
compras: [ 'pão', 'leite' ]
daBia:   [ 'pão', 'leite', 'chocolate' ]
false
[ … ]
Os colchetes criam um array novo (uma caixa nova).
...compras
Os três pontinhos são o spread (em inglês, "espalhar"): pegam cada item de compras e os espalham dentro do array novo, como se você tivesse escrito ["pão", "leite"] à mão. A aula Spread e Rest mostra outros usos.
false
Agora são duas caixas: o chocolate só entrou na da Bia.

Missão: este programa estraga o original sem querer: o "bolo" aparece nas duas listas. Troque a linha da copia para fazer uma cópia de verdade, e o original deve continuar [ 'pão', 'leite' ].

const original = ["pão", "leite"];
const copia = original;
copia.push("bolo");
console.log("Original:", original);
console.log("Cópia:", copia);

const original = ["pão", "leite"];
const copia = [...original];
copia.push("bolo");
console.log("Original:", original);
console.log("Cópia:", copia);

3. Outros jeitos de copiar

O spread é o mais usado hoje, mas você vai encontrar outros em código pronto. Todos fazem uma caixa nova:

const original = [3, 1, 2];
const a = [...original];
const b = original.slice();
const c = Array.from(original);
const d = original.concat();
a.push("a");
b.push("b");
c.push("c");
d.push("d");
console.log(original, a, b, c, d);

$ node formas.js
[ 3, 1, 2 ] [ 3, 1, 2, 'a' ] [ 3, 1, 2, 'b' ] [ 3, 1, 2, 'c' ] [ 3, 1, 2, 'd' ]

O original ficou intacto e cada cópia ganhou o seu item. O slice() sem números "fatia" o array do começo ao fim (aula splice e slice); o Array.from cria um array a partir de outro (aula some, every, join, flat e Outros); o concat() sem nada para juntar devolve só a cópia.

Copiar e mudar de uma vez

Muitas vezes você copia para, em seguida, acrescentar ou trocar alguma coisa. O spread faz as duas coisas numa linha, e os métodos "to…" ES2023 devolvem a cópia já mudada:

const compras = ["pão", "leite"];
console.log([...compras, "café"]);
console.log(["café", ...compras]);
console.log([...compras, ...["ovos", "queijo"]]);
console.log(compras.toSpliced(1, 1, "manteiga"));
console.log(compras);

$ node mais.js
[ 'pão', 'leite', 'café' ]
[ 'café', 'pão', 'leite' ]
[ 'pão', 'leite', 'ovos', 'queijo' ]
[ 'pão', 'manteiga' ]
[ 'pão', 'leite' ]
  • [...compras, "café"]: cópia com um item no fim (o push sem estragar o original).
  • ["café", ...compras]: cópia com um item no começo (o unshift sem estragar).
  • [...a, ...b]: dois arrays juntos num novo.
  • toSpliced(1, 1, "manteiga"): o mesmo que o splice, mas numa cópia. Junto com toSorted, toReversed (aula Ordenando) e with, forma a família que não mexe no original.

A última linha confirma: depois de tudo isso, compras continua [ 'pão', 'leite' ].

4. O limite: a cópia rasa

Todos os jeitos acima fazem uma cópia rasa (em inglês, shallow copy): a caixa de fora é nova, mas o que está dentro dela é copiado com =. Para números e textos, tudo bem. Mas, se os itens forem objetos ou arrays, a cópia ganha etiquetas para os mesmos objetos de dentro.

A professora da Ana quer simular "e se a Ana tirasse 10?" sem mexer nas notas de verdade:

const turma = [
  { nome: "Ana", nota: 7 },
  { nome: "Bia", nota: 8 },
];
const copia = [...turma];
copia[0].nota = 10;
copia.push({ nome: "Caio", nota: 6 });
console.log("turma:", turma);
console.log("copia:", copia);

$ node rasa.js
turma: [ { nome: 'Ana', nota: 10 }, { nome: 'Bia', nota: 8 } ]
copia: [
  { nome: 'Ana', nota: 10 },
  { nome: 'Bia', nota: 8 },
  { nome: 'Caio', nota: 6 }
]

Olhe com atenção:

  • O Caio só entrou na cópia: o array de fora é novo. Até aqui, a cópia funcionou.
  • A nota 10 da Ana apareceu também na turma original. O objeto { nome: "Ana", … } não foi copiado: as duas listas apontam para o mesmo objeto da Ana.

Com arrays dentro de arrays acontece o mesmo. Um jogo da velha copiado com spread:

const tabuleiro = [["X", " "], [" ", "O"]];
const copia = [...tabuleiro];
copia[0][1] = "O";
console.log(tabuleiro);
console.log(copia[0] === tabuleiro[0]);

$ node rasa2.js
[ [ 'X', 'O' ], [ ' ', 'O' ] ]
true

A jogada feita na cópia apareceu no tabuleiro original, e o true mostra que a primeira linha das duas é a mesma caixa. (Arrays de arrays têm aula própria: Matrizes.)

5. A cópia profunda: structuredClone

Para copiar tudo, a caixa de fora e todas as caixas de dentro, em qualquer profundidade, existe o structuredClone ("clone estruturado"). Ele é uma função global: existe no Node.js (desde a versão 17) e em todos os navegadores atuais, sem precisar de import.

const turma = [
  { nome: "Ana", nota: 7 },
  { nome: "Bia", nota: 8 },
];
const copia = structuredClone(turma);
copia[0].nota = 10;
console.log("turma:", turma);
console.log("copia:", copia);
console.log(copia[0] === turma[0]);

$ node clone.js
turma: [ { nome: 'Ana', nota: 7 }, { nome: 'Bia', nota: 8 } ]
copia: [ { nome: 'Ana', nota: 10 }, { nome: 'Bia', nota: 8 } ]
false

Agora a turma de verdade continua com o 7. O false mostra que o objeto da Ana na cópia é outro objeto, com o mesmo conteúdo. Isso é uma cópia profunda (em inglês, deep copy).

O jeito antigo: JSON.parse(JSON.stringify(…))

Antes do structuredClone, o truque era transformar o array em texto JSON e de volta (aula JSON). Funciona para números, textos e booleanos, mas estraga outros valores:

const dados = [1, undefined, new Date(0)];
console.log(structuredClone(dados));
console.log(JSON.parse(JSON.stringify(dados)));

$ node json.js
[ 1, undefined, 1970-01-01T00:00:00.000Z ]
[ 1, null, '1970-01-01T00:00:00.000Z' ]

O structuredClone manteve o undefined e a data (Date). Pelo JSON, o undefined virou null e a data virou um texto (repare nas aspas). Em código novo, use o structuredClone.

Formas diferentes de fazer a mesma coisa

SituaçãoQual usar
Array de números, textos, booleanos (o caso comum)[...lista]
Código antigo / quer deixar claro "uma fatia inteira"lista.slice()
Copiar e acrescentar[...lista, novo] / [novo, ...lista]
Copiar e ordenar / inverter / trocar / tirartoSorted / toReversed / with / toSpliced
Array com objetos ou arrays dentro, que você vai mudarstructuredClone(lista)
Só quer dar outro nome, sem copiarconst outro = lista (de propósito!)

Quando dá errado

Achou que o = copiava

Sem mensagem de erro: o original muda "sozinho" (seção 1). Se um array mudou e você não se lembra de mexer nele, procure um outro = esteArray no caminho. Como consertar: const outro = [...esteArray].

Cópia rasa de objetos

Também sem erro: você copiou com spread, mudou um objeto de dentro da cópia, e o original mudou junto (seção 4). Como consertar: structuredClone(lista).

Comparou duas cópias com === 
const a = [1, 2, 3];
const b = [...a];
console.log(a === b);
console.log(a.length === b.length && a.every((item, i) => item === b[i]));
console.log(JSON.stringify(a) === JSON.stringify(b));

$ node comparar.js
false
true
true

Mesmo conteúdo, mas a === b dá false: são duas caixas. O === nunca compara o conteúdo de arrays. Como consertar: compare o tamanho e cada item (com every, aula some, every…) ou, para arrays simples, compare as versões em texto JSON.

Missão final: a simulação de notas

Missão: a professora simula "e se a Ana tirasse 10?", mas a nota real da Ana também está mudando. Troque a cópia rasa por uma cópia profunda, para aparecer Nota real da Ana: 7 e Nota simulada da Ana: 10.

const turma = [
  { nome: "Ana", nota: 7 },
  { nome: "Bia", nota: 8 },
];
const simulacao = [...turma];
simulacao[0].nota = 10;
console.log(`Nota real da Ana: ${turma[0].nota}`);
console.log(`Nota simulada da Ana: ${simulacao[0].nota}`);

const turma = [
  { nome: "Ana", nota: 7 },
  { nome: "Bia", nota: 8 },
];
const simulacao = structuredClone(turma);
simulacao[0].nota = 10;
console.log(`Nota real da Ana: ${turma[0].nota}`);
console.log(`Nota simulada da Ana: ${simulacao[0].nota}`);

No lab, a solução mostrou Nota real da Ana: 7 e Nota simulada da Ana: 10.

Resumo

  • Uma variável de array é uma etiqueta para uma caixa. const b = a cola outra etiqueta na mesma caixa: não copia nada.
  • Para copiar: [...a] (o mais comum), a.slice(), Array.from(a). Para copiar e acrescentar: [...a, novo].
  • Essas cópias são rasas: objetos e arrays de dentro continuam compartilhados.
  • structuredClone(a) faz a cópia profunda, de tudo, mas não copia funções (DataCloneError).
  • === entre arrays pergunta "é a mesma caixa?", e não "têm o mesmo conteúdo?".
