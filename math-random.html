JavaScript Math.random()

Jogos de dado, sorteio de amigo secreto, a música aleatória da playlist, a pergunta surpresa do quiz: tudo isso precisa de um número que ninguém sabe qual vai ser. No JavaScript, quem entrega esse número é o Math.random() (random = "aleatório"), uma ferramenta do objeto Math. Ele sozinho só sabe fazer uma coisa (um número quebrado entre 0 e 1), mas com uma continha você transforma isso em um dado, um sorteio de 1 a 60 ou um item sorteado de uma lista.

Você vai aprender
  • O que o Math.random() devolve, e por que cada execução dá um resultado diferente.
  • A receita do dado: Math.floor(Math.random() * 6) + 1, peça por peça.
  • Como sortear um inteiro entre dois números quaisquer, um item de um array e cara ou coroa.
  • Como conferir se o sorteio é justo, jogando o dado 6000 vezes.
  • Como embaralhar uma lista.
  • Os erros mais comuns (o Math.round que vicia o dado, o + 1 esquecido ou no lugar errado) e quando usar o crypto em vez do Math.random.

Todos os programas desta aula rodaram no Node.js 24 da máquina da Ana (usuária ana, computador notebook). Atenção: por definição, quando você rodar os mesmos programas, os números serão outros. As saídas abaixo são as que saíram no lab, naquela vez.

A ideia: tirar um papelzinho do saco

Na quermesse da escola, a Ana vende rifas. Para sortear, ela põe papeizinhos num saco, chacoalha e tira um sem olhar. O Math.random() é um saco com infinitos papeizinhos, cada um com um número entre 0 e 1: 0.0001, 0.5, 0.7391…. A cada chamada, ele tira um.

Para sortear de 1 a 6 (um dado), você não precisa de outro saco: basta esticar o número sorteado (multiplicar por 6), cortar a parte quebrada e empurrar uma casa (somar 1). É isso que esta aula ensina.

Não recebe nada entre os parênteses. Devolve um número com casas decimais maior ou igual a 0 e menor que 1. Pode sair 0 (muito raro), mas nunca sai 1. Esse detalhe é o que faz a receita do dado funcionar.

"Aleatório" de mentirinha

O computador não joga dados de verdade: o Math.random() calcula uma sequência de números que parecem sorteados (os programadores dizem pseudoaleatórios). Para jogos, sorteios da escola e exercícios, ele é ótimo. Para senhas e códigos de segurança, existe uma ferramenta própria (veja a seção 7).

2. A receita do dado: Math.floor(Math.random() * 6) + 1

const dado = Math.floor(Math.random() * 6) + 1;
console.log(`Você tirou ${dado}`);

$ node dado.js

Três vezes 4 seguidas! Não é defeito: num dado de verdade isso também acontece. Tirar o mesmo número três vezes seguidas acontece, em média, em uma de cada 36 sequências de três jogadas. Sorte não tem memória. Para entender a receita, a Ana separou cada passo numa variável:

const sorteio = Math.random();
const vezesSeis = sorteio * 6;
const inteiro = Math.floor(vezesSeis);
const dado = inteiro + 1;

console.log(sorteio);
console.log(vezesSeis);
console.log(inteiro);
console.log(dado);

Cada um dos 6 resultados tem a mesma chance, porque cada um ocupa um pedaço do mesmo tamanho entre 0 e 6: de 0 a 0,999… vira 1; de 1 a 1,999… vira 2; e assim por diante. É por isso que se usa o Math.floor (para baixo) e não o Math.round (veja Quando dá errado).

O dado é justo? Jogando 6000 vezes

Se o dado é justo, cada face deve sair mais ou menos 1000 vezes em 6000 jogadas:

const contagem = [0, 0, 0, 0, 0, 0, 0];

for (let i = 0; i < 6000; i++) {
  const dado = Math.floor(Math.random() * 6) + 1;
  contagem[dado]++;
}

for (let face = 1; face <= 6; face++) {
  console.log(`${face}: ${contagem[face]} vezes`);
}

$ node contar.js

2: 978 vezes
3: 971 vezes
4: 1019 vezes

O array contagem tem 7 posições (de 0 a 6) para que a face 1 seja contada em contagem[1], a face 2 em contagem[2]… (a posição 0 fica sem uso). Nenhuma face saiu exatamente 1000 vezes, mas todas ficaram perto: é assim que o acaso se comporta.

3. Sortear entre dois números quaisquer

A receita do dado vale para qualquer intervalo. Para sortear um inteiro de minimo até maximo (os dois incluídos), quantos resultados existem? maximo - minimo + 1 (de 1 a 6 são 6; de 100 a 199 são 100). Esse é o tamanho da "esticada"; depois, em vez de empurrar 1, empurre até o minimo:

function sortearEntre(minimo, maximo) {
  return Math.floor(Math.random() * (maximo - minimo + 1)) + minimo;
}

console.log(`Mega-Sena: ${sortearEntre(1, 60)}`);
console.log(`Senha da fila: ${sortearEntre(100, 199)}`);
console.log(`Dado: ${sortearEntre(1, 6)}`);

$ node entre.js
Mega-Sena: 35
Senha da fila: 179
Dado: 5

Guarde essa função: ela aparece em quase todo programa com sorteio. Os parênteses em volta de maximo - minimo + 1 são obrigatórios: sem eles, a multiplicação seria feita antes da conta (veja Precedência).

4. Sortear um item de uma lista

Qual pizza a família da Ana pede hoje? Os itens de um array ficam nas posições 0, 1, 2… até length - 1. Então basta sortear uma posição (o índice):

const sabores = ["calabresa", "mussarela", "frango", "portuguesa"];
const indice = Math.floor(Math.random() * sabores.length);

console.log(`Índice sorteado: ${indice}`);
console.log(`Pizza de hoje: ${sabores[indice]}`);

$ node lista.js
Índice sorteado: 3
Pizza de hoje: portuguesa
$ node lista.js
Índice sorteado: 1
Pizza de hoje: mussarela

Aqui não tem o + 1: com 4 sabores, Math.floor(Math.random() * 4) dá 0, 1, 2 ou 3, exatamente as posições do array. O sabores.length faz a conta se ajustar sozinha se a lista crescer.

5. Cara ou coroa: uma chance em duas

Como o Math.random() se espalha por igual entre 0 e 1, a chance de sair menos de 0.5 é de 50%:

const resultado = Math.random() < 0.5 ? "cara" : "coroa";
console.log(resultado);

$ node moeda.js
cara
$ node moeda.js
coroa
$ node moeda.js
cara

O ? : é o operador ternário. Com outro número, você muda a chance: Math.random() < 0.1 é verdadeiro em 10% das vezes (um "prêmio raro" num jogo).

6. Embaralhar uma lista

A professora quer a ordem de apresentação dos trabalhos sorteada. O jeito certo de embaralhar tem nome: embaralhamento de Fisher-Yates. Ele vai do fim da lista para o começo, trocando cada item com um item sorteado entre os que ainda não foram fixados:

function embaralhar(lista) {
  const copia = [...lista];
  for (let i = copia.length - 1; i > 0; i--) {
    const j = Math.floor(Math.random() * (i + 1));
    [copia[i], copia[j]] = [copia[j], copia[i]];
  }
  return copia;
}

const turma = ["Ana", "Bia", "Caio", "Duda", "Edu"];
console.log(embaralhar(turma));
console.log(turma);

Trabalha numa cópia, para não bagunçar a lista original (veja Copiando Arrays). A segunda linha da saída mostra a turma intacta.
Math.floor(Math.random() * (i + 1))
A receita da seção 4: sorteia uma posição de 0 até i.

Troca os dois itens de lugar, com desestruturação.
O atalho que parece funcionar

Na internet você vai encontrar lista.sort(() => Math.random() - 0.5). Ele embaralha, mas não de forma justa: algumas ordens saem bem mais que outras, porque o sort não foi feito para comparações que mudam de ideia. Para sortear de verdade, use o Fisher-Yates acima.

7. Quando o Math.random() não serve: segurança

Para criar uma senha, um código de verificação ou um token de acesso, o número precisa ser impossível de prever, mesmo para alguém que estude o programa. O Math.random() não promete isso. Para esses casos, o JavaScript tem o crypto (de "criptografia"):

const { randomInt } = require("node:crypto");

console.log(`Código de verificação: ${randomInt(100000, 1000000)}`);
console.log(crypto.randomUUID());

$ node seguro.js
Código de verificação: 531261
d6abb5f8-4dec-41d9-81bb-9ca27099c038
require("node:crypto") e randomInt(100000, 1000000)
O módulo crypto do Node (veja require). O randomInt(min, max) sorteia um inteiro seguro de min até antes de max: aqui, um código de 6 dígitos, de 100000 a 999999. Só existe no Node.
crypto.randomUUID()
Um identificador único e aleatório, no formato padrão chamado UUID. Esse crypto já vem pronto, sem require, no Node e no navegador.

Quando dá errado

Os erros com sorteio quase nunca mostram mensagem: o programa roda, mas sorteia errado. Por isso vale a pena contar os resultados, como na seção 2.

Usou Math.round: o dado viciado

for (let i = 0; i < 6000; i++) {
  const dado = Math.round(Math.random() * 6);
  contagem[dado]++;
}

for (let face = 0; face <= 6; face++) {
  console.log(`${face}: ${contagem[face]} vezes`);
}

$ node round-errado.js

1: 997 vezes
2: 1013 vezes
3: 952 vezes
4: 1040 vezes
5: 1003 vezes

Dois problemas de uma vez: saiu 0, que não existe num dado, e o 0 e o 6 saíram metade das vezes das outras faces. O Math.round leva para o 0 só o que fica entre 0 e 0,5 (meio pedaço), e para o 6 só o que fica entre 5,5 e 6 (outro meio pedaço). Como consertar: Math.floor(Math.random() * 6) + 1.

Esqueceu o + 1 no dado

Math.floor(Math.random() * 6) dá de 0 a 5. O dado nunca tira 6 e às vezes tira 0. Como consertar: some 1 depois do Math.floor.

Pôs + 1 no índice de um array 
const sabores = ["calabresa", "mussarela", "frango", "portuguesa"];

for (let i = 0; i < 8; i++) {
  const indice = Math.floor(Math.random() * sabores.length) + 1;
  console.log(`${indice}: ${sabores[indice]}`);
}

$ node fora.js

4: undefined

4: undefined

Com o + 1, o índice vai de 1 a 4. A posição 4 não existe (os sabores vão de 0 a 3), então ler sabores[4] dá undefined, sem erro (veja Acessando Itens). E a calabresa, na posição 0, nunca é sorteada. Como consertar: tire o + 1; índices de array começam em 0.

Passou o intervalo para o Math.random

Em outras linguagens existe random(1, 6). No JavaScript, o Math.random ignora o que você põe nos parênteses, sem avisar, e continua devolvendo um número entre 0 e 1. Como consertar: use a receita (ou a sua função sortearEntre(1, 6)).

Uma meta de teste que depende da sorte

Se o seu programa sorteia, ele não dá para ser conferido comparando a saída com um número fixo ("tem de mostrar 4"): uma hora passa, outra não. Para testar, confira o que sempre vale (o resultado está entre 1 e 6? a lista embaralhada tem os mesmos itens?), ou rode milhares de vezes e confira o menor e o maior, como na missão da seção 2.

Resumo

  • Math.random() devolve um número de 0 até quase 1 (o 1 nunca sai), diferente a cada chamada.
  • Para um inteiro de 1 a N: Math.floor(Math.random() * N) + 1. Esticar, cortar para baixo, empurrar.
  • Para um intervalo qualquer: Math.floor(Math.random() * (max - min + 1)) + min. Para um item de array: lista[Math.floor(Math.random() * lista.length)], sem + 1.
  • Use Math.floor, nunca Math.round, para o sorteio sair justo. Na dúvida, rode milhares de vezes e conte.
  • Para embaralhar, Fisher-Yates. Para senhas e códigos, crypto, nunca Math.random.
