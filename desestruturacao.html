JavaScript Desestruturação

Muitas vezes você tem um objeto ou um array e quer pôr alguns dos valores dele em variáveis. Dá para fazer uma linha por valor (const nome = ana.nome;), mas o JavaScript tem um atalho que faz várias de uma vez: a desestruturação (em inglês, destructuring, "desmontar a estrutura"). Você vai vê-la em todo código JavaScript moderno, principalmente nos parâmetros de funções.

Você vai aprender
  • A desestruturar um objeto: const { nome, idade } = ana;.
  • A dar outro nome à variável e um valor padrão para o que falta.
  • A desestruturar um array pela posição, pular itens e trocar duas variáveis numa linha.
  • A desestruturar objetos dentro de objetos, parâmetros de função e o Object.entries no for … of.
  • Os erros reais: Cannot destructure property, is not iterable, o Unexpected token '=' e a armadilha do ponto e vírgula.

Todos os programas desta aula rodaram no Node.js 24 da máquina da Ana (usuária ana, computador notebook), com node arquivo.js.

A ideia: desfazer a sacola de compras

A Ana chega do mercado com uma sacola. Ela não guarda a sacola inteira na geladeira: tira o leite e põe na porta, tira o queijo e põe na gaveta. A desestruturação é isso: você diz quais itens quer tirar da "sacola" (o objeto ou o array) e em que variável cada um vai. A sacola continua lá, intacta; você só ganhou variáveis com os valores.

1. Desestruturando um objeto

O jeito longo, que você já conhece:

const ana = { nome: "Ana", idade: 30, cidade: "Recife" };
const nome = ana.nome;
const idade = ana.idade;
console.log(nome, idade);

$ node antes.js
Ana 30

O mesmo com desestruturação:

const ana = { nome: "Ana", idade: 30, cidade: "Recife" };
const { nome, idade } = ana;
console.log(nome);
console.log(idade);
const
Cria as variáveis, como sempre. Também pode ser let.
{ nome, idade }
Do lado esquerdo do =, as chaves não criam um objeto: elas dizem "quero estas propriedades". Cada nome vira uma variável e diz qual propriedade buscar: a variável nome recebe ana.nome.
= ana
De onde tirar os valores. A cidade não foi pedida, então fica só no objeto.
$ node objeto.js
Ana
30

A ordem dentro das chaves não importa: const { idade, nome } = ana; dá o mesmo resultado, porque a busca é pelo nome da propriedade. E se o nome não existir no objeto, a variável recebe undefined, sem erro:

const produto = { nome: "Pão", preco: 0.8 };
const { nome, estoque } = produto;
console.log(nome);
console.log(estoque);

$ node faltando.js
Pão
undefined

2. Outro nome e valor padrão

Renomear: propriedade: variavel

Às vezes o nome da propriedade não serve (já existe uma variável nome, ou ele não diz muita coisa). Escreva a propriedade, dois-pontos e o nome que você quer:

const produto = { nome: "Pão francês", preco: 0.8 };
const { nome: nomeProduto, preco: valor } = produto;
console.log(nomeProduto);
console.log(valor);

$ node renomear.js
Pão francês
0.8

Leia nome: nomeProduto como "pegue a propriedade nome e guarde em nomeProduto". Aqui não existe variável nome nem preco; só nomeProduto e valor.

Valor padrão: variavel = valor

Para o caso de a propriedade não existir, ponha um = com o valor que deve ser usado no lugar do undefined:

const produto = { nome: "Pão", preco: 0.8 };
const { nome, estoque = 0, preco = 1 } = produto;
console.log(nome, estoque, preco);

$ node padrao.js
Pão 0 0.8

O estoque não existia, então ficou com o padrão 0. Já o preco existia (0.8), e o padrão 1 foi ignorado: o padrão só entra quando o valor é undefined. Dá para combinar as duas coisas: const { preco: valor = 1 } = produto;.

Missão: troque as três linhas que começam com const (depois da do objeto) por uma desestruturação que crie nome e preco, e estoque com o padrão 0. O resultado tem de continuar o mesmo.

const bolo = { nome: "Bolo de milho", preco: 25 };
const nome = bolo.nome;
const preco = bolo.preco;
const estoque = bolo.estoque === undefined ? 0 : bolo.estoque;
console.log(`${nome} custa R$ ${preco} (estoque: ${estoque})`);

const bolo = { nome: "Bolo de milho", preco: 25 };
const { nome, preco, estoque = 0 } = bolo;
console.log(`${nome} custa R$ ${preco} (estoque: ${estoque})`);

3. Desestruturando um array

Com arrays, você usa colchetes do lado esquerdo e os valores são tirados pela posição, não pelo nome:

const podio = ["Bia", "Ana", "Caio", "Davi"];
const [primeiro, segundo, terceiro] = podio;
console.log("Ouro:", primeiro);
console.log("Prata:", segundo);
console.log("Bronze:", terceiro);

$ node array.js
Ouro: Bia
Prata: Ana
Bronze: Caio

A primeira variável recebe o item 0, a segunda o item 1, e assim por diante. Os itens que sobram ("Davi") são ignorados. Aqui os nomes das variáveis são livres: não têm relação com nada no array.

Pular itens e valor padrão

Uma vírgula sem nome antes "pula" uma posição. O valor padrão funciona igual ao dos objetos:

const data = ["19", "10", "2026"];
const [, mes, ano] = data;
console.log(mes, ano);
const [dia, , , extra = "nada"] = data;
console.log(dia, extra);

$ node pular.js
10 2026
19 nada

Um uso muito comum: desmontar o resultado de um split, que sempre devolve um array.

const linha = "Ana;30;Recife";
const [nome, idade, cidade] = linha.split(";");
console.log(`${nome} tem ${idade} anos e mora em ${cidade}.`);

$ node split.js
Ana tem 30 anos e mora em Recife.

Trocar o valor de duas variáveis

Na padaria, a Ana e a Bia trocaram de turno. Sem desestruturação, trocar dois valores exige uma terceira variável temporária. Com ela, uma linha:

let manha = "Ana";
let tarde = "Bia";
[manha, tarde] = [tarde, manha];
console.log("Manhã:", manha);
console.log("Tarde:", tarde);

$ node trocar.js
Manhã: Bia
Tarde: Ana

O lado direito monta um array novo com os valores atuais (["Bia", "Ana"]); o lado esquerdo desmonta esse array nas duas variáveis. Repare: sem let nem const, porque as variáveis já existem (e precisam ser let, já que mudam). Atenção ao ponto e vírgula na linha anterior: veja Quando dá errado.

4. Objetos dentro de objetos

A desestruturação pode "descer" níveis. Escreva o mesmo formato do objeto, só que com as variáveis no lugar dos valores:

const cliente = {
  nome: "Ana",
  endereco: { rua: "Rua das Flores", cidade: "Recife" },
  pedidos: ["pão", "leite"],
};
const { nome, endereco: { cidade }, pedidos: [primeiroPedido] } = cliente;
console.log(nome, cidade, primeiroPedido);

$ node aninhado.js
Ana Recife pão

endereco: { cidade } quer dizer "entre em endereco e tire a cidade"; pedidos: [primeiroPedido], "entre em pedidos e tire o primeiro item". Neste caso não é criada a variável endereco nem pedidos. Use com moderação: mais de dois níveis fica difícil de ler, e é melhor fazer em duas linhas.

5. Nos parâmetros de uma função

É aqui que a desestruturação mais aparece. Uma função que recebe um objeto pode desmontá-lo já nos parâmetros:

function etiqueta({ nome, preco }) {
  console.log(`${nome}: R$ ${preco.toFixed(2)}`);
}

etiqueta({ nome: "Pão", preco: 0.8 });
etiqueta({ nome: "Bolo", preco: 15 });

$ node parametro.js
Pão: R$ 0.80
Bolo: R$ 15.00

Quem chama passa um objeto; a função recebe direto as variáveis nome e preco. A vantagem: na chamada, cada valor vem com o nome dele ({ nome: "Pão", preco: 0.8 }), sem precisar decorar a ordem dos parâmetros. Valores padrão nos parâmetros têm aula própria: Parâmetros Padrão.

No for … of com Object.entries

Object.entries(obj) devolve um array de pares [chave, valor] (veja Percorrendo Objetos). Desestruturando o par no próprio for … of, cada volta já tem as duas variáveis:

const estoque = { pao: 20, leite: 8, cafe: 3 };
for (const [produto, quantidade] of Object.entries(estoque)) {
  console.log(`${produto}: ${quantidade}`);
}

$ node entries.js
pao: 20
leite: 8
cafe: 3

Missão: o laço usa par[0] e par[1], que não dizem nada. Troque const par por const [aluno, nota] e use essas variáveis no console.log.

const notas = { Ana: 9, Bia: 7.5, Caio: 6 };
for (const par of Object.entries(notas)) {
  console.log(par[0] + " " + par[1]);
}

const notas = { Ana: 9, Bia: 7.5, Caio: 6 };
for (const [aluno, nota] of Object.entries(notas)) {
  console.log(`${aluno}: ${nota}`);
}

Formas diferentes de fazer a mesma coisa

SituaçãoSem desestruturaçãoCom desestruturação
Pegar 1 propriedadeconst nome = ana.nome;const { nome } = ana;
Pegar várias propriedadesuma linha para cadaconst { nome, idade, cidade } = ana;
Itens de um arrayconst a = lista[0]; const b = lista[1];const [a, b] = lista;
Trocar duas variáveisconst temp = a; a = b; b = temp;[a, b] = [b, a];
Parâmetros com nomefunction f(p) { p.nome … }function f({ nome }) { … }

Qual usar? Para uma propriedade só, as duas formas servem; muita gente prefere ana.nome direto no lugar onde usa. A desestruturação ganha quando você tira várias coisas do mesmo objeto, nos parâmetros de funções e no Object.entries. Para pegar "o resto" das propriedades num objeto separado (const { nome, ...resto } = ana;), veja a próxima aula, Spread e Rest.

let nome;

"Erro de sintaxe: símbolo = inesperado." Uma linha que começa com { é lida como um bloco de código (como o de um if), e um bloco não pode receber =. É erro de sintaxe, então nada do programa roda. Como consertar: ponha a linha inteira entre parênteses, ({ nome } = ana); (no lab, mostrou Ana), ou, melhor, desestruture já na criação: const { nome } = ana;.

Usou colchetes num objeto 
const ana = { nome: "Ana", idade: 30 };
const [nome, idade] = ana;

"ana não é iterável": os colchetes tiram valores pela posição, e um objeto comum não tem posições (não dá para percorrê-lo com for … of). Como consertar: objeto com chaves, const { nome, idade } = ana;; array com colchetes.

Trocou as variáveis sem ponto e vírgula na linha anterior 
let a = 1
let b = 2
[a, b] = [b, a]
console.log(a, b)

$ node semponto.js
/home/ana/semponto.js:3

    ^

ReferenceError: Cannot access 'b' before initialization
    at Object.<anonymous> (/home/ana/semponto.js:3:5)    « (mais 7 linhas node:internal cortadas)

Node.js v24.22.0

Uma mensagem estranha, porque o JavaScript leu as linhas 2 e 3 como uma só: let b = 2[a, b] = [b, a]. Sem o ponto e vírgula, o [ no começo da linha 3 foi entendido como "pegue um item de 2", e aí ele tentou usar o b enquanto ainda o estava criando ("não é possível acessar b antes da inicialização"). Como consertar: termine as instruções com ;, como o guia recomenda desde Instruções, Ponto e Vírgula e Blocos.

Resumo

  • Desestruturar é criar variáveis a partir de partes de um objeto ou array, numa linha só. O original não muda.
  • Objeto: chaves e nomes (const { nome } = ana;). Array: colchetes e posições (const [a, b] = lista;).
  • { nome: outroNome } renomeia; { estoque = 0 } dá um padrão, usado só quando o valor é undefined.
  • [a, b] = [b, a]; troca dois valores. Vírgula sem nome pula uma posição.
  • Nos parâmetros, function f({ nome, preco } = {}) recebe um objeto já desmontado.
  • Não dá para desestruturar undefined/null (Cannot destructure property) nem usar colchetes num objeto comum (is not iterable).
