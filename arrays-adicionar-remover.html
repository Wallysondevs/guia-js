JavaScript push, pop, shift e unshift

Uma lista de verdade muda o tempo todo: a Ana lembra do pão e acrescenta na lista de compras; o cliente da vez é atendido e sai da fila da padaria; o último prato lavado vai para o topo da pilha. Na aula Acessando e Alterando Itens, você trocou itens que já existiam. Agora vai pôr e tirar itens, fazendo o array crescer e diminuir. Para isso o array tem quatro métodos, dois para cada ponta da lista.

Você vai aprender
  • push: acrescentar um ou mais itens no fim.
  • pop: tirar o último item.
  • unshift: acrescentar no começo.
  • shift: tirar o primeiro item.
  • O que cada um devolve (o novo tamanho ou o item tirado) e como aproveitar isso.
  • Dois usos clássicos: a fila (quem chega primeiro sai primeiro) e a pilha (o último que entra é o primeiro que sai).
  • Como esvaziar um array e como acrescentar sem mexer no original.
  • Os erros reais mais comuns: guardar o resultado do push no lugar da lista, chamar push em algo que não é array e esperar que o pop tire um item específico.

Todos os programas desta aula rodaram no Node.js 24 da máquina da Ana (usuária ana, computador notebook), com node arquivo.js. Você pode rodar cada um no editor do guia.

A ideia: as duas pontas da lista

Pense numa fila de pessoas. Ela tem duas pontas: o começo (quem vai ser atendido agora) e o fim (onde chega quem acabou de entrar). Os quatro métodos desta aula mexem só nas pontas:

No começoNo fim
Pôr um itemunshiftpush
Tirar um itemshiftpop

Os nomes vêm do inglês: push = "empurrar" (para dentro, no fim), pop = "estourar", "saltar fora" (o último sai), shift = "deslocar" (todo mundo anda um lugar para a frente quando o primeiro sai) e unshift = o contrário do shift. Para tirar ou pôr itens no meio da lista existe o splice, da próxima aula (splice e slice).

Os quatro mudam o próprio array: não fazem uma cópia. Por isso funcionam mesmo com const (a folha de papel é a mesma; só o que está escrito nela muda, como você viu em Arrays).

1. push: acrescentar no fim

const compras = ["arroz", "feijão"];
compras.push("café");
console.log(compras);
compras.push("leite", "pão");
console.log(compras);
compras.push("café")
"Empurre o café para o fim da lista de compras". O ponto liga o array ao método, como em texto.toUpperCase(); o valor novo vai entre os parênteses.
compras.push("leite", "pão")
Vários valores separados por vírgula entram todos, nessa ordem.
$ node push.js
[ 'arroz', 'feijão', 'café' ]
[ 'arroz', 'feijão', 'café', 'leite', 'pão' ]

O push é o jeito mais comum de encher um array que começa vazio, item por item, como a Ana fazendo a lista da semana:

const lista = [];
console.log(lista, lista.length);
lista.push("sabão");
lista.push("esponja");
lista.push("detergente");
console.log(lista, lista.length);

$ node lista_vazia.js
[] 0
[ 'sabão', 'esponja', 'detergente' ] 3

O que o push devolve

Todo método pode devolver um valor (veja Retornando Valores). O push devolve o novo tamanho do array:

const fila = ["Ana", "Bia"];
const tamanho = fila.push("Caio");
console.log(tamanho);
console.log(`Você é o ${fila.push("Duda")}º da fila.`);
console.log(fila);

$ node push_devolve.js
3
Você é o 4º da fila.
[ 'Ana', 'Bia', 'Caio', 'Duda' ]

Repare: ele não devolve o array, e sim um número. Guardar esse número na variável da lista é um dos erros mais comuns desta aula (veja Quando dá errado).

2. pop: tirar o último

const compras = ["arroz", "feijão", "café"];
const tirado = compras.pop();
console.log(tirado);
console.log(compras);
compras.pop()
Tira o último item do array. Os parênteses ficam vazios: o pop não precisa de nenhuma informação, porque sempre tira o último.
const tirado = …
O pop devolve o item que tirou. Assim você pode usá-lo (mostrar, guardar em outro lugar). Se não precisar dele, é só escrever compras.pop(); sozinho.
$ node pop.js
café
[ 'arroz', 'feijão' ]

E se o array estiver vazio? O pop não dá erro: devolve undefined e o array continua vazio.

const vazio = [];
console.log(vazio.pop());
console.log(vazio);

$ node pop_vazio.js
undefined
[]

3. unshift: acrescentar no começo

A Ana lembrou de uma coisa urgente e quer pô-la no topo da lista:

const compras = ["arroz", "feijão", "café"];
const tamanho = compras.unshift("remédio");
console.log(tamanho);
console.log(compras);
console.log(compras[1]);

$ node unshift.js
4
[ 'remédio', 'arroz', 'feijão', 'café' ]
arroz

Como o push, o unshift devolve o novo tamanho e aceita vários valores. Mas repare na última linha: o arroz, que estava na posição 0, agora está na posição 1. Ao entrar alguém no começo, todos os outros andam uma posição para a frente, e os índices de todos mudam. Se você guardou "o arroz está na posição 0" numa variável, essa informação ficou velha.

4. shift: tirar o primeiro

const fila = ["Ana", "Bia", "Caio"];
const daVez = fila.shift();
console.log(`Atendendo: ${daVez}`);
console.log(fila);
console.log(fila[0]);

$ node shift.js
Atendendo: Ana
[ 'Bia', 'Caio' ]
Bia

O shift tira o primeiro item e o devolve, como o pop faz com o último. Os que ficaram andam uma posição para a frente: a Bia, que era a posição 1, agora é a posição 0. Com o array vazio, também devolve undefined.

Missão: a Ana já foi atendida. Complete o programa: chame a próxima pessoa da fila com shift, guarde em daVez, e depois acrescente a "Duda", que acabou de chegar, no fim da fila.

const daVez = "ninguém";
console.log(`Atendendo: ${daVez}`);

console.log(fila);

const fila = ["Bia", "Caio"];
const daVez = fila.shift();
console.log(`Atendendo: ${daVez}`);
fila.push("Duda");
console.log(fila);

5. Os quatro juntos no modo interativo

No modo interativo (veja O Modo Interativo), o Node mostra o que cada método devolve. É o melhor jeito de decorar quem devolve o quê:

$ node
Welcome to Node.js v24.22.0.
Type ".help" for more information.
> const fila = ["Ana", "Bia", "Caio"]
undefined
> fila.push("Duda")
4
> fila.pop()
'Duda'
> fila.unshift("Eva")
4
> fila.shift()
'Eva'
> fila
[ 'Ana', 'Bia', 'Caio' ]
> .exit

Os que põem (push, unshift) devolveram o novo tamanho: 4 e depois 4 de novo. Os que tiram (pop, shift) devolveram o item que saiu.

6. A fila e a pilha

Juntando os métodos em pares, você tem duas das estruturas mais usadas da computação, e as duas aparecem na vida da Ana.

A fila da padaria: push + shift

Numa fila, quem chega primeiro é atendido primeiro (os programadores chamam isso de FIFO, do inglês first in, first out, "primeiro a entrar, primeiro a sair"). Quem chega entra no fim (push); quem é atendido sai do começo (shift):

const fila = [];
fila.push("Ana");
fila.push("Bia");
fila.push("Caio");
console.log("Fila:", fila);

console.log(`Atendendo ${fila.shift()}. Ainda na fila: ${fila.length}`);
fila.push("Duda");
console.log(`Atendendo ${fila.shift()}. Ainda na fila: ${fila.length}`);
console.log("Fila:", fila);

$ node fila.js
Fila: [ 'Ana', 'Bia', 'Caio' ]
Atendendo Ana. Ainda na fila: 2
Atendendo Bia. Ainda na fila: 2
Fila: [ 'Caio', 'Duda' ]

A pilha de pratos: push + pop

Numa pilha de pratos, o último prato posto em cima é o primeiro a ser pego (LIFO: last in, first out, "último a entrar, primeiro a sair"). O botão "desfazer" dos editores de texto funciona assim: cada ação vai para o topo da pilha, e o desfazer tira a mais recente.

const historico = [];
historico.push("escreveu 'Olá'");
historico.push("pôs negrito");
historico.push("apagou uma palavra");

console.log("Desfazendo:", historico.pop());
console.log("Desfazendo:", historico.pop());
console.log("Sobrou:", historico);

$ node desfazer.js
Desfazendo: apagou uma palavra
Desfazendo: pôs negrito
Sobrou: [ "escreveu 'Olá'" ]

Repare na última linha: o Node mostrou o item com aspas duplas, "escreveu 'Olá'". Como o texto já tem aspas simples dentro, o console.log troca para as duplas, para a saída não ficar confusa. O texto guardado é o mesmo.

Para ler sem tirar

Se você só quer espiar quem é o próximo, sem tirá-lo da fila, não use shift nem pop: leia com fila[0] (o primeiro) ou pilha.at(-1) (o topo), como na aula Acessando e Alterando Itens.

7. Esvaziar o array

A Ana fez as compras e quer a lista em branco de novo. Com let, basta pôr um array vazio na variável. Com const, não dá para trocar o array (você viu o Assignment to constant variable na aula Arrays), mas dá para mudar o tamanho dele para zero:

const compras = ["arroz", "feijão", "café"];
compras.length = 0;
console.log(compras);

let outra = ["sabão", "esponja"];
outra = [];
console.log(outra);

$ node esvaziar.js
[]
[]

O length pode ser escrito, e não só lido: pôr um número menor corta o array nesse tamanho (compras.length = 1 deixaria só o arroz). Outro jeito, com const, é tirar com pop até acabar, num laço; mas length = 0 resolve numa linha.

Formas diferentes de fazer a mesma coisa

Para acrescentar no fim existem três jeitos. Os dois primeiros mudam o array; o terceiro, com os três pontinhos (o spread, "espalhar"; aula Spread e Rest), cria um array novo e deixa o original como estava:

const a = ["arroz", "feijão"];
a.push("café");

const b = ["arroz", "feijão"];
b[b.length] = "café";

const c = ["arroz", "feijão"];
const d = [...c, "café"];
const e = ["remédio", ...c];

console.log(a);
console.log(b);
console.log(c);
console.log(d);
console.log(e);

$ node formas.js
[ 'arroz', 'feijão', 'café' ]
[ 'arroz', 'feijão', 'café' ]
[ 'arroz', 'feijão' ]
[ 'arroz', 'feijão', 'café' ]
[ 'remédio', 'arroz', 'feijão' ]

O c continuou com 2 itens: [...c, "café"] quer dizer "um array novo com tudo o que está em c e, depois, o café". Esse jeito de não mexer no original é útil quando outra parte do programa ainda precisa da lista antiga.

Sem erro nenhum, e por isso perigoso: a Ana queria tirar o arroz, mas saiu o café. O pop ignora o que você põe entre os parênteses e sempre tira o último (o shift, sempre o primeiro). Resumo

  • push põe no fim e unshift põe no começo; os dois aceitam vários valores e devolvem o novo tamanho.
  • pop tira o último e shift tira o primeiro; os dois devolvem o item tirado (undefined se o array estiver vazio) e ignoram o que for posto entre os parênteses.
  • Os quatro mudam o próprio array (funcionam com const). shift e unshift mudam os índices de todos os outros itens.
  • Fila: push + shift. Pilha: push + pop.
  • lista.length = 0 esvazia; [...lista, x] cria um array novo sem mexer no original.
  • Nunca guarde o resultado do push na variável da lista: ela vira um número.
