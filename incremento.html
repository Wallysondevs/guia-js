JavaScript Incremento e Decremento

Contar é uma das coisas que os programas mais fazem: quantas pessoas visitaram o site, quantas vidas sobram no jogo, em que volta do laço estamos. Contar é somar 1, de novo e de novo. É tão comum que o JavaScript tem dois operadores só para isso: o ++, que soma 1 (o incremento), e o --, que tira 1 (o decremento).

Você vai aprender
  • O que contador++ e contador-- fazem, e a que eles equivalem.
  • Como usar os dois em contadores do dia a dia: visitas, vidas, senhas.
  • A diferença entre x++ (depois) e ++x (antes), e quando ela importa.
  • Onde você mais vai ver o ++: o laço for.
  • Os erros reais: ++ numa const, num número escrito, e o pontos = pontos++ que não soma nada.

A ideia: o contador de mão

Na porta de uma festa, o segurança segura um contador de mão, aquele aparelhinho de metal com um botão. Cada pessoa que entra, ele aperta o botão uma vez: clic, o número sobe 1. Ele não faz conta nenhuma, não precisa saber quantas pessoas já entraram: só aperta. Alguns contadores têm um segundo botão, que diminui 1, para quando alguém sai.

O ++ é o botão de subir, e o -- é o botão de descer. Você só diz qual variável, e ela ganha ou perde 1.

1. ++ soma 1, -- tira 1

let visitas = 0;
visitas++;
console.log(visitas);
visitas++;
visitas++;
console.log(visitas);
visitas--;
console.log(visitas);
let visitas = 0;
O contador começa em zero. Tem de ser let, porque o valor vai mudar (veja Variáveis).
visitas++;
"Some 1 às visitas". Lê-se "visitas mais mais". Os dois sinais vão colados um no outro e na variável.
visitas++; visitas++;
Mais dois cliques: de 1 para 3.
visitas--;
"Tire 1 das visitas": de 3 para 2.
$ node contador.js
1
3
2

O ++ faz a mesma coisa que as formas que você viu na aula Atribuição, só que mais curta:

Por extensoCom atalho de atribuiçãoCom incremento
visitas = visitas + 1;visitas += 1;visitas++;
visitas = visitas - 1;visitas -= 1;visitas--;

Repare que o ++ só serve para 1. Para somar 2, 5 ou 10, use o +=: pontos += 10;.

2. Antes ou depois: x++ × ++x

O ++ pode ficar depois da variável (x++) ou antes (++x). Nos dois casos, a variável ganha 1. A diferença está no valor que a expressão devolve naquele instante, e ela só aparece quando você usa o ++ dentro de outra coisa (uma atribuição, um console.log, uma conta).

let a = 5;
const b = a++;
console.log(`a = ${a}, b = ${b}`);
let c = 5;
const d = ++c;
console.log(`c = ${c}, d = ${d}`);

$ node posicao.js
a = 6, b = 5
c = 6, d = 6
const b = a++;
Pós-incremento (o ++ vem depois): "entregue o valor atual de a e depois some 1". O b recebeu o 5 antigo; o a virou 6.
const d = ++c;
Pré-incremento (o ++ vem antes): "some 1 antes e entregue o valor novo". O c virou 6, e o d recebeu esse 6.

No modo interativo do Node (veja O Modo Interativo), dá para ver o valor que cada forma devolve, um passo de cada vez:

$ node

> ++x

O x++ respondeu 5 (o valor de antes), mas logo depois o x já valia 6. O ++x respondeu 7, o valor novo, na hora. O -- segue a mesma regra: x-- respondeu 7 e só depois o x virou 6.

Um uso do x++: a senha da fila

Na padaria, a máquina de senhas entrega o número atual e já avança para o próximo. É exatamente o pós-incremento:

let senha = 1;
console.log(`Senha ${senha++}`);
console.log(`Senha ${senha++}`);
console.log(`Senha ${senha++}`);
console.log(`Próxima: ${senha}`);

$ node senha.js
Senha 1
Senha 2
Senha 3
Próxima: 4

Funciona e é curto, mas exige que quem lê saiba a regra do "depois". Na dúvida, separe em duas linhas: console.log(`Senha ${senha}`); e senha++;. O resultado é o mesmo, e ninguém precisa pensar.

A regra prática do guia

Use o ++ e o -- sozinhos na linha (visitas++;) ou no for. Assim, tanto faz x++ ou ++x: o resultado é igual, e a diferença desta seção nunca te pega. O costume mais comum é o x++.

Experimente: este programa usou ++senha (antes) e por isso a fila começa na senha 2. Troque para senha++ (depois) nas quatro linhas para a fila começar na 1 e a próxima ser a 5.

3. Onde o ++ mais aparece: o laço for

O lugar mais famoso do ++ é o laço for, que repete um bloco de código contando as voltas. O i++ no fim da primeira linha é o "aperte o contador" de cada volta. O for tem aula própria (for); aqui, repare só no i++:

for (let i = 1; i <= 3; i++) {
  console.log(`Volta ${i}`);
}

$ node for.js
Volta 1
Volta 2
Volta 3

O i começa em 1; depois de cada volta, o i++ soma 1; quando ele passa de 3, o laço para. Para contar para trás, o mesmo laço usa i--. O nome i (de "índice") é uma tradição para contadores de laço.

4. Com outros tipos de valor

O ++ funciona com qualquer número, inteiro ou não. E, diferente do +=, ele sempre converte para número antes de somar:

let quantidade = "5";
quantidade++;
console.log(quantidade, typeof quantidade);
let preco = 1.5;
preco++;
console.log(preco);
let nada;
nada++;
console.log(nada);
let nulo = null;
nulo++;
console.log(nulo);

$ node texto.js
6 number
2.5
NaN
1
quantidade++ com "5" → 6, number
O texto "5" virou o número 5 e ganhou 1. Com quantidade += 1, o resultado seria o texto "51" (veja Conversão Automática). Mesmo assim, não conte com isso: converta antes, com Number().
preco++ com 1.5 → 2.5
Soma 1 a qualquer número, com casas decimais ou não.
nada++ → NaN
Uma variável sem valor é undefined, e undefined mais 1 é NaN. Contador sempre começa com valor: let nada = 0;.
nulo++ → 1
O null vira 0 numa conta (veja null e undefined), e 0 + 1 = 1.

"Expressão inválida no lado esquerdo de uma operação pós-fixa" (pós-fixa é a que vem depois, o x++). O ++ precisa de um lugar onde guardar o resultado, uma variável. O 5 é só um valor: não dá para "somar 1 no 5 e guardar no 5". Com o ++ antes (++5), a mensagem fala em prefix operation (operação prefixa). Como consertar: para mostrar o número seguinte, faça a conta: console.log(5 + 1);. Para contar, use uma variável.

pontos = pontos++: o incremento que some 
let pontos = 10;
pontos = pontos++;
console.log(pontos);

$ node xigual.js
10

Nenhum erro, e os pontos continuaram 10. Siga a ordem: o pontos++ devolve o valor antigo (10) e soma 1 (os pontos viram 11); depois, a atribuição guarda aquele 10 devolvido em pontos, apagando o 11. O incremento aconteceu e foi desfeito na mesma linha. Como consertar: o ++ já guarda o resultado sozinho; escreva só pontos++;.

Escreveu pontos + 1 e esperou que mudasse 
let pontos = 10;
pontos + 1;
console.log(pontos);

$ node maisum.js
10

A linha pontos + 1; calcula 11 e joga o resultado fora: não tem = para guardar. Diferente do ++, o + sozinho não muda a variável. Como consertar: pontos++; ou pontos += 1;.

Com espaço no meio, já não é o operador ++: são dois + separados, e o JavaScript esperava um valor depois do segundo. Encontrou o ; ("símbolo ; inesperado"). Como consertar: os dois sinais colados: pontos++;.

a+++b: o código que confunde

O JavaScript aceita a+++b, e lê como (a++) + b. Com a = 2 e b = 3, o console.log(a+++b) mostrou 5 no lab, e o a passou a valer 3. Funciona, mas ninguém consegue ler isso de primeira. Como consertar: separe em linhas e use espaços: const soma = a + b; e depois a++;.

Resumo

  • x++ soma 1 à variável e x-- tira 1. É o mesmo que x += 1 e x -= 1, mais curto. Para outros valores, use += e -=.
  • Os dois sinais vão colados e a variável tem de ser let (numa const: Assignment to constant variable.). Num valor solto, como 5++, é erro de sintaxe.
  • x++ devolve o valor de antes; ++x devolve o valor novo. A diferença só aparece quando o ++ está dentro de outra coisa.
  • Use o ++ sozinho na linha ou no passo do for (i++), e a diferença nunca vai te pegar. Nunca escreva x = x++.
