JavaScript map: Transformando um Array

A padaria vai reajustar todos os preços em 10%. A professora quer a lista da chamada em letras maiúsculas para imprimir. A Ana quer cada preço escrito bonitinho, como R$ 4.50. As três tarefas têm a mesma forma: pegar um array, fazer a mesma transformação em cada item e obter um array novo com os resultados. Para isso existe o map (em inglês, "mapear": fazer corresponder a cada item de uma lista um item de outra).

Você vai aprender
  • Como o map cria um array novo a partir de uma função que transforma um item.
  • Que o array original não muda, e que o novo tem sempre o mesmo tamanho.
  • Exemplos do dia a dia: aumentar preços, mudar textos, formatar valores, numerar uma lista.
  • A diferença entre a arrow function curta e a com chaves (que precisa de return).
  • A converter textos em números com map(Number), e a pegadinha do map(parseInt).
  • Por que map é melhor que forEach + push para montar um array.
  • Os erros reais mais comuns: o array cheio de undefined, o map que "não fez nada" e o map is not a function.

Todos os programas desta aula rodaram no Node.js 24 da máquina da Ana (usuária ana, computador notebook), com node arquivo.js. Você pode rodar cada um no editor do guia.

A ideia: a máquina de suco

Na lanchonete, a Ana põe as frutas na máquina de suco, uma de cada vez. Para cada fruta que entra, sai um copo de suco: entra laranja, sai suco de laranja; entra uva, sai suco de uva. No fim, ela tem uma fileira de copos, um para cada fruta, na mesma ordem. E as frutas que sobraram na fruteira continuam lá (a máquina não mexeu na fruteira; trabalhou com as que você deu a ela).

  • A fruteira é o array original.
  • A máquina é a função que você escreve: ela sabe transformar uma fruta em um suco.
  • A fileira de copos é o array novo que o map devolve.

1. O primeiro map

const numeros = [1, 2, 3, 4];
const dobros = numeros.map((n) => n * 2);
console.log(dobros);
console.log(numeros);
numeros.map( … )
"Mapeie numeros": para cada item, chame a função e guarde o que ela devolver.
(n) => n * 2
A "máquina": uma arrow function que recebe um número e devolve o dobro dele. Na forma curta (sem chaves), o valor depois da seta é devolvido automaticamente.
const dobros = …
O map devolve um array novo com os resultados, na mesma ordem. Ele precisa ser guardado numa variável (ou usado na hora); senão, o resultado se perde.
$ node dobro.js
[ 2, 4, 6, 8 ]
[ 1, 2, 3, 4 ]

E a segunda linha da saída confirma: numeros continua [ 1, 2, 3, 4 ]. O map nunca mexe no original.

const novos = precos.map((preco) => preco * 1.1);
console.log(novos);

const arredondados = precos.map((preco) => Math.round(preco * 1.1 * 100) / 100);
console.log(arredondados);

$ node reajuste.js

A primeira linha mostra a imprecisão das contas com vírgula (veja NaN, Infinity e a Precisão). A segunda arredonda cada preço para 2 casas: multiplica por 100, arredonda com Math.round (veja Math) e divide de volta. Toda essa conta cabe dentro da função do map.

const alunos = ["Ana", "Bia", "Caio", "Duda"];
console.log(alunos.map((nome) => nome.toUpperCase()));
console.log(alunos.map((nome) => nome.length));

Repare que o array novo não precisa ter o mesmo tipo de item do original: de nomes (textos) saiu um array de tamanhos (números). O que não muda é a quantidade: 4 nomes, 4 resultados.

Formatar para mostrar

3. Com chaves, precisa de return

Quando a transformação precisa de mais de uma linha (uma variável no meio, um if), a arrow function ganha chaves. E aí, como em qualquer função, o valor só sai se tiver return (veja Retornando Valores):

const notas = [7.5, 5, 9, 4];
const situacao = notas.map((nota) => {
  if (nota >= 6) {
    return `${nota}: aprovado`;
  }
  return `${nota}: recuperação`;
});
console.log(situacao);

$ node situacao.js
[ '7.5: aprovado', '5: recuperação', '9: aprovado', '4: recuperação' ]

A mesma coisa cabe numa linha com o operador ternário: notas.map((nota) => nota >= 6 ? `${nota}: aprovado` : `${nota}: recuperação`). Use a forma que for mais fácil de ler. O que acontece quando o return é esquecido está em Quando dá errado.

4. A posição: numerando a lista

Como no forEach, a função recebe a posição como segundo parâmetro:

const alunos = ["Ana", "Bia", "Caio"];
const chamada = alunos.map((nome, i) => `${i + 1}. ${nome}`);
console.log(chamada);

$ node numerar.js
[ '1. Ana', '2. Bia', '3. Caio' ]

5. Textos que viram números: map(Number)

Quando os números chegam como texto (de um arquivo, do teclado, de um split), o map converte todos de uma vez. Dá para entregar a função Number (veja Conversão) pelo nome, como você fez com funções em forEach:

const linha = "7.5;8;6.5;10";
const textos = linha.split(";");
const notas = textos.map(Number);
console.log(textos);
console.log(notas);

$ node numeros.js
[ '7.5', '8', '6.5', '10' ]
[ 7.5, 8, 6.5, 10 ]

Os itens de textos aparecem com aspas (são strings); os de notas, sem (são números, e agora dá para somar). textos.map(Number) é o mesmo que textos.map((t) => Number(t)).

A pegadinha do map(parseInt)

E com o parseInt, que também converte texto em número inteiro?

const textos = ["10", "10", "10"];
console.log(textos.map(Number));
console.log(textos.map(parseInt));
console.log(textos.map((t) => parseInt(t)));

$ node parseint.js
[ 10, 10, 10 ]
[ 10, NaN, 2 ]
[ 10, 10, 10 ]

O segundo resultado parece um defeito, mas tem explicação. O map chama a função com dois valores, o item e a posição: parseInt("10", 0), parseInt("10", 1), parseInt("10", 2). E o segundo valor do parseInt é a base do número: 0 quer dizer "decida sozinho" (deu 10), base 1 não existe (deu NaN), e na base 2 (binário) "10" vale 2. É a mesma armadilha do forEach(console.log). Regra prática: passe pelo nome só funções feitas para receber um valor, como Number; na dúvida, escreva a arrow function.

Missão: a Ana anotou os preços com vírgula, e o Number("1,5") dá NaN. Use o map para trocar a vírgula por ponto em cada texto (t.replace(",", ".")) e converter para número, numa função só.

const textos = ["1,5", "2,25", "3"];
const precos = textos.map(Number);
console.log(precos);

const textos = ["1,5", "2,25", "3"];
const precos = textos.map((t) => Number(t.replace(",", ".")));
console.log(precos);

Formas diferentes de fazer a mesma coisa

Antes do map, um array transformado se montava à mão, com um laço e push. Você ainda vai ver isso em muito código:

const precos = [0.9, 4, 6.5];

// 1. map
const a = precos.map((preco) => preco * 2);

// 2. for … of + push
const b = [];
for (const preco of precos) {
  b.push(preco * 2);
}

// 3. forEach + push
const c = [];
precos.forEach((preco) => c.push(preco * 2));

console.log(a);
console.log(b);
console.log(c);

$ node formas.js
[ 1.8, 8, 13 ]
[ 1.8, 8, 13 ]
[ 1.8, 8, 13 ]

Os três dão o mesmo array, mas o map diz numa linha só o que está acontecendo ("a é precos transformado"), sem um array vazio que vai sendo enchido, e o resultado pode ser uma const desde o começo.

SituaçãoQual usar
Um array novo, com cada item transformado (mesmo tamanho)map
Só fazer algo com cada item (mostrar, salvar), sem montar arrayforEach ou for … of
Um array novo com só alguns itensfilter (próxima aula)
Um valor só a partir de todos (soma, maior)reduce ou um laço com acumulador
Mudar o próprio array, sem criar outroUm laço escrevendo em lista[i] (raro; prefira o map)

Como o map devolve um array, dá para emendar outro método logo depois: alunos.map((n) => n.toUpperCase()).map((n) => `${n}!`). Esse "encadeamento" fica ainda mais útil junto com o filter, na próxima aula.

Quando dá errado

Chaves sem return: um array de undefined 
const precos = [0.9, 4, 6.5];
const dobros = precos.map((preco) => {
  preco * 2;
});
console.log(dobros);

$ node sem_return.js
[ undefined, undefined, undefined ]

Nenhuma mensagem de erro, mas o array novo está cheio de undefined. A conta preco * 2 foi feita e jogada fora: com chaves, a função só devolve o que estiver num return, e sem ele devolve undefined. O map guardou fielmente esses três undefined. Como consertar: return preco * 2;, ou a forma curta, sem chaves: (preco) => preco * 2.

Achou que o map mudava o original 
const nomes = ["ana", "bia"];
nomes.map((nome) => nome.toUpperCase());
console.log(nomes);

$ node original.js
[ 'ana', 'bia' ]

O map trabalhou e devolveu [ 'ANA', 'BIA' ], mas ninguém guardou o resultado, e o nomes continuou igual. Como consertar: guarde o array novo: const maiusculos = nomes.map(…). (Se a variável for let, dá até para pôr o novo no lugar do velho: nomes = nomes.map(…).)

Usou map para filtrar 
const notas = [7.5, 5, 9, 4];
const aprovadas = notas.map((nota) => {
  if (nota >= 6) {
    return nota;
  }
});
console.log(aprovadas);

$ node filtrar.js
[ 7.5, undefined, 9, undefined ]

As notas baixas não sumiram: viraram undefined. O map sempre devolve um array do mesmo tamanho; quando a função não devolve nada, o lugar fica com undefined. Como consertar: para ficar só com alguns itens, o método é o filter: notas.filter((nota) => nota >= 6).

const precos = [4, 12];

const comDesconto = precos;
const cardapio = produtos;

  console.log(linha);
}

Resumo

  • lista.map(funcao) chama a função para cada item e devolve um array novo com o que ela devolveu, na mesma ordem.
  • O array novo tem sempre o mesmo tamanho; o original não muda. Guarde o resultado numa variável.
  • Na arrow function curta, o valor sai sozinho; com chaves, precisa de return (senão, sai um array de undefined).
  • A função recebe (item, posição, array), como no forEach.
  • textos.map(Number) converte textos em números; map(parseInt) dá NaN por causa da posição.
  • Para transformar, map; para escolher alguns itens, filter; para só fazer algo com cada um, forEach.
