JavaScript Pedaços de String

Na aula anterior, você descobriu onde um pedaço está dentro de um texto. Agora vem o passo seguinte: recortar esse pedaço. Pegar os 3 primeiros caracteres do código do produto, o nome do usuário antes do @, a extensão do arquivo, a última letra de uma palavra. Para isso, as strings têm o slice ("fatia") e o at ("na posição").

Você vai aprender
  • slice(início, fim): a fatia entre duas posições, e por que o fim não entra.
  • slice(início): do início até o final do texto.
  • Posições negativas: contar a partir do fim (slice(-3), os 3 últimos).
  • at(posição): um caractere só, com at(-1) para o último.
  • Receitas do dia a dia: o nome antes do @, a primeira letra maiúscula, cortar um texto comprido com ….
  • O que são substring e charAt, que aparecem em código antigo.
  • Os erros reais: nome[-1], slice com colchetes, e o -1 do indexOf que corta uma letra sem você perceber.

A ideia: cortar a fita métrica

Imagine o texto escrito numa fita, uma letra em cada quadradinho, e uma régua por cima marcando as divisas entre os quadradinhos: a divisa 0 antes da primeira letra, a 1 depois dela, e assim por diante.

Divisa (posição)0123456
Letra de "padoca"padoca

Para recortar, você diz em qual divisa a tesoura entra e em qual ela sai. Cortando na divisa 0 e na 3, sai pad. É por isso que, no slice(0, 3), a letra da posição 3 (o o) não entra: a tesoura passa antes dela. Um bônus dessa ideia: o tamanho da fatia é sempre fim − início (3 − 0 = 3 letras).

Exemplo real: o código do produto

Na padaria, cada produto tem um código como PAO-2026-0042: 3 letras do tipo, o ano e o número. Como o formato é fixo, as posições também são:

const codigo = "PAO-2026-0042";

const tipo = codigo.slice(0, 3);
const ano = codigo.slice(4, 8);
const numero = codigo.slice(9);

console.log("Tipo:", tipo);
console.log("Ano:", ano);
console.log("Número:", numero);

$ node codigo.js
Tipo: PAO
Ano: 2026
Número: 0042

O ano é slice(4, 8): começa depois do primeiro hífen (que está na posição 3) e tem 4 dígitos (8 − 4 = 4). Repare que o numero continua texto ("0042", com os zeros); para fazer conta com ele, converta com Number() (veja Conversão).

Missão: os bolos têm código no formato BOLO-CHOC-G: tipo, sabor (4 letras) e tamanho (1 letra). Use slice para separar o sabor e o tamanho. Deve aparecer Sabor: CHOC e Tamanho: G.

const codigo = "BOLO-CHOC-G";
const sabor = codigo;
const tamanho = codigo;
console.log("Sabor:", sabor);
console.log("Tamanho:", tamanho);

const codigo = "BOLO-CHOC-G";
const sabor = codigo.slice(5, 9);
const tamanho = codigo.slice(10);
console.log("Sabor:", sabor);
console.log("Tamanho:", tamanho);

2. Posições negativas: contando do fim

No slice, um número negativo conta a partir do fim do texto: -1 é a última divisa antes do fim, -3 é três letras antes do fim. É o jeito fácil de pegar "os últimos" sem saber o tamanho do texto:

const arquivo = "cardapio.pdf";
const telefone = "81999990042";

console.log(arquivo.slice(-3));
console.log(arquivo.slice(0, -4));
console.log(telefone.slice(-4));
console.log("final: " + telefone.slice(-4).padStart(telefone.length, "*"));

$ node negativo.js

cardapio
0042
final: *******0042
slice(-3)
As 3 últimas letras: a extensão do arquivo.
slice(0, -4)
Do começo até 4 antes do fim: o nome do arquivo sem o .pdf.
slice(-4).padStart(…, "*")
Os 4 últimos dígitos do telefone, completados com * à esquerda até o tamanho original (o padStart é da aula Métodos de String). É assim que os sites mostram "cartão final 0042".

3. Um caractere só: at()

Para pegar um caractere, você já conhece os colchetes: nome[0]. O at faz o mesmo, com uma vantagem: ele aceita posições negativas.

const nome = "Caio";

console.log(nome.at(0));
console.log(nome.at(1));
console.log(nome.at(-1));
console.log(nome.at(-2));
console.log(nome[nome.length - 1]);
console.log(nome.at(10));

$ node at.js
C
a
o
i
o
undefined

at(-1) é o último caractere, at(-2) o penúltimo. Antes do at, o jeito era nome[nome.length - 1], que dá o mesmo resultado com mais esforço. Posição que não existe dá undefined, sem erro. O at é do ES2022 e funciona em qualquer Node atual.

4. Receitas do dia a dia

O nome antes do @

Juntando o indexOf da aula Procurando em Strings com o slice: primeiro você acha a posição, depois corta nela.

const email = "bia.lima@padaria.com.br";
const arroba = email.indexOf("@");

const usuario = email.slice(0, arroba);
const dominio = email.slice(arroba + 1);

console.log("Posição do @:", arroba);
console.log("Usuário:", usuario);
console.log("Domínio:", dominio);

$ node email.js
Posição do @: 8
Usuário: bia.lima
Domínio: padaria.com.br

O slice(0, arroba) pega tudo antes do @ (o fim não entra, e aqui isso é ótimo: o @ fica de fora). O slice(arroba + 1) começa um depois do @ e vai até o fim.

A primeira letra maiúscula

const nome = "bia";
const bonito = nome.at(0).toUpperCase() + nome.slice(1);
console.log(bonito);

$ node capitalizar.js
Bia

A primeira letra em maiúscula ("B") emendada com o resto a partir da posição 1 ("ia"). O JavaScript não tem um método pronto para isso: essa combinação é o jeito de sempre.

Cortar um texto comprido

const recado = "Encomenda de 3 bolos de cenoura com cobertura de chocolate para sábado";
const curto = recado.slice(0, 30) + "…";
console.log(curto);
console.log("Oi".slice(0, 30));

$ node resumo.js
Encomenda de 3 bolos de cenour…
Oi

Se o texto for menor que o corte, o slice simplesmente devolve o que tem, sem erro: "Oi".slice(0, 30) é "Oi". (Para pôr o … só quando o texto foi cortado de verdade, você vai precisar de um if.)

Experimente: troque o texto e os números do slice. Teste números negativos, um início maior que o fim, e números maiores que o tamanho do texto.

const texto = "pão de queijo";
console.log(texto.slice(0, 3));
console.log(texto.slice(7));
console.log(texto.slice(-6));

Formas diferentes de fazer a mesma coisa

Em código antigo você vai encontrar outros métodos que fazem quase o mesmo:

const nome = "padoca";

console.log(nome.slice(0, 3), nome.substring(0, 3));
console.log(nome.slice(-3), nome.substring(-3));
console.log(nome.at(0), nome.charAt(0), nome[0]);
console.log(nome.at(-1), nome.charAt(-1), nome[-1]);

$ node formas.js

p p p
a  undefined
  • substring(início, fim) é igual ao slice com números positivos. Mas ele não entende negativos: trata -3 como 0 e devolveu o texto inteiro.
  • charAt(posição) ("caractere na") é o at antigo: com -1, devolve a string vazia (o espaço em branco depois do a na última linha).
  • nome[-1] dá undefined: os colchetes também não entendem negativos (veja Quando dá errado).
  • Existe ainda o substr(início, quantidade), marcado como obsoleto na documentação: não use em código novo.

Quando dá errado

nome[-1]: os colchetes não contam do fim 
const nome = "Caio";
console.log(nome[-1]);
console.log(nome.at(-1));

Quem vem do Python espera que nome[-1] seja a última letra. No JavaScript, os colchetes procuram uma posição chamada literalmente -1, que não existe: undefined, sem erro. Como consertar: nome.at(-1).

Não achou o separador, e o -1 cortou uma letra 
const email = "biapadaria.com";
const arroba = email.indexOf("@");
console.log("Posição:", arroba);
console.log("Usuário:", email.slice(0, arroba));

$ node semarroba.js
Posição: -1
Usuário: biapadaria.co

O e-mail veio sem @. O indexOf devolveu -1 ("não achei"), e o slice(0, -1) entendeu isso como "até 1 antes do fim": cortou o m e devolveu um "usuário" sem sentido. Nenhum erro na tela. Como consertar: antes de cortar, confira se achou (email.includes("@"), ou arroba !== -1) e trate o caso com um if.

Colchetes no lugar dos parênteses 
const nome = "padoca";
console.log(nome.slice[0, 3]);
console.log(nome.slice(0, 3));

$ node colchetes.js
undefined
pad

Com colchetes, você não chamou o método: pediu "a posição 3 do slice" (o 0, 3 entre colchetes vale só o último número). O método não tem isso, e veio undefined. Como consertar: métodos usam parênteses: slice(0, 3).

Início maior que o fim 
const palavra = "padoca";
console.log(`[${palavra.slice(4, 1)}]`);
console.log(`[${palavra.slice(1, 4)}]`);

$ node invertido.js

[ado]

Com o início depois do fim, o slice não "vira" o pedaço: devolve a string vazia (por isso os colchetes vazios). Como consertar: o primeiro número é sempre o da esquerda: slice(1, 4).

Missão final: o nome e a extensão

Missão: o arquivo se chama cardapio.pdf. Mostre o nome sem a extensão e com a primeira letra maiúscula (Arquivo: Cardapio) e a extensão sem o ponto (Tipo: pdf). Use slice, at e toUpperCase. Para um desafio extra, faça funcionar também com foto.jpeg usando o lastIndexOf(".").

const arquivo = "cardapio.pdf";
const nome = arquivo;
const tipo = arquivo;
console.log(`Arquivo: ${nome}`);
console.log(`Tipo: ${tipo}`);

const arquivo = "cardapio.pdf";
const ponto = arquivo.lastIndexOf(".");
const semExtensao = arquivo.slice(0, ponto);
const nome = semExtensao.at(0).toUpperCase() + semExtensao.slice(1);
const tipo = arquivo.slice(ponto + 1);
console.log(`Arquivo: ${nome}`);
console.log(`Tipo: ${tipo}`);

Resumo

  • texto.slice(início, fim) recorta da posição início até antes do fim; o tamanho do pedaço é fim − início. Sem o fim, vai até o final.
  • Números negativos contam do fim: slice(-3) são os 3 últimos; slice(0, -4) tira os 4 últimos.
  • texto.at(i) pega um caractere e aceita negativos: at(-1) é o último. Os colchetes (texto[i]) não aceitam.
  • Com indexOf + slice: slice(0, pos) é o que vem antes do separador; slice(pos + 1), o que vem depois. Confira o -1 antes de cortar.
  • Primeira maiúscula: texto.at(0).toUpperCase() + texto.slice(1).
  • substring e charAt são versões antigas, sem negativos; substr é obsoleto.
