JavaScript Regex na Prática

Na aula Expressões Regulares, você aprendeu a escrever padrões e a perguntar "o texto tem esse formato?" com o test. Mas uma regex faz muito mais do que responder sim ou não: ela acha o pedaço do texto que casou com o padrão, separa as partes dele (o DDD e o número, o dia e o mês), troca o que você quiser e divide um texto bagunçado. Esta aula mostra os métodos que fazem cada uma dessas coisas, sempre com exemplos do dia a dia da Ana.

Você vai aprender
  • Quando usar cada método: test, match, matchAll, replace, replaceAll, split e search.
  • Como achar a primeira ocorrência e, com a flag g, todas.
  • Como capturar partes do texto com grupos ( ) e com grupos com nome (?<dia>…).
  • Como trocar com replace: um texto fixo, os pedaços capturados ($1, $<nome>) ou uma função.
  • Como limpar CPF e telefone, juntar espaços repetidos e dividir uma lista com separadores misturados.
  • As armadilhas: o null do match, o g esquecido, o replaceAll sem g e o test que alterna true e false.

Todos os programas desta aula rodaram no Node.js 24 da máquina da Ana (usuária ana, computador notebook), com node arquivo.js. Tudo aqui é da linguagem e funciona igual no navegador.

A ideia: o marca-texto, a tesoura e a borracha

Pense numa folha de recados presa na geladeira. Com uma regex na mão, a Ana pode fazer quatro coisas diferentes com ela:

  • perguntar: "tem algum telefone neste recado?" (sim ou não) → test;
  • passar o marca-texto no pedaço que casou, para copiar: "qual é o telefone?" → match e matchAll;
  • apagar e escrever por cima: "troque todo gato por cão" → replace e replaceAll;
  • recortar com a tesoura onde o padrão aparece: "separe a lista em cada vírgula ou ponto e vírgula" → split.

Repare que só o test é chamado na regex (regex.test(texto)). Os outros são métodos do texto, que recebem a regex: texto.match(regex), texto.replace(regex, …).

1. test: filtrar uma lista

O test você já conhece. Ele brilha junto com o filter: "fique só com os itens que têm o padrão":

const temNumero = /\d/;
const frases = ["Mesa 7", "Balcão", "Pedido 1042"];

const comNumero = frases.filter((frase) => temNumero.test(frase));
console.log(comNumero);

$ node rm-test.js
[ 'Mesa 7', 'Pedido 1042' ]

Todas as ocorrências: a flag g

Com a flag g (global, "todas"), o match muda de comportamento: devolve um array simples com todos os pedaços que casaram:

const cupom = "Pão R$ 4,50 · Leite R$ 6,25 · Café R$ 21,90";

console.log(cupom.match(/\d+,\d{2}/));
console.log(cupom.match(/\d+,\d{2}/g));
console.log("sem preço".match(/\d+,\d{2}/g));

$ node rm-match-g.js

  input: 'Pão R$ 4,50 · Leite R$ 6,25 · Café R$ 21,90',
  groups: undefined

[ '4,50', '6,25', '21,90' ]

Sem g: só o primeiro preço, com index e companhia. Com g: os três preços, sem detalhes. E, se não achar nada, continua sendo null.

3. Grupos de captura: separando as partes

Na aula anterior, os parênteses serviam para agrupar. Eles têm um segundo poder: cada par de parênteses captura o pedaço do texto que casou com ele, e o match devolve cada captura numa posição do array:

const telefone = "(11) 91234-5678";
const partes = telefone.match(/\((\d{2})\) (\d{4,5}-\d{4})/);

console.log(partes[0]);
console.log(partes[1]);
console.log(partes[2]);

$ node rm-grupos.js
(11) 91234-5678
11
91234-5678
\( e \)
Parênteses escapados: os do texto, de verdade.
(\d{2})
O 1º grupo de captura (parênteses sem barra): os 2 dígitos do DDD → partes[1].
(\d{4,5}-\d{4})
O 2º grupo: o número → partes[2].
partes[0]
Sempre o pedaço inteiro que casou.

4. Grupos com nome: (?<nome>…)

Com muitos grupos, lembrar que o mês é o [2] e o ano é o [3] confunde. Dá para dar um nome a cada grupo, escrevendo ?<nome> logo depois do (. Os pedaços aparecem no objeto groups:

const data = "05/03/2026";
const resultado = data.match(/^(?<dia>\d{2})\/(?<mes>\d{2})\/(?<ano>\d{4})$/);

console.log(resultado.groups);
const { dia, mes, ano } = resultado.groups;
console.log(`Dia ${dia}, mês ${mes}, ano ${ano}`);
console.log(new Date(Number(ano), Number(mes) - 1, Number(dia)).getDay());

$ node rm-nomeados.js
[Object: null prototype] { dia: '05', mes: '03', ano: '2026' }
Dia 05, mês 03, ano 2026
4
(?<dia>\d{2})
Um grupo chamado dia, com 2 dígitos.
\/
A barra / de verdade precisa de escape, porque a barra também fecha a regex.
resultado.groups
Um objeto com uma propriedade por grupo. O [Object: null prototype] é só o Node avisando que é um objeto "puro", sem os métodos de sempre; use como qualquer objeto.
const { dia, mes, ano } = …
Tira as três propriedades de uma vez (veja Desestruturação). As capturas são sempre textos ('05'); para fazer contas ou criar um Date, converta com Number. O 4 da última linha é quinta-feira.

Esse é o jeito certo de ler uma data no formato brasileiro, que o new Date("05/03/2026") não entende.

5. matchAll: todas as ocorrências, com os grupos

O match com g devolve todos os pedaços, mas perde os grupos. Quando você quer as duas coisas (todos os itens do cupom, e de cada um o nome e o preço), use o matchAll ("casar todos") num for … of. Ele exige a flag g:

const cupom = "Pão R$ 4,50 · Leite R$ 6,25 · Café R$ 21,90";
const item = /(?<nome>[A-Za-zçãé]+) R\$ (?<preco>\d+,\d{2})/g;

let total = 0;
for (const achado of cupom.matchAll(item)) {
  const { nome, preco } = achado.groups;
  const valor = Number(preco.replace(",", "."));
  total += valor;
  console.log(`${nome}: ${valor}`);
}
console.log(`Total: ${total.toFixed(2)}`);

$ node rm-matchall.js
Pão: 4.5
Leite: 6.25
Café: 21.9
Total: 32.65

Cada achado é igual ao resultado de um match sem g (com [0], index e groups), um para cada item. O preco.replace(",", ".") troca a vírgula por ponto, para o Number entender (veja Conversão).

6. replace e replaceAll: trocar

Você já viu o replace com texto na aula Substituindo. Com regex, ele fica muito mais poderoso:

const texto = "O gato viu outro gato no telhado do gato vizinho";

console.log(texto.replace("gato", "cão"));
console.log(texto.replace(/gato/, "cão"));
console.log(texto.replace(/gato/g, "cão"));
console.log(texto.replaceAll("gato", "cão"));
console.log(texto.replaceAll(/gato/g, "cão"));

$ node rm-replace.js
O cão viu outro gato no telhado do gato vizinho
O cão viu outro gato no telhado do gato vizinho
O cão viu outro cão no telhado do cão vizinho
O cão viu outro cão no telhado do cão vizinho
O cão viu outro cão no telhado do cão vizinho

Sem g, o replace troca só a primeira ocorrência; com g, troca todas. O replaceAll troca todas sempre, mas, quando recebe uma regex, ela tem de ter o g (senão dá erro; veja Quando dá errado).

Limpando o que as pessoas digitam

O uso mais comum do replace com regex é limpar dados: tirar a pontuação de um CPF, deixar só os números de um telefone, juntar espaços repetidos:

const digitado = "  Ana    Maria   da   Silva ";
const cpf = "123.456.789-09";

console.log(`[${digitado.trim().replace(/\s+/g, " ")}]`);
console.log(cpf.replace(/\D/g, ""));
console.log("(11) 91234-5678".replace(/\D/g, ""));

$ node rm-limpar.js

11912345678
.replace(/\s+/g, " ")
Cada sequência de um ou mais espaços vira um espaço. O trim() antes tira os espaços das pontas. Os colchetes no console.log só mostram onde o texto começa e termina.
.replace(/\D/g, "")
\D é "qualquer coisa que não seja dígito". Trocar tudo isso por nada ("") deixa só os números.

Usando o que foi capturado: $1 e $<nome>

No texto de troca, $1, $2… são os grupos capturados, e $<nome> é um grupo com nome. Assim dá para reorganizar as partes:

const data = "2026-03-05";

console.log(data.replace(/(\d{4})-(\d{2})-(\d{2})/, "$3/$2/$1"));
console.log(data.replace(/(?<ano>\d{4})-(?<mes>\d{2})-(?<dia>\d{2})/, "$<dia>/$<mes>/$<ano>"));
console.log("11912345678".replace(/(\d{2})(\d{5})(\d{4})/, "($1) $2-$3"));

$ node rm-dolar.js
05/03/2026
05/03/2026
(11) 91234-5678

A data do jeito do computador virou a data do jeito brasileiro, e os 11 dígitos viraram um telefone formatado: o caminho de volta da limpeza.

Uma função no lugar do texto de troca

Quando a troca depende do que foi achado, passe uma função. Ela é chamada para cada pedaço que casou, recebe esse pedaço, e o que ela devolver entra no lugar:

const recado = "comprar 2 pães e 3 leites";
const dobrado = recado.replace(/\d+/g, (numero) => String(Number(numero) * 2));
console.log(dobrado);

const titulo = "a padaria do bairro".replace(/\b\w/g, (letra) => letra.toUpperCase());
console.log(titulo);

$ node rm-funcao.js
comprar 4 pães e 6 leites
A Padaria Do Bairro

No segundo, \b é a borda de palavra (o ponto entre um espaço e uma letra, ou o começo do texto), então \b\w é "a primeira letra de cada palavra". (Como o \w, o \b não conhece acentos: uma palavra que começa com é não seria pega.)

7. split com regex: separadores misturados

A lista de compras que a Ana recebeu por mensagem veio bagunçada: umas vírgulas, uns pontos e vírgulas, espaços sobrando. O split com texto não dá conta; com regex, sim:

const lista = "pão, leite;café ,  queijo;manteiga";

console.log(lista.split(","));
console.log(lista.split(/\s*[,;]\s*/));
console.log("um  dois   três".split(/\s+/));

$ node rm-split.js
[ 'pão', ' leite;café ', '  queijo;manteiga' ]
[ 'pão', 'leite', 'café', 'queijo', 'manteiga' ]
[ 'um', 'dois', 'três' ]

/\s*[,;]\s*/ quer dizer "uma vírgula ou um ponto e vírgula, com quantos espaços houver em volta". O corte acontece ali, e os espaços vão embora junto. O último exemplo separa palavras por qualquer quantidade de espaços.

8. search: a posição

O search ("procurar") é o indexOf das regex: devolve a posição da primeira ocorrência, ou -1 se não achar:

const recado = "Ligar para (11) 91234-5678";

console.log(recado.search(/\d/));
console.log(recado.search(/@/));
console.log(recado.indexOf("("));

$ node rm-search.js
12
-1
11

"String.prototype.replaceAll chamado com uma regex que não é global". O String.prototype.replaceAll é o nome completo do método replaceAll dos textos (veja Protótipos). O nome promete trocar todas, e uma regex sem g diria "só a primeira": o JavaScript prefere avisar a adivinhar. Com o matchAll acontece igual: TypeError: String.prototype.matchAll called with a non-global RegExp argument. Como consertar: ponha o g: /-/g.

O mesmo teste, no mesmo texto, deu true, false, true! Uma regex com g lembra onde parou, na propriedade lastIndex ("última posição"), e o próximo test continua a busca dali. Na 2ª vez, ela começou depois do 7, não achou mais nada, deu false e voltou para o 0. Isso causa erros muito difíceis de achar num filter. Como consertar: não use g no test: para "tem ou não tem", basta achar o primeiro.

Resumo

  • regex.test(texto) pergunta; texto.match(regex) acha (o primeiro, com index e grupos; ou todos, com g); texto.matchAll(regex) dá todos com os grupos.
  • Parênteses capturam: resultado[1], resultado[2]… Com nome, (?<dia>…) e resultado.groups.dia. As capturas são textos.
  • texto.replace(regex, troca) troca a primeira (ou todas, com g); na troca, $1 e $<nome> reaproveitam os grupos, e uma função decide caso a caso. Limpeza clássica: replace(/\D/g, "").
  • texto.split(regex) corta com separadores variados; texto.search(regex) dá a posição.
  • Cuidados: o match sem resultado é null; sem g, o replace troca uma só; replaceAll e matchAll exigem g; e nunca use g no test.
