JavaScript Procurando (includes, indexOf, find)

Antes de sair para o mercado, a Ana confere: "o café já está na lista?". Na chamada, a professora quer saber "em que posição está o Caio?". No boletim, "qual foi a primeira nota abaixo de 6?". São três perguntas diferentes, e o array tem um método para cada uma. Nesta aula você vai aprender a procurar num array sem precisar olhar item por item com os próprios olhos.

Você vai aprender
  • includes: "tem ou não tem?" (responde true ou false).
  • indexOf e lastIndexOf: "em que posição está?" (e o -1, que quer dizer "não achei").
  • find: "qual é o primeiro item que combina com uma regra?", com uma arrow function.
  • findIndex: a posição desse primeiro item.
  • findLast e findLastIndex: procurar de trás para a frente.
  • Como usar a posição achada para tirar o item com splice, sem cair na armadilha do -1.
  • Os erros reais mais comuns: maiúsculas e minúsculas, o -1 esquecido, a arrow function sem return e o texto no lugar da função.

Todos os programas desta aula rodaram no Node.js 24 da máquina da Ana (usuária ana, computador notebook), com node arquivo.js. Você pode rodar cada um no editor do guia.

A ideia: três perguntas diferentes

Imagine a Ana procurando algo na prateleira de temperos da cozinha. Ela pode querer saber três coisas:

  1. "Tem orégano?" A resposta é sim ou não. → includes
  2. "Em que lugar da prateleira está o orégano?" A resposta é uma posição, ou "não está aqui". → indexOf
  3. "Qual é o primeiro pote que está quase vazio?" Aqui ela não sabe o nome do que procura: sabe só a regra ("quase vazio"). Ela olha pote por pote até achar um que obedeça à regra. → find

As duas primeiras procuram um valor conhecido. A terceira procura por uma condição. Essa diferença decide qual método usar.

1. includes: tem ou não tem?

const compras = ["arroz", "feijão", "café", "leite"];
console.log(compras.includes("café"));
console.log(compras.includes("pão"));

if (!compras.includes("pão")) {
  compras.push("pão");
}
console.log(compras);
compras.includes("café")
"A lista de compras inclui o café?". O valor procurado vai entre os parênteses. A resposta é um booleano: true (sim) ou false (não).
if (!compras.includes("pão"))
Como a resposta é true ou false, ela cabe direto num if. O ! quer dizer "não" (veja Operadores Lógicos): "se a lista não inclui o pão, acrescente". Assim o pão não entra duas vezes.
$ node includes.js
true
false
[ 'arroz', 'feijão', 'café', 'leite', 'pão' ]

O includes compara cada item com o valor procurado usando a mesma ideia do === (veja Comparação): "Café", com C maiúsculo, não é igual a "café", e o número 7 não é igual ao texto "7".

const compras = ["arroz", "feijão", "café"];
const notas = [7, 8, 10];
console.log(compras.includes("Café"));
console.log(notas.includes("7"));
console.log(notas.includes(7));

2. indexOf: em que posição está?

const chamada = ["Ana", "Bia", "Caio", "Duda", "Bia"];
console.log(chamada.indexOf("Caio"));
console.log(chamada.indexOf("Bia"));
console.log(chamada.lastIndexOf("Bia"));
console.log(chamada.indexOf("Zeca"));
chamada.indexOf("Caio")
"O índice de Caio": a posição onde ele está. É o 2 (contando do 0).
chamada.indexOf("Bia")
Há duas Bias. O indexOf procura do começo para o fim e para na primeira: posição 1.
chamada.lastIndexOf("Bia")
"O último índice": procura do fim para o começo. A outra Bia está na posição 4.
chamada.indexOf("Zeca")
Não achou: -1. Como nenhuma posição de verdade é negativa, o -1 é o jeito de o indexOf dizer "não está aqui".

1
4
-1

Achar e tirar: indexOf + splice

Um uso muito comum: descobrir a posição de um item para tirá-lo da lista com o splice (aula splice e slice). Antes de tirar, confira se achou:

const compras = ["arroz", "feijão", "café", "leite"];

const posicao = compras.indexOf("feijão");
if (posicao !== -1) {
  compras.splice(posicao, 1);
}
console.log(compras);

const outra = compras.indexOf("chocolate");
if (outra !== -1) {
  compras.splice(outra, 1);
} else {
  console.log("Não tem chocolate na lista.");
}
console.log(compras);

$ node tirar.js
[ 'arroz', 'café', 'leite' ]
Não tem chocolate na lista.
[ 'arroz', 'café', 'leite' ]

Por que o if (posicao !== -1) é tão importante? Porque o splice aceita posição negativa, e splice(-1, 1) tira o último item. Sem a conferência, procurar algo que não existe apagaria o leite. Você vai ver isso acontecer em Quando dá errado.

3. find: o primeiro que obedece a uma regra

A professora quer saber qual foi a primeira nota abaixo de 6. Ela não sabe qual número procurar; sabe só a regra: "menor que 6". Para isso, você entrega ao find uma pequena função com a regra:

const notas = [8, 7.5, 5, 9, 4.5];
const baixa = notas.find((nota) => nota < 6);
console.log(baixa);
notas.find( … )
"Ache em notas…". O find (em inglês, "encontrar") passa pelos itens, do primeiro ao último.
(nota) => nota < 6
Uma arrow function com a regra. Para cada item, o find chama essa função, pondo o item em nota, e pergunta: "nota < 6?". O nome nota é você quem escolhe (no singular, porque é um item de cada vez).
const baixa = …
Assim que a função responde true, o find para e devolve aquele item. Aqui, o 5. O 4.5, que também é baixo, nem é olhado.
$ node find.js
5

Para ver o find trabalhando, ponha um console.log dentro da função (com chaves e return, como em Arrow Functions):

const notas = [8, 7.5, 5, 9, 4.5];
const baixa = notas.find((nota) => {
  console.log(`Olhando a nota ${nota}...`);
  return nota < 6;
});
console.log(`Primeira nota baixa: ${baixa}`);

$ node find_passos.js
Olhando a nota 8...
Olhando a nota 7.5...
Olhando a nota 5...
Primeira nota baixa: 5

Três chamadas: 8 (não), 7.5 (não), 5 (sim, parou). Essa função que você entrega para outra função chamar se chama callback (em inglês, "chamar de volta"); o assunto tem aula própria, Funções como Valores, e vai aparecer em todas as próximas aulas deste grupo (forEach, map, filter).

Quando ninguém obedece à regra

const notas = [8, 7.5, 9];
const baixa = notas.find((nota) => nota < 6);
console.log(baixa);
console.log(baixa === undefined ? "Ninguém ficou abaixo de 6." : `Nota baixa: ${baixa}`);

$ node find_nada.js
undefined
Ninguém ficou abaixo de 6.

Se nenhum item faz a função responder true, o find devolve undefined. A última linha usa o operador ternário para tratar os dois casos.

Outras regras

A regra pode ser qualquer coisa que dê true ou false. Com textos, os métodos de string (aula Procurando em Strings) ajudam muito:

const alunos = ["Ana", "Bia", "Caio", "Carla", "Duda"];
console.log(alunos.find((nome) => nome.startsWith("C")));
console.log(alunos.find((nome) => nome.length > 4));

const precos = [3.5, 12.9, 7, 25];
console.log(precos.find((preco) => preco >= 10 && preco <= 20));

Onde o find brilha de verdade

Com listas de objetos (aula Objetos), como os produtos da lojinha, cada um com nome e preço, o find é o jeito natural de achar "o produto cujo nome é arroz": produtos.find((p) => p.nome === "arroz"). O includes e o indexOf não servem para isso. Você vai usar muito essa forma depois.

Missão: o array tem as vendas de pão de cada dia. Use o find para achar a primeira venda maior que 150.

const vendas = [120, 98, 143, 171, 87, 156];
const boa = vendas[0];
console.log(`Primeiro dia com mais de 150: ${boa}`);

const vendas = [120, 98, 143, 171, 87, 156];
const boa = vendas.find((venda) => venda > 150);
console.log(`Primeiro dia com mais de 150: ${boa}`);

4. findIndex: a posição do primeiro que obedece

O findIndex recebe a mesma função do find, mas devolve a posição em vez do item, e -1 se ninguém obedecer (igual ao indexOf):

const notas = [8, 7.5, 5, 9, 4.5];
const posicao = notas.findIndex((nota) => nota < 6);
console.log(posicao);
console.log(`O ${posicao + 1}º aluno da chamada precisa de reforço.`);
console.log(notas.findIndex((nota) => nota > 10));

$ node findindex.js
2
O 3º aluno da chamada precisa de reforço.
-1

Repare no posicao + 1: para pessoas, o primeiro aluno é o "1º"; para o array, é a posição 0. Na hora de mostrar, some 1.

5. De trás para a frente: findLast e findLastIndex ES2023

Às vezes o que interessa é o item mais recente, que fica no fim da lista. "Qual foi a última nota abaixo de 6?" O findLast e o findLastIndex fazem o mesmo que o find e o findIndex, começando do fim:

const notas = [8, 7.5, 5, 9, 4.5, 10];
console.log(notas.find((nota) => nota < 6));
console.log(notas.findLast((nota) => nota < 6));
console.log(notas.findIndex((nota) => nota < 6));
console.log(notas.findLastIndex((nota) => nota < 6));

$ node findlast.js
5
4.5
2
4

Eles chegaram ao JavaScript em 2023 e funcionam no Node 24 e nos navegadores atuais. (O lastIndexOf, da seção 2, é o "de trás para a frente" do indexOf.)

Quando dá errado

Usou a posição sem conferir o -1

Não tinha chocolate, o indexOf devolveu -1, e splice(-1, 1) quer dizer "tire 1 a partir do último". Lá se foi o leite, sem nenhuma mensagem de erro. Como consertar: sempre if (posicao !== -1) antes de usar a posição (seção 2). O mesmo vale para o findIndex; e um lista[-1] devolveria undefined.

A nota 5 está lá, mas o find devolveu undefined. Com chaves { }, a arrow function só devolve alguma coisa se tiver return (veja Arrow Functions). Sem ele, a função devolve undefined para todo item, o find entende como "não" todas as vezes, e chega ao fim sem achar nada. Como consertar: escreva return nota < 6;, ou tire as chaves: (nota) => nota < 6.

Resumo

  • includes(valor) responde true ou false: "tem ou não tem?".
  • indexOf(valor) devolve a posição da primeira ocorrência (lastIndexOf, da última), ou -1 se não achar.
  • Os três comparam como o ===: maiúsculas importam, e 7 não é "7".
  • find(função) devolve o primeiro item para o qual a função responde true, ou undefined; findIndex devolve a posição dele, ou -1. findLast/findLastIndex procuram do fim.
  • A função do find é um callback: o find a chama uma vez para cada item, até achar.
  • Antes de usar uma posição achada, confira !== -1: splice(-1, 1) apaga o último item.
