Tutorial JavaScript

Aprenda a programar do zero com JavaScript, como numa escola: cada comando é explicado pedaço por pedaço, você vê o que o programa responde de verdade e pratica num editor aqui mesmo na página. Quem roda os seus programas é o JavaScript do seu próprio navegador, imitando o Node.js 24, o JavaScript do terminal. Você não precisa instalar nada para começar, em qualquer sistema: Windows, macOS, Linux ou até um Chromebook.

Experimente agora

A caixa abaixo é o editor Experimente do guia. Em cima fica o programa; clique em ▶ Rodar e o que ele escreve aparece embaixo, num terminal. Pode mexer à vontade: nada que você fizer aqui estraga o guia.

Missão: rode o programa como está e veja a lista de compras da Ana. Depois, ela lembrou que acabou a manteiga: acrescente "manteiga" na lista da primeira linha (depois de "café", com uma vírgula antes) e rode de novo.

const compras = ["pão", "leite", "café"];
for (const item of compras) {
  console.log(`Comprar: ${item}`);
}
console.log(`Total de itens: ${compras.length}`);

const compras = ["pão", "leite", "café", "manteiga"];
for (const item of compras) {
  console.log(`Comprar: ${item}`);
}
console.log(`Total de itens: ${compras.length}`);

O que aconteceu: você escreveu um programa, uma lista de instruções que o computador segue na ordem. Lido em voz alta, ele diz: "a lista de compras é pão, leite, café e manteiga; para cada item da lista, escreva 'Comprar: ' e o item; no fim, escreva quantos itens a lista tem". O JavaScript seguiu as instruções e escreveu uma linha por item. Você não precisou mudar o resto do programa: ele se adaptou sozinho à lista maior.

Se você esqueceu de fechar as aspas, viu uma mensagem em vermelho, em inglês: SyntaxError: Invalid or unexpected token ("erro de sintaxe: símbolo inválido ou inesperado"), com uma setinha ^^^ embaixo do texto que ficou sem fim. E se esqueceu a vírgula, a mensagem foi SyntaxError: Unexpected string ("texto inesperado"): o JavaScript esperava uma vírgula ou o ] e encontrou outro texto colado no anterior. O computador não adivinha: ele diz exatamente onde não entendeu. Errar e ler o que ele responde é metade do aprendizado: todas as aulas mostram os erros mais comuns, com a mensagem real e o jeito de consertar.

Um programa que conversa

Programas também podem perguntar. Rode a caixa, digite o seu nome no terminal dela (no campo que aparece depois da pergunta) e tecle Enter:

import * as readline from "node:readline/promises";
import { stdin as input, stdout as output } from "node:process";

const rl = readline.createInterface({ input, output });
const nome = await rl.question("Qual é o seu nome? ");
console.log(`Olá, ${nome}! Bem-vinda ao JavaScript.`);
rl.close();

O que é este guia

Um programa é uma receita que o computador segue. O JavaScript é uma língua para escrever essas receitas, criada em 1995 para dar vida às páginas web. Hoje ele está em todo navegador do mundo e, com o Node.js, também fora dele: em servidores, em ferramentas de linha de comando, em aplicativos de celular e de computador. A aula O que é JavaScript conta essa história, e Onde o JavaScript Roda explica a diferença entre o navegador e o Node.js.

Quem aprende JavaScript consegue:

  • fazer o computador repetir tarefas e tomar decisões: "se a nota for 7 ou mais, aprovada; senão, recuperação";
  • guardar e organizar informações em arrays e objetos: o estoque da lojinha, a agenda de contatos, as notas da turma;
  • ler e gravar arquivos com o Node.js e trocar dados em JSON;
  • criar páginas interativas: botões, formulários, listas que crescem, dados guardados no navegador;
  • escrever programas grandes, divididos em funções, módulos e classes, e lidar com tarefas que demoram (async/await, fetch).

O guia é para quem nunca programou. Ele começa do zero absoluto (o que é um programa? como se roda um?) e vai até classes, Promises, o DOM e os eventos. Cada aula ensina um assunto só, com calma. O JavaScript das aulas é o moderno (até o ECMAScript 2025), no Node.js 24 LTS; quando algo é antigo (o var, o ==), a aula mostra para você reconhecer e explica por que evitar.

Como as aulas funcionam

Nenhum código aparece "seco". Toda aula segue o mesmo caminho:

  1. A ideia primeiro. Antes do código, você entende o problema que ele resolve, com uma comparação do dia a dia: uma receita de bolo, uma caixa com etiqueta, uma lista de compras.
  2. Anatomia. Cada parte de um comando novo é separada e explicada.
  3. A saída real. Depois de cada exemplo, o que o Node.js (ou o navegador) respondeu de verdade. Nenhuma saída foi inventada.
  4. Experimente. Pelo menos duas caixas por aula para você mudar o código e rodar, muitas com uma missão que confere sozinha se você acertou.
  5. Várias formas de fazer. Quase sempre há mais de um jeito de escrever a mesma coisa, e uma tabela "qual usar" mostra quando escolher cada um.
  6. Quando dá errado. O código com erro e a mensagem real (/home/ana/main.js:3, a setinha ^, o TypeError: …), traduzida e explicada linha por linha.
  7. Exercícios e resumo. Perguntas com correção na hora e uma lista curta do que levar da aula.

Exemplo: a anatomia de um programa

Veja como as aulas desmontam um programa. Primeiro o código, num arquivo chamado compras.js:

const compras = ["pão", "leite", "café"];
for (const item of compras) {
  console.log(`Comprar: ${item}`);
}
console.log(`Total de itens: ${compras.length}`);

Agora cada parte:

const compras = [...];
Uma constante: um nome (compras) que guarda um valor. Aqui o valor é um array, uma lista com três textos, entre colchetes. O ; termina a instrução (aulas Constantes e Arrays).
for (const item of compras) {
"Para cada item de compras, faça": repete o bloco de baixo uma vez para cada elemento da lista. A chave { abre o bloco (aula for…of).
console.log(`Comprar: ${item}`);
O bloco que se repete. O console.log escreve uma linha; a crase e o ${} põem o item no meio do texto (aulas console.log() e Template Strings). Os 2 espaços no começo são para você enxergar que a linha está "dentro" do for.
}
Fecha o bloco do for.
console.log(`Total de itens: ${compras.length}`);
Depois do }: roda uma vez só. O .length conta os itens da lista.

Exemplo: o terminal

Além do editor, as aulas mostram o terminal da máquina das aulas: um computador chamado notebook, da usuária ana, com o Node.js instalado. Lá, o programa fica no arquivo compras.js, e quem o roda é o comando node:

$ node compras.js
Comprar: pão
Comprar: leite
Comprar: café
Total de itens: 3

E o programa que conversa, com a Ana digitando o nome dela:

$ node conversa.mjs
Qual é o seu nome? Ana
Olá, Ana! Bem-vinda ao JavaScript.

A resposta é a mesma do editor. A aula O Editor do Guia mostra tudo o que as caixas Experimente sabem fazer e o que muda no terminal, e Instalar o Node.js ensina a pôr o Node.js no seu computador.

Como estudar

Programar se aprende programando, como quem aprende a cozinhar cozinhando. Para cada aula, siga estes quatro passos:

  1. Leia com calma. Leia a ideia, a anatomia e a saída. Não pule a parte "Quando dá errado": quem entende a mensagem de erro conserta o problema em segundos.
  2. Mexa nos exemplos. Em toda caixa Experimente, mude um número, troque um texto, apague um pedaço de propósito e veja o que o JavaScript responde. Não tem como estragar nada: cada Rodar começa do zero.
  3. Faça as missões. As caixas com Missão conferem sozinhas se você acertou. Tente de verdade antes de abrir a solução; se abrir, digite a solução você mesmo em vez de só olhar.
  4. Repita no seu computador. Quando chegar à aula Instalar o Node.js, instale-o e refaça os programas no terminal. Algumas coisas (instalar pacotes com o npm, criar um servidor, guardar arquivos de verdade) só existem lá.
A regra de ouro

Ler não basta: digite cada programa. Copiar e colar ensina pouco; digitar faz você reparar em cada aspa, cada chave e cada ponto e vírgula. Comece pela aula O que é JavaScript e, antes de ir longe, dê uma olhada em O Editor do Guia.

Versão de referência: Node.js 24 LTS

O guia ensina o JavaScript moderno com o Node.js 24 LTS. As saídas de terminal foram colhidas no Node.js v24.22.0 oficial, num Ubuntu 26.04 em português do Brasil, e as do navegador num Chromium. O editor das aulas roda o JavaScript do seu navegador: no Chrome e no Edge, o motor é o mesmo do Node.js (o V8), e as respostas e mensagens de erro saem iguais; no Firefox e no Safari, o programa roda igual, mas o texto de algumas mensagens de erro muda. As mensagens saem em inglês, exatamente como o JavaScript as escreve, e as aulas as explicam em português. O Node.js 26 chega como LTS no fim de outubro de 2026: o que muda está em Versões.
