JavaScript Selecionando Elementos

Antes de mudar qualquer coisa na página, o JavaScript precisa encontrar o elemento certo na árvore do DOM: o título, o terceiro item da lista, todos os preços. Isso se chama selecionar. A ferramenta principal é o querySelector, que usa a mesma linguagem de "endereços" do CSS, os seletores. Quem já escreveu um pouco de CSS vai se sentir em casa; quem nunca escreveu aprende aqui o essencial.

Você vai aprender
  • document.querySelector(…): o primeiro elemento que combina com um seletor (ou null).
  • Os seletores mais usados: tag, #id, .classe, [atributo], "dentro de" (#doces .item) e alguns como :last-child e :checked.
  • document.querySelectorAll(…): todos os que combinam, numa NodeList, e como percorrê-la.
  • Por que a NodeList não tem map, e como transformá-la num array.
  • getElementById e os outros métodos antigos.
  • Buscar dentro de um elemento, e subir na árvore com closest.
  • Os erros reais: o null, o # esquecido, o seletor inválido e a lista tratada como se fosse um elemento só.

As respostas do Console desta aula foram colhidas no Chromium da máquina da Ana, com a página do cardápio abaixo aberta.

A ideia: endereços de entrega

Para entregar uma encomenda, o motoboy precisa de um endereço. Ele pode ser bem exato ("Rua das Flores, 123", só existe uma casa assim) ou valer para várias casas ("todas as casas amarelas da rua"). Os seletores são endereços de elementos:

  • #titulo é um endereço exato: o elemento cujo id é titulo (um id não deve se repetir na página).
  • .preco vale para vários: todos os elementos da classe preco, como "todas as casas amarelas".

Com o endereço em mãos, você escolhe: quer a primeira casa que bate (querySelector) ou todas (querySelectorAll)?

1. querySelector: o primeiro que combina

> document.querySelector("h1")
<h1 id="titulo">Cardápio da Padaria da Ana</h1>
> document.querySelector("#titulo").textContent
'Cardápio da Padaria da Ana'
> document.querySelector(".preco")
<span class="preco">6.50</span>
> document.querySelector(".destaque").textContent
'Pão de queijo 4.50'
document.querySelector("h1")
Procura em todo o documento o primeiro elemento da tag h1. O seletor é um texto, por isso vai entre aspas.
"#titulo"
O # quer dizer "o id é". Encontra o elemento com id="titulo".
".preco"
O ponto quer dizer "tem a classe". Há cinco preços na página, mas o querySelector devolve só o primeiro, na ordem do HTML: o da coxinha, 6.50.
".destaque"
O primeiro com a classe destaque é o pão de queijo. O textContent junta todo o texto de dentro, inclusive o do <span>: 'Pão de queijo 4.50'.

Seletores mais elaborados

Os seletores se combinam, como no CSS:

> document.querySelector("#doces .item").textContent
'Brigadeiro 3.00'
> document.querySelector("li.destaque").textContent
'Pão de queijo 4.50'
> document.querySelector("[data-novo]").textContent
'Bolo de pote 9.00'
> document.querySelector("#salgados li:last-child").textContent
'Esfiha 5.00'
> document.querySelector("input:checked").id
'entrega'
SeletorLê-seAqui encontrou
h1elementos da tag h1o título
#tituloo elemento com id="titulo"o título
.precoelementos com a classe precoo primeiro preço
#doces .itemcom a classe item, dentro do #doces (o espaço quer dizer "dentro de")o brigadeiro
li.destaqueum li que também tem a classe destaque (sem espaço = "e ao mesmo tempo")o pão de queijo
[data-novo]quem tem o atributo data-novoo bolo de pote
#salgados li:last-childo li que é o último filho, dentro de #salgadosa esfiha
input:checkedo input que está marcadoa caixinha "Entrega"

Qualquer seletor que funciona no CSS funciona aqui. Os que você vai usar em 90% das vezes são os três primeiros e o "dentro de".

Quando não acha nada: null

> document.querySelector(".esgotado")
null

Nenhum elemento tem a classe esgotado, e o querySelector devolve null ("nada"), sem erro. O erro vem na linha seguinte, quando você tenta usar esse nada (veja Quando dá errado).

Missão: o script quer mostrar o texto do título, mas quebra com Cannot read properties of null. O seletor está procurando uma tag chamada titulo, que não existe. Conserte o seletor para procurar o id titulo.

2. querySelectorAll: todos os que combinam

Para pegar todos os elementos de um endereço, use querySelectorAll ("selecionar todos"). Ele devolve uma lista:

> document.querySelectorAll(".item").length
5
> document.querySelectorAll(".preco")[2].textContent
'5.00'
> document.querySelectorAll(".item").constructor.name
'NodeList'
> document.querySelectorAll(".esgotado").length
0
.length
Quantos elementos a lista tem: 5 itens no cardápio.
[2]
A posição, contada do 0, como nos arrays: o [2] é o terceiro preço, o da esfiha.
NodeList
O tipo da lista: uma NodeList ("lista de nós"). Ela parece um array, mas não é um (seção 3).
Lista vazia
Se nada combina, o querySelectorAll não devolve null: devolve uma lista vazia, com length 0.

Percorrendo a lista

A NodeList tem forEach (aula forEach) e funciona com for … of (aula for … of). A Ana pôs no script.js da página:

const precos = document.querySelectorAll(".preco");
precos.forEach((preco) => {
  console.log(preco.textContent);
});
for (const item of document.querySelectorAll("#doces .item")) {
  console.log(`Doce: ${item.textContent}`);
}

3. A NodeList não é um array

A NodeList tem length, posições e forEach, mas não tem map, filter nem reduce:

> document.querySelectorAll(".preco").map(p => p.textContent)
Uncaught TypeError: document.querySelectorAll(...).map is not a function
    at <anonymous>:1:37

"….map não é uma função." Para usar os métodos de array, transforme a lista num array de verdade, com o spread ([...lista]) ou com Array.from:

> [...document.querySelectorAll(".preco")].map(p => Number(p.textContent))
(5) [6.5, 4.5, 5, 3, 9]
> Array.from(document.querySelectorAll("h2"), h => h.textContent)
(2) ['Salgados', 'Doces']
[...document.querySelectorAll(".preco")]
Os ... espalham os itens da NodeList dentro de colchetes novos: vira um array, e aí o map funciona. O Number(…) converte o texto "6.50" no número 6.5 (veja Conversão).
Array.from(lista, função)
Cria um array a partir da lista e, de quebra, aplica a função em cada item (como um map embutido).
(5) [6.5, 4.5, 5, 3, 9]
O jeito do Console do navegador mostrar um array: o (5) é o tamanho. (O Node mostraria [ 6.5, 4.5, 5, 3, 9 ].)

4. Os métodos antigos: getElementById e companhia

Antes do querySelector (que chegou aos navegadores por volta de 2009), havia métodos mais específicos. Eles continuam funcionando e aparecem em muito código:

> document.getElementById("doces")
<ul id="doces">
    <li class="item">Brigadeiro <span class="preco">3.00</span></li>
    <li class="item destaque" data-novo="sim">Bolo de pote <span class="preco">9.00</span></li>
  </ul>
> document.getElementsByClassName("item").constructor.name
'HTMLCollection'
> document.getElementsByTagName("h2").length
2
Método antigoEquivale aDetalhe
document.getElementById("doces")document.querySelector("#doces")Recebe o id sem o #
document.getElementsByClassName("item")document.querySelectorAll(".item")Recebe a classe sem o ponto; devolve uma HTMLCollection
document.getElementsByTagName("h2")document.querySelectorAll("h2")Devolve uma HTMLCollection

A HTMLCollection é outra lista parecida com array, só que "viva": se um elemento novo com aquela classe aparecer na página depois, ele entra na lista sozinho (a NodeList do querySelectorAll é uma foto do momento). Ela não tem forEach; use for … of ou [...lista].

5. Buscando a partir de um elemento

O querySelector e o querySelectorAll não são só do document: todo elemento os tem, e aí a busca acontece só dentro dele. Também dá para subir na árvore:

> document.querySelector("#doces").querySelectorAll("li").length
2
> document.querySelectorAll("li").length
5
> document.querySelector(".preco").closest("ul").id
'salgados'
> document.querySelector("#doces li").matches(".destaque")
false
elemento.querySelectorAll("li")
Só os li de dentro da lista de doces: 2. No document inteiro são 5.
elemento.closest("ul")
"O mais próximo": sobe pelos pais, a partir do próprio elemento, até achar um que combine com o seletor. O primeiro preço está dentro do ul de salgados. Devolve null se chegar ao topo sem achar.
elemento.matches(".destaque")
"Combina?": true ou false. O primeiro li dos doces (o brigadeiro) não tem a classe destaque.

O closest vai ser muito útil na aula O Objeto do Evento: quando alguém clica num preço, ele descobre em qual item o clique aconteceu.

Quando dá errado

Esqueceu o # ou o ponto 
> document.querySelector("aviso")
null
> document.querySelector(".aviso").textContent
'Aceitamos Pix.'

Sem o ponto, "aviso" procura uma tag <aviso>, que não existe: null. E o null só explode na próxima linha, com Uncaught TypeError: Cannot read properties of null (reading 'textContent') (lendo) ou Cannot set properties of null (mudando). Como consertar: # para id, ponto para classe, nada para tag.

Pôs o # no getElementById 
> document.getElementById("#doces")
null

O getElementById já sabe que é um id: o # vira parte do nome procurado, e nenhum elemento tem id="#doces". Como consertar: getElementById("doces"), ou querySelector("#doces").

Tratou a lista como se fosse um elemento 
> document.querySelectorAll(".item").textContent
undefined

Nenhum erro, só um undefined: a NodeList não tem textContent, quem tem é cada elemento dentro dela. E, pior, document.querySelectorAll(".item").textContent = "Esgotado" também não dá erro e não muda nada na página. Como consertar: percorra a lista com forEach ou for … of e mude um por um.

map is not a function

O erro da seção 3: a NodeList não tem map. Como consertar: [...lista].map(…).

Seletor inválido 
> document.querySelector(".1preco")
Uncaught SyntaxError: Failed to execute 'querySelector' on 'Document': '.1preco' is not a valid selector.
    at <anonymous>:1:10

"Falha ao executar o querySelector no Document: '.1preco' não é um seletor válido." No CSS, um nome de classe ou de id não pode começar com um número no seletor (outros erros comuns: um colchete ou uma aspa sem fechar). Diferente do null, aqui o erro aparece na hora. Como consertar: escolha nomes que comecem com letra: preco1.

Resumo

  • Selecionar é encontrar o elemento na árvore do DOM, usando os seletores do CSS: tag, #id, .classe, A B (B dentro de A), [atributo]…
  • querySelector devolve o primeiro elemento que combina, ou null; querySelectorAll devolve todos, numa NodeList (vazia se nenhum).
  • A NodeList tem length, posições, forEach e for … of, mas não tem map: use [...lista] ou Array.from.
  • getElementById (sem #), getElementsByClassName e getElementsByTagName são os métodos antigos.
  • Todo elemento tem querySelector (busca dentro dele), closest (sobe até um pai) e matches.
  • O null não dá erro na hora: o erro aparece na linha seguinte (Cannot read properties of null).
