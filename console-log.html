JavaScript console.log()

Você já usou o console.log em todas as aulas até aqui, para mostrar textos e contas. Ele é, de longe, a função mais usada por quem programa em JavaScript: é com ele que você enxerga o que o programa está fazendo. Esta aula mostra tudo o que ele sabe fazer: como ele mostra cada tipo de valor, como mostrar vários de uma vez, como montar frases com valores no meio, e os erros mais comuns.

Você vai aprender
  • Como o console.log mostra cada tipo de valor: textos, números, true/false, null, undefined, listas e objetos.
  • A mostrar vários valores de uma vez, separados por vírgula (e o espaço que ele põe entre eles).
  • Os marcadores %s, %d, %i, %f e %o.
  • Três jeitos de montar uma frase com valores, e qual usar.
  • Quebras de linha com \n, e o process.stdout.write, que não pula linha.
  • Os erros reais: [object Object], console.Log is not a function, Unexpected string.

Todas as saídas são do Node.js 24 LTS, rodado na máquina fictícia da Ana, na pasta /home/ana/js. No navegador, o console.log escreve no Console do F12, e algumas coisas aparecem de outro jeito (veja O Console do Navegador); esta aula segue o Node.js.

A ideia: o alto-falante da padaria

Na padaria há um alto-falante: "Senha 42, seu pão está pronto!". Quem está no balcão escreve o recado e o alto-falante anuncia para todo mundo, em voz alta. O console.log é o alto-falante do seu programa: você entrega um ou mais valores, e ele os anuncia no terminal, numa linha, e passa para a linha de baixo.

O nome vem do inglês: console é o "painel" onde aparecem as mensagens, e log é "registrar, anotar". console.log = "anote no painel".

1. Um valor de cada tipo

O console.log mostra qualquer valor do JavaScript. Veja como sai cada tipo:

console.log(30);
console.log(1.75);
console.log(true);
console.log(null);
console.log(undefined);
console.log([1, 2, 3]);
console.log(["pão", "leite", "café"]);
console.log({ nome: "Ana", idade: 30 });

Um booleano: true ("verdadeiro") ou false ("falso") (aula Booleanos).

{ nome: 'Ana', idade: 30 }
Um objeto (uma ficha com campos) aparece entre chaves, cada campo com o seu valor (aula Objetos).

Textos com aspas dentro

Se um texto dentro de uma lista ou de um objeto tem um apóstrofo, o Node.js troca para aspas duplas na hora de mostrar, para não confundir:

console.log("Padaria D'Ouro");
console.log(["Padaria D'Ouro", "Pão"]);
console.log({ loja: "Padaria D'Ouro" });

$ node aspas-dentro.js
Padaria D'Ouro
[ "Padaria D'Ouro", 'Pão' ]
{ loja: "Padaria D'Ouro" }

Objetos grandes

Quando o objeto não cabe numa linha, o Node.js o quebra em várias, com indentação. E, a partir do terceiro nível de "objeto dentro de objeto", ele resume com [Object], para a tela não virar uma bagunça:

const pedido = {

2. Vários valores de uma vez

Dentro dos parênteses cabem quantos valores você quiser, separados por vírgula. O console.log mostra todos na mesma linha, com um espaço entre eles, posto por ele mesmo:

console.log("Ana", 30, true);
console.log("Pães:", 12, "unidades");
console.log("Lista:", ["pão", "leite"]);
console.log("Cliente:", { nome: "Ana" });
console.log("a", "b", "c");

$ node varios.js
Ana 30 true
Pães: 12 unidades
Lista: [ 'pão', 'leite' ]
Cliente: { nome: 'Ana' }
a b c
"Pães:", 12, "unidades"
Três valores. A vírgula não aparece na tela; no lugar dela, um espaço. Por isso "Pães:" não precisa terminar com espaço.
"Lista:", [...]
Dá para misturar qualquer tipo: texto, número, lista, objeto. Cada um aparece do seu jeito.

Esse é o jeito mais prático de investigar um programa: "o que tem nessa variável agora?" → console.log("total:", total);. O texto na frente ajuda a saber qual linha é qual quando há muitas.

Missão: acrescente um terceiro valor, o texto "unidades", para a saída ficar Pães: 12 unidades. Mantenha o 12 como número, entre vírgulas.

console.log("Pães:", 12);

console.log("Pães:", 12, "unidades");

3. Os marcadores: %s, %d e companhia

Se o primeiro valor for um texto com marcadores (um % seguido de uma letra), o console.log encaixa os valores seguintes no lugar deles, na ordem:

console.log("%s tem %d anos", "Ana", 30);
console.log("Preço: %f", 7.5);
console.log("Inteiro: %i", 7.9);
console.log("Objeto: %o", { nome: "Ana" });
console.log("100% de farinha");
console.log("%s e %s", "pão");

$ node formato.js
Ana tem 30 anos
Preço: 7.5
Inteiro: 7
Objeto: { nome: 'Ana' }
100% de farinha
pão e %s
MarcadorEncaixaExemplo da saída
%sUm valor como texto (string)Ana
%d / %iUm número inteiro (o %i corta as casas decimais: 7.9 → 7)30, 7
%fUm número com casas decimais (float)7.5
%o / %OUm objeto, do jeito do Node.js{ nome: 'Ana' }
%%Um % de verdade, quando há marcadores na frase%

Duas observações da saída: "100% de farinha" saiu inteiro: quando não há outros valores para encaixar, o texto sai como está (na máquina da Ana, até console.log("100%d sozinho") mostrou 100%d sozinho). E em "%s e %s" com um valor só, o segundo marcador ficou sem par e apareceu como está: pão e %s.

Os marcadores vêm de linguagens mais antigas (como o C) e você vai encontrá-los em código dos outros. No JavaScript de hoje, o jeito mais usado de encaixar valores numa frase é a template string (seção 4).

Missão: sem mexer no texto com os marcadores, troque os valores para sair Bia tem 25 anos.

console.log("%s tem %d anos", "Ana", 30);

console.log("%s tem %d anos", "Bia", 25);

4. Três jeitos de montar uma frase

Com os valores guardados em variáveis (aula Variáveis), as quatro linhas abaixo mostram a mesma frase:

const nome = "Ana";
const idade = 30;
console.log(nome + " tem " + idade + " anos");
console.log(nome, "tem", idade, "anos");
console.log(`${nome} tem ${idade} anos`);
console.log("%s tem %d anos", nome, idade);

$ node template.js
Ana tem 30 anos

5. Quebrando linhas e ficando na mesma linha

Cada console.log termina pulando para a linha de baixo. Para quebrar a linha no meio de um texto, use \n (barra invertida e n, de new line, "linha nova"); para um TAB, \t:

console.log("Lista de compras:\n- pão\n- leite");
console.log("Nome:\tAna");

$ node quebra.js
Lista de compras:
- pão
- leite
Nome:	Ana

Um console.log, três linhas na tela. Esses "caracteres especiais" têm aula própria: Caracteres Especiais.

Sem pular linha: process.stdout.write (só no Node)

O console.log sempre pula a linha no fim. Para escrever sem pular, o Node.js tem o process.stdout.write, que escreve exatamente o texto que receber, nem mais, nem menos:

process.stdout.write("Carregando");
process.stdout.write("...");
process.stdout.write(" pronto!\n");

$ node escreve.js
Carregando... pronto!

Três escritas, uma linha só; o \n do fim pulou a linha. O process.stdout.write só aceita texto e é só do Node.js (o stdout, "saída padrão", é o nome técnico do lugar para onde vai a saída do programa: normalmente, a tela). Para o dia a dia, fique com o console.log.

A saída pode ir para um arquivo

No terminal, o sinal > manda a saída de um programa para um arquivo, em vez da tela:

$ node varios.js > saida.txt
$ cat saida.txt
Ana 30 true
Pães: 12 unidades
Lista: [ 'pão', 'leite' ]
Cliente: { nome: 'Ana' }
a b c

Nada apareceu na tela durante o node: tudo o que o console.log escreveu foi para o saida.txt. Isso vai importar na próxima aula, porque o console.error não vai para o mesmo lugar (aula console.error, warn e table).

6. O console.log não devolve nada

No modo interativo, você já viu o undefined que aparece depois de um console.log. É que o console.log escreve na tela, mas não devolve valor nenhum. Guardar o "resultado" dele numa variável dá undefined:

$ node
Welcome to Node.js v24.22.0.
Type ".help" for more information.
> console.log("Bom dia")
Bom dia
undefined
> const x = console.log("oi")
oi
undefined
> x
undefined
> .exit

O oi foi escrito; o x ficou undefined. Para guardar uma frase, monte o texto numa variável primeiro e depois mostre: const frase = `Bom dia, ${nome}`; console.log(frase);.

Quando dá errado

Juntar um objeto com +: [object Object] 
console.log("Total:" + [1, 2, 3]);
console.log("Cliente: " + { nome: "Ana" });
console.log("Cliente:", { nome: "Ana" });

$ node e5.js
Total:1,2,3
Cliente: [object Object]
Cliente: { nome: 'Ana' }

Nenhuma mensagem de erro, mas a saída não ajuda. Com +, a lista e o objeto são transformados em texto antes de juntar: a lista vira 1,2,3 (sem colchetes nem espaços) e o objeto vira [object Object], que só diz "aqui tem um objeto". Como consertar: use a vírgula, que entrega o objeto inteiro ao console.log, e ele o mostra direitinho (terceira linha).

console.Log com L maiúsculo 
console.Log("Olá, Ana!");

$ node e2.js
/home/ana/js/e2.js:1
console.Log("Olá, Ana!");
        ^

TypeError: console.Log is not a function
    at Object.<anonymous> (/home/ana/js/e2.js:1:9)
    «  mais 7 linhas "at … (node:internal/…)" cortadas

Node.js v24.22.0

Desta vez não é ReferenceError: o console existe (está certo, minúsculo). O problema é a parte depois do ponto: dentro do console não existe nada chamado Log, com L maiúsculo; o que existe é log. O JavaScript achou undefined ali e não dá para "chamar" isso: TypeError ("erro de tipo"), "console.Log não é uma função". O ^ aponta o L (coluna 9). Como consertar: console.log, tudo minúsculo.

Sem os parênteses 
console.log "Olá, Ana!";

$ node e1.js
/home/ana/js/e1.js:1
console.log "Olá, Ana!";
            ^^^^^^^^^^^

SyntaxError: Unexpected string
    at wrapSafe (node:internal/modules/cjs/loader:1861:18)
    «  mais 7 linhas "at … (node:internal/…)" cortadas

Node.js v24.22.0

"Texto (string) inesperado". Em algumas linguagens (como Lua ou Ruby) dá para chamar uma função sem parênteses; no JavaScript, nunca. Depois de console.log, o JavaScript esperava um ( ou o fim da instrução e encontrou um texto solto. Como consertar: console.log("Olá, Ana!");.

Esqueceu a vírgula entre os valores 
console.log("Olá" "Ana");

$ node e3.js
/home/ana/js/e3.js:1
console.log("Olá" "Ana");
            ^^^^^

SyntaxError: missing ) after argument list
    «  8 linhas "at …" cortadas

Node.js v24.22.0

Dois textos colados, sem vírgula nem +. Depois do primeiro valor, o JavaScript esperava uma vírgula (mais um valor) ou o ). Como consertar: console.log("Olá", "Ana"); (dois valores) ou console.log("Olá " + "Ana"); (um texto só).

Sem os parênteses e sem nada: não mostra nada 
console.log;
console.log("fim");

$ node e4.js
fim

A linha 1 não dá erro, mas também não faz nada: sem os parênteses, você só citou a função, não a chamou (como dizer "o alto-falante" sem apertar o botão). Como consertar: console.log(); para uma linha em branco, ou com o valor dentro.

Missão final: o cliente por inteiro

Missão: o programa mostra Cliente: [object Object]. Faça ele mostrar o objeto inteiro: Cliente: { nome: 'Ana', idade: 30 }.

const cliente = { nome: "Ana", idade: 30 };
console.log("Cliente: " + cliente);

const cliente = { nome: "Ana", idade: 30 };
console.log("Cliente:", cliente);

Resumo

  • console.log(valor) mostra o valor no terminal (no navegador, no Console) e pula a linha.
  • Textos saem sem aspas; dentro de listas e objetos, com aspas simples. Listas: [ 1, 2, 3 ]; objetos: { nome: 'Ana' }; objetos muito fundos viram [Object].
  • Vários valores separados por vírgula saem na mesma linha, com um espaço entre eles: o melhor jeito de investigar um programa.
  • Marcadores: %s texto, %d/%i inteiro, %f decimal, %o objeto. Para frases, prefira a template string: `${nome} tem ${idade} anos`.
  • \n quebra a linha dentro do texto; process.stdout.write (só Node) escreve sem pular linha.
  • O console.log não devolve nada (undefined).
  • Erros: objeto com + → [object Object]; console.Log → is not a function; sem parênteses → Unexpected string.
