JavaScript Criando e Removendo Elementos

Nas aulas anteriores você mudou elementos que já estavam na página: trocou um texto, um atributo, uma cor. Mas muita página precisa de elementos que não existiam quando ela abriu: o item novo da lista de compras, a mensagem nova do chat, a linha nova da tabela de notas. E precisa tirar coisas: o item já comprado, o aviso que já foi lido. Nesta aula, o JavaScript vai fabricar elementos do zero, colocá-los no lugar certo e removê-los.

Você vai aprender
  • Como fabricar um elemento com document.createElement e pôr um texto nele com textContent.
  • Por que um elemento criado ainda não aparece, e como colocá-lo na página: append, prepend, before e after.
  • Como montar uma lista inteira a partir de um array.
  • Como remover (remove), esvaziar (replaceChildren), trocar (replaceWith) e copiar (cloneNode) elementos.
  • O atalho innerHTML, e por que ele é perigoso com texto digitado pelo usuário.
  • Os erros reais mais comuns: o null do seletor errado, o texto passado para o appendChild e o nome de etiqueta inválido.

Esta aula é do navegador: document só existe numa página web, não no Node.js (a seção Quando dá errado mostra o que o Node responde). As respostas do Console mostradas aqui vieram do Chromium da máquina da Ana; os exemplos rodam nas caixas "Experimente", que abrem a página de verdade no seu navegador. Se ainda não leu, veja antes O que é o DOM e Selecionando Elementos.

A ideia: escrever o bilhete e depois colar na geladeira

A Ana deixa a lista de compras presa na porta da geladeira com um ímã. Para acrescentar "Café", ela faz três coisas, nesta ordem:

  1. Pega um papelzinho em branco. Ele existe, está na mão dela, mas ninguém da casa o vê.
  2. Escreve "Café" no papel.
  3. Prende o papel na geladeira, embaixo dos outros. Só agora ele faz parte da lista.

No JavaScript são os mesmos três passos: criar o elemento (createElement), preencher (textContent) e anexar na página (append). O erro mais comum de quem começa é parar no passo 2: o papel fica escrito na mão, e a lista da geladeira continua igual.

1. Criar, preencher e anexar

A página da Ana tem uma lista com dois itens. O script acrescenta um terceiro:

<h2>Compras</h2>
<ul id="lista">
  <li>Pão</li>
  <li>Leite</li>
</ul>
<script src="script.js"></script>

const lista = document.querySelector("#lista");

const item = document.createElement("li");
item.textContent = "Café";
lista.append(item);
document.querySelector("#lista")
Acha a lista que já está na página (veja Selecionando Elementos). É nela que o item novo vai entrar.
document.createElement("li")
"Criar elemento". Fabrica um elemento novo, vazio, da etiqueta que você pedir: "li", "p", "button", "img"… Escreva só o nome da etiqueta, sem < e >. O elemento nasce fora da página: é o papelzinho na mão.
const item
Guardamos o elemento novo numa variável para poder mexer nele. const porque a variável vai apontar sempre para o mesmo elemento (o conteúdo dele pode mudar à vontade).
item.textContent = "Café"
Escreve o texto dentro do elemento (veja Mudando Textos e Atributos).
lista.append(item)
"Anexar". Põe o item dentro da lista, no fim, depois do último filho. Só agora ele aparece na tela.

Na página aparece a lista com três itens: Pão, Leite e Café. No Console do navegador (F12, aba Console; veja O Console do Navegador), a Ana pediu o HTML da lista depois que o script rodou:

> document.querySelector("#lista").outerHTML
'<ul id="lista">\n  <li>Pão</li>\n  <li>Leite</li>\n<li>Café</li></ul>'

O outerHTML ("HTML de fora") mostra o elemento com tudo o que tem dentro. Os \n e os espaços são as quebras de linha e a indentação que estavam no arquivo index.html; o <li>Café</li> entrou colado no fim, sem indentação, porque o JavaScript só colocou o elemento, não espaços. Para o navegador isso não faz diferença nenhuma na tela.

O arquivo não muda

O append muda a página que está aberta (o DOM), não o arquivo index.html. Se você recarregar a página, ela volta a ter dois itens, e o script acrescenta o Café de novo. Para lembrar de coisas entre uma visita e outra, existe o localStorage.

Criado não é o mesmo que estar na página

Dá para ver os três passos um por um no Console. A propriedade isConnected ("está conectado?") diz se o elemento já está dentro da página:

> const papel = document.createElement("li")
undefined
> papel.textContent = "Manteiga"
'Manteiga'
> papel.isConnected
false
> document.querySelector("#lista").append(papel)
undefined
> papel.isConnected
true

Depois do createElement e do textContent, o elemento existe e tem texto, mas isConnected é false: nada mudou na tela. Só depois do append ele vira true e a Manteiga aparece na lista. (O undefined depois do const e do append não é erro: é o Console dizendo que aquela instrução não devolve nenhum valor.)

2. Onde colocar: append, prepend, before e after

O append põe no fim. Há outros três lugares possíveis, e cada um tem o seu método. Dois põem o elemento dentro de outro (como filho); dois põem ao lado (como irmão):

const lista = document.querySelector("#lista");
const leite = lista.querySelector("li:nth-child(2)");

const primeiro = document.createElement("li");
primeiro.textContent = "Arroz";
lista.prepend(primeiro);

const antes = document.createElement("li");
antes.textContent = "Ovos";
leite.before(antes);

const depois = document.createElement("li");
depois.textContent = "Queijo";
leite.after(depois);

const ultimo = document.createElement("li");
ultimo.textContent = "Café";
lista.append(ultimo);

Com a mesma página (Pão e Leite), a lista termina assim: Arroz, Pão, Ovos, Leite, Queijo, Café. Conferido no Console:

> [...document.querySelectorAll("#lista li")].map((li) => li.textContent)
(6) ['Arroz', 'Pão', 'Ovos', 'Leite', 'Queijo', 'Café']

(O [...] transforma a lista de elementos num array, e o map pega só o texto de cada um; veja map. O (6) na frente é o Chrome dizendo que o array tem 6 itens.)

MétodoOnde o elemento novo entraNa geladeira
pai.append(novo)Dentro do pai, como último filhoEmbaixo do último papel
pai.prepend(novo)Dentro do pai, como primeiro filhoEm cima do primeiro papel
vizinho.before(novo)Fora do vizinho, logo antes dele (irmão)Logo acima de um papel escolhido
vizinho.after(novo)Fora do vizinho, logo depois dele (irmão)Logo abaixo de um papel escolhido

Os quatro aceitam vários elementos de uma vez (lista.append(a, b, c)) e também textos soltos: paragrafo.append(" (promoção!)") acrescenta esse texto no fim do parágrafo, sem precisar criar elemento nenhum.

3. Elementos com atributos e classes

O elemento recém-criado é um elemento como qualquer outro: tudo o que você aprendeu em Mudando Textos e Atributos e em Mudando o Estilo vale para ele, antes ou depois de anexar. Aqui a Ana cria um link e um item marcado com uma classe:

const link = document.createElement("a");
link.textContent = "Receita de bolo";
link.href = "https://exemplo.com/bolo";
document.body.append(link);

const urgente = document.createElement("li");
urgente.textContent = "Remédio da vó";
urgente.classList.add("urgente");
document.querySelector("#lista").prepend(urgente);

> document.querySelector("a").outerHTML
'<a href="https://exemplo.com/bolo">Receita de bolo</a>'
> document.querySelector(".urgente").outerHTML
'<li class="urgente">Remédio da vó</li>'

O document.body é o <body> da página: um jeito rápido de anexar algo no fim dela inteira.

4. Montar uma lista inteira a partir de um array

Raramente se cria um elemento só. O caso mais comum é ter os dados num array e criar um elemento para cada item, com um for … of:

const compras = ["Pão", "Leite", "Café", "Banana"];
const lista = document.querySelector("#lista");

for (const nome of compras) {
  const item = document.createElement("li");
  item.textContent = nome;
  lista.append(item);
}

console.log(`A lista tem ${lista.children.length} itens.`);

Com o index.html trazendo só <ul id="lista"></ul> (vazia), a página mostra os quatro itens, e o Console mostra:

A lista tem 4 itens.

A cada volta do laço, um li novo é criado (o createElement está dentro do for), recebe o nome da vez e é anexado. O lista.children ("os filhos") é a coleção dos elementos dentro da lista; o .length diz quantos são.

Um elemento só pode estar em um lugar

E se a Ana criasse o li antes do laço, uma vez só?

const compras = ["Pão", "Leite", "Café", "Banana"];
const lista = document.querySelector("#lista");
const item = document.createElement("li");

for (const nome of compras) {
  item.textContent = nome;
  lista.append(item);
}

console.log(`A lista tem ${lista.children.length} itens.`);

A lista tem 1 itens.

A tela mostra só Banana. Não deu erro: é a regra do DOM. Um elemento é um papel; ele só pode estar num lugar da página. Quando você dá append num elemento que já está na página, ele é movido, não copiado. Aqui ele foi "movido" para o mesmo lugar quatro vezes, e o texto foi trocado a cada volta, sobrando o último. Para ter quatro itens, são precisos quatro createElement.

Esse "mover" também é útil de propósito: lista.append(lista.firstElementChild) pega o primeiro item e o leva para o fim.

Quando você quer mesmo uma cópia: cloneNode

Para duplicar um elemento que já existe, use cloneNode(true) ("clonar o nó"). O true quer dizer "com tudo o que tem dentro"; sem ele, a cópia sai vazia, só com a etiqueta e os atributos:

> const pao = document.querySelector("#lista li")
undefined
> pao.cloneNode(true).outerHTML
'<li>Pão</li>'
> pao.cloneNode().outerHTML
'<li></li>'

A cópia nasce fora da página, igual a um createElement: é preciso anexá-la.

5. Removendo elementos

Para tirar um elemento da página, chame remove() ("remover") nele mesmo:

const lista = document.querySelector("#lista");
console.log(`Antes: ${lista.children.length} itens`);

const primeiro = lista.querySelector("li");
primeiro.remove();

console.log(`Depois: ${lista.children.length} itens`);

Com a lista de Pão e Leite:

Antes: 2 itens
Depois: 1 itens

O Pão sumiu da tela. O elemento em si continua guardado na variável primeiro (como um papel tirado da geladeira e posto no bolso): se você fizer lista.append(primeiro), ele volta, agora no fim.

Esvaziar tudo: replaceChildren()

Para apagar todos os itens de uma vez, chame replaceChildren() ("substituir os filhos") sem nada nos parênteses: todos os filhos são trocados por nada. Com elementos nos parênteses, ele apaga os antigos e põe os novos:

> const lista = document.querySelector("#lista")
undefined
> lista.replaceChildren()
undefined
> lista.children.length
0

Trocar um por outro: replaceWith

O replaceWith ("substituir por") põe o elemento novo exatamente no lugar do antigo, que sai da página. A Ana trocou o Leite por Leite sem lactose:

const leite = document.querySelector("#lista li:nth-child(2)");
const novo = document.createElement("li");
novo.textContent = "Leite sem lactose";
leite.replaceWith(novo);

Formas diferentes de fazer a mesma coisa

O atalho: innerHTML

Em vez de criar o elemento peça por peça, dá para escrever o HTML num texto e deixar o navegador montar. O innerHTML ("HTML de dentro") lê e troca todo o conteúdo de um elemento:

const lista = document.querySelector("#lista");
lista.innerHTML += "<li>Café</li>";

Funciona, e é curto. O += pega o HTML que já estava, junta o novo no fim e põe tudo de volta. Há também o insertAdjacentHTML("beforeend", "<li>Café</li>"), que acrescenta sem reescrever o resto. Mas os dois têm o mesmo problema quando o texto vem de uma pessoa.

Nunca jogue texto digitado pelo usuário no innerHTML

Imagine que o nome do item vem de um campo de texto, e alguém digita <img src=x onerror="alert('invadido')">. Com innerHTML, o navegador lê isso como HTML: cria uma imagem quebrada, e o "quando der erro" (onerror) roda o código que a pessoa escreveu. Numa página de verdade, esse código poderia roubar dados de quem está usando o site. Esse ataque tem nome: XSS (cross-site scripting). Com textContent, o mesmo texto aparece na tela como texto, letra por letra, sem rodar nada.

A Ana testou os dois jeitos no Console, com um texto inofensivo, <b>Café</b>:

> const a = document.createElement("li")
undefined
> a.innerHTML = "<b>Café</b>"
'<b>Café</b>'
> a.children.length
1
> const b = document.createElement("li")
undefined
> b.textContent = "<b>Café</b>"
'<b>Café</b>'
> b.children.length
0
> b.outerHTML
'<li>&lt;b&gt;Café&lt;/b&gt;</li>'

No a (innerHTML), o navegador criou um elemento <b> de verdade: 1 filho, e "Café" aparece em negrito. No b (textContent), nenhum filho: o <b> virou texto comum (o &lt; é o jeito de o HTML guardar um < que é só texto), e a tela mostra <b>Café</b> literalmente.

appendChild: o jeito antigo

Em código mais antigo e em muitos tutoriais você vai ver lista.appendChild(item) ("anexar filho"). Ele faz o mesmo que o append com um elemento, mas não aceita vários de uma vez nem textos soltos (veja o erro em Quando dá errado). Da mesma época são o insertBefore e o removeChild (pai.removeChild(filho)). Reconheça, mas prefira os novos.

SituaçãoQual usar
Texto que veio do usuário, de um arquivo, da internetcreateElement + textContent + append (sempre)
Um elemento com atributos, classes, eventoscreateElement: você já tem a variável para mexer nele
Um trecho de HTML fixo, escrito por você no códigoinnerHTML ou insertAdjacentHTML servem
Apagar tudo de dentro de um elementoreplaceChildren() (ou innerHTML = "")
Tirar um elementoelemento.remove() (no código antigo: pai.removeChild(elemento))

Quando dá errado

O seletor não achou nada: null 
const lista = document.querySelector("#lsita");
const item = document.createElement("li");
item.textContent = "Café";
lista.append(item);

Uncaught TypeError: Cannot read properties of null (reading 'append')
    at script.js:4:7
Uncaught
"Não capturado": o erro aconteceu e ninguém o tratou (veja try … catch). O script para nessa linha.
TypeError
"Erro de tipo": tentaram usar um valor de um jeito que o tipo dele não permite.
Cannot read properties of null (reading 'append')
"Não dá para ler propriedades de null (lendo append)". A variável lista vale null, e null não tem append.
at script.js:4:7
Onde: arquivo script.js, linha 4, coluna 7 (o .append).

O erro aparece na linha 4, mas a causa está na linha 1: #lsita, com as letras trocadas. Quando o querySelector não acha nada, ele não reclama; devolve null em silêncio, e o problema só estoura quando alguém usa esse null. O mesmo acontece se o <script> estiver no <head>, antes da lista existir (veja JavaScript na Página). Como consertar: confira o seletor e a posição do <script>; no Console, document.querySelector("#lsita") mostrando null confirma a suspeita.

Passou um texto para o appendChild 
const lista = document.querySelector("#lista");
lista.appendChild("Café");

Uncaught TypeError: Failed to execute 'appendChild' on 'Node': parameter 1 is not of type 'Node'.
    at script.js:2:7

"Falhou ao executar appendChild em Node: o parâmetro 1 não é do tipo Node". Node ("nó") aqui é o nome que o DOM dá a cada pedaço da página (elementos, textos); não tem nada a ver com o Node.js. O appendChild só aceita um nó, e "Café" é uma string. Como consertar: crie o li e anexe o elemento, ou use append, que aceita texto (mas lembre: lista.append("Café") põe o texto solto dentro do ul, sem li, o que não forma um item de lista).

Escreveu a etiqueta com < e > 
const item = document.createElement("<li>");

Uncaught InvalidCharacterError: Failed to execute 'createElement' on 'Document': The tag name provided ('<li>') is not a valid name.
    at script.js:1:23

"Caractere inválido: o nome de etiqueta fornecido ('<li>') não é um nome válido". O createElement quer só o nome: "li". Como consertar: tire os sinais: document.createElement("li").

Nada aparece, e não há erro nenhum 
const item = document.createElement("li");
item.textContent = "Café";

O Console fica limpo e a lista continua igual. É o papel escrito na mão: o elemento foi criado e preenchido, mas ninguém o anexou. Como consertar: falta o passo 3, document.querySelector("#lista").append(item). Se aparece só um item onde deviam aparecer vários, é o caso da seção 4: o createElement ficou fora do laço.

Rodou no Node.js

O document é do navegador. No terminal, o Node não sabe o que é:

const compromissos = [
  { hora: "9h", oque: "Dentista" },
  { hora: "14h", oque: "Reunião da escola" },
  { hora: "18h", oque: "Academia" },
];
const agenda = document.querySelector("#agenda");
const total = document.querySelector("#total");

for (const c of compromissos) {
  const item = document.createElement("li");
  item.textContent = `${c.hora}: ${c.oque}`;
  agenda.append(item);
}
total.textContent = `${compromissos.length} compromissos`;

Para ir além: crie também um botão "Limpar" que chame agenda.replaceChildren() quando for clicado.

Resumo

  • Criar um elemento tem três passos: document.createElement("etiqueta"), preencher (textContent, atributos, classes) e anexar. Sem o terceiro passo, nada aparece.
  • append e prepend põem dentro (no fim, no começo); before e after põem ao lado.
  • Para montar uma lista a partir de um array, crie um elemento novo a cada volta: o mesmo elemento só pode estar num lugar, e anexá-lo de novo o move.
  • remove() tira um elemento; replaceChildren() esvazia; replaceWith troca; cloneNode(true) copia.
  • innerHTML monta HTML a partir de texto: serve para HTML fixo seu, nunca para texto do usuário (XSS). Para texto, textContent.
  • Cannot read properties of null quase sempre é um seletor que não achou nada.
