JavaScript Variáveis (let)

Até agora, os seus programas escreveram valores "soltos": console.log(6), console.log("Ana"). Mas um programa de verdade precisa lembrar das coisas: quantos pães sobraram, quanto custa o leite, o nome de quem está usando. Para guardar um valor e usá-lo depois existe a variável. Nesta aula você vai criar variáveis com a palavra let (em inglês, "deixe", no sentido de "deixe paes valer 6").

Você vai aprender
  • O que é uma variável: uma caixa com uma etiqueta.
  • Como criar uma com let nome = valor; e como usar o valor guardado.
  • Como mudar o valor depois (sem repetir o let) e como somar ao valor que já estava lá: paes = paes + 10.
  • O que vale uma variável criada sem valor (undefined).
  • Que uma variável let só existe dentro do bloco { } onde foi criada.
  • Os erros reais mais comuns: usar antes de criar, nome digitado errado, criar duas vezes, nome com espaço.

Todos os programas desta aula rodaram no Node.js v24.22.0 da máquina da Ana (usuária ana, computador notebook), com node arquivo.js (veja Rodando um Programa).

A ideia: uma caixa com etiqueta

Na cozinha da Ana há várias caixinhas de plástico. Em cada uma ela colou uma etiqueta: "açúcar", "café", "pães". Quando quer saber quantos pães tem, ela não precisa lembrar de onde guardou: procura a caixa com a etiqueta "pães" e olha o que tem dentro.

Uma variável é exatamente isso:

  • a etiqueta é o nome da variável (paes);
  • o que tem dentro da caixa é o valor (6);
  • o conteúdo pode mudar: a Ana come dois pães e a caixa passa a ter 4, mas a etiqueta continua a mesma.

Por isso o nome "variável": o valor pode variar ao longo do programa. A caixa fica na memória do computador, e quem cuida dela é o JavaScript; você só precisa saber a etiqueta.

1. Criando uma variável

let paes = 6;
console.log(paes);
console.log("A Ana comprou", paes, "pães.");
let
A palavra que cria a variável. Os programadores dizem que ela declara a variável: avisa ao JavaScript "vai existir uma caixa com este nome". Só se escreve let na primeira vez.
paes
O nome (a etiqueta). Sem acento e sem espaço; as regras completas estão em Nomes de Variáveis.
=
O sinal de atribuição: "guarde na caixa o valor da direita". Atenção: aqui o = não é o "igual" da matemática; leia como "paes recebe 6".
6
O valor guardado. Pode ser um número, um texto entre aspas, true/false… (os tipos de valor estão em Os Tipos de Dados).
;
Fecha a instrução.
console.log(paes)
Usar a variável: onde você escreve o nome, o JavaScript põe o valor que está na caixa. Repare que paes vai sem aspas.
$ node caixa.js
6
A Ana comprou 6 pães.

Na segunda linha, o console.log recebeu três valores separados por vírgula: o texto "A Ana comprou", o valor da variável (6) e o texto "pães.". Ele os escreveu com um espaço entre cada um.

Com aspas é texto; sem aspas é a variável

Uma diferença pequena na escrita, uma diferença grande no resultado:

let nome = "Ana";
console.log("nome");
console.log(nome);

$ node aspas.js
nome
Ana

"nome", entre aspas, é a palavra nome, letra por letra. nome, sem aspas, é a etiqueta da caixa: o JavaScript abre a caixa e usa o que tem dentro, Ana.

2. Mudando o valor

Depois de criada, a variável pode receber um valor novo. Agora sem o let: a caixa já existe, você só está trocando o conteúdo.

let paes = 6;
console.log("De manhã:", paes);
paes = 4;
console.log("Depois do café:", paes);
paes = paes + 10;
console.log("Depois da padaria:", paes);

$ node mudar.js
De manhã: 6
Depois do café: 4
Depois da padaria: 14
paes = 4;
Joga fora o 6 e guarda 4. O valor antigo se perde: a caixa guarda um valor de cada vez.
paes = paes + 10;
A linha que mais confunde quem começa, porque na matemática "x = x + 10" é impossível. Na programação ela se lê da direita para a esquerda: primeiro o JavaScript calcula paes + 10 com o valor de agora (4 + 10 = 14); depois guarda o resultado na caixa paes.

Esse "pegar o valor atual, mudar e guardar de volta" aparece o tempo todo: somar pontos num jogo, juntar o total de uma compra, contar clientes. Veja os pontos de um jogo subindo de 10 em 10:

let pontos = 0;
console.log("Pontos:", pontos);
pontos = pontos + 10;
console.log("Pontos:", pontos);
pontos = pontos + 10;
console.log("Pontos:", pontos);

$ node mesa.js
Pontos: 0
Pontos: 10
Pontos: 20

(Existe um atalho para pontos = pontos + 10, que é pontos += 10; ele tem aula própria: Atribuição.)

Missão: a Ana comeu 2 pães. No lugar do comentário, escreva uma linha que tire 2 da variável paes (sem criar outra variável), para o programa mostrar Sobraram: 4.

3. Uma variável a partir de outras

O valor guardado pode ser o resultado de uma conta com outras variáveis. A Ana compra 6 pães de R$ 0,75 (no JavaScript, as casas decimais usam ponto: 0.75):

let preco = 0.75;
let quantidade = 6;
let total = preco * quantidade;
console.log("Total:", total);
quantidade = 10;
console.log("Total depois de mudar a quantidade:", total);
total = preco * quantidade;
console.log("Total recalculado:", total);

$ node conta.js
Total: 4.5
Total depois de mudar a quantidade: 4.5
Total recalculado: 7.5

O * é a multiplicação (veja Operadores Aritméticos). E repare na segunda linha da saída: a quantidade mudou para 10, mas o total continuou 4.5. Por quê?

Porque a variável guarda um valor, e não a conta. Na linha 3, o JavaScript calculou 0.75 * 6, obteve 4.5 e guardou o 4.5 na caixa total. A caixa não "lembra" de onde o número veio. Se a quantidade mudar, você precisa refazer a conta (linha 7). É diferente de uma planilha, onde a célula do total se atualiza sozinha.

4. Variável sem valor: undefined

Dá para criar a caixa vazia e encher depois:

let troco;
console.log(troco);
troco = 2.5;
console.log(troco);

$ node vazia.js
undefined
2.5

Uma variável criada sem valor vale undefined ("indefinido"): é o jeito do JavaScript dizer "esta caixa existe, mas ainda não tem nada dentro". Não é um erro; o undefined é um valor de verdade, que você vai conhecer melhor em null e undefined.

A caixa aceita qualquer tipo de valor

No JavaScript, a mesma variável pode guardar um número e, depois, um texto. Ninguém reclama:

let coisa = 10;
console.log(coisa);
coisa = "dez";
console.log(coisa);
coisa = true;
console.log(coisa);

$ node tipos.js
10
dez
true

Poder não quer dizer dever: uma variável que começa como número e vira texto no meio do programa é uma fonte clássica de confusão. Na prática, cada variável guarda um tipo de coisa do começo ao fim. (Linguagens como o TypeScript, que você vai conhecer em TypeScript, existem justamente para proibir essa troca.)

5. Várias variáveis numa linha

Um let só pode criar várias variáveis, separadas por vírgula:

let nome = "Ana", idade = 30, cidade = "Recife";
console.log(nome, idade, cidade);

$ node varias.js
Ana 30 Recife

Funciona, mas a maioria dos programadores prefere uma variável por linha: fica mais fácil de ler e de apagar uma delas depois.

6. A variável vive dentro do seu bloco { }

Um trecho de código entre chaves { } é um bloco. Uma variável criada com let dentro de um bloco só existe ali dentro; quando o bloco termina, a caixa é jogada fora:

let saldo = 100;
{
  let bonus = 20;
  saldo = saldo + bonus;
  console.log("Dentro do bloco:", saldo, bonus);
}
console.log("Fora do bloco:", saldo);
console.log(bonus);

$ node bloco.js
Dentro do bloco: 120 20
Fora do bloco: 120
/home/ana/bloco.js:8
console.log(bonus);
            ^

ReferenceError: bonus is not defined
    at Object.<anonymous> (/home/ana/bloco.js:8:13)
    «  … mais 7 linhas "at" de dentro do Node (cortadas aqui)

Node.js v24.22.0

O saldo foi criado fora do bloco, então continua existindo depois dele (com o valor 120). O bonus foi criado dentro, então na linha 8 ele não existe mais: bonus is not defined ("bonus não está definido"). Um bloco sozinho, assim, é raro; você vai ver blocos o tempo todo no if, nos laços e nas funções. Os detalhes estão na aula Escopo.

7. let no modo interativo

No modo interativo do Node (o >, veja O Modo Interativo), cada linha que você digita é executada na hora, e o Node mostra o resultado:

$ node
Welcome to Node.js v24.22.0.
Type ".help" for more information.
> let paes = 6
undefined
> paes
6
> paes = paes + 2
8
> paes
8
> let paes = 1
Uncaught SyntaxError: Identifier 'paes' has already been declared
> let troco
undefined
> troco
undefined
> .exit
> let paes = 6 → undefined
Esse undefined não quer dizer que paes ficou vazia. O modo interativo sempre mostra o "resultado" da linha, e uma linha com let não tem resultado: por isso undefined. Quando você digita paes, aparece o 6.
> paes = paes + 2 → 8
Uma atribuição tem resultado: o valor que foi guardado.
Uncaught SyntaxError: Identifier 'paes' has already been declared
Não dá para criar a mesma variável duas vezes (o erro aparece de novo em Quando dá errado). O Uncaught ("não capturado") é como o modo interativo começa as mensagens de erro.
> let troco → undefined, e troco → undefined
Aqui, sim, a caixa está vazia.

Formas diferentes de criar uma variável

O let não é a única palavra que cria variáveis. Existem três:

let quantidade = 6;        // pode mudar depois
const preco = 0.75;        // não pode mudar: uma constante
var cliente = "Ana";       // o jeito antigo: evite
PalavraPode receber outro valor?Quando usar
constNãoPor padrão. A maior parte dos valores de um programa não muda depois de criada (aula Constantes (const)).
letSimQuando o valor vai mudar: contadores, totais, pontos, o saldo.
varSimNunca em código novo. Ela existe desde 1995 e tem comportamentos estranhos; aparece em código antigo (aula var: o Jeito Antigo).

Nesta aula usamos let em tudo para você ver as caixas mudando. Na próxima aula você vai ver que, quando o valor não muda, const é a escolha melhor.

Resumo

  • Uma variável é uma caixa com etiqueta: o nome é a etiqueta e o valor é o conteúdo.
  • let nome = valor; cria a variável. Para mudar o valor depois, escreva sem o let: nome = novoValor;.
  • O = quer dizer "recebe". paes = paes + 10 calcula a direita primeiro e guarda o resultado na esquerda.
  • A variável guarda o valor, não a conta: se uma parte da conta mudar, refaça a conta.
  • Sem valor, a variável vale undefined. Criada dentro de { }, ela só existe lá dentro.
  • Erros comuns: is not defined (nome errado ou inexistente), Cannot access … before initialization (usou antes do let), has already been declared (dois let com o mesmo nome).
  • const por padrão, let quando o valor muda, var nunca: é o assunto das duas próximas aulas.
