JavaScript Formatando Datas

Na aula Datas (Date), você criou datas e leu as partes delas. Mas, quando chega a hora de mostrar, o JavaScript tem o costume americano: Thu Mar 05 2026 ou 2026-03-05T17:30:00.000Z. A agenda da Ana precisa de 05/03/2026, de quinta-feira, 5 de março, de 14:30, e até de amanhã. Esta aula mostra como transformar uma data num texto do jeito que as pessoas leem, primeiro montando à mão e depois com as ferramentas prontas do JavaScript.

Você vai aprender
  • Como montar 05/03/2026 às 09:05 à mão, com padStart.
  • Como usar toLocaleDateString, toLocaleTimeString e toLocaleString com "pt-BR".
  • Os estilos prontos (dateStyle e timeStyle) e as opções para escolher cada parte: o dia da semana, o mês por extenso, a hora com 2 dígitos.
  • Como formatar muitas datas com Intl.DateTimeFormat e mostrar o mesmo horário em outra cidade com timeZone.
  • Como guardar uma data em texto com toISOString, e a armadilha da data que muda de dia.
  • Como escrever "ontem", "amanhã" e "em 3 dias" com Intl.RelativeTimeFormat.
  • Os erros reais do Node 24 ao formatar.

Todos os programas desta aula rodaram no Node.js 24 da máquina da Ana (usuária ana, computador notebook, no horário de Brasília), com node arquivo.js. Tudo aqui é da linguagem e funciona igual no navegador; só o fuso horário do seu computador pode mudar o resultado de exemplos que comparam fusos.

A ideia: a mesma data, várias etiquetas

A consulta da Ana é no dia 5 de março de 2026, às 14h30. Isso é um instante. Mas ele pode ser escrito de muitos jeitos: 05/03/2026 no formulário, quinta-feira, 5 de março na agenda, 14:30 no lembrete do celular, 3/5/2026 para uma prima nos Estados Unidos (onde o mês vem antes do dia), amanhã numa mensagem. Como os números da aula Formatando Números: o Date é o valor, e o texto formatado é a etiqueta. Guarde a data como Date; formate só na hora de mostrar.

1. Montando à mão: padStart

Com os métodos get da aula anterior dá para montar qualquer formato. O detalhe é o zero à esquerda: getDate() devolve 5, e a gente quer 05. O padStart(2, "0") completa o texto com zeros no começo até ter 2 caracteres (veja Métodos de String):

const consulta = new Date(2026, 2, 5, 9, 5);

const dia = String(consulta.getDate()).padStart(2, "0");
const mes = String(consulta.getMonth() + 1).padStart(2, "0");
const ano = consulta.getFullYear();
const hora = String(consulta.getHours()).padStart(2, "0");
const minuto = String(consulta.getMinutes()).padStart(2, "0");

console.log(`${dia}/${mes}/${ano} às ${hora}:${minuto}`);

Montar à mão é bom quando você precisa de um formato muito específico (por exemplo, 2026-03-05 para o nome de um arquivo). Para mostrar a uma pessoa, as ferramentas da próxima seção fazem o mesmo em uma linha, e ainda sabem os nomes dos meses e dos dias da semana.

console.log(consulta.toLocaleString("pt-BR"));

console.log(consulta.toLocaleDateString("pt-PT"));

3. Estilos prontos: dateStyle e timeStyle

Depois da localidade, esses métodos aceitam um objeto de opções. As mais simples são os estilos prontos: "full" (completo), "long" (longo), "medium" (médio) e "short" (curto):

const consulta = new Date(2026, 2, 5, 14, 30);

console.log(consulta.toLocaleDateString("pt-BR", { dateStyle: "full" }));
console.log(consulta.toLocaleDateString("pt-BR", { dateStyle: "long" }));
console.log(consulta.toLocaleDateString("pt-BR", { dateStyle: "medium" }));
console.log(consulta.toLocaleDateString("pt-BR", { dateStyle: "short" }));
console.log(consulta.toLocaleString("pt-BR", { dateStyle: "short", timeStyle: "short" }));
console.log(consulta.toLocaleTimeString("pt-BR", { timeStyle: "short" }));

4. Escolhendo cada parte

Em vez de um estilo pronto, você pode dizer quais partes quer e como: weekday (dia da semana), day (dia), month (mês), year (ano), hour (hora) e minute (minuto). O JavaScript junta as partes na ordem e com as palavras de ligação da língua:

const consulta = new Date(2026, 2, 5, 14, 30);

console.log(consulta.toLocaleDateString("pt-BR", { weekday: "long" }));
console.log(consulta.toLocaleDateString("pt-BR", { month: "long" }));
console.log(consulta.toLocaleDateString("pt-BR", { month: "short" }));
console.log(consulta.toLocaleDateString("pt-BR", { day: "numeric", month: "long" }));
console.log(consulta.toLocaleDateString("pt-BR", { month: "long", year: "numeric" }));
console.log(consulta.toLocaleDateString("pt-BR", { weekday: "short", day: "2-digit", month: "2-digit" }));
console.log(consulta.toLocaleTimeString("pt-BR", { hour: "2-digit", minute: "2-digit" }));

Muitas datas: Intl.DateTimeFormat

Como o Intl.NumberFormat dos números, o Intl.DateTimeFormat cria um formatador uma vez, para usar com o .format(data) quantas vezes quiser:

const formato = new Intl.DateTimeFormat("pt-BR", { weekday: "long", day: "numeric", month: "long" });

const provas = [new Date(2026, 2, 5), new Date(2026, 2, 12), new Date(2026, 3, 2)];
for (const prova of provas) {
  console.log(`Prova: ${formato.format(prova)}`);
}

5. O mesmo instante em outra cidade: timeZone

A Ana marcou uma reunião por vídeo às 14h30 de Brasília, com gente de Manaus, Lisboa e Tóquio. Que horas vai ser para cada um? A opção timeZone ("fuso horário") formata o mesmo instante no relógio de outro lugar. Os nomes dos fusos seguem o padrão Continente/Cidade, em inglês:

const reuniao = new Date("2026-03-05T14:30:00-03:00");

const opcoes = { dateStyle: "short", timeStyle: "short" };
console.log(`Brasília: ${reuniao.toLocaleString("pt-BR", { ...opcoes, timeZone: "America/Sao_Paulo" })}`);
console.log(`Manaus:   ${reuniao.toLocaleString("pt-BR", { ...opcoes, timeZone: "America/Manaus" })}`);
console.log(`Lisboa:   ${reuniao.toLocaleString("pt-BR", { ...opcoes, timeZone: "Europe/Lisbon" })}`);
console.log(`Tóquio:   ${reuniao.toLocaleString("pt-BR", { ...opcoes, timeZone: "Asia/Tokyo" })}`);

$ node fusos.js

6. Para guardar, não para mostrar: toISOString

Para salvar uma data num arquivo, mandar para um servidor ou guardar no localStorage, o formato certo é o ISO, em UTC, que qualquer programa no mundo entende:

const consulta = new Date(2026, 2, 5, 14, 30);
const tarde = new Date(2026, 2, 5, 22, 30);

console.log(consulta.toISOString());
console.log(tarde.toISOString());
console.log(tarde.toISOString().slice(0, 10));
console.log(JSON.stringify({ consulta }));

7. "Ontem", "amanhã", "em 3 dias": Intl.RelativeTimeFormat

Os aplicativos de mensagem não dizem "05/03/2026"; dizem "ontem" ou "há 5 minutos". O Intl.RelativeTimeFormat ("formato de tempo relativo") escreve essas frases. Você dá um número (negativo é passado, positivo é futuro) e a unidade ("day", "week", "minute"…):

const relativo = new Intl.RelativeTimeFormat("pt-BR", { numeric: "auto" });

console.log(relativo.format(-1, "day"));
console.log(relativo.format(1, "day"));
console.log(relativo.format(3, "day"));
console.log(relativo.format(-2, "week"));
console.log(relativo.format(-5, "minute"));

$ node relativo.js
ontem
amanhã
em 3 dias
há 2 semanas
há 5 minutos

O numeric: "auto" permite as palavras especiais (ontem, amanhã, anteontem); sem ele, sairia há 1 dia. Juntando com a diferença de datas da aula Datas, a agenda da Ana fica assim:

const umDia = 1000 * 60 * 60 * 24;
const relativo = new Intl.RelativeTimeFormat("pt-BR", { numeric: "auto" });
const hoje = new Date(2026, 2, 5);

const eventos = [
  ["Prova de matemática", new Date(2026, 2, 6)],
  ["Aniversário da Bia", new Date(2026, 2, 12)],
  ["Pagamento da luz", new Date(2026, 2, 3)]
];

for (const [nome, data] of eventos) {
  const dias = Math.round((data - hoje) / umDia);
  console.log(`${nome}: ${relativo.format(dias, "day")}`);
}

Resumo

  • Guarde a data como Date e formate só na hora de mostrar. Sempre diga a localidade: "pt-BR".
  • toLocaleDateString("pt-BR") → 05/03/2026; toLocaleTimeString → 14:30:00; toLocaleString → as duas juntas.
  • Estilos prontos: dateStyle/timeStyle ("full", "long", "medium", "short"). Ou escolha as partes: weekday, day, month, year, hour, minute. Nunca os dois juntos.
  • Para muitas datas, new Intl.DateTimeFormat("pt-BR", opções) e .format(d). Para outro fuso, timeZone: "Continente/Cidade".
  • Para guardar, toISOString() (em UTC; cuidado com o slice(0, 10) à noite). Para "ontem" e "em 3 dias", Intl.RelativeTimeFormat.
  • À mão: getMonth() + 1 e padStart(2, "0").
