JavaScript splice e slice

Com push, pop, shift e unshift, você mexeu nas pontas do array. Mas e quando a Ana quer tirar o feijão, que está no meio da lista? Ou pôr um aluno novo na terceira posição da chamada? Ou só olhar os três primeiros colocados de uma corrida, sem mexer no resultado? Para isso existem dois métodos de nomes quase iguais e trabalhos bem diferentes: slice e splice.

Você vai aprender
  • slice ("fatia"): copiar um pedaço do array, sem mudar o original.
  • A regra do início e do fim: o início entra, o fim não entra.
  • Índices negativos, que contam a partir do fim.
  • splice ("emendar"): tirar, pôr e trocar itens em qualquer lugar do array, mudando o original.
  • O que o splice devolve: um array com os itens que ele tirou.
  • toSpliced, que faz o mesmo que o splice numa cópia.
  • Como não confundir os dois, e os erros reais mais comuns.

Todos os programas desta aula rodaram no Node.js 24 da máquina da Ana (usuária ana, computador notebook), com node arquivo.js. Você pode rodar cada um no editor do guia.

A ideia: a fotocópia e a tesoura

A Ana tem a lista da chamada da turma num papel. Ela pode fazer duas coisas bem diferentes com ela:

  • Tirar uma fotocópia de um pedaço (só os cinco primeiros nomes, para o time de vôlei). O papel original fica intacto. Isso é o slice.
  • Pegar a tesoura e a cola: recortar um nome que saiu da turma, colar um nome novo no meio. Agora o papel original mudou. Isso é o splice.

Os nomes ajudam a lembrar: slice é "fatia" (como uma fatia de pão: você pega um pedaço e o pão continua lá); splice é "emendar" (como se emendam duas pontas de corda: você corta e junta). O splice tem um p a mais, de "perigoso": ele mexe no original.

1. slice: copiar um pedaço

const alunos = ["Ana", "Bia", "Caio", "Duda", "Edu", "Fabi"];
const time = alunos.slice(1, 4);
console.log(time);
console.log(alunos);
alunos.slice(1, 4)
"Uma fatia de alunos, da posição 1 até a posição 4". Os dois números são índices (começando do 0, como sempre).
1 (o início)
A posição onde a fatia começa. Entra na fatia: a Bia.
4 (o fim)
A posição onde a fatia para. Não entra na fatia: o Edu (posição 4) fica de fora. A fatia vai até a posição 3.
const time = …
O slice devolve um array novo com o pedaço.
$ node slice.js
[ 'Bia', 'Caio', 'Duda' ]
[ 'Ana', 'Bia', 'Caio', 'Duda', 'Edu', 'Fabi' ]

A segunda linha mostra que o alunos continuou com os seis nomes: o slice só copiou.

Por que o fim não entra?

Parece estranho, mas tem uma vantagem: fim − início = quantos itens vêm na fatia. slice(1, 4) traz 4 − 1 = 3 itens. E slice(0, 3) traz os 3 primeiros. É a mesma regra do slice das strings (aula Pedaços de String).

Sem o fim, com números negativos, sem nada

const alunos = ["Ana", "Bia", "Caio", "Duda", "Edu", "Fabi"];
console.log(alunos.slice(0, 3));
console.log(alunos.slice(4));
console.log(alunos.slice(-2));
console.log(alunos.slice(1, -1));
console.log(alunos.slice());
console.log(alunos.slice(10));

2. splice: tirar itens do meio

O feijão (posição 1) saiu da lista de compras. O splice recorta a partir de uma posição, a quantidade de itens que você disser:

const compras = ["arroz", "feijão", "café", "leite"];
const tirados = compras.splice(1, 1);
console.log(tirados);
console.log(compras);
compras.splice(1, 1)
"A partir da posição 1, tire 1 item".
1 (o primeiro número)
A posição onde o corte começa (o índice).
1 (o segundo número)
Quantos itens tirar. Atenção: no splice, o segundo número é uma quantidade; no slice, é uma posição. Essa diferença confunde muita gente.
const tirados = …
O splice devolve um array com os itens tirados (mesmo que seja um só). Se você não precisa deles, escreva só compras.splice(1, 1);.
$ node splice_tirar.js
[ 'feijão' ]
[ 'arroz', 'café', 'leite' ]

Agora o compras mudou: tem 3 itens, e o café, que era a posição 2, agora é a posição 1 (os que estavam depois do corte andaram para a frente, como no shift).

Para tirar vários de uma vez, aumente a quantidade. E, como no slice, a posição pode ser negativa:

const alunos = ["Ana", "Bia", "Caio", "Duda", "Edu", "Fabi"];
alunos.splice(2, 3);
console.log(alunos);

const notas = [7, 8, 5, 9, 10];
notas.splice(-2, 1);
console.log(notas);

const fila = ["Ana", "Bia", "Caio", "Duda"];
fila.splice(1);
console.log(fila);

$ node splice_varios.js
[ 'Ana', 'Bia', 'Fabi' ]
[ 7, 8, 5, 10 ]
[ 'Ana' ]
alunos.splice(2, 3)
A partir da posição 2, tirou 3: Caio, Duda e Edu.
notas.splice(-2, 1)
A partir do penúltimo, tirou 1: o 9.
fila.splice(1)
Sem a quantidade, o splice tira tudo dali até o fim. Cuidado: esquecer o segundo número apaga muito mais do que você queria.

3. splice: pôr itens no meio

Depois da quantidade, você pode escrever valores: eles são colados no lugar do corte. Se a quantidade for 0, nada é tirado, e o splice só põe:

const chamada = ["Ana", "Bia", "Duda"];
chamada.splice(2, 0, "Caio");
console.log(chamada);
chamada.splice(4, 0, "Edu", "Fabi");
console.log(chamada);
chamada.splice(2, 0, "Caio")
"Na posição 2, tire 0 itens e ponha o Caio". O Caio entra na posição 2, e a Duda (que estava lá) anda para a posição 3. A chamada continua em ordem alfabética.
chamada.splice(4, 0, "Edu", "Fabi")
Vários valores entram todos, nessa ordem. A posição 4 era o fim do array, então funcionou como um push.
$ node splice_por.js
[ 'Ana', 'Bia', 'Caio', 'Duda' ]
[ 'Ana', 'Bia', 'Caio', 'Duda', 'Edu', 'Fabi' ]

4. splice: trocar itens

Tirar e pôr ao mesmo tempo é trocar. O café em pó (posição 2) acabou na loja; a Ana troca por café em cápsula e ainda acrescenta açúcar:

const compras = ["arroz", "feijão", "café em pó", "leite"];
const saiu = compras.splice(2, 1, "café em cápsula", "açúcar");
console.log("Saiu:", saiu);
console.log(compras);

$ node splice_trocar.js
Saiu: [ 'café em pó' ]
[ 'arroz', 'feijão', 'café em cápsula', 'açúcar', 'leite' ]

Saiu 1 item e entraram 2: o array cresceu um. O splice não exige que a quantidade que sai seja igual à que entra.

Para…EscrevaLê-se
Tirarlista.splice(i, n)"Na posição i, tire n"
Tirar tudo dali em diantelista.splice(i)"Da posição i, tire tudo"
Pôrlista.splice(i, 0, a, b)"Na posição i, tire 0 e ponha a e b"
Trocarlista.splice(i, 1, a)"Na posição i, tire 1 e ponha a"

Missão: a chamada está quase certa: o "Zeca" mudou de escola, e o "Caio", que é novo, ainda não está na lista. Use o splice (um só, ou dois) para tirar o Zeca e pôr o Caio no lugar dele.

const chamada = ["Ana", "Bia", "Zeca", "Duda", "Edu"];

console.log(chamada);

const chamada = ["Ana", "Bia", "Zeca", "Duda", "Edu"];
chamada.splice(2, 1, "Caio");
console.log(chamada);

5. toSpliced: o splice numa cópia ES2023

Às vezes você quer o resultado do splice, mas sem estragar o original. O toSpliced recebe exatamente os mesmos números e valores, e devolve um array novo já recortado e colado:

const compras = ["arroz", "feijão", "café", "leite"];
const semFeijao = compras.toSpliced(1, 1);
const comPao = compras.toSpliced(2, 0, "pão");
console.log(semFeijao);
console.log(comPao);
console.log(compras);

$ node tospliced.js
[ 'arroz', 'café', 'leite' ]
[ 'arroz', 'feijão', 'pão', 'café', 'leite' ]
[ 'arroz', 'feijão', 'café', 'leite' ]

Repare na diferença do que cada um devolve: o splice devolve os itens tirados; o toSpliced devolve o array inteiro, já modificado. O toSpliced chegou em 2023, junto com o with (aula Acessando e Alterando Itens), e funciona no Node 24 e nos navegadores atuais.

6. No modo interativo

No modo interativo (veja O Modo Interativo), dá para ver lado a lado o que cada um devolve e o que acontece com o original:

Formas diferentes: qual usar

slice(início, fim)splice(início, quantos, …novos)toSpliced(início, quantos, …novos)
Muda o original?NãoSimNão
O 2º número é…uma posição (o fim, que não entra)uma quantidadeuma quantidade
DevolveO pedaço copiadoOs itens tiradosO array novo, já modificado
Use paraPegar um pedaço (os 3 primeiros, os 2 últimos)Tirar, pôr ou trocar no meio da própria listaTer uma versão modificada e manter a original

Para tirar itens por valor ("tire todos os que estão em falta"), e não por posição, existe um jeito mais fácil: o filter. E para tirar ou pôr nas pontas, prefira push/pop/shift/unshift, que são mais claros que um splice(0, 1).

Quando dá errado

Usou slice achando que ia tirar o item 
const compras = ["arroz", "feijão", "café"];
compras.slice(1, 2);
console.log(compras);

$ node slice_nao_tira.js
[ 'arroz', 'feijão', 'café' ]

Nada mudou, e o Node não reclamou. O slice fez uma cópia do feijão e devolveu essa cópia, que ninguém guardou. Como consertar: para tirar, é splice: compras.splice(1, 1);.

Usou o 2º número do splice como se fosse o fim 
const alunos = ["Ana", "Bia", "Caio", "Duda", "Edu", "Fabi"];
alunos.splice(3, 4);
console.log(alunos);

$ node splice_fim.js
[ 'Ana', 'Bia', 'Caio' ]

A ideia era tirar só a Duda (da posição 3 "até a 4", pensando como no slice). Mas no splice o 4 é quantos: "tire 4 a partir da posição 3". Como só havia 3 itens dali em diante, foram todos. Como consertar: alunos.splice(3, 1);.

Guardou o resultado do splice achando que era a lista 
let compras = ["arroz", "feijão", "café"];
compras = compras.splice(1, 1);
console.log(compras);

$ node splice_resultado.js
[ 'feijão' ]

Sobrou só o feijão, justamente o que devia sair. O splice devolve os itens tirados, e a linha 2 guardou isso em compras. Como consertar: não guarde: compras.splice(1, 1);. Ou, se queria um array novo sem o feijão, use const semFeijao = compras.toSpliced(1, 1);.

Resumo

  • slice(início, fim) copia um pedaço e não muda o original. O início entra, o fim não. Sem o fim, vai até o final; negativos contam do fim.
  • splice(início, quantos, …novos) muda o original: tira quantos itens a partir de início e cola os novos no lugar. Devolve os itens tirados.
  • Com quantidade 0, o splice só põe; sem quantidade, tira tudo até o fim.
  • toSpliced faz o mesmo que o splice numa cópia e devolve o array novo.
  • No slice o 2º número é posição; no splice, quantidade. Strings têm slice, mas não splice.
