JavaScript do … while

O while pergunta antes de cada volta; se a resposta já for "não" de cara, o bloco não roda nenhuma vez. Às vezes você precisa do contrário: fazer primeiro e só depois perguntar se repete. Para isso existe o do … while: "faça isto, enquanto a condição for verdadeira". O bloco roda pelo menos uma vez, sempre.

Você vai aprender
  • Como se escreve do { … } while (condição);, com o ponto e vírgula no fim.
  • Por que o bloco roda pelo menos uma vez, e a diferença para o while quando a condição já começa falsa.
  • Um caso em que o do … while acerta e o while erra: contar os dígitos do número 0.
  • Repetir até acontecer algo: jogar o dado até sair 6.
  • O mesmo laço escrito com while (true) e break.
  • Os erros reais: a variável criada dentro do bloco e usada na condição, e o while esquecido.

Todos os programas desta aula rodaram no Node.js 24 da máquina da Ana (usuária ana, computador notebook), salvos na pasta pessoal dela e executados com node arquivo.js (veja Rodando um Programa). Você pode rodar cada um no editor do guia.

A ideia: provar o tempero

A Ana está fazendo o feijão. Ela não pergunta "está bom de sal?" antes de provar: isso não faria sentido. Ela faz assim:

  1. Prova uma colherada.
  2. Pergunta: falta sal? Se sim, põe uma pitada e volta ao passo 1. Se não, desliga o fogo.

A prova acontece pelo menos uma vez, e a pergunta vem depois. É exatamente a ordem do do … while. No while comum, a pergunta vem antes, como no cesto de pães da aula anterior.

1. O primeiro do … while

let contador = 1;

do {
  console.log(`Volta ${contador}`);
  contador++;
} while (contador <= 5);

console.log(`Fim! contador agora vale ${contador}`);
do
"Faça". Abre o laço. Repare: não tem condição aqui.
{ … }
O bloco que se repete. Ele vem antes da condição, então roda antes de qualquer pergunta.
while (contador <= 5)
"Enquanto…": a condição, entre parênteses, testada no fim de cada volta. Se der true, o Node volta para o do; se der false, segue em frente.
;
O do … while termina com ponto e vírgula, como uma instrução comum. (Aqui é o contrário do while, onde o ; depois do ) trava o programa.)
$ node contador.js
Volta 1
Volta 2
Volta 3
Volta 4
Volta 5
Fim! contador agora vale 6

A mesma saída do while da aula anterior. Quando a condição começa verdadeira, os dois laços fazem o mesmo número de voltas. A diferença aparece quando ela começa falsa.

2. A diferença: pelo menos uma volta

Os dois laços abaixo começam com o contador em 10, então a condição contador <= 5 já é falsa desde o início:

let a = 10;
while (a <= 5) {
  console.log(`while: volta com ${a}`);
  a++;
}

let b = 10;
do {
  console.log(`do … while: volta com ${b}`);
  b++;
} while (b <= 5);

console.log(`Depois: a = ${a}, b = ${b}`);

$ node diferenca.js
do … while: volta com 10
Depois: a = 10, b = 11

O while perguntou primeiro, ouviu "não" e nem entrou: a continuou 10. O do … while rodou o bloco uma vez (mostrou a linha e mudou b para 11) e só então perguntou 11 <= 5, ouviu "não" e parou.

3. Onde o do … while acerta: contar dígitos

Quantos dígitos tem um número? Um jeito é dividir por 10 (descartando a parte quebrada) até não sobrar nada, contando as divisões: 2026 → 202 → 20 → 2 → 0, foram 4. O Math.trunc corta a parte depois da vírgula (veja Math). Com while:

let numero = 2026;
let digitos = 0;

while (numero > 0) {
  numero = Math.trunc(numero / 10);
  digitos++;
}

console.log(`Dígitos: ${digitos}`);

$ node digitos-while.js
Dígitos: 4

Certo. Mas troque 2026 por 0:

let numero = 0;
let digitos = 0;

while (numero > 0) {
  numero = Math.trunc(numero / 10);
  digitos++;
}

console.log(`Dígitos: ${digitos}`);

$ node digitos-zero.js
Dígitos: 0

O número 0 tem um dígito, o próprio 0! O while testou 0 > 0, deu falso, e não contou nada. Todo número tem pelo menos um dígito, então a contagem tem de acontecer pelo menos uma vez: é o trabalho do do … while.

let numero = 0;
let digitos = 0;

do {
  numero = Math.trunc(numero / 10);
  digitos++;
} while (numero > 0);

console.log(`Dígitos: ${digitos}`);

$ node digitos-do.js
Dígitos: 1

Com o 0, o bloco rodou uma vez (contou 1 dígito), e a condição 0 > 0 encerrou o laço. Com 2026, continua dando 4: as voltas seguintes acontecem normalmente.

4. Repetir até acontecer: jogar o dado até sair 6

No jogo de tabuleiro da família da Ana, para sair da casa inicial é preciso tirar 6 no dado. Quantas jogadas vai levar? Ninguém sabe, mas é certo que a primeira jogada acontece. O Math.random() sorteia um número, e a conta abaixo o transforma num dado de 1 a 6 (aula Números Aleatórios):

let dado;
let jogadas = 0;

do {
  dado = Math.floor(Math.random() * 6) + 1;
  jogadas++;
  console.log(`Jogada ${jogadas}: saiu ${dado}`);
} while (dado !== 6);

console.log(`Saiu da casa inicial na jogada ${jogadas}!`);

Duas execuções no notebook da Ana (as suas vão dar números diferentes, porque o dado é sorteado):

$ node dado.js

Jogada 2: saiu 6

let dado;
A variável é criada antes do do, sem valor. Ela precisa existir fora do bloco porque a condição, lá no while, usa o dado (veja o primeiro cenário de Quando dá errado).
dado = …
Dentro do bloco, a variável só recebe o sorteio da vez.
while (dado !== 6)
"Enquanto não sair 6, jogue de novo". O !== é o "diferente" (veja Comparação).

Experimente: rode várias vezes e veja o número de jogadas mudar. Depois troque o 6 da condição por 1: "sair da casa inicial tirando 1".

let dado;
let jogadas = 0;

do {
  dado = Math.floor(Math.random() * 6) + 1;
  jogadas++;
  console.log(`Jogada ${jogadas}: saiu ${dado}`);
} while (dado !== 6);

console.log(`Saiu da casa inicial na jogada ${jogadas}!`);

Este é o mesmo formato de "perguntar de novo até a resposta ser válida": a pergunta acontece pelo menos uma vez, e repete enquanto a resposta não presta. Você vai usar isso quando aprender a ler o teclado, em Lendo o Teclado no Node.

Formas diferentes de fazer a mesma coisa

Todo do … while pode ser escrito com while (true) e um break no fim do bloco (veja break e continue). Os dois programas abaixo contam os dígitos de 0 do mesmo jeito:

let n1 = 0;
let d1 = 0;
do {
  n1 = Math.trunc(n1 / 10);
  d1++;
} while (n1 > 0);

let n2 = 0;
let d2 = 0;
while (true) {
  n2 = Math.trunc(n2 / 10);
  d2++;
  if (!(n2 > 0)) {
    break;
  }
}

console.log(d1, d2);

$ node formas.js
1 1

O do … while é mais curto e diz logo no começo o tipo de laço. O while (true) com break é mais flexível: a saída pode ficar em qualquer ponto do bloco, não só no fim. Na prática, o do … while é o laço menos usado do JavaScript; mas quando a situação é "pelo menos uma vez", ele é o mais claro.

Funciona: depois do ) de um do … while, o JavaScript põe o ponto e vírgula sozinho. Mesmo assim, escreva o ;: é o estilo do guia, e deixa claro onde a instrução termina.

A condição nunca fica falsa

O do … while também pode virar um laço infinito, pelos mesmos motivos do while: o passo que falta, que fica fora do bloco ou que anda para o lado errado. Para parar, Ctrl+C no terminal ou o botão ■ Parar no editor (veja while).

Missão: conserte o programa do primeiro cenário para ele rodar sem erro e terminar mostrando quantas jogadas foram necessárias.

let jogadas = 0;

do {
  const dado = Math.floor(Math.random() * 6) + 1;
  jogadas++;
} while (dado !== 6);

console.log(`Total de jogadas: ${jogadas}`);

let jogadas = 0;
let dado;

do {
  dado = Math.floor(Math.random() * 6) + 1;
  jogadas++;
} while (dado !== 6);

console.log(`Total de jogadas: ${jogadas}`);

Missão final: o caixa da padaria

Missão: o caixa da padaria registra os itens de um pedido, um por volta. Os preços vão do mais caro para o mais barato: R$ 15, R$ 10, R$ 5. A cada volta: some o preco ao total, some 1 em itens e diminua o preco em 5. Escreva um do … while que repita enquanto o preco for maior que 0. Deve aparecer Total: R$ 30 em 3 itens.

let preco = 15;
let total = 0;
let itens = 0;

// escreva o do … while aqui

console.log(`Total: R$ ${total} em ${itens} itens`);

let preco = 15;
let total = 0;
let itens = 0;

do {
  total += preco;
  itens++;
  preco -= 5;
} while (preco > 0);

console.log(`Total: R$ ${total} em ${itens} itens`);

Resumo

  • do { … } while (condição); ("faça … enquanto") roda o bloco e depois testa a condição; repete enquanto ela for verdadeira.
  • O bloco roda pelo menos uma vez, mesmo que a condição seja falsa desde o começo. O while comum pode rodar zero vezes.
  • Use quando a primeira volta tem de acontecer de qualquer jeito: contar os dígitos (o 0 tem um), jogar o dado, perguntar até a resposta ser válida.
  • Termina com ;. Variáveis usadas na condição precisam ser criadas antes do do, não dentro do bloco.
  • O mesmo laço pode ser escrito com while (true) e um break no fim do bloco.
