Projeto Contador de Palavras

Quais palavras um texto mais usa? A pergunta parece simples, e é um ótimo treino: o programa precisa ler um arquivo, separar as palavras, decidir que "Sabiá;" e "sabiá" são a mesma palavra, contar cada uma e mostrar as campeãs. A Ana vai testar com a "Canção do Exílio", de Gonçalves Dias (1843), um poema que todo brasileiro já leu na escola e que repete muito as mesmas palavras.

Você vai praticar
  • Ler um arquivo de texto com fs.readFileSync.
  • Separar palavras com split e uma expressão regular (/\s+/).
  • Limpar com toLowerCase e replace, sem estragar os acentos (\p{L}).
  • Encadear map e filter.
  • Contar com um Map e o operador ??.
  • Ordenar com toSorted e localeCompare, e tirar as palavras comuns com um Set.

Vamos chegar lá em quatro versões:

  1. Ler o arquivo e separar as palavras (split(/\s+/)).
  2. Limpar: minúsculas e sem pontuação (toLowerCase, replace, \p{L}).
  3. Contar num Map e ordenar (Map, ??, toSorted).
  4. Palavras comuns, barras e colunas (Set, repeat, process.argv).

Antes de começar

Crie a pasta e, dentro dela, o cancao.txt com o poema acima (copie e cole num editor de texto e salve). O programa vai se chamar palavras.js:

$ mkdir -p projetos/palavras
$ cd projetos/palavras

Nas caixas Experimente, o cancao.txt fica numa aba ao lado do programa. Troque o poema por outro texto e rode de novo: o programa conta o que estiver lá.

Versão 1 · Ler o arquivo e separar as palavras

A primeira ideia de quase todo mundo: palavras são separadas por espaço, então basta cortar o texto nos espaços.

import fs from "node:fs";

const texto = fs.readFileSync("cancao.txt", "utf8");
const palavras = texto.split(" ");

console.log(`Caracteres: ${texto.length}`);
console.log(`Palavras: ${palavras.length}`);
console.log(palavras.slice(0, 6));

$ node palavras.js
Caracteres: 678
Palavras: 95
[
  'Canção',
  'do',
  'Exílio\nGonçalves',
  'Dias\n\nMinha',
  'terra',
  'tem'
]

O slice(0, 6) mostra só as 6 primeiras, para conferir, e elas revelam o problema: 'Exílio\nGonçalves' virou uma palavra só. No fim de cada linha não há espaço, há uma quebra de linha (\n), e o split(" ") não corta ali. Entre os versos também há linhas em branco (\n\n). E, se alguém digitar dois espaços seguidos, apareceria uma "palavra" vazia entre eles.

A solução é cortar em qualquer sequência de espaços em branco: espaço, quebra de linha, tabulação, quantos forem. Uma expressão regular diz isso em quatro caracteres: /\s+/.

import fs from "node:fs";

const texto = fs.readFileSync("cancao.txt", "utf8");
const linhas = texto.split("\n").filter((linha) => linha.trim() !== "");
const palavras = texto.trim().split(/\s+/);

console.log(`Caracteres: ${texto.length}`);
console.log(`Linhas com texto: ${linhas.length}`);
console.log(`Palavras: ${palavras.length}`);
console.log(palavras.slice(0, 6));
/\s+/
Uma regex (o que fica entre as barras). \s quer dizer "um espaço em branco qualquer" (espaço, \n, tabulação); o +, "um ou mais seguidos". O split aceita uma regex no lugar de um texto.
texto.trim()
Tira os brancos das pontas antes de cortar. Sem ele, a quebra de linha do fim do arquivo deixaria uma palavra vazia '' no fim do array.
texto.split("\n").filter((linha) => linha.trim() !== "")
As linhas do arquivo, sem as linhas em branco: só fica a linha que, sem os espaços, não é vazia.
texto.length
Quantos caracteres o texto tem, contando espaços e quebras de linha.

As 120 palavras batem com o wc ("word count", o contador do Linux), que mostra linhas, palavras e bytes. Os bytes (706) são mais que os caracteres (678) porque cada letra acentuada, como o ç e o á, ocupa 2 bytes no arquivo em UTF-8. As 31 linhas do wc contam as linhas em branco; o programa contou só as 26 com texto.

Versão 2 · Limpar: minúsculas e sem pontuação

As palavras ainda vêm com a pontuação grudada ('palmeiras,', 'Sabiá;') e com maiúsculas ('Minha' no começo do verso, 'minha' no meio). Para contar, "Sabiá;", "Sabiá." e "sabiá" têm de ser a mesma palavra. Cada palavra passa por uma função limpar:

import fs from "node:fs";

// Minúsculas e só letras: "Sabiá;" vira "sabiá", "—" vira ""
function limpar(palavra) {
  return palavra.toLowerCase().replace(/[^\p{L}]/gu, "");
}

const texto = fs.readFileSync("cancao.txt", "utf8");
const palavras = texto
  .trim()
  .split(/\s+/)
  .map(limpar)
  .filter((palavra) => palavra !== "");

console.log(`Palavras: ${palavras.length}`);
console.log(palavras.slice(0, 12));
palavra.toLowerCase()
Tudo em minúsculas, inclusive as acentuadas: "SABIÁ" vira "sabiá" (veja Métodos de String).
.replace(/[^\p{L}]/gu, "")
Troca por nada (apaga) todo caractere que não é letra. Os colchetes […] são "um destes"; o ^ logo depois do [ inverte: "qualquer um, menos estes". O \p{L} é "uma letra de qualquer alfabeto", acentos incluídos. O g troca todas as ocorrências, não só a primeira; o u liga o modo Unicode, sem o qual o \p{…} não funciona.
texto.trim().split(/\s+/).map(limpar).filter(…)
Um encadeamento: cada método recebe o resultado do anterior. Corta, limpa cada palavra, e o filter tira as que ficaram vazias (o travessão — do poema, sozinho entre espaços, vira ""). Uma etapa por linha deixa a leitura fácil.

A regex que come os acentos: [^a-z] e \w

Na internet, a receita mais comum para "só letras" é /[^a-z]/g. Com ela no limpar:

Versão 3 · Contar num Map e ordenar

Agora, contar. A ideia é a de uma folha de papel com uma coluna de palavras e uma de tracinhos: para cada palavra do texto, se ela já está na folha, mais um tracinho; se não está, escreve a palavra com um tracinho. Em JavaScript, essa folha é um Map: um dicionário que liga cada chave (a palavra) a um valor (quantas vezes).

import fs from "node:fs";

function limpar(palavra) {
  return palavra.toLowerCase().replace(/[^\p{L}]/gu, "");
}

const texto = fs.readFileSync("cancao.txt", "utf8");
const palavras = texto
  .trim()
  .split(/\s+/)
  .map(limpar)
  .filter((palavra) => palavra !== "");

// Conta quantas vezes cada palavra aparece
const contagem = new Map();
for (const palavra of palavras) {
  contagem.set(palavra, (contagem.get(palavra) ?? 0) + 1);
}

// Da mais frequente para a menos; empate: ordem alfabética
const ranking = [...contagem].toSorted(
  (a, b) => b[1] - a[1] || a[0].localeCompare(b[0], "pt-BR"),
);

console.log(`Palavras: ${palavras.length}, diferentes: ${contagem.size}`);
for (const [palavra, vezes] of ranking.slice(0, 10)) {
  console.log(`${palavra}: ${vezes}`);
}
PeçaO que faz
new Map()Um Map vazio.
contagem.get(palavra) ?? 0O get devolve a contagem atual, ou undefined se a palavra ainda não está no Map. O ?? troca o undefined por 0: "quantas vezes já vi, ou zero".
contagem.set(palavra, … + 1)Guarda o valor novo (cria a chave, se não existia).
contagem.sizeQuantas chaves o Map tem: as palavras diferentes.
[...contagem]O spread transforma o Map num array de pares [palavra, vezes]: [ [ 'minha', 4 ], [ 'terra', 4 ], … ]. Arrays sabem ordenar; Maps, não.
b[1] - a[1]Compara as contagens (a posição 1 do par): a maior vem primeiro.
|| a[0].localeCompare(b[0], "pt-BR")Se as contagens empatam, b[1] - a[1] dá 0, que é falso, e o || passa para a comparação das palavras em ordem alfabética do português.
ranking.slice(0, 10)Só as 10 primeiras.
for (const [palavra, vezes] of …)Desestrutura cada par em duas variáveis com nome.

Versão 4 · Palavras comuns, barras e colunas

O ranking da versão 3 diz que o poema fala de "que", "eu" e "o". É verdade, mas não ajuda: essas palavras pequenas aparecem em qualquer texto. Quem estuda textos chama isso de palavras vazias (stop words) e as tira da conta. A versão 4 faz isso com um Set, desenha uma barra para cada contagem e deixa a Ana escolher o arquivo e quantas palavras ver:

// Contador de Palavras da Ana, versão 4: palavras comuns, barras e colunas
import fs from "node:fs";

// Palavras pequenas que aparecem em qualquer texto e não dizem nada sobre ele
const COMUNS = new Set([
  "a", "à", "as", "o", "os", "e", "é", "de", "do", "da", "dos", "das",
  "em", "no", "na", "um", "uma", "que", "eu", "por", "para", "não", "sem",
]);

function limpar(palavra) {
  return palavra.toLowerCase().replace(/[^\p{L}]/gu, "");
}

function contar(palavras) {
  const contagem = new Map();
  for (const palavra of palavras) {
    contagem.set(palavra, (contagem.get(palavra) ?? 0) + 1);
  }
  return contagem;
}

const arquivo = process.argv[2] ?? "cancao.txt";
const quantas = Number(process.argv[3] ?? 10);
if (!Number.isInteger(quantas) || quantas < 1) {
  console.error(`Quantidade inválida: ${process.argv[3]}. Use um número inteiro, como 5.`);
  process.exit(1);
}

const texto = fs.readFileSync(arquivo, "utf8");
const palavras = texto
  .trim()
  .split(/\s+/)
  .map(limpar)
  .filter((palavra) => palavra !== "" && !COMUNS.has(palavra));

const ranking = [...contar(palavras)].toSorted(
  (a, b) => b[1] - a[1] || a[0].localeCompare(b[0], "pt-BR"),
);

console.log(`As ${quantas} palavras mais usadas em ${arquivo}:`);
for (const [palavra, vezes] of ranking.slice(0, quantas)) {
  console.log(`${palavra.padEnd(10)} ${String(vezes).padStart(2)} ${"█".repeat(vezes)}`);
}

Sem a conferência do número: As NaN palavras

Antes do if que confere a quantidade, a Ana escreveu o número por extenso:

$ node palavras.js cancao.txt três
As NaN palavras mais usadas em cancao.txt:

Number("três") é NaN, e ranking.slice(0, NaN) trata o NaN como 0 e devolve um array vazio: o programa mostra o título e mais nada. Com o if (!Number.isInteger(quantas) || quantas < 1), a Ana recebe uma frase dizendo o que fazer, e o programa termina com o código 1 ("deu errado").

Missão (versão 4): o conjunto COMUNS já existe, mas ninguém o usa, e o ranking continua cheio de "que" e "eu". No filter, tire também as palavras que estão em COMUNS (com COMUNS.has), para "sabiá" e "terra" entrarem no ranking.

// Contador de Palavras da Ana, versão 4: palavras comuns, barras e colunas
import fs from "node:fs";

// Palavras pequenas que aparecem em qualquer texto e não dizem nada sobre ele
const COMUNS = new Set([
  "a", "à", "as", "o", "os", "e", "é", "de", "do", "da", "dos", "das",
  "em", "no", "na", "um", "uma", "que", "eu", "por", "para", "não", "sem",
]);

function limpar(palavra) {
  return palavra.toLowerCase().replace(/[^\p{L}]/gu, "");
}

function contar(palavras) {
  const contagem = new Map();
  for (const palavra of palavras) {
    contagem.set(palavra, (contagem.get(palavra) ?? 0) + 1);
  }
  return contagem;
}

const arquivo = process.argv[2] ?? "cancao.txt";
const quantas = Number(process.argv[3] ?? 10);
if (!Number.isInteger(quantas) || quantas < 1) {
  console.error(`Quantidade inválida: ${process.argv[3]}. Use um número inteiro, como 5.`);
  process.exit(1);
}

const texto = fs.readFileSync(arquivo, "utf8");
const palavras = texto
  .trim()
  .split(/\s+/)
  .map(limpar)
  .filter((palavra) => palavra !== "");

const ranking = [...contar(palavras)].toSorted(
  (a, b) => b[1] - a[1] || a[0].localeCompare(b[0], "pt-BR"),
);

console.log(`As ${quantas} palavras mais usadas em ${arquivo}:`);
for (const [palavra, vezes] of ranking.slice(0, quantas)) {
  console.log(`${palavra.padEnd(10)} ${String(vezes).padStart(2)} ${"█".repeat(vezes)}`);
}

Formas diferentes de separar e de contar

Separar: cortar nos brancos × pegar as letras

A versão 2 corta nos brancos e depois apaga o que não é letra. Dá para fazer as duas coisas de uma vez, pedindo direto as sequências de letras com match: texto.toLowerCase().match(/\p{L}+/gu). O resultado quase sempre é o mesmo; a diferença aparece em palavras com apóstrofo ou hífen. No poema, "qu'inda" vira "quinda" com o replace (o apóstrofo é apagado e as partes se juntam) e "qu" + "inda" com o match (o apóstrofo separa). Para "guarda-chuva", o mesmo: uma palavra ou duas. Escolha conforme o que você quer contar.

Contar: Map × objeto

FormaComo ficaQuando usar
Map (este projeto)contagem.set(p, (contagem.get(p) ?? 0) + 1)Contagens e dicionários em geral: qualquer texto pode ser chave, tem size e vira array com [...contagem].
Objeto comumcontagem[p] = (contagem[p] ?? 0) + 1Funciona, e você vai ver muito em código antigo. Cuidado com chaves que já existem em todo objeto, como "constructor": num texto que contenha essa palavra, a conta sai errada. Para virar array: Object.entries(contagem).

Ordenar os empates

Sem o critério de desempate (|| a[0].localeCompare(…)), as palavras com a mesma contagem ficariam na ordem em que apareceram no texto (o toSorted mantém a ordem dos empates). Não é errado, mas a ordem alfabética deixa o resultado igual toda vez, fácil de conferir.

Resumo

  • Para cortar um texto em palavras, use texto.trim().split(/\s+/): pega espaços, quebras de linha e brancos repetidos.
  • Para limpar, toLowerCase() e replace(/[^\p{L}]/gu, ""). Em português, nunca [a-z] nem \w: eles apagam as letras acentuadas.
  • map e filter encadeados deixam cada etapa numa linha.
  • Um Map conta: contagem.set(p, (contagem.get(p) ?? 0) + 1). Sem o ?? 0, tudo vira NaN.
  • [...map].toSorted(…) ordena; localeCompare(…, "pt-BR") põe as palavras acentuadas no lugar certo.
  • Um Set com has é o jeito de perguntar "esta palavra está na lista?".
