JavaScript Operadores

Esta é a página de consulta rápida de todos os operadores do JavaScript: os símbolos e palavras que fazem contas (+, *), guardam valores (=, +=), comparam (===, <), combinam condições (&&, ||), escolhem um valor padrão (??), leem com cuidado (?.) e perguntam coisas sobre um valor (typeof, in). No fim está a tabela de precedência: a ordem em que o JavaScript faz as operações quando há várias na mesma linha.

Como ler as tabelas
  • Exemplo é o que você digitaria depois do > do modo interativo do Node.
  • Resultado é o que o Node.js v24.22.0 respondeu no computador da Ana. Textos aparecem entre aspas simples ('105'): é o jeito do modo interativo mostrar que o resultado é uma string, e não um número.
  • Quando o resultado é um erro, a tabela mostra a mensagem como o Node escreveu (em inglês); a explicação em português está em Mensagens de Erro Comuns.
  • A coluna Aula leva à aula que explica o operador com calma.

O 7 / 2 deu 3.5: no JavaScript, a divisão nunca corta as casas decimais. O "10" + 5 deu o texto '105', e não 15: com uma string, o + junta em vez de somar. O 2 + 3 * 4 deu 14, porque a multiplicação vem antes da soma. E o === não considera o número 1 igual ao texto "1".

Para montar frases, prefira a template string

Em vez de "Total: " + total + " reais", escreva `Total: ${total} reais`, com crase. Fica mais fácil de ler e não tem pegadinha de soma × junção. Veja Template Strings.

Lógicos e valor padrão

Missão: a lojinha da Ana tem 0 cadernos no estoque, mas o programa diz "sem informação", porque o || trata o 0 como falso. Troque os dois || por ??: o estoque deve aparecer como Estoque: 0 e o desconto (que é null) continua Desconto: sem informação.

const estoque = 0;
const desconto = null;

console.log(`Estoque: ${estoque || "sem informação"}`);
console.log(`Desconto: ${desconto || "sem informação"}`);

const estoque = 0;
const desconto = null;

console.log(`Estoque: ${estoque ?? "sem informação"}`);
console.log(`Desconto: ${desconto ?? "sem informação"}`);

A tabela de precedência

Na dúvida, use parênteses

Ninguém decora a tabela inteira. Os parênteses deixam a intenção clara para quem lê e para o JavaScript: (a + b) / 2, !(x === y), (n & 1) === 0. A explicação com mais exemplos está em Precedência dos Operadores.

Missão: a Ana tirou 7, 8 e 9, mas o programa diz que a média é 18. O problema é a precedência: a divisão acontece antes da soma, então só o n3 está sendo dividido por 3. Use parênteses para que a soma aconteça primeiro. O resultado certo é Média: 8.

const n1 = 7;
const n2 = 8;
const n3 = 9;

const media = n1 + n2 + n3 / 3;
console.log(`Média: ${media}`);

const n1 = 7;
const n2 = 8;
const n3 = 9;

const media = (n1 + n2 + n3) / 3;
console.log(`Média: ${media}`);

No lab: o programa original mostrou Média: 18; com os parênteses, Média: 8.

Resumo

  • Aritméticos: + - * / % **. A divisão dá casas decimais (7 / 2 → 3.5); dividir por zero dá Infinity ou NaN, não erro.
  • Com uma string, o + junta ("10" + 5 → '105'); os outros convertem em número. Para frases, use template strings.
  • x++ devolve o valor de antes; ++x, o novo. +=, -=… encurtam x = x + …; ??= e ||= dão valor padrão.
  • Compare com === e !==, nunca com ==. Não existe "entre": use x >= 1 && x <= 3.
  • && e || devolvem um dos lados. ?? só troca null/undefined (mantém 0 e ""); ?. lê sem quebrar quando algo falta.
  • typeof dá o tipo em texto (typeof null é 'object'!); in, delete e instanceof perguntam e mexem em objetos; ... espalha.
  • Precedência, resumida: parênteses; . ?. (); ! typeof -x; **; * / %; + -; comparações; igualdades; bits; &&; || ??; ternário e atribuições; vírgula. Na dúvida, parênteses.
