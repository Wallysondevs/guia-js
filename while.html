JavaScript while

Até agora, cada linha dos seus programas rodou uma vez só (ou nenhuma, com o if). Mas boa parte do trabalho de um computador é repetir: mostrar os 30 alunos da turma, somar os preços de todas as compras, conferir mês a mês quanto falta para a meta. Para repetir existem os laços (em inglês, loops). O mais simples deles é o while, que em inglês quer dizer "enquanto": enquanto a condição for verdadeira, repita.

Você vai aprender
  • O que é um laço e como se escreve um while: a condição entre parênteses e o bloco entre chaves.
  • Como contar de 1 até 5, e de 5 até 1, com uma variável contadora.
  • Como repetir quando você não sabe quantas voltas vão ser: juntar dinheiro até chegar à meta.
  • Como acumular um total volta a volta.
  • O que é um laço infinito e como pará-lo: Ctrl+C no terminal e o botão Parar no editor.
  • while (true) com break, e o while no modo interativo do Node.
  • Os erros reais: const no contador, a variável que não existe e o ponto e vírgula depois do while.

Todos os programas desta aula rodaram no Node.js 24 da máquina da Ana (usuária ana, computador notebook), salvos na pasta pessoal dela e executados com node arquivo.js (veja Rodando um Programa). Você pode rodar cada um no editor do guia.

A ideia: "enquanto tiver pão no cesto, atenda o próximo"

A padaria do bairro abre às 6 horas com um cesto de pães. O dono deixa um bilhete para o funcionário: "Enquanto tiver pão no cesto, atenda o próximo cliente." O bilhete não diz quantos clientes vão ser atendidos. Mesmo assim, ele funciona:

  1. O funcionário olha o cesto: tem pão? Sim → atende um cliente.
  2. Olha de novo: tem pão? Sim → atende mais um.
  3. … e assim por diante …
  4. Olha de novo: tem pão? Não → para de atender e vai fazer outra coisa.

Três detalhes desse bilhete valem para todo while:

  • A pergunta vem antes de cada atendimento. Se o cesto já começar vazio, ninguém é atendido.
  • Cada volta muda alguma coisa (sai pão do cesto). Sem isso, a resposta seria sempre a mesma, e o funcionário atenderia para sempre.
  • Quando a resposta vira não, ele sai da repetição e continua o resto do dia.

Em JavaScript, a "pergunta" é uma condição, igual à do if. A diferença: o if roda o bloco uma vez se a condição for verdadeira; o while roda o bloco de novo e de novo, enquanto ela continuar verdadeira.

1. O primeiro while: contar de 1 a 5

let contador = 1;

while (contador <= 5) {
  console.log(`Volta ${contador}`);
  contador++;
}

console.log(`Fim! contador agora vale ${contador}`);

Cada execução do corpo se chama uma volta (os programadores também dizem iteração). Aqui foram 5 voltas.

Passo a passo: o que o Node fez

Siga a variável contador volta por volta. Fazer de conta que você é o computador é a melhor forma de entender laços:

MomentoValor de contadorcontador <= 5?O que acontece
1º teste1trueEntra: mostra Volta 1, o contador vira 2
2º teste2trueMostra Volta 2, o contador vira 3
3º teste3trueMostra Volta 3, o contador vira 4
4º teste4trueMostra Volta 4, o contador vira 5
5º teste5trueMostra Volta 5, o contador vira 6
6º teste6falseSai do laço e vai para a primeira linha depois da }

Por isso a última linha mostra contador agora vale 6: o laço só termina quando a condição fica falsa, e ela só fica falsa quando o contador passa de 5. A condição foi testada 6 vezes para o corpo rodar 5 vezes.

As três peças de todo laço com contador

1) o início: let contador = 1; · 2) a condição: contador <= 5 · 3) o passo: contador++;. Se faltar qualquer uma, o laço dá errado (a seção Quando dá errado mostra cada caso). Na aula for, você vai ver um laço que junta as três numa linha só.

2. Contar para trás

O passo não precisa ser "mais 1". Para uma contagem regressiva, comece do maior número, diminua e troque a condição para "maior que zero":

let segundos = 5;

while (segundos > 0) {
  console.log(`${segundos}...`);
  segundos--;
}

console.log("Já!");

$ node regressiva.js
5...
4...
3...
2...
1...
Já!

Quando segundos chega a 0, a pergunta 0 > 0 dá false e o laço termina. O Já! está depois da }, então aparece uma vez só, no fim.

O passo também pode ser de 2 em 2 (contador += 2), de 10 em 10, ou até uma multiplicação (valor *= 2; veja Atribuição), como na missão final.

3. Quando você não sabe quantas voltas vão ser

Nos dois exemplos acima, dava para saber de antemão: 5 voltas. O while brilha mesmo quando ninguém sabe quantas voltas serão. A Ana quer juntar R$ 1000 para comprar um notebook novo. Ela consegue guardar R$ 150 por mês. Quantos meses vai levar?

let saldo = 0;
let meses = 0;

while (saldo < 1000) {
  saldo += 150;
  meses++;
  console.log(`Mês ${meses}: R$ ${saldo}`);
}

console.log(`A Ana juntou R$ ${saldo} em ${meses} meses.`);

$ node poupanca.js
Mês 1: R$ 150
Mês 2: R$ 300
Mês 3: R$ 450
Mês 4: R$ 600
Mês 5: R$ 750
Mês 6: R$ 900
Mês 7: R$ 1050
A Ana juntou R$ 1050 em 7 meses.

Repare nos papéis das duas variáveis:

  • saldo é um acumulador: começa em 0 e, a cada volta, recebe mais um pouco. É ele que a condição olha.
  • meses é um contador: conta as voltas, para no fim a gente saber quantas foram.

No mês 6 o saldo era 900, ainda menor que 1000: mais uma volta. No mês 7 ele passou para 1050, a condição 1050 < 1000 deu false, e o laço parou. O programa descobriu sozinho que eram 7 meses.

Zero voltas também é possível

Como a pergunta vem antes da primeira volta, o corpo pode não rodar nenhuma vez. Se a Ana já tivesse R$ 1200:

let saldo = 1200;
let meses = 0;

while (saldo < 1000) {
  saldo += 150;
  meses++;
}

console.log(`Meses de espera: ${meses}`);

$ node nunca.js
Meses de espera: 0

Logo no primeiro teste, 1200 < 1000 deu false: o Node pulou o bloco inteiro. Isso não é erro; é o cesto que já começou vazio. Se você precisa que o bloco rode pelo menos uma vez, existe outro laço, que testa no fim: do … while.

4. Acumular: somar de 1 até 100

Conta a história que um professor mandou a turma somar todos os números de 1 a 100, para ter sossego por um bom tempo. Para o computador, é um laço de 100 voltas com um acumulador:

let numero = 1;
let soma = 0;

while (numero <= 100) {
  soma += numero;
  numero++;
}

console.log(`A soma de 1 até 100 é ${soma}`);

$ node soma.js
A soma de 1 até 100 é 5050

A cada volta, soma += numero junta o número da vez no total: 0 + 1 = 1, depois 1 + 2 = 3, depois 3 + 3 = 6, … até 5050. O acumulador começa em 0, o "nada" da soma. (Para uma multiplicação acumulada, o começo seria 1.)

5. O laço infinito, e como pará-lo

Um laço cuja condição nunca fica falsa não termina nunca: é um laço infinito. O jeito mais comum de criar um sem querer é esquecer a linha que faz o laço andar. Olhe o contador da seção 1 sem o contador++:

let contador = 1;

while (contador <= 5) {
  console.log(`Volta ${contador}`);
}

console.log("Fim!");

O contador fica em 1 para sempre, então 1 <= 5 é sempre true, e o programa mostra Volta 1 sem parar. A Ana deixou ele rodar 1 segundo só (com o comando timeout 1) e contou as linhas com o wc -l:

$ timeout 1 node infinito.js | head -3
Volta 1
Volta 1
Volta 1
$ timeout 1 node infinito.js | wc -l
493714

Quase meio milhão de linhas em um segundo (o número muda de um computador para outro, e de uma vez para outra). O Fim! nunca chega.

No terminal: Ctrl+C

Para interromper um programa que não termina, segure Ctrl e aperte C. Um laço infinito também pode ser silencioso; aqui a Ana esqueceu de somar o dinheiro no saldo, e o programa ficou parado, "pensando":

let saldo = 0;
let meses = 0;

while (saldo < 1000) {
  meses++;
}

console.log(`A Ana juntou R$ ${saldo} em ${meses} meses.`);

$ node esqueceu.js
^C
$ echo $?
130
^C
O terminal mostrando que você apertou Ctrl+C. O Node para na hora, sem mensagem de erro.
echo $? → 130
O código de saída do programa (o $? do terminal). 0 quer dizer "terminou bem"; 130 é o código de "interrompido pelo Ctrl+C" (veja process.env e process.exit).

No editor do guia

A caixa "Experimente" roda o JavaScript de verdade dentro do navegador, então um laço infinito lá também não termina sozinho. Enquanto o programa roda, o botão de rodar vira ■ Parar: ele é o Ctrl+C do editor. Os detalhes estão em O Editor do Guia.

Experimente: este é o programa da Ana que esqueceu de somar no saldo. Clique em Rodar e depois em ■ Parar. Depois, conserte: acrescente saldo += 150; dentro do laço e rode de novo.

let saldo = 0;
let meses = 0;

  meses++;
}

console.log(`A Ana juntou R$ ${saldo} em ${meses} meses.`);

Quando o infinito é de propósito: while (true)

Às vezes o laço "infinito" é proposital, e a saída fica no meio do bloco, com o break (em inglês, "quebrar"), que você já viu no switch. O dinheiro da Ana, agora com a saída no meio:

let saldo = 0;
let meses = 0;

while (true) {
  saldo += 150;
  meses++;
  if (saldo >= 1000) {
    break;
  }
}

console.log(`${meses} meses, R$ ${saldo}`);

$ node whiletrue.js
7 meses, R$ 1050

A condição true nunca fica falsa; quem encerra o laço é o break, quando o saldo chega à meta. Ele tem aula própria: break e continue.

6. while no modo interativo

Dá para escrever um laço direto no > do Node (veja O Modo Interativo do Node). Depois da linha com o {, aparece a barrinha |: o Node está esperando o resto do laço. Ele só roda quando recebe a }:

$ node
Welcome to Node.js v24.22.0.
Type ".help" for more information.
> let n = 3;
undefined
> while (n > 0) {
| console.log(n);
| n--;
| }
3
2
1
1
> n
0
> .exit

A variável continua lá depois do laço: n terminou valendo 0, o valor que fez a condição n > 0 ficar falsa. E o 1 repetido, logo depois do 3, 2, 1? Os três primeiros vieram do console.log. O último é o "valor" da última coisa que o laço calculou: o n-- da última volta, que vale o número antes de diminuir (1). No modo interativo o Node mostra esse valor; num arquivo, ele não aparece.

Formas diferentes de fazer a mesma coisa

Contar de 1 a 5 pode ser escrito com três laços:

let a = 1;
while (a <= 5) {
  a++;
}

let b = 1;

  b++;
} while (b <= 5);

for (let c = 1; c <= 5; c++) {
  // o for junta início, condição e passo numa linha
}

console.log(a, b);

O passo ficou fora do laço: laço infinito

Este é mais traiçoeiro, porque o Node não reclama de nada:

let contador = 1;

while (contador <= 5) {
  console.log(`Volta ${contador}`);
}
contador++;

O contador++ está depois da }, então está fora do laço: só rodaria depois que o laço terminasse, e o laço nunca termina. O resultado é o mesmo da seção 5: Volta 1 sem parar, até o Ctrl+C. Como consertar: ponha o passo antes da }.

Ponto e vírgula depois do while 
let contador = 1;

while (contador <= 5); {
  console.log(`Volta ${contador}`);
  contador++;
}

$ node pontoevirgula.js
^C

Nada aparece, nem a Volta 1, e o programa não termina: a Ana teve de apertar Ctrl+C. O ; logo depois do ) é um laço com corpo vazio: "enquanto o contador for até 5, não faça nada". Como nada muda o contador, ele repete esse "nada" para sempre, e o bloco de baixo nunca chega a rodar. É a mesma armadilha do if com ponto e vírgula (aula if), só que aqui ela trava o programa. Como consertar: nunca ponha ; entre o ) e o {.

A Ana escreveu ++ numa contagem regressiva: 5, 6, 7, 8… o valor só cresce, e segundos > 0 nunca fica falso. Mais um laço infinito sem mensagem nenhuma. Como consertar: confira se o passo leva o valor na direção de deixar a condição falsa: aqui, segundos--.

Missão final: o dinheiro que dobra

Missão: a Ana leu uma história: alguém começa com R$ 1 e, a cada dia, o dinheiro dobra. Em quantos dias passa de R$ 1000? Escreva o while no lugar do comentário: enquanto o valor for menor ou igual a 1000, dobre o valor (valor *= 2) e some 1 em dias.

  valor *= 2;
  dias++;
}

A resposta é 10 dias, com R$ 1024. No lab, saiu Passou de R$ 1000 em 10 dias: R$ 1024. Experimente trocar o 1000 da condição por um milhão (1000000): bastam mais 10 dias (no lab, deu 20 dias: R$ 1048576). É a força de dobrar.

Resumo

  • while (condição) { … } ("enquanto") repete o bloco enquanto a condição for verdadeira. A condição é testada antes de cada volta; se for falsa logo de cara, o bloco não roda nenhuma vez.
  • Laço com contador tem três peças: início (antes do laço, com let), condição e passo (dentro do bloco, andando na direção certa).
  • O while é a escolha quando não se sabe quantas voltas vão ser. Acumuladores começam em 0 e recebem += a cada volta.
  • Sem o passo, o laço é infinito. No terminal, Ctrl+C para o programa; no editor, o botão ■ Parar.
  • while (true) é um laço infinito de propósito; ele precisa de um break para sair.
  • Nunca ponha ; depois do while (…): o laço fica com corpo vazio e trava.
