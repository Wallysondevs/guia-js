JavaScript prompt() e alert()

Na aula anterior, o programa perguntava no terminal, com o readline do Node. Numa página web, o jeito mais simples de conversar com a pessoa são três caixinhas prontas do navegador: alert() ("alerta") mostra um aviso, prompt() ("pedido") pergunta um texto, e confirm() ("confirmar") pede um OK ou Cancelar. Uma linha de código, e a caixinha aparece na frente da página.

Você vai aprender
  • Como mostrar um aviso com alert().
  • Como perguntar com prompt(), guardar a resposta e usar na página.
  • Que a resposta do prompt() é sempre texto, e o que vem quando a pessoa clica em Cancelar (null).
  • Como pedir uma confirmação com confirm() (true ou false).
  • Por que essas caixinhas não existem no Node, e por que os sites de verdade quase não as usam.
  • Os erros reais mais comuns.

Os exemplos desta aula são páginas com um index.html e um script.js (veja JavaScript na Página). As mensagens do Console foram colhidas no Chromium 155 da máquina da Ana, abrindo o index.html com dois cliques e respondendo às caixinhas. Nas caixas "Experimente", clique em Rodar: as caixinhas aparecem de verdade, no seu navegador, e quem responde é você.

A ideia: o bilhete, a pergunta e o "pode ser?"

Imagine o balcão da padaria:

  • O cartaz "Hoje tem pão de queijo!" é um alert: só avisa. Você lê e diz "ok".
  • "Qual é o seu nome?", para escrever no copo, é um prompt: espera uma resposta escrita.
  • "Vai querer sacola?" é um confirm: a resposta é só sim ou não.

Nos três casos, o atendimento para até você responder. Com as caixinhas é igual: enquanto uma delas está aberta, a página fica travada, e o programa espera.

const nome = prompt("Qual é o seu nome?");
console.log(nome);
document.querySelector("#saida").textContent = `Olá, ${nome}!`;

Aparece uma caixinha com a pergunta, um campo para digitar e os botões OK e Cancelar. A Ana digitou Ana e clicou em OK. O Console mostrou:

Ana

E o parágrafo #saida da página passou a mostrar Olá, Ana!.

prompt("Qual é o seu nome?")
Mostra a pergunta com um campo de texto e espera. Quando a pessoa clica em OK, a chamada "vira" o que ela digitou (veja return: o prompt devolve a resposta).
const nome = …
Guarda a resposta. Repare que aqui não tem await nem import: o prompt já vem pronto em toda página, e ele trava a página enquanto espera.

Escreve o texto no parágrafo de id="saida" da página. Essa linha é assunto de Mudando Textos e Atributos; por enquanto, use-a como "escreva isto na página".

A resposta é sempre texto

Igual ao readline do Node: o prompt devolve uma string, mesmo que a pessoa digite algarismos.

const idade = prompt("Quantos anos você tem?");
console.log(typeof idade);
console.log(`Daqui a 10 anos: ${idade + 10}`);

A Ana respondeu 30:

Daqui a 10 anos: 3010

"30" + 10 junta os textos (veja Conversão Automática). Convertendo com Number() (veja Conversão):

const idade = Number(prompt("Quantos anos você tem?"));
console.log(typeof idade);
console.log(`Daqui a 10 anos: ${idade + 10}`);

Cancelar, OK vazio e o texto padrão

A pessoa nem sempre responde do jeito esperado. Este programa trata os três casos:

const nome = prompt("Qual é o seu nome?");
if (nome === null) {
  console.log("A pessoa cancelou.");
} else if (nome === "") {
  console.log("A pessoa clicou em OK sem digitar nada.");
} else {
  console.log(`Olá, ${nome.toUpperCase()}!`);
}

A Ana abriu a página três vezes: na primeira clicou em Cancelar; na segunda, em OK com o campo vazio; na terceira digitou Bia. O Console de cada vez:

A pessoa cancelou.

A pessoa clicou em OK sem digitar nada.

Olá, BIA!

O prompt aceita um segundo argumento: o texto que já aparece escrito no campo. Com prompt("Sua cidade?", "Recife"), o campo abre com Recife; se a pessoa só clicar em OK, a resposta é "Recife".

3. confirm(): sim ou não

const querSacola = confirm("Quer uma sacola? (R$ 0,25)");
console.log(querSacola);
if (querSacola) {
  document.querySelector("#saida").textContent = "Sacola incluída.";
} else {
  document.querySelector("#saida").textContent = "Sem sacola.";
}

A caixinha mostra a pergunta e os botões OK e Cancelar, sem campo de texto. Clicando em OK, o Console mostrou true e a página, Sacola incluída.; clicando em Cancelar:

false

e a página mostrou Sem sacola.. O confirm devolve um booleano: true para OK, false para Cancelar. Por isso ele vai direto no if.

No Console, digitando

As três funções também funcionam digitadas no Console do F12. A Ana digitou cada linha, respondeu Bia ao prompt e clicou em OK nas outras caixinhas:

> typeof prompt
'function'
> prompt("Qual é o seu nome?")
'Bia'
> confirm("Tem certeza?")
true
> alert("Oi")
undefined
> window.alert === alert
true

Repare: o prompt devolveu o texto 'Bia', o confirm devolveu true, e o alert não devolve nada (undefined). A última linha mostra de onde elas vêm: são funções do objeto window, a "janela" do navegador. Escrever alert(…) é o mesmo que window.alert(…).

4. Só no navegador, e com moderação

No Node, elas não existem

O window é do navegador. No Node não há janela, e nem prompt, nem alert, nem confirm:

const nome = prompt("Qual é o seu nome?");
console.log(nome);

"prompt não está definido". No terminal, use o readline; o mesmo vale para o alert (que vira console.log). Veja a lista do que é de cada lado em Onde o JavaScript Roda.

Por que os sites quase não usam

As caixinhas são ótimas para aprender e para testes rápidos, mas os sites de verdade quase nunca as usam:

  • Travam a página: enquanto a caixinha está aberta, nada mais funciona.
  • Não dá para mudar a aparência: cor, fonte e botões são do navegador.
  • Irritam: muitos navegadores oferecem a opção de impedir que o site abra mais caixinhas.

Nos sites, perguntas se fazem com campos na própria página (Formulários), e avisos se mostram escrevendo na página (Mudando Textos).

Quando dá errado

A pessoa cancelou, e o programa usou a resposta 
const nome = prompt("Qual é o seu nome?");
console.log(nome);
console.log(nome.toUpperCase());

A Ana clicou em Cancelar:

null
Uncaught TypeError: Cannot read properties of null (reading 'toUpperCase')
    at script.js:3:18

Linha por linha: o null é o console.log(nome), a resposta do Cancelar; Uncaught TypeError é um erro de tipo que ninguém tratou ("uncaught" = "não capturado"); Cannot read properties of null (reading 'toUpperCase') diz que não dá para pegar o toUpperCase de null; e at script.js:3:18 é o arquivo, a linha 3 e a coluna 18. No Console de verdade, o erro aparece em vermelho, e o script.js:3 é um link que leva à linha. Como consertar: teste o null antes de usar a resposta, como na seção 2: if (nome === null) { … }.

Nome da função errado 
const nome = promt("Qual é o seu nome?");
console.log(nome);

Uncaught ReferenceError: promt is not defined
    at script.js:1:14

"promt não está definido": faltou o p antes do t. Nenhuma caixinha apareceu, e o resto do programa não rodou. Como consertar: prompt. Se uma página "não faz nada", abra o Console: o erro estará lá.

Usou prompt no Node

É o ReferenceError: prompt is not defined da seção 4. Como consertar: no terminal, use o readline; o prompt é só para páginas.

A conta deu errado: 3010 ou NaN

3010 é a resposta usada como texto: converta com Number(). NaN aparece quando a pessoa digitou letras, ou vírgula no lugar do ponto (Number("0,5") dá NaN). Confira com Number.isNaN(valor) antes da conta.

Missão final: o pedido da padaria

Missão: complete o script.js: pergunte com prompt quantos pães a pessoa quer (cada um custa R$ 0,50; converta a resposta), pergunte com confirm se ela quer sacola (mais R$ 0,25) e mostre na página Total: R$ com o valor e 2 casas (total.toFixed(2)). Teste com 10 pães e OK na sacola: Total: R$ 5.25.

<h1>Padaria do Bairro</h1>
<p id="saida"></p>
<script src="script.js"></script>

// 1. pergunte quantos pães (prompt) e converta com Number

// 2. pergunte se quer sacola (confirm)

// 3. calcule o total e mostre na página:
// document.querySelector("#saida").textContent = `Total: R$ ${total.toFixed(2)}`;

const quantidade = Number(prompt("Quantos pães?"));
const querSacola = confirm("Quer uma sacola? (R$ 0,25)");
let total = quantidade * 0.5;
if (querSacola) {
  total = total + 0.25;
}
document.querySelector("#saida").textContent = `Total: R$ ${total.toFixed(2)}`;

No Chromium do lab, a solução mostrou Total: R$ 5.25 com OK na sacola e Total: R$ 5.00 com Cancelar.

Resumo

  • alert("…") mostra um aviso; prompt("…") pergunta um texto; confirm("…") pede OK ou Cancelar. As três travam a página até a resposta.
  • O prompt devolve texto (Number() para contas), "" se a pessoa não digitar nada e null se ela cancelar: teste o null antes de usar.
  • O confirm devolve true ou false, prontos para o if.
  • São funções do window: só existem no navegador. No Node, use o readline.
  • Servem para aprender e testar; nos sites, use formulários e escreva na página.
