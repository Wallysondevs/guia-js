Projeto Lista de Compras na Página

Os projetos anteriores rodavam no terminal. Este roda no navegador: uma página com um campo, um botão e a lista da feira, que a Ana pode abrir no celular no mercado. Ela digita o item, a quantidade e o preço; a página soma quanto falta gastar, risca o que já foi para o carrinho e, quando ela fecha e abre de novo, a lista continua lá.

Você vai praticar
  • Pegar elementos da página com querySelector.
  • Reagir ao envio de um formulário com submit e preventDefault.
  • Criar e remover elementos com createElement, append e replaceChildren.
  • Guardar os dados num array de objetos e redesenhar a lista a partir dele.
  • Mostrar dinheiro com toLocaleString e mudar o estilo com classList.
  • Guardar a lista no navegador com localStorage e JSON.

O que vamos construir

A página pronta tem um formulário (item, quantidade e preço), a lista e o total. Cada item tem uma caixinha para marcar quando já está no carrinho (ele fica riscado e sai do "Falta comprar") e um botão ✕ para remover. Testada no Chromium do computador da Ana, depois de adicionar 2 leites a R$ 4,99, 10 pães a R$ 0,75 e 1 café a R$ 18,90, e marcar o leite, a Ana conferiu no Console (F12):

> [...document.querySelectorAll("#lista li")].map((li) => li.className + " |" + li.textContent)
(3) ['comprado | 2 × Leite: R$ 9,98✕', ' | 10 × Pão francês: R$ 7,50✕', ' | 1 × Café: R$ 18,90✕']

E o parágrafo do total mostrava Falta comprar: R$ 26,40 (o pão e o café). Vamos chegar lá em quatro versões:

  1. O formulário e a lista (submit, preventDefault, createElement).
  2. Quantidade, preço e total (array de objetos, desenhar(), toLocaleString).
  3. Marcar como comprado e remover (caixinha, botão ✕, classList).
  4. Guardar no navegador (localStorage e JSON).

Antes de começar

Uma página com JavaScript tem três arquivos, numa pasta: o index.html (o conteúdo), o style.css (a aparência) e o script.js (o comportamento). Crie a pasta compras, salve os três e abra o index.html com dois cliques: ele abre no navegador. Depois de mudar um arquivo, salve e aperte F5 para recarregar (veja JavaScript na Página).

Nas caixas Experimente, os três arquivos são abas. Rodar abre a página no quadro Resultado, onde você digita e clica de verdade; embaixo fica o Console, com os erros. A missão de cada caixa diz o que digitar.

No fim do <body>: quando o script roda, o formulário e a lista já existem. (Veja o que acontece se ele estiver no <head>, logo abaixo.)
document.querySelector("#formulario")
Acha o elemento com id="formulario". O # quer dizer "id", como no CSS.
formulario.addEventListener("submit", (evento) => { … })
"Quando o formulário for enviado, rode esta função." O envio acontece com o clique no botão ou com o Enter no campo (veja Eventos).
evento.preventDefault();
"Impeça o comportamento padrão." O padrão de um formulário é mandar os dados e recarregar a página, o que apagaria a lista. Esta linha cancela isso.
campo.value.trim()
O que está digitado no campo, sem os espaços das pontas. Se ficou vazio, o return sai da função sem fazer nada.
document.createElement("li")
Fabrica um item de lista novo, ainda fora da página.
li.textContent = nome;
Põe o texto dentro do item, como texto (veja o perigo do innerHTML abaixo).
lista.append(li);
Coloca o item no fim da lista: agora ele aparece.
campo.value = ""; campo.focus();
Limpa o campo e devolve o cursor para ele, pronto para o próximo item.

Sem o preventDefault: o item aparece e some

O <script> no <head>: Cannot read properties of null

A Ana moveu a linha do <script src="script.js"> para o <head>, logo abaixo do <link>. Ao abrir a página, o Console mostrou:

Uncaught TypeError: Cannot read properties of null (reading 'addEventListener')
    at script.js:5:12
> document.querySelector("#formulario")
<form id="formulario">
    <input id="item" placeholder="O que comprar?">
    <button>Adicionar</button>

"Erro de tipo não capturado: não dá para ler propriedades de null (lendo 'addEventListener')", em script.js, linha 5, coluna 12. O navegador lê o HTML de cima para baixo e roda o script assim que o encontra. No <head>, o formulário ainda não tinha sido lido: o querySelector("#formulario") devolveu null, e null.addEventListener é impossível. Repare que, digitado no Console depois, o mesmo querySelector acha o formulário: quando a página terminou de carregar, ele já existia. Como consertar: o <script> no fim do <body> (ou <script src="script.js" defer> no <head>; veja JavaScript na Página).

Por que textContent, e não innerHTML

O innerHTML também põe texto num elemento, mas ele interpreta o texto como HTML. Com li.innerHTML = nome;, a Ana adicionou dois itens: <b>Pão</b> francês e <img src="x" onerror="alert(1)">. O primeiro apareceu com "Pão" em negrito; no segundo, a página mostrou um alerta com o número 1: o texto digitado virou uma imagem quebrada, e o código do onerror rodou. Pedindo o HTML da lista no Console:

> document.querySelector("#lista").outerHTML
'<ul id="lista"><li><b>Pão</b> francês</li><li><img src="x" onerror="alert(1)"></li></ul>'

Numa lista só sua, é uma curiosidade. Num site em que o texto de uma pessoa aparece para outras (comentários, chat), é uma porta para alguém rodar código no navegador dos outros. Para texto que veio de uma pessoa, use sempre textContent: ele mostra <b> como os caracteres <b>, sem interpretar.

Versão 2 · Quantidade, preço e total

Para somar o total, a página precisa lembrar de cada item: nome, quantidade e preço. Ler isso de volta dos <li> seria complicado (eles só têm texto). A ideia que organiza o projeto daqui em diante: os dados ficam num array de objetos, e uma função desenhar() apaga a lista da página e a monta de novo a partir do array, junto com o total. Mudou alguma coisa? Muda o array e chama desenhar().

<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <title>Lista de Compras</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <h1>Lista de Compras</h1>
  <form id="formulario">
    <input id="item" placeholder="O que comprar?">
    <input id="quantidade" type="number" min="1" value="1">
    <input id="preco" placeholder="Preço (R$)">
    <button>Adicionar</button>
  </form>
  <p id="aviso"></p>
  <ul id="lista"></ul>
  <p id="total">Total: R$ 0,00</p>
  <script src="script.js"></script>
</body>
</html>

const formulario = document.querySelector("#formulario");
const campoItem = document.querySelector("#item");
const campoQuantidade = document.querySelector("#quantidade");
const campoPreco = document.querySelector("#preco");
const aviso = document.querySelector("#aviso");
const lista = document.querySelector("#lista");
const total = document.querySelector("#total");

const itens = [];

// 12.5 vira "R$ 12,50"
function real(valor) {
  return valor.toLocaleString("pt-BR", { style: "currency", currency: "BRL" });
}

// Redesenha a lista e o total a partir do array itens
function desenhar() {
  lista.replaceChildren();
  for (const item of itens) {
    const li = document.createElement("li");
    li.textContent = `${item.quantidade} × ${item.nome}: ${real(item.quantidade * item.preco)}`;
    lista.append(li);
  }
  const soma = itens.reduce((acumulado, item) => acumulado + item.quantidade * item.preco, 0);
  total.textContent = `Total: ${real(soma)}`;
}

formulario.addEventListener("submit", (evento) => {
  evento.preventDefault();
  const nome = campoItem.value.trim();
  const quantidade = Number(campoQuantidade.value);
  const preco = Number(campoPreco.value.replace(",", "."));

  if (nome === "" || !(quantidade >= 1) || campoPreco.value === "" || Number.isNaN(preco)) {
    aviso.textContent = "Preencha o item, a quantidade e o preço (ex.: 4,99).";
    return;
  }

  aviso.textContent = "";
  itens.push({ nome, quantidade, preco });
  desenhar();
  formulario.reset();
  campoItem.focus();
});
PeçaO que faz
<input id="quantidade" type="number" min="1" value="1">Um campo de número, com setinhas, que começa em 1. Mesmo assim, o .value dele é um texto ('1'): por isso o Number(…).
const itens = [];Os dados da lista. É const porque a variável aponta sempre para o mesmo array; o que muda é o conteúdo (veja Objetos são Referências).
function real(valor)Formata em reais: valor.toLocaleString("pt-BR", { style: "currency", currency: "BRL" }) transforma 9.98 em 'R$ 9,98', com vírgula e o símbolo certo.
lista.replaceChildren();Sem nada entre os parênteses, apaga todos os filhos da lista: começa em branco antes de redesenhar.
itens.reduce(…, 0)Soma quantidade * preco de todos os itens (veja reduce).
campoPreco.value.replace(",", ".")Aceita o preço com vírgula, como todo brasileiro digita: "4,99" vira "4.99".
!(quantidade >= 1)"Não é pelo menos 1". Escrito assim, pega também o NaN: NaN >= 1 é falso.
itens.push({ nome, quantidade, preco });Guarda o item novo no array (a forma curta de { nome: nome, … }).
formulario.reset();Volta todos os campos do formulário ao valor inicial: o item e o preço vazios, a quantidade em 1.

Sem o replace e sem o aviso: R$ NaN

Na primeira tentativa, a Ana não tinha o replace(",", ".") nem o if do aviso. Com os mesmos três itens (o leite a 4,99, o pão a 0.75 e o café a dezoito), a página mostrou 2 × Leite: R$ NaN, 1 × Pão francês: R$ 0,75, 1 × Café: R$ NaN e Total: R$ NaN. O Number("4,99") e o Number("dezoito") são NaN, e um único NaN na soma contamina o total inteiro. Nenhum erro no Console: só a página mostrando bobagem.

O espaço do R$ 9,98 não é um espaço comum 
> real(9.98) === "R$ 9,98"
false
> real(9.98).charCodeAt(2)
160

O toLocaleString põe entre o R$ e o número um espaço inquebrável (o caractere 160, que impede a quebra de linha ali), e não o espaço comum (32). Na tela, é igual. Mas, se você comparar o texto com === ou procurar por "R$ 9,98", não vai achar. Compare os números, não os textos formatados.

Versão 3 · Marcar como comprado e remover

No mercado, a Ana quer marcar o que já pôs no carrinho e apagar o que desistiu de comprar. Cada objeto ganha a propriedade comprado (true ou false), e cada linha da lista ganha uma caixinha e um botão ✕. O total passa a mostrar só o que falta comprar. No HTML, só muda o texto inicial do total (Falta comprar: R$ 0,00); no CSS, entra a classe que risca o item:

.comprado {
  text-decoration: line-through;
  color: gray;
}

li button {
  margin-left: 8px;
}

const formulario = document.querySelector("#formulario");
const campoItem = document.querySelector("#item");
const campoQuantidade = document.querySelector("#quantidade");
const campoPreco = document.querySelector("#preco");
const aviso = document.querySelector("#aviso");
const lista = document.querySelector("#lista");
const total = document.querySelector("#total");

const itens = [];

function real(valor) {
  return valor.toLocaleString("pt-BR", { style: "currency", currency: "BRL" });
}

// Cria o <li> de um item: caixinha, texto e botão de remover
function criarLinha(item, posicao) {
  const li = document.createElement("li");
  li.classList.toggle("comprado", item.comprado);

  const caixa = document.createElement("input");
  caixa.type = "checkbox";
  caixa.checked = item.comprado;
  caixa.addEventListener("change", () => {
    item.comprado = caixa.checked;
    desenhar();
  });

  const texto = document.createElement("span");
  texto.textContent = ` ${item.quantidade} × ${item.nome}: ${real(item.quantidade * item.preco)}`;

  const remover = document.createElement("button");
  remover.textContent = "✕";
  remover.title = "Remover";
  remover.addEventListener("click", () => {
    itens.splice(posicao, 1);
    desenhar();
  });

  li.append(caixa, texto, remover);
  return li;
}

function desenhar() {
  lista.replaceChildren(...itens.map(criarLinha));
  const falta = itens
    .filter((item) => !item.comprado)
    .reduce((soma, item) => soma + item.quantidade * item.preco, 0);
  total.textContent = `Falta comprar: ${real(falta)}`;
}

formulario.addEventListener("submit", (evento) => {
  evento.preventDefault();
  const nome = campoItem.value.trim();
  const quantidade = Number(campoQuantidade.value);
  const preco = Number(campoPreco.value.replace(",", "."));

  if (nome === "" || !(quantidade >= 1) || campoPreco.value === "" || Number.isNaN(preco)) {
    aviso.textContent = "Preencha o item, a quantidade e o preço (ex.: 4,99).";
    return;
  }

  aviso.textContent = "";
  itens.push({ nome, quantidade, preco, comprado: false });
  desenhar();
  formulario.reset();
  campoItem.focus();
});
function criarLinha(item, posicao)
Monta o <li> de um item. Recebe o objeto e a posição dele no array (o map passa os dois).
li.classList.toggle("comprado", item.comprado)
Põe a classe comprado se o segundo valor for true, tira se for false. O CSS faz o resto: risca e deixa cinza (veja classList).
caixa.type = "checkbox"; caixa.checked = item.comprado;
Um <input> de caixinha, já marcado se o item estiver comprado.
caixa.addEventListener("change", …)
Quando a Ana marca ou desmarca: copia o estado da caixinha para o objeto e redesenha. A função "lembra" de qual item e qual caixa são dela (veja Closures).
itens.splice(posicao, 1)
O ✕ tira o item do array (veja splice) e redesenha.
li.append(caixa, texto, remover)
O append aceita vários elementos de uma vez, na ordem.
lista.replaceChildren(...itens.map(criarLinha))
Transforma cada item num <li> e troca o conteúdo da lista por todos eles (os ... espalham o array em argumentos; veja Spread).
.filter((item) => !item.comprado).reduce(…)
Soma só os que ainda não foram comprados.

Por que redesenhar tudo a cada mudança?

Dava para, ao marcar a caixinha, mexer só naquele <li> e recalcular o total à parte. Funciona, mas cada ação precisa lembrar de atualizar tudo o que depende dela, e um esquecimento deixa a tela mentindo. Com um desenhar() só, a página é sempre um retrato fiel do array. Para uma lista de compras, redesenhar algumas dezenas de itens é instantâneo. É a mesma ideia de bibliotecas como o React (veja JavaScript no Mundo).

Formas diferentes de fazer

EscolhaOpçõesQual usar
Reagir ao Adicionarsubmit no <form> × click no botãoO submit: pega o clique e o Enter. Com click, o Enter no campo não faria nada (sem <form>) ou recarregaria a página (com <form>).
Pôr texto no elementotextContent × innerHTMLtextContent para texto que veio de uma pessoa. innerHTML só para HTML que você mesmo escreveu.
Atualizar a telaredesenhar tudo × mexer só no que mudouRedesenhar tudo é mais simples e não esquece nada; só com milhares de itens vale a pena otimizar.
DinheirotoLocaleString("pt-BR", { style: "currency", currency: "BRL" }) × "R$ " + valor.toFixed(2)O toLocaleString já põe a vírgula e o ponto dos milhares (R$ 1.234,50); o toFixed daria R$ 1234.50.
GuardarlocalStorage × sessionStorageO sessionStorage funciona igual, mas é apagado quando a aba é fechada: bom para um rascunho; para a lista de compras, localStorage.

Desafio extra: limpar os comprados

Depois do mercado, a lista fica cheia de itens riscados. A Ana quer um botão Limpar comprados, embaixo do total: <button id="limpar" type="button">Limpar comprados</button>. O type="button" é importante: um botão sem ele, dentro de um formulário, enviaria o formulário; este está fora, mas o costume evita surpresas. A dica: troque o const itens por let itens e, no clique, faça itens = itens.filter(…) ficando só com os não comprados, e chame desenhar() (que também salva).

> [...document.querySelectorAll("#lista li")].map((li) => li.textContent)
(1) [' 1 × Café: R$ 18,90✕']

Se esquecer de trocar o const por let, o clique dá, no Console:

Uncaught TypeError: Assignment to constant variable.
    at script.js:89:9

"Atribuição a uma variável constante": o const não deixa a variável apontar para outro array, e o filter cria um array novo (veja Constantes).

Desafio no editor: o botão Limpar comprados já está no index.html, mas não faz nada. No fim do script.js, faça o clique nele tirar do array os itens comprados e redesenhar (lembre do let). const formulario = document.querySelector("#formulario");
const campoItem = document.querySelector("#item");
const campoQuantidade = document.querySelector("#quantidade");
const campoPreco = document.querySelector("#preco");
const aviso = document.querySelector("#aviso");
const lista = document.querySelector("#lista");
const total = document.querySelector("#total");

const CHAVE = "lista-de-compras";

// Lê a lista guardada no navegador (ou [] na primeira vez)
function carregar() {
  const texto = localStorage.getItem(CHAVE);
  if (texto === null) {
    return [];
  }
  return JSON.parse(texto);
}

// Guarda a lista no navegador, como texto JSON
function salvar() {
  localStorage.setItem(CHAVE, JSON.stringify(itens));
}

let itens = carregar();

function real(valor) {
  return valor.toLocaleString("pt-BR", { style: "currency", currency: "BRL" });
}

// Cria o <li> de um item: caixinha, texto e botão de remover
function criarLinha(item, posicao) {
  const li = document.createElement("li");
  li.classList.toggle("comprado", item.comprado);

  const caixa = document.createElement("input");
  caixa.type = "checkbox";
  caixa.checked = item.comprado;
  caixa.addEventListener("change", () => {
    item.comprado = caixa.checked;
    desenhar();
  });

  const texto = document.createElement("span");
  texto.textContent = ` ${item.quantidade} × ${item.nome}: ${real(item.quantidade * item.preco)}`;

  const remover = document.createElement("button");
  remover.textContent = "✕";
  remover.title = "Remover";
  remover.addEventListener("click", () => {
    itens.splice(posicao, 1);
    desenhar();
  });

  li.append(caixa, texto, remover);
  return li;
}

function desenhar() {
  lista.replaceChildren(...itens.map(criarLinha));
  const falta = itens
    .filter((item) => !item.comprado)
    .reduce((soma, item) => soma + item.quantidade * item.preco, 0);
  total.textContent = `Falta comprar: ${real(falta)}`;
  salvar();
}

formulario.addEventListener("submit", (evento) => {
  evento.preventDefault();
  const nome = campoItem.value.trim();
  const quantidade = Number(campoQuantidade.value);
  const preco = Number(campoPreco.value.replace(",", "."));

  if (nome === "" || !(quantidade >= 1) || campoPreco.value === "" || Number.isNaN(preco)) {
    aviso.textContent = "Preencha o item, a quantidade e o preço (ex.: 4,99).";
    return;
  }

  aviso.textContent = "";
  itens.push({ nome, quantidade, preco, comprado: false });
  desenhar();
  formulario.reset();
  campoItem.focus();
});

desenhar();

document.querySelector("#limpar").addEventListener("click", () => {
  itens = itens.filter((item) => !item.comprado);
  desenhar();
});

Resumo

  • Uma página com JavaScript tem index.html, style.css e script.js; o <script> vai no fim do <body>.
  • Use o evento submit do formulário (clique e Enter) e sempre evento.preventDefault(), ou a página recarrega.
  • createElement, textContent e append criam itens; textContent, e não innerHTML, para texto digitado.
  • Guarde os dados num array de objetos e tenha um desenhar() que monta a tela a partir dele.
  • O .value dos campos é sempre texto: converta com Number, aceite a vírgula com replace e confira o vazio e o NaN.
  • toLocaleString("pt-BR", { style: "currency", currency: "BRL" }) mostra reais.
  • localStorage guarda texto: JSON.stringify para salvar, JSON.parse para carregar, e trate o null da primeira visita.
