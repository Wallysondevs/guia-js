JavaScript Os Tipos de Dados

Você já guardou nas variáveis coisas bem diferentes: o nome "Ana", o preço 0.75, o true de "a padaria está aberta". Cada valor tem um tipo: é texto, é número, é sim/não… O tipo decide o que dá para fazer com o valor: número se soma, texto se junta, sim/não se usa para decidir. Esta aula apresenta os tipos do JavaScript, um por um. Cada um vai ganhar a sua própria aula mais adiante.

Você vai aprender
  • Os oito tipos do JavaScript: string, number, boolean, undefined, null, bigint, symbol e object.
  • A diferença entre os primitivos (um valor simples) e os objetos (uma coleção de valores).
  • Por que "6" e 6 não são a mesma coisa: "6" + 1 dá 61.
  • Como o Node mostra cada tipo (as aspas no texto, o n no bigint…).
  • Que uma variável não tem tipo fixo (a tipagem dinâmica).
  • Os erros reais quando o tipo não é o que você esperava.

Todos os programas desta aula rodaram no Node.js v24.22.0 da máquina da Ana (ana@notebook), com node arquivo.js.

1. string: texto

Qualquer texto, de uma letra a um livro inteiro, é uma string (em inglês, "cordão", "fileira": uma fileira de caracteres). Ele vai sempre entre aspas, e o JavaScript aceita três tipos de aspas:

const a = "pão";
const b = 'pão';
const c = `pão`;
console.log(a, b, c);

$ node aspas.js
pão pão pão
"pão"
Aspas duplas: o padrão deste guia.
'pão'
Aspas simples: fazem o mesmo. É como o Node mostra os textos dentro de listas e objetos (você vai ver logo abaixo).
`pão`
A crase: cria uma template string, que aceita valores no meio do texto (`Olá, ${nome}`). Tem aula própria: Template Strings.

Mais em Strings.

2. number: números

Inteiros (30), com casas decimais (1.68), negativos (-5): no JavaScript, todos são do mesmo tipo, number. Outras linguagens separam "inteiro" de "decimal"; o JavaScript não. Os detalhes (e algumas surpresas) estão em Números e NaN, Infinity e a Precisão.

3. boolean: verdadeiro ou falso

Só dois valores possíveis: true ("verdadeiro") e false ("falso"), sem aspas. É o tipo das perguntas de sim/não: a padaria está aberta? O cliente tem desconto? O nome vem de George Boole, matemático que estudou a lógica do verdadeiro e falso. Aula própria: Booleanos.

4. undefined e null: o vazio

O JavaScript tem dois jeitos de dizer "não tem nada aqui":

  • undefined ("indefinido") é o vazio automático: uma variável criada sem valor, um campo que não existe. É o campo da ficha que ficou em branco.
  • null ("nulo") é o vazio de propósito: o programador escreveu null para dizer "eu sei que não tem". É a Ana escrevendo "não tenho" no campo do telefone.

Os dois têm aula própria: null e undefined.

Um bigint ("inteiro grande"): um número inteiro com um n no fim. Serve para inteiros gigantes, maiores do que o number consegue guardar com exatidão. Aula: BigInt.

Um symbol ("símbolo"): um valor único, usado como "etiqueta secreta" em objetos. Você quase não vai precisar dele no começo. Aula: Symbol.

6. object: as coleções

Os sete tipos acima guardam um valor cada. Para guardar vários valores juntos existe o objeto. As duas formas mais comuns:

const cliente = { nome: "Ana", idade: 30, temCadastro: true };
const compras = ["pão", "leite", "café"];
console.log(cliente);
console.log(compras);
console.log(cliente.nome, compras[0]);

$ node objetos.js
{ nome: 'Ana', idade: 30, temCadastro: true }
[ 'pão', 'leite', 'café' ]
Ana pão
{ nome: "Ana", idade: 30, … }
Um objeto com campos que têm nome: a ficha inteira numa variável só. Cada campo tem o seu próprio tipo (um texto, um número, um booleano). cliente.nome pega um campo. Aula: Objetos.
["pão", "leite", "café"]
Um array (lista): valores em ordem, numerados a partir do 0. compras[0] pega o primeiro. Para o JavaScript, um array é um tipo especial de objeto. Aula: Arrays.

As funções (trechos de código com nome, aula Funções) também são objetos.

Um primitivo é um valor simples, que não se divide: o número 30, o texto "Ana". Um objeto é uma coleção, com valores dentro. A diferença vai importar mais tarde: lembra que uma lista num const pode ganhar itens (aula Constantes)? Isso só acontece com objetos. Um primitivo nunca muda por dentro: o número 30 é sempre 30.

Numa lista, dá para ver como o Node mostra cada primitivo:

console.log(["Ana", 30, 1.68, true, undefined, null]);

$ node lista.js
[ 'Ana', 30, 1.68, true, undefined, null ]

Só o texto ganhou aspas. É assim que o Node mostra, dentro de uma lista, quem é texto e quem não é.

8. "6" não é 6

Esta é a lição mais importante da aula. Um número entre aspas não é um número: é um texto que, por acaso, tem o caractere 6.

const quantidadeNumero = 6;
const quantidadeTexto = "6";
console.log(quantidadeNumero + 1);
console.log(quantidadeTexto + 1);
console.log([quantidadeNumero, quantidadeTexto]);

$ node texto-numero.js
7
61
[ 6, '6' ]
quantidadeNumero + 1 → 7
Número mais número: o + soma.
quantidadeTexto + 1 → 61
Texto mais qualquer coisa: o + junta (o nome técnico é concatenar). O "6" e o 1 foram colados lado a lado: "61".
[ 6, '6' ]
Na lista, a diferença aparece: o número sem aspas, o texto com aspas. Quando você não sabe se um valor é texto ou número, este é um jeito rápido de conferir. (Outro jeito é o typeof, assunto da próxima aula.)

De onde vêm números "disfarçados" de texto? De todo lugar que fala com pessoas: o que alguém digita no teclado, o que vem de um formulário de site, o que se lê de um arquivo. Tudo isso chega como string, e precisa ser convertido antes da conta (aula Conversão). E o JavaScript às vezes converte sozinho, de um jeito que surpreende:

const preco = "4.50";

console.log(preco * quantidade);
console.log(preco + quantidade);

$ node conta.js

Com *, o JavaScript transformou o texto em número e multiplicou (9). Com +, juntou os dois como texto (4.502). Essas "pegadinhas" têm aula própria: Conversão Automática.

9. A variável não tem tipo; o valor tem

Em algumas linguagens, você diz o tipo da variável ao criá-la ("esta caixa só aceita números"). No JavaScript, não: a caixa aceita qualquer coisa, e quem tem tipo é o valor que está dentro dela. Isso se chama tipagem dinâmica.

let valor = 42;
console.log(valor);
valor = "quarenta e dois";
console.log(valor);
valor = false;
console.log(valor);

$ node muda.js
42
quarenta e dois
false

A mesma variável guardou um número, um texto e um booleano, sem nenhuma reclamação. É prático, mas perigoso: se o valor mudar de tipo sem você perceber, a conta seguinte dá um resultado estranho (como o 46 da missão acima). Por isso, mantenha cada variável com um tipo só do começo ao fim. (O TypeScript é uma versão do JavaScript que obriga a isso.)

Formas diferentes de escrever o mesmo valor

O mesmo "seis" pode ser escrito de vários jeitos, e cada jeito dá um tipo diferente:

EscritaTipoQuando usar
6numberQuantidades, preços, contas: quase sempre
6.0number (o mesmo 6)Não há motivo: o Node mostra 6
"6", '6', `6`stringSó quando é texto de verdade (um código, um número de casa que não entra em conta)
6nbigintSó para inteiros gigantes

E o "vazio" também tem dois jeitos: deixe o undefined para o JavaScript (variável sem valor, campo que não existe) e use null quando você quiser dizer "não tem".

Resumo

  • Todo valor tem um tipo, e o tipo decide o que dá para fazer com ele.
  • São oito tipos: sete primitivos (string, number, boolean, undefined, null, bigint, symbol) e o object (objetos, arrays e funções).
  • Texto vai entre aspas; número, booleano, null e undefined, sem aspas. No Node, dentro de listas e objetos, o texto aparece com aspas simples.
  • "6" é texto, 6 é número: "6" + 1 dá "61", 6 + 1 dá 7.
  • undefined é o vazio automático; null, o vazio de propósito.
  • No JavaScript, a variável não tem tipo fixo (tipagem dinâmica): quem tem tipo é o valor. Mantenha cada variável com um tipo só.
