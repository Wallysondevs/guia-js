JavaScript Template Strings

Na aula Strings, você montou frases emendando pedaços com +: "Olá, " + nome + "! Você tem " + idade + " anos.". Funciona, mas é fácil esquecer um espaço ou uma aspa no meio de tantos pedaços. O JavaScript tem um jeito mais confortável: o template string (em inglês, "texto-modelo"), escrito entre crases, em que as variáveis entram direto no meio do texto: `Olá, ${nome}!`.

Você vai aprender
  • Como escrever um template string com crase e encaixar valores com ${ }.
  • Que dentro do ${ } cabe qualquer expressão: contas, comparações, .length.
  • Como fazer um texto de várias linhas (a nota da padaria).
  • Quando usar crase e quando usar + ou aspas comuns.
  • O que aparece quando o valor encaixado é um array, um objeto, null ou undefined.
  • Os erros reais: ${} dentro de aspas comuns, o acento agudo no lugar da crase, a variável que não existe e o $( ).

Todos os programas desta aula rodaram no Node.js 24 da máquina da Ana (usuária ana, computador notebook), com node arquivo.js. Você pode rodar cada um no editor do guia.

A ideia: o formulário com lacunas

Sabe aqueles recibos de papel que vêm prontos, só com os espaços em branco para preencher? "Recebi de ________ a quantia de R$ ______ referente a ________." O texto fixo já está impresso; você só completa as lacunas.

Um template string é esse recibo. A crase marca o começo e o fim do modelo, e cada ${ } é uma lacuna. Na hora de rodar, o JavaScript calcula o que está dentro de cada lacuna e encaixa o resultado no texto.

1. O primeiro template string

const nome = "Ana";
const idade = 30;

const frase = `Olá, ${nome}! Você tem ${idade} anos.`;
console.log(frase);
` … `
As crases (o acento grave sozinho; no teclado ABNT, Shift + a tecla à direita do P, e depois a barra de espaço). Elas abrem e fecham o template string. Não confunda com o apóstrofo ' nem com o acento agudo ´.
Olá,
Texto fixo, que sai como está, com o espaço depois da vírgula.
${nome}
Uma lacuna: cifrão, abre chave, a variável, fecha chave. O JavaScript troca tudo isso pelo valor de nome, Ana.
${idade}
Outra lacuna. O número 30 vira texto sozinho, sem você precisar converter.
$ node ola.js
Olá, Ana! Você tem 30 anos.

Compare com a mesma frase usando +: "Olá, " + nome + "! Você tem " + idade + " anos.". São seis pedaços, cinco + e seis pares de aspas. No template string há um par de crases, e o texto se lê de corrido, do jeito que vai sair na tela.

Missão: reescreva a frase usando crase e ${ } no lugar dos +, e troque os valores das variáveis para sair A Bia comprou 3 pães.

const cliente = "Ana";
const quantidade = 5;
const frase = "A " + cliente + " comprou " + quantidade + " pães.";
console.log(frase);

const cliente = "Bia";
const quantidade = 3;
const frase = `A ${cliente} comprou ${quantidade} pães.`;
console.log(frase);

2. Dentro do ${ } cabe uma conta

A lacuna não precisa ser só uma variável. Ela aceita qualquer expressão, isto é, qualquer pedaço de código que resulte num valor: uma conta, uma comparação, o tamanho de um texto.

const produto = "café";
const preco = 4.5;
const quantidade = 3;

console.log(`${quantidade} x ${produto} = R$ ${preco * quantidade}`);
console.log(`A palavra "${produto}" tem ${produto.length} letras.`);
console.log(`Passou de R$ 10? ${preco * quantidade > 10}`);
console.log(`Total: ${2 + 3}`);

$ node contas.js
3 x café = R$ 13.5
A palavra "café" tem 4 letras.
Passou de R$ 10? true
Total: 5

Repare em três detalhes:

  • A conta preco * quantidade foi feita antes de virar texto: saiu 13.5. Sem casas decimais fixas, porque o JavaScript mostra o número como ele é; para mostrar 13.50, veja Formatando Números.
  • Dentro da crase, as aspas duplas são letras comuns: "${produto}" mostrou "café" com aspas, sem nenhum erro. É uma vantagem da crase.
  • `Total: ${2 + 3}` dá Total: 5. Com +, "Total: " + 2 + 3 dá Total: 23 (veja Precedência). Na lacuna, a conta fica isolada e não tem como se misturar com o texto.

3. Textos de várias linhas

Com aspas comuns, o texto tem de caber numa linha só. Com crase, você pode apertar Enter no meio do texto, e a quebra de linha faz parte dele. A Ana usa isso para imprimir a nota da padaria:

const cliente = "Caio";
const paes = 6;
const precoPao = 0.75;

const nota = `PADARIA DO BAIRRO
Cliente: ${cliente}
Pães: ${paes} x R$ ${precoPao}
Total: R$ ${paes * precoPao}
Volte sempre!`;

console.log(nota);

$ node nota.js
PADARIA DO BAIRRO
Cliente: Caio
Pães: 6 x R$ 0.75
Total: R$ 4.5
Volte sempre!

O texto saiu com as quebras de linha exatamente onde estavam no código. O mesmo com aspas comuns precisaria do \n (o "pule linha", aula Caracteres Especiais): "PADARIA DO BAIRRO\nCliente: " + cliente + "\nPães: " ….

Os espaços da frente também entram

Num template de várias linhas, tudo o que está entre as crases faz parte do texto, inclusive os espaços que você põe no começo das linhas para o código ficar "bonito". Se você indentar as linhas de dentro, elas saem indentadas:

const nota = `PADARIA
    Cliente: Caio
    Volte sempre!`;
console.log(nota);

$ node recuo.js
PADARIA
    Cliente: Caio
    Volte sempre!

Por isso, num template de várias linhas, comece as linhas de dentro encostadas na margem, como em nota.js.

Experimente: mude a quantidade de pães e o preço, acrescente uma linha Café: ${cafes} (criando a variável cafes) e veja a nota mudar.

const cliente = "Caio";
const paes = 6;
const precoPao = 0.75;

const nota = `PADARIA DO BAIRRO
Cliente: ${cliente}
Pães: ${paes} x R$ ${precoPao}
Total: R$ ${paes * precoPao}
Volte sempre!`;

console.log(nota);

4. O que sai quando o valor não é texto nem número

A lacuna transforma qualquer valor em texto. Para números e booleanos, o resultado é o esperado. Para outros valores, nem sempre é o que você quer ver:

const compras = ["pão", "leite", "café"];
const cliente = { nome: "Ana", idade: 30 };
let apelido;

console.log(`Lista: ${compras}`);
console.log(`Cliente: ${cliente}`);
console.log(`Nome: ${cliente.nome}`);
console.log(`Apelido: ${apelido}`);
console.log(`Vazio: ${null}`);

$ node valores.js
Lista: pão,leite,café
Cliente: [object Object]
Nome: Ana
Apelido: undefined
Vazio: null
Valor na lacunaO que saiObservação
Um array (lista)pão,leite,caféOs itens separados por vírgula, sem espaço. Para escolher o separador, use compras.join(", ") (aula Dividindo e Juntando)
Um objeto[object Object]Quase nunca é o que você quer. Encaixe uma propriedade (${cliente.nome}) ou use JSON.stringify(cliente) (aula JSON)
Uma variável sem valorundefinedSinal de que a variável não recebeu valor (aula null e undefined)
nullnull

O [object Object] e o undefined no meio de uma frase são sintomas clássicos: quando eles aparecerem na tela, confira o que está dentro da lacuna.

Formas diferentes de fazer a mesma coisa

As três linhas abaixo montam o mesmo texto:

const item = "leite";
const preco = 6;

console.log("O " + item + " custa R$ " + preco + ".");
console.log(`O ${item} custa R$ ${preco}.`);
console.log("O", item, "custa R$", preco + ".");

$ node formas.js

O leite custa R$ 6.

Os templates são do ES2015, a grande atualização do JavaScript de 2015. Em código mais antigo você vai ver muito +; em código moderno, a crase é o jeito preferido sempre que há algo para encaixar.

Quando dá errado

Usou aspas comuns com ${ } 
const nome = "Ana";
console.log("Olá, ${nome}!");
console.log('Olá, ${nome}!');
console.log(`Olá, ${nome}!`);

$ node aspas.js
Olá, ${nome}!
Olá, ${nome}!
Olá, Ana!

Sem mensagem de erro, e o ${nome} saiu ao pé da letra. Só a crase entende lacunas; entre aspas duplas ou simples, ${nome} são só seis caracteres. É o erro mais comum com template strings. Como consertar: troque as aspas das pontas por crases.

Usou o acento agudo ´ no lugar da crase 
const nome = "Ana";
console.log(´Olá, ${nome}!´);

Aqui deveriam vir as setinhas ^, mas, neste caso, o Node 24 da Ana deixou a linha só com espaços. Os espaços vão até a coluna do ´: é ali o problema.
SyntaxError: Invalid or unexpected token
"Erro de sintaxe: símbolo inválido ou inesperado." Para o JavaScript, o acento agudo ´ não é aspa nem crase nem nada: é um símbolo que ele não sabe ler.

Acontece muito no teclado brasileiro, em que o acento agudo e a crase ficam na mesma tecla: sem o Shift sai o agudo ´; com Shift, a crase `. Como consertar: apague os ´ e digite Shift + a tecla à direita do P, seguido de espaço.

"Erro de referência: nmoe não está definido". A Ana trocou duas letras de lugar. Dentro da lacuna vale o mesmo que fora dela: o nome tem de ser de uma variável que existe. A setinha aponta o nmoe, e a linha at Object.<anonymous> (/home/ana/naoexiste.js:2:21) confirma: linha 2, coluna 21. Ao contrário do erro de sintaxe, este é um erro de execução: se houvesse linhas antes da 2, elas teriam rodado. Como consertar: ${nome}, com o nome igual ao da variável (maiúsculas contam).

Escreveu $( ) ou { } sem o cifrão 
const nome = "Ana";
console.log(`Olá, $(nome)!`);
console.log(`Olá, {nome}!`);

$ node parenteses.js
Olá, $(nome)!
Olá, {nome}!

A lacuna tem um formato só: cifrão e chaves, ${ }. Com parênteses, ou sem o cifrão, o JavaScript não reconhece a lacuna e mostra o texto como está. Como consertar: ${nome}.

Abriu a lacuna e não fechou a chave

console.log(`Olá, ${nome!`);

"Erro de sintaxe: faltou o } na expressão do template". As setinhas apontam o nome!: o JavaScript estava dentro da lacuna, esperando o }, e encontrou um !. Como consertar: feche a chave logo depois do nome: `Olá, ${nome}!`.

Resumo

  • Um template string é um texto entre crases `…`. Cada ${ } é uma lacuna onde o JavaScript encaixa um valor.
  • Dentro do ${ } cabe qualquer expressão: variável, conta, comparação, .length. A conta é feita antes de virar texto.
  • Crase aceita quebras de linha (e os espaços da frente também entram no texto) e aspas duplas e simples sem escape.
  • Array numa lacuna vira a,b,c; objeto vira [object Object]; variável sem valor vira undefined.
  • Erros comuns: ${} entre aspas comuns (sai ao pé da letra), acento agudo no lugar da crase (SyntaxError), variável inexistente (ReferenceError), $( ) no lugar de ${ }.
